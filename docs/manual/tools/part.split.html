分割(立体を平面で2つに)

具体例: 箱を高さ5mmで2部品に分ける

準備

top_XYを作業面にし、Z=0～10mmの箱を作る

操作手順

  1. 分割を選ぶ
  2. 箱を指定する
  3. 作業平面からずらす5mmを設定し、両側を確認して確定する

設定: 現在の作業平面を基準に分割

結果を確認

高さ5mmの切断面を持つ2部品ができる。

取消・やり直し

ダイアログの取消、またはペインの取消を使います。即時操作には未確定段階がありません。 確定済みの文書変更はCtrl+Z、やり直しはCtrl+Yです。保存・書出し済みのファイルはUndoの対象ではありません。

進めない場合

部品を1つ以上選んでください。

対象欄と3Dの強調を照合し、必要な線・面・部品を各役割へ指定します。処理中は計算表示を確認し、取消が可能な処理は取消を使います。
