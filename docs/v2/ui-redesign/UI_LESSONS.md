# UI_LESSONS — 確定した原則と再発防止(短く)

- 3 HTML(作図/部品/製作 2026-09-18)が UI の正本。旧 mock・旧棚・GuideTable 中心 UI より優先。
- 文法は全モード同じ: 道具 → 右ペインが道具専用 → Input Slot → 3D クリック → 次 Slot → 設定 → Preview → Enter。Esc = Cancel。
- 右ペインは「現在の道具」か「選択物のプロパティ」だけ。複数道具の一覧を同時に出さない。
- Tool 中は Slot に合う geometry を優先して拾う(Extrude=領域/平面Face、Revolve軸=線、Loft断面=輪郭、Fillet=Edge、近似=Surface/Face、Boolean=Solid)。Wire が常に勝つ状態は禁止。
- Preview と Commit は同じ input snapshot から。Preview 後に選択を読み直さない。
- Ctrl を暗黙に必須にしない(道具中の素クリックで足す)。
- 「押せるが何も起きない」禁止。backend に無い機能は disabled + 日本語の理由。見た目だけの実装済みにしない。
- 診断は日本語の文が主、コードは補足。
- self-test は人の道(実際の viewport pick、見えているボタン)。hidden widget 直叩き・UUID 注入だけを合格にしない。
- 「まとまり」は「グループ」と呼ぶ。Origin は Explorer の最上段。
- 押し出しの距離と板厚は別パラメータ(20mm 上限を漏らさない)。
- Enter/Esc は viewport の focus に依存しない。
- 進捗・完了の主張はそのセッションの tool 結果に紐づける。PC 未確認は PC_VERIFIED と書かない。
- MainWindow.cpp を太らせない(関数 100 行・ファイル 1500 行の門)。独立ファイルへ置く。
- PC への .cmd は Shift-JIS(cp932)+ CRLF で送る(UTF-8 だと日本語コメントが命令として実行される)。
- 本番で QDialog::exec() を据え付けると自己試験(offscreen)は永遠に止まる。窓は差し替え口(SetXxxChooser)にだけ入れ、本番は棚へ。
- 木(QTreeWidget)を作り直す関数(AdoptCurrentDocument/RefreshEntityList)を呼んだ後に QTreeWidgetItem* を触らない。必要な値は先に写す。
- 380px の棚に収めるには QFormLayout::WrapLongRows + AllNonFixedFieldsGrow、横並びは 3 つまで、長い説明はツールチップへ。
- 新しい命令は **5 か所**に足す: 台帳(CommandCatalog) / 振り分け(`Is*Command` の id の並び) / 献立(V2Menus.cpp) / 説明書(docs/manual.html) / モードの一覧(UiMode.cpp)。どれか 1 つ抜けると「押せるのに何も起きない」になる。抜けは自己試験「未接続のコマンドが1つも無い」が拾う(2026-09-20、view.number_settings で実際に拾えた)。
- 入力の単位は **欄の表示と同じ読み方** にする。度で見せている欄に打った数をラジアンとして読むと、90 と打った人が 5156 度の線を引かされる(2026-09-21)。
- Tab は「隣へ移る」ではなく「いまの値を留めてから隣へ移る」。移るだけだと、案内どおりに操作した人の打った字が黙って消える(2026-09-21)。
- 画面に引くもの(グリッド・補助線)は **見えている範囲から** 決める。原点を中心にした決まった大きさで引くと、原点から離れて拡大したときに端から消える(2026-09-21)。
- ポインタに付いて動く吸着(最近点)は距離がいつもほぼ 0 になる。**同じか上の順位に「点」の吸着を置くと、その点は永遠に選ばれない**。点のほうを上に置く(2026-09-21、線上のグリッド)。
- **人が引いたワイヤーは、面が必ずそこを通る線である**(オーナー方針 2026-09-22)。面の道具は、選ばれた線を「境界に使えないから」と断るのではなく、外周・通る線などの役割へ振り分けて全部使う。使えない線があるなら、どの線がなぜ使えないかを言う。作ったあとは全部の線を面が通っているかを測り、通っていなければ面を捨てる。
- **数学的に決まった数でない入力は何個でも受ける**。1 回の生成が 1 つしか受けない演算は「1 つずつ全部作り、1 回の元に戻すで消える」(一括)。1 つでも作れなければ全部やめる。数の約束は 1 か所(SurfaceCardinality)に置き、画面・検査・表が同じ表を読む(2026-09-22)。
- **N 個を 1 回で作ったら、N 個それぞれが自分の入力だけを記録する**。全部の入力を N 個に持たせると、作り直したとき(開き直す・確定直後の作り直し)に全部が 1 個目の写しになる(押し出し・かごで実際に起きた)。
- **輪郭の内側を拾う道具でも、線の上を押したら線を 1 本だけ拾う**(面を作る)。縁の線を押すたびに輪郭がまとめて入ったり外れたりすると、線を 1 本ずつ選べない(おまかせで起きた)。
- **並びへ足したあとで、足す前に取った参照・ポインタを読まない**(文書の entities / features、試験の中の並びも同じ)。MSVC は並びの伸ばし方が GCC と違い、PC だけで壊れた値を読む(2026-09-22、試験で実際に起きた)。
- 核の近似(埋める面)に G1 を任せると、張りを強くしたとき許容を超える。作りで満たせる条件(縁の上の横切る向き)は、面を直に組んで満たす。測って許容を超えたら断るのは変えない(2026-09-22、つなぐ)。
- `tools/qtstub/include/QtStub*.h` は上の `tools/qtstub/QtStub*.h` への symlink。**`sed -i` で直すと symlink が普通のファイルに化け、同じ当て木が 2 つに分かれる**(Widgets は 70cfb9c、Core は 818113d で実際に起きた。09-22 に戻した)。上のファイルを直すか `sed --follow-symlinks` を使う。
- **線を通るかだけを測る試験は、線と線の間の波打ちを見逃す。**面の試験には、断面の間の筋の山の数や高さの範囲も入れる。両端のガイド 2 本 + 断面 3 本の掃き(MakePipeShell)は、ずれ 0 のまま断面の間で 7 つに波打っていた(2026-09-22、PC の撮影 ui/12 で見つけた。試験は全部通っていた)。
- **名前を足す前に grep する。**新しい種類・ファイル・関数の名前が既にほかの意味で使われていないか確かめる。`PartEdit` は製作の部材編集で使われていて、`cat >` で同じ名前の自己試験のファイルを上書きしかけた(2026-09-22、git の元から戻し、シェル・分割は `ShellSplit` にした)。新しいファイルを書く前に `ls` で無いことを見る。
- **自分の棚を持つ道具は 1 つだけ構える。**構えたまま別の道具を押すと、3D の押しが両方へ入り、棚は先に構えた道具のまま残る(2026-09-22、立体 → フィレットで起きうる形を BeginToolFirstCommand で止めた)。
- **形の部分(辺・面)は番号ではなく、その上の点で文書に残す。**点は隣の要素から、選び直すときの許す離れ(許容差の上限)より十分離しておく。辺の上の点のように 2 つに同じ距離なら、どちらか決めずに断る(2026-09-22、シェルの面)。
- **雲で型検査できない層(OCCT)は、身代わりで自分の誤りだけでも拾う**(tools/occtstub)。`if (!result)` のように自分の型の使い方を間違えても、PC まで 1 時間かかって初めて分かる(2026-09-22、4 か所拾えた)。
- **右の棚の字は短く。**道具の棚は QStackedWidget のページなので、**見えていない棚でも一番広いページの幅が窓の最小幅になる**。作り方ボタンに説明まで書いたら、1024px の窓が 1122px に押し広げられた(2026-09-22、シェル・分割。名前は短く、説明はツールチップへ)。
