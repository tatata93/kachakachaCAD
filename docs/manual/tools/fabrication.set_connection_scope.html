形に追従する線

具体例: 窓線を帯近似の形へ寄せて残す

準備

帯近似と元形状上の窓線を用意する

操作手順

  1. 近似モデルと対象線を選ぶ
  2. 形に追従する線を実行する

設定: 帯近似のみ対応

結果を確認

近似へ寄せた通常ワイヤーが名前に_接続を付けてできる。元線は残る。

取消・やり直し

ダイアログの取消、またはペインの取消を使います。即時操作には未確定段階がありません。 確定済みの文書変更はCtrl+Z、やり直しはCtrl+Yです。保存・書出し済みのファイルはUndoの対象ではありません。

進めない場合

ワイヤーを1つ以上選んでください。

対象欄と3Dの強調を照合し、必要な線・面・部品を各役割へ指定します。処理中は計算表示を確認し、取消が可能な処理は取消を使います。

fabrication.set_connection_scope。図の設定と縮尺は例です。方式ごとの制限、プレビューと確定済み結果の区別を確認してください。
