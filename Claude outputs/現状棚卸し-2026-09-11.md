# V2 の棚卸し(2026-09-11)

**何ができて、何ができなくて、次に何をやるか。** オーナーの問い
「今できるすべての操作とできないこと、今後やる予定をすべて教えろ」への答え。

数え方: 台帳(`docs/v2/command-catalog.md`)のコマンド 94 件、自己試験 139 件、
ctest 123 件。PC は `2d6f6d4` まで緑・push 済み。

---

## 0. 先に、いちばん大きな穴

**3D 画面に、面と立体が出ていません。**

`V2Viewport` が描くのは 線・点・作業平面・グリッド・軸・型紙の下見 だけです。
押し出しても、形状ガイドで面を作っても、厚みを付けても、**画面には何も増えません。**
できた物は一覧(左)に名前で出るだけで、形は見えません。

V1 は面・板材・立体を塗って描いていました(`CadViewport.cpp` に 42 か所)。
V2 では核(OCCT)が作った形を `partShapes_` / `guideShapes_` に持っていますが、
画面へ渡す道がありません。書き出し(STL/STEP)にしか使っていません。

工程 5(形をつくる)から先が「押したら一覧に名前が増えるだけ」になるので、
**使いにくさの大半はここだと考えています。** 次の予定の1番に置きました。

| できること | やり方 |

| ファイル | 新規 / 開く(.kcd2 と V1 の .kcd)/ 保存 / 名前を付けて保存 |

### 1-2. 作図モード

- **作業平面**: 原点の3面(top_XY / front_XZ / side_YZ)と3軸が最初からある。
  作り方 **12 通り**(標準面・平面から離す・点を通り平行・2面の中間・円筒の軸・辺のまわりに角度・
  3点・2辺・曲面に接し辺を含む・曲面上の点で接する・曲線に直角・数値で位置と向き)。名前が付く。
- **線を引く**: 点・直線・ポリライン・矩形・円・円弧(3方式)・ベジェ・スプライン。
  作図中は**カーソル脇に数値の欄**が出て、打った値のまま置ける。矩形は幅・高さで打てる。
  「数値で線を作る」欄もある。補助線として引く / 指定した点を残す の印。
- **直す**: トリム・延長・分割・結合・端点一致・接線接続・曲率接続・C面取り・R丸め・
  オフセット・2線を交点まで・交点に点・角の加工(落とす/丸める、頂点1つだけも可)・
  基準線に設定/解除(一点鎖線)。
- **動かす**: 移動・コピー・ミラー複製・回転。選んだものを掴んで動かすこともできる。
- **数値で編集**: 選んだ作業平面(原点・法線・平面内X)や線(点・中心・半径・角度・長さ)を欄で直す。
- **投影**: 平面へ / 曲面へ / **回り込み(角をまたぐ窓を、面ごとの区間に分けて落とす)**。
- **吸着**: 端点・中点・中心・四半点・交点・画面上の交点・作図点・グリッド・延長線・接点・垂足。
  記号と名前が出る。Ctrl で一時停止。
- **作図中は作業平面の外の線を掴まない**(別の面の線を巻き込まない)。

### 1-3. 部品モード

- **形状ガイド(面)**: 役割の表を人が組んで作る。作り方 **8 通り** ──
  平面・ルールド・ロフト・案内付きロフト・曲線網(Gordon)・境界埋め・離した面・**回転体**。
  表は 行を足す/既存行へ追加/上下/削除/向きを反転/空にする。
- **立体**: 押し出し(向き・終端・出力・足す/引く)、面に厚みを付ける(外側/中央/内側)、
  面を平面まで立体に、ワイヤー群から部品、足す、引く。
- **治具**: 選んだ面から「離した面(すき間)+ 厚み」をひとまとまりで作る。厚みの符号で表/裏。
- **固定**: 作り方への依存を切って、形だけにする。

### 1-4. 製作モード

- **製作モデルを作る**: 方式は2つ。
  - **V2方式(面を分類して展開)**: 曲面は1枚ずつ展開。伸ばさないと平らにできない面は**断る**。
  - **V1方式(帯へ近似し直す)**: 帯に割って近似する。
- **製作の棚**(V1 の近似モデル画面と同じ1枚): 方式・分割軸・境界(自動/手動)・帯の上限・
  最小幅・再現度・板厚・許すずれ・範囲(u/v)・材料・積層・組立率・**曲げる部材**(番号で指定)・
  固定で作るもの。
- **境界の役割**: 開口(窓)/ 折り線 / **切れ目**(平らな部材の型紙に RELIEF 層で入る)。
- **接続範囲**、**組立率**(0=平ら〜100=完成形)、**任意の状態で固定**。
- **型紙を作る**(用紙に並べる)。

### 1-5. 出力モード

- 出力を検査 → STL / STEP / SVG / DXF。対象は ワイヤー・型紙・部材・部品・文書。
- **選んだものだけの .kcd2**(部分書き出し)。

### 1-6. 断り方

押せないコマンドは**隠さず灰色**で出し、理由をツールチップと帯に出します。
理由には番号が付き(`docs/v2/diagnostic-catalog.md`、156 件)、番号は core で作ります。
**黙って何も起きない、はありません。**

### 2-1. 画面に出ないもの(いちばん痛い)

| # | できないこと | 理由 |
| --- | --- | --- |
| A-1 | **面・立体が 3D 画面に出ない** | 画面に描く道が無い。核の形は書き出しにしか使っていない |

### 2-2. 仕組みとして持っていないもの

| # | できないこと | 説明 |
| --- | --- | --- |
| B-1 | **拘束(スケッチ拘束)が無い** | 水平・垂直・平行・直角・同心・対称・寸法拘束が無い。「端点一致」「接線接続」は**その場で置き直す**だけで、後から保たれない。だから「一致解除」「滑らか解除」も無い |
| B-2 | **配列・パターン複製が無い** | 等間隔に並べる、円周に並べる、が無い(窓を 10 個並べるのは手作業) |

| B-6 | 断面表示・干渉チェックが無い | |
| B-7 | 元に戻すの履歴がファイルに残らない | 開き直すと履歴は空 |

## 3. これからやる予定

順番は「使えなさの大きい順」です。上3つで、道具としての形が変わります。

### 3-1. 面と立体を画面に描く ★最優先

核の形を三角に割って(`BRepMesh`)、画面へ渡し、塗りと稜線で描きます。
選んでいるものは色を変え、透け具合を変えられるようにします。V1 と同じ出し方です。
**これが無いと、工程5から先が目で確かめられません。**
併せて、部品の面をクリックで選べるようにします(A-2)。

### 3-2. 3D と展開図の対応を見せる

展開図の辺を指したら 3D の元の辺が光り、逆も光る。
複雑な前頭部では「この辺が展開後のどこか」が分からなくなるのが、いちばんの混乱です。
(ChatGPT も第3位に挙げていました。)

### 3-3. 展開できるかどうかを、展開する前に見せる

ガウス曲率・曲げの向き・切れ目の候補・伸びの誤差を、面の上に色で出します。
いまは作ってみて断られるまで分かりません。
**曲面から板材を作る道具として、ここが V2 の強みになります。**
core に `fabrication/CurvatureAnalysis` があるので、出し方だけの仕事です。

### 3-4. 拘束(せめて水平・垂直・平行・直角・寸法)

いまは置き直すだけなので、あとから寸法を変えられません。
根拠のある形を作るには要ります。ただし**大きい仕事**です(解き手を作る)。
順番としてはここですが、3-1〜3-3 より重い点は見ておいてください。

### 3-5. 残りの V1 移植

- 切れ目の自動化(`ReliefCut` の結線、C-4)
- 部品を自動で部材に割る(`PanelStrategy`、C-5)
- 平らな部材をまたぐ窓(`OpeningClip`、C-6)
- ライトケース(C-1)
- 一覧のドラッグ&ドロップ(C-3)

### 3-6. 小さいもの(いつでも入る)

- `export.pdf_1to1` を足す + 門の穴を塞ぐ(D-1)
- 配列・パターン複製(B-2)── 窓を並べるのに要る
- 点線の件の確定(E-1)── オーナー環境の画面が要る

## 4. 考えるための材料(私の見立て)

1. **今日直したのは「見える・選べる」でした。次は「作った物が見える」です。**
   3-1 をやるまでは、部品モードから先は名前の一覧を見ながら作ることになります。

2. **3-2 と 3-3 は、他の CAD がやっていないところです。**
   汎用 CAD は曲面を板材に割るのが専門ではありません。
   「この面は一枚板で行けるか、切れ目が要るか」を先に見せる道具は強みになります。

3. **拘束(3-4)は、入れるなら早いほうが安いです。**
   線の持ち方に関わるので、後から入れるほど作り直しが増えます。
   ただし 3-1 が無いままだと、拘束を入れても作った物が見えないままです。
   **順番としては 3-1 → 3-4 → 3-2/3-3 という組み方もあります。** ここは決めてください。

4. **V1 の残り(3-5)は、急ぎではないものが多いです。**
   自動の部材割り(C-5)は「自分で面を選ぶ」で代用できています。
   ライトケース(C-1)は作る物が決まっているなら要りますが、そうでなければ後ろで構いません。
