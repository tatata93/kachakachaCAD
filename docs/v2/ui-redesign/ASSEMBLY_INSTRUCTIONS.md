# 組み立て説明書モード

2026-10-05 オーナー選択A案。従来の4モードに「説明書」を追加する。
形状編集とは別に、手順ページと分解図・矢印・番号・文章を作る。

## 操作

1. 作図・部品モードで、説明図に使いたい視点と表示を決める。
2. 「説明書」→「部品・面を取込」。選択があればその部品・面、選択なしなら表示中の部品・面を使う。
3. 各部品をドラッグして分解図を配置。「図から除去」はそのページからだけ除去する。
4. 「矢印」はページの始点・終点をクリック。Escで未確定矢印を中止。
5. 右の文章欄を入力して「番号・文章」を押す。文字を選んで「選択した文字を更新」で編集する。
6. 「新しい手順」「手順を複製」で次ページを作る。上の一覧で切替、見出し欄で手順名を変更。
7. 「説明書を保存」で専用 `.kci` に保存。「PDF」で全手順をA4横の複数ページに出力する。

ページの編集には専用Undo/Redo（30操作）がある。CADの形状・位置・履歴は変更しない。
モードを戻して再度入ってもページを保持する。アプリ終了時に未保存なら保存・破棄・取消を選ぶ。

## 初期版の範囲

- 説明図は表示メッシュから取り込む部品単位の画像。静止した2Dの説明図であり、3D形状の編集ではない。
- 別角度の図はモデリング側で視点を変えて取り込む。既存の図は自動更新しない。
- ワイヤ・作業面・参照画像は取込対象外。混在選択は理由を表示して止める。
- 1回の取込は部品・面1～128個。CADとは別の自己完結したJSON形式 `.kci`（図のPNGを内包）で保存。
- 部品画像を重ねる方式。部品同士の3D隠面計算は行わず、「選択を前へ」で前後を調整する。
- 部品への自動追従・組立アニメーション・自動組立順序は今回の範囲外。

## フェイスの近似

従来版・GPT版とも、フェイスを選択して通常の近似を開始できる。
ツール先行でもフェイスをクリックでき、対象欄の「ソリッドのフェイスを選ぶ」から明示的にも選べる。
選択した1面を独立面として取り出して近似へ渡す。元ソリッドは残り、取り出した面は文書に保存される。
1枚で許容偏差を満たす候補に「分割不要」を表示。GPT版は標本での判定であり、連続領域全体の誤差上界を保証しない。
手動の分割指定は勝手に無視せず、分割不要の候補を提示する。
