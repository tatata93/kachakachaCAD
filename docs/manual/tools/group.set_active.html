作業中グループ

具体例: 新しい線を屋根グループへ入れる

準備

屋根グループを作る

操作手順

  1. 上部グループ欄で屋根を選ぶ
  2. 線を1本作る

設定: 作業中グループ: 屋根

結果を確認

新しい線が屋根グループに入る。

取消・やり直し

ダイアログの取消、またはペインの取消を使います。即時操作には未確定段階がありません。 確定済みの文書変更はCtrl+Z、やり直しはCtrl+Yです。保存・書出し済みのファイルはUndoの対象ではありません。

進めない場合

グループは1つまで選べます。

対象欄と3Dの強調を照合し、必要な線・面・部品を各役割へ指定します。処理中は計算表示を確認し、取消が可能な処理は取消を使います。

Windows版の操作画面

group.set_active。図の設定と縮尺は例です。方式ごとの制限、プレビューと確定済み結果の区別を確認してください。
