# 閉曲線の投影と押し出しへの接続

状態: 完了（2026-10-14）。WP-08の投影不具合修正。

円・閉輪郭の周期継ぎ目、投影先の面境界、複数交点を適切に扱う。
投影で全周が面に当たる場合は、途中の弧を捨てず閉輪郭を生成する。
面の範囲外や穴で本当に途切れる場合は、その状態を明示し、勝手な直線で閉じない。
直線・円・円弧として厳密に表せる結果は元の形式を優先する。曲面上で
その形式にならない結果は、許容偏差内の滑らかな曲線として保持する。
不要な分割をまとめる際も、全区間の偏差と接続を検査する。

投影した貫通扉等の閉輪郭は、平面なら通常の押し出しに使用できる。
曲面上の非平面輪郭は支持面を使う曲面押し出しへ接続し、開いた輪郭や
支持面不足は理由を表示する。元の線・部品は変更しない。

## 受入

- 円の基準方向・巻き方向・寸法、周期面の継ぎ目、前後複数交点、面の境界、
  部分重なり、実際のライト輪郭を試験する。欠けと偽の閉鎖を区別する。
- 円・直線・円弧の保存、閉輪郭の接続、面上偏差と投影元形状の維持を検査する。
- 添付モデルのライトと貫通扉を投影し、押し出し、保存再読込と取消/Undoを確認する。
  元ファイルを変更せず別名保存し、実画面を記録する。
- Windows全体ゲート、配布版の自己試験と通常起動を通す。

周期閉曲線の相補的な投影弧を重複と誤判定して捨てる不具合を修正した。

同一直線上の辺や同一円の連続弧をまとめる。斜め投影が楕円になる場合は円へ強制しない。
C0有理曲面の変換継ぎ目は元曲線の接続関係と全区間の許容偏差内で補正する。
穴・異なる深さ・本当に離れた元曲線を勝手に接続しない。

閉じた非平面輪郭には曲面押し出しの案内を表示する。
