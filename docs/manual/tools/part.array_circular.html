部品を円に並べる

具体例: 部品を円周上に4個並べる

準備

top_XYを作業面にして中心から10mm離れた部品を置く

操作手順

  1. 部品を円に並べるを選ぶ
  2. 部品を追加する
  3. 中心u=v=0、個数4、全体角度360度で確定する

設定: 回転軸は作業平面の法線

結果を確認

90度ずつ回った4個の部品が並ぶ。

取消・やり直し

ダイアログの取消、またはペインの取消を使います。即時操作には未確定段階がありません。 確定済みの文書変更はCtrl+Z、やり直しはCtrl+Yです。保存・書出し済みのファイルはUndoの対象ではありません。

進めない場合

部品を1つ以上選んでください。

対象欄と3Dの強調を照合し、必要な線・面・部品を各役割へ指定します。処理中は計算表示を確認し、取消が可能な処理は取消を使います。

part.array_circular。図の設定と縮尺は例です。方式ごとの制限、プレビューと確定済み結果の区別を確認してください。
