# 押し出しの入力・方向選択の検証

対象: WP-08。製品変更 `4958824fa`、試験整備を含む候補コミット `b106ee6d9`（2026-10-15）。

## 修正

- 対象未選択でも、距離・方向・範囲と入力選択ボタンを表示する。
- 押す面／輪郭、足す／引く相手、方向用の直線を別の役割で選ぶ。
- 「選んだ線の向き」→「3Dで選ぶ」で直線を拾う。元面を置換せず、方向線を輪郭へ混ぜない。
- 方向選択中のEscは方向選択だけを取消。空所クリックでは選択待ちを維持し、別ツールへ移ると解除する。
- 押し出し中の候補フェイスをHover色で塗る。候補移動・空所・ビュー外への移動で解除し、CPU/GPUの描画用キャッシュにも反映する。
- 入力した小数距離を面選択後も維持する。輪郭サイズに応じて距離を勝手に拡大する旧処理を外した。
- 無効な方向ではボタンとEnterの双方で確定を止める。

方向用の線は従来の選択肢と同じく、1本の直線からなるワイヤーが対象。
曲線の接線や複数線のうちの1辺を方向として新たに解釈する機能は追加していない。
幾何API・保存形式は変更していない。
