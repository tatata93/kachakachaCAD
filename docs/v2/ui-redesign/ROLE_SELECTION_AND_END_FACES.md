# 役割別入力と終端面（2026-10-15）

オーナー指示に基づくUI修正。WP-08を主担当とし、終端オフセット・選択フェイスの保存に必要な最小の幾何/保存拡張を含む。

## 操作契約

複数入力を持つ道具では、役割名、選択開始、現在の対象、解除を同じ場所に表示する。
複数対象の役割は追加選択と個別解除を提供する。別役割の選択や数値を消さない。
3Dと左ペインから同じ役割へ入力し、役割色と選択中の表示を合わせる。
既存の順序・向き・連続性等の専門設定は維持する。点クリック型の入力も現在の役割を明示する。

## 終端面

押し出しは作業平面、サーフェス、ソリッドの単一フェイスを直接終端に選べる。
終端を未指定のときは最初の作業平面を勝手に採用しない。
終端オフセットはmm、正は押し出し方向の奥、負は手前。終端形状を押し出し方向に平行移動する。
法線方向の一定距離とは区別し、欄の説明に明記する。0は選択面そのもの。

ソリッドフェイスは選択時の厳密BRepを保持し、一時的な面番号を保存しない。
UIに「選択時の形を保持」と示す。元立体変更への自動追従を装わない。
通常のサーフェス/作業平面は従来どおりUUID参照で再生成する。
旧ファイルでは新オフセット0、保存面なしとして読む。Undo/保存/再生成で同じ結果を保持する。

## 受入

役割切替で他入力を保持、追加/個別解除/全解除、3D/ツリー選択、Esc取消を確認する。
押し出しは平面/曲面/ソリッドフェイス、正負/0オフセット、小数、方向反転、到達不能、
プレビュー/確定、Undo、保存再読込を試験する。面まで厚み等の対象制限も確認し、未対応を成功扱いしない。
適用ツールの一覧と未解決事項は開発検証記録に残す。

## 終端姿勢と平面の延長（2026-10-15 追加指示）

距離・押し出す方向とは独立して、終端を「自動」「元の面と同じ向き」「選んだ面と平行」「角度を入力」で指定する。
通常押し出し、ネイティブフェイスの押し出し、曲面押し出しで共通の入力欄を使用する。
選んだ面の向きは選択時の法線を保持し、その面の位置は使わない。曲面はクリック位置の接平面とする。
角度は元面の基準法線からの傾きと方位。曲面押し出しでは輪郭のUV範囲中心を基準とする。
両方向の押し出しでは正方向側の終端に適用し、開始側は元形状の平行移動を保持する。
貫通切削には終端面がないため、独立した終端姿勢が必要なら距離または面までを指定する。

「選んだ面まで」の平面フェイスは「終端の平面を延長して使う」を明示選択できる。
既定は有限の面を尊重し、旧データの結果を変えない。延長ONでは外周・穴による制限を外した支持平面まで伸ばす。
これは中央の面の外周から離れたライトを、中央の面と同じ位置・傾きで揃える用途に使う。
曲面の無制限延長は行わず、理由を表示する。終端オフセットは従来どおり押し出し方向の距離。
自動では終端面そのものの姿勢、独立姿勢では元輪郭の外接箱中心から終端の支持面への交点を終端位置の基準にする。
独立姿勢を指定した結果は、曲面の終端へ全域が密着するという意味ではない。

この追加は元形状、投影ワイヤー、既存近似モデルを変更しない。通常押し出しの設定はフィーチャーに保存し、
曲面押し出しは従来どおり確定BRepを保持する。既定値の新規フィールドは保存を省略して旧サンプルとの互換性を保つ。

曲面押し出しの「元の面と同じ向き」は、従来の法線方向へのオフセット曲面を使用する（半径等は高さに応じて変わる）。
通常の曲面フェイス押し出しは、一方向へ平行移動した曲面を使用する。
