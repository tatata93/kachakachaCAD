曲線から近似面

具体例: 複数の断面曲線から近似面を作る

準備

平行な位置に3本の弧を置く

操作手順

  1. 曲線から近似面を選ぶ
  2. 作り方を断面をつなぐへ変更する
  3. 断面を追加する
  4. 形状と誤差を確認して確定する

設定: 近似面。原曲線と同一とは限らない

結果を確認

断面群に近い面ができる。精度条件がある場合は誤差を確認する。

取消・やり直し

未確定入力をEscで取り消します。道具を終えるときは選択(V)または別の道具へ切り替えます。 確定済みの文書変更はCtrl+Z、やり直しはCtrl+Yです。保存・書出し済みのファイルはUndoの対象ではありません。

進めない場合

ワイヤーを追加してください。

対象欄と3Dの強調を照合し、必要な線・面・部品を各役割へ指定します。処理中は計算表示を確認し、取消が可能な処理は取消を使います。

Windows版の操作画面

surface.gpt_create。図の設定と縮尺は例です。方式ごとの制限、プレビューと確定済み結果の区別を確認してください。
