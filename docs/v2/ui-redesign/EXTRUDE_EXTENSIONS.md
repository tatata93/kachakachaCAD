# 押し出しの入力・方向・終端（2026-10-02）

オーナー指示に基づく WP-07 / 押し出し UI の変更。既存の `part.extrude` を拡張する。
新しいコマンド ID は増やさない。PC_TESTED（Windows実機の自動試験）。

## 操作

- 部品 → 作成 → 押し出し。作図ツールが残っていても選択操作へ切り替える。
- その後で閉じた輪郭または形状ガイドの面を選択する。先に選択してから始めることもできる。
- 方向は面に垂直、作業平面、XYZ、指定した直線、数値の方向から選ぶ。
  「選んだ線の向き」では専用欄に独立した直線を指定する。方向の長さは正規化する。
- 「方向を反転」は1回押すたびに正負を入れ替える。距離の値は保持する。
- 「左右対称」は入力距離を全長として半分ずつ、「両方向に別々の距離」は正側と逆側を個別指定する。
  プレビュー、確定、保存後の再生成で同じ範囲を使う。
- 「選んだ面まで」の終端欄には作業平面、形状ガイドの面、独立した直線、作図点が並ぶ。
  直線全体と始点・終点は別項目。線全体を選ぶと線を含む斜面で終端を切る。
  終端面の法線は押し出し方向から直線方向の成分を引いた向き（押し出し方向に最も正対する面）。
  押し出しに平行な線ではこの面を決められないため、端点または作業平面を指定する。
- 点・端点はその点を通り押し出し方向に垂直な面で止める。
- 曲面は元の BRep を一定方向に平行移動し、元と移動先の曲面、境界の側面で閉じた立体を作る。
  法線方向の厚み付けとは別の操作。元の曲面を平面に置換しない。
- 曲面の終端は対象の BRep 面で切る。平均距離への置換はしない。
  表示用メッシュによる到達検査を行い、到達しない場所や不正な閉形状があれば確定しない。

## 保存

ExtrudeDefinition に `secondDistanceMm`、`extentTarget`、`targetParameter` を追加。
旧ファイルで省略されていれば順に 0、未指定、-1。
`extentTarget` は演算する部品と別の UUID 参照。依存・別文書抽出にも含める。
`targetParameter` は直線全体で -1、始点で 0、終点で 1。
曲面の押し出しは `profiles` に元の形状ガイドの UUID を保持し、再読込時も元の BRep から作り直す。
方向の直線は選択時の方向ベクトルを保存する（直線の後編集への追従はしない）。

## 現段階の制約

- 曲面入力は形状ガイド1個。複数の面・輪郭を混在選択した入力は無視せず拒否する。
- 曲面入力、および新しい面・線・点までの経路はソリッド出力が対象。独立ワイヤー出力は未対応と明記する。
- 終端の自由曲面は1枚の BRep 面。複数面の形状ガイドは1枚を指定する必要がある。
- 曲面入力で「全部貫く」は未対応。距離、対称、非対称、指定終端を使う。
- 立体内の曲がった部分面を直接押す経路は従来の平面制約が残る。
