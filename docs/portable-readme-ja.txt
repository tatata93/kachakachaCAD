kachakachaCAD Windows 64-bit ポータブル版
============================================

起動手順
--------
1. ダウンロードした ZIP を右クリックし、「すべて展開」を選びます。
2. 展開先の「START_REVIEW.cmd」をダブルクリックします。
3. 確認用モデルと一緒に kachakachaCAD が起動します。

ZIP の中から直接起動しないでください。
kachakacha_cad.exe だけを別の場所へ移すと、必要な DLL が見つからず起動できません。

マニュアル
----------
「OPEN_MANUAL.cmd」をダブルクリックすると、画像付きマニュアルが開きます。

通常起動
--------
確認用モデルを開かずに始める場合は「kachakacha_cad.exe」をダブルクリックします。

対応環境
--------
Windows 10 / 11 64-bit
インストール作業は不要です。
