# 開発ロードマップ

## Phase 0: 土台

- リポジトリの方針文書を固定する。
- C++20 / CMake の最小構成を作る。
- UIに依存しない幾何コアを作る。
- 作業平面の数学モデルをテスト可能にする。

## Phase 1: 作業平面とワイヤー

- 3D空間内の作業平面。
- 3点指定、点＋法線、面＋オフセット、辺＋角度。
- 作業平面上の2D座標と3D座標の相互変換。
- 点、直線、ポリライン、円、円弧。
- 作業平面上の直線・曲線から3Dワイヤーを作る。
- 補助線。
- 参照寸法。

## Phase 2: 作図編集と拘束

- 移動、回転、コピー、ミラー。
- オフセット、トリム、延長、分割、結合。
- 交差する2直線のC面取り、R丸め、任意プロファイル面取り。
- 拘束寸法。
- G0/G1/G2 の接続条件。

## Phase 3: 面

- 閉じたワイヤーから平面。
- 境界面。
- ルールド面。
- ロフト面。
- ネットワーク面。
- サーフェスの可視化。

## Phase 4: 板材工作

- 面を板として定義。
- 板厚、材質、板厚方向。
- 一方向曲げ。
- 展開可能性の判定。
- 曲げ方向表示。
- 手動分割。
- 半自動分割。

## Phase 5: 出力

- SVG / PDF / DXF。
- STEP / STL。
- 選択部品のみ出力。
- 1:1実寸出力。

## Phase 6: UI完成度

- Qt 6 デスクトップUI。
- プロジェクトツリー。
- 3Dビュー。
- 作業平面に正対して2D編集。
- 選択物の寸法・状態パネル。
- 表示切替。
