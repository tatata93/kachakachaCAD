# 寸法ツールと測定の3D表示（2026-10-09）

担当範囲はWP-14の測定・注記UI。オーナー要求: Inventor相当の寸法ツール、測定結果を右ペインと3Dビューへ同時表示。

## 先行して確定する測定表示
- 測定ツールを選んでから対象を選ぶ。有効な事前選択も使える。
- 測定中の対象点・線と結果を3Dビューへ表示する。右ペインと同じ計算結果を使う。
- 2点距離、3点角度、線の長さ、半径・直径、要素間の距離・角度、面積を扱う。
- 文字はズームに依存しないサイズと背景を持ち、画面内へ収める。表示しきれない項目は右ペインへの案内を示す。
- 選択変更・測り直し・消去・文書切替で表示を更新する。ツールを離れたら一時表示を消す。文書へは自動保存しない。
- 曲線長・曲面など近似による値は既存計算の意味を変えない。

## 寸法ツールの確認事項
Inventorには形を変更する駆動寸法と参照寸法がある。従来の製品契約では寸法拘束ソルバを後続候補としていた。オーナー回答「両方。寸法値で形状も変更したい」により、今回の作図線寸法を対象範囲へ追加した。

参考: Autodesk公式「To Work with Sketch Dimensions」
https://help.autodesk.com/cloudhelp/2025/ENU/Inventor-Help/files/GUID-026FE8D3-AFBB-4834-BC18-73D9CFF78185.htm

検証: 測定種別・対象位置と数値の対応をコアで確認。GUIで対象先行／ツール先行、点指定・再測定、ツール変更、消去、通常／Win95の表示を確認する。

## 実装する寸法
作図→注記→寸法。直線の長さ、作業面U/V方向の寸法、円・円弧の半径と直径、2直線の角度、2線の端点間距離。形状を変更する寸法と参照寸法を切替可能。対象を押し、値と配置位置を指定してEnter。続けて次の寸法を付けられる。既存寸法は3Dの文字か右ペインの一覧から編集する。
拘束は正本のCreateWireDefinitionの直線・円・円弧を対象とする。接続端点と既存の駆動寸法を同時に満たし、水平・垂直の直線の向きを維持する（角度拘束の対象は角度を優先）。最初の対象の始点、円では中心を固定する。解けない場合は変更全体を取消し、黙って拘束を捨てない。加工結果・派生辺やスプラインの駆動、任意の接線拘束・数式・拘束の完全性表示は今回含まない。変数240超の接続範囲は明示して拒否する。
保存はSegment UUID参照、駆動/参照、基準U/V、3D文字位置を保持する。旧参照寸法は従来どおり読み込む。新規フィールドは新しい寸法にのみ書き、既存サンプルのバイトを変更しない。
