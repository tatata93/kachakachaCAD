# kachakachaCAD

kachakachaCAD は、鉄道模型製作用のワイヤーフレーム／板材CADです。

目的は、画面上で形を作るだけではなく、プラ板・紙・3Dプリント部品・3Dプリント治具として実際に製作できるデータへつなげることです。

## 中核コンセプト

**3D空間内に自由に紙を置いて、その紙の上に正確な2D図面を描けるCAD。**

この「紙」が作業平面です。正面、側面、上面だけでなく、任意角度、辺との角度指定、3点指定、オフセット指定などで作成できます。

## 技術方針

本命構成は以下です。

```text
言語: C++20
UI: Qt 6
CADカーネル: Open CASCADE Technology
数値計算: Eigen
ビルド: CMake
```

初期段階では、UIやOCCT連携より先に、幾何コアを小さく実装して検証します。

## 現在の骨格

```text
src/core/      UIに依存しない幾何・モデルの中核
tests/         小さな検証テスト
scripts/       開発用スクリプト
docs/          方針・仕様・作業手順
```

現在のコアでは、作業平面、3D直線ワイヤー、3Dポリライン、Cubic Bezier、円、円弧、作業平面上の2D作図、閉じた境界の平面、2断面の曲面、平面図から面へのワイヤー投影を扱います。

## 最初の確認

PowerShell で以下を実行します。

```powershell
.\scripts\doctor.ps1
.\scripts\check.ps1
```

`check.ps1` は構成、ビルド、テストをまとめて実行します。Windows では Visual Studio Build Tools 2022 を優先して使います。

## 画面で確認

本命のQtデスクトップ版を起動します。

```powershell
.\scripts\run-cad.ps1
```

既存プロジェクトを開いて起動する場合:

```powershell
.\scripts\run-cad.ps1 -Project examples\first-check.kcd
```

Qt版では、画面からプロジェクトの新規作成・読み込み・保存、作業平面の数値作成、3Dワイヤーと平面上ワイヤーの作成、選択物の数値編集、複数ワイヤーの直接移動・回転・コピー・ミラー複製、ワイヤーの分割・結合、直線のトリム・延長、交差直線のC面取りとR丸め、平面・2断面曲面の作成、平面図から面へのワイヤー投影、1:1図面出力、削除、Undo/Redoができます。保存時は一時ファイルを介して置き換えるため、書き込み途中の既存ファイルを残しにくい方式です。

起動直後は右側の「作図」タブと直線ツールが開きます。「作図面」で3D空間内の紙を選ぶと真正面へ向き、3D画面をクリックまたはドラッグして作図できます。直線、ポリライン、矩形、円、3点円弧、4点ベジェ曲線を直接作成でき、現在入力している点の役割とU/V座標、長さ・幅高さ・半径を表示します。ポリラインは「完了」、右クリック、または`Enter`で確定し、`Esc`で途中入力を取り消します。位置は指定したmm間隔のグリッド、既存ワイヤーの端点、ポリラインの頂点へスナップします。数値入力は独立した「数値入力」タブに残し、作成後のワイヤーは編集タブから数値を修正できます。

起動時の視点は3Dです。3D画面右上のビューキューブは「上」「正」「右」の面をクリックして標準方向へ正対でき、キューブのドラッグで視点を回転できます。下の「3D」をクリックすると斜めの3D視点へ戻ります。作業平面タブでは、平面の作成と同じ方法・オフセット・角度を入力し、「この向きで見る」を押すと作業平面をプロジェクトへ追加せず視点だけを正対できます。

3D画面またはモデル一覧で `Ctrl` を押しながら複数の線を選択できます。加工タブでは、選択した2本が直線A/Bへ自動設定されます。A/B欄の「3D選択」を押してから線をクリックし、1本ずつ割り当てることもできます。

編集タブの「移動」「コピー」は、選択したワイヤーの基準点と移動先を3D画面で順に指定します。「回転」は中心、角度の基準点、回転先の3点を指定し、「ミラー複製」は作図面上で軸の2点を指定します。いずれも確定前の形を破線で表示し、複数選択したワイヤーをまとめて処理します。「分割」はワイヤーを1本選択して線上をクリックします。直線、ポリライン、円弧、ベジェ曲線を元の曲線精度のまま二分できます。端点が連続する直線・ポリラインを複数選択して「結合」を押すと、1本のポリラインになります。2本の直線を選択して「交点まで」を押すと、短い場合は延長し、交差部分が余る場合はトリムして同じ交点へ合わせます。

直線を1本だけ選んで「基準線に設定」を押すと、通常選択とは別に基準線として保持し、3D画面上へ緑色の破線と「基準」を表示します。その後で対象ワイヤーを選び直して「ミラー複製」を押すと、表示中の作図面内で基準線を軸に即時複製します。同じ基準線を作業平面タブの「回転軸に使用」から任意角度の平面作成にも利用できます。

「面」タブでは、3D画面で閉じたワイヤー1本を選んで平面を、断面ワイヤー2本を選んで曲面を作成できます。ライト穴などは別の作業平面へ円や輪郭を作図し、投影先の面と平面図を選んで「選択ワイヤーを面へ投影」を押します。投影結果は元の平面図と面へ関連付けて保存され、元の断面や平面図を編集すると追従します。投影結果自体は直接編集せず、情報欄に表示される元の平面図を編集します。`examples\curved-panel-light-holes.kcd` でこの一連の形を確認できます。

「出力」タブでは、作業平面と対象を選び、面上のワイヤーをミリ単位の1:1 SVGまたはDXFへ保存できます。面上の全ワイヤーをまとめて出す方法と、3D画面で選択したワイヤーだけを出す方法を選べます。円・円弧・ベジェ曲線は0.01 mmの許容差で出力用の線へ変換します。選択した面から外れているワイヤーは混入させず、選択出力の場合はエラーとして知らせます。

単体で起動できる配布フォルダを作る場合:

```powershell
.\scripts\package-cad.ps1
```

作成後は `out\kachakachaCAD\kachakacha_cad.exe` を直接起動できます。

## 開発用ビューア

最小ビューアを起動します。

```powershell
.\scripts\run-viewer.ps1
```

表示された画面では、ワイヤーや作業平面をクリックして選択できます。右側の情報パネルの一覧から名前をクリックしても選択できます。選択した対象は強調表示され、名前、種類、平面ポリシー、座標、概算長さなどが表示されます。
選択中の対象は、`A`/`D` で X 方向、`W`/`S` で Y 方向、`Q`/`E` で Z 方向に移動できます。通常は 0.5mm、`Shift` を押しながらなら 5mm、`Ctrl` を押しながらなら 0.1mm ずつ動きます。
`C` で選択中の対象を複製、`Delete` または `Backspace` で削除、`Ctrl+Z` で Undo、`Ctrl+Y` または `Ctrl+Shift+Z` で Redo できます。
`Ctrl+S` で現在の表示内容を `out` フォルダへ `.kcd` として保存できます。
`Tab` で次の対象を選択、`Esc` で選択解除、`1`、`2`、`3` でサンプル切り替え、マウスドラッグで回転、ホイールでズームできます。

数値で定義したプロジェクトを開く場合:

```powershell
.\scripts\run-viewer.ps1 -Project examples\first-check.kcd
```

画像だけ確認する場合:

```powershell
.\scripts\snapshot-viewer.ps1
```

プロジェクトを `.kcd` として書き出す場合:

```powershell
.\scripts\export-project.ps1 -Project examples\first-check.kcd -OutputPath out\first-check-export.kcd
```
