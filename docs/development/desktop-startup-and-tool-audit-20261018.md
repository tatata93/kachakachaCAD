# 通常起動・全ツール入口・詳細マニュアル（2026-10-18）

## 通常起動の問題

前回の起動確認は、プロセス生存と応答を成功とした点が不十分だった。
Windows版はコンソール用subsystemへ変更されていた。また全体検証のUI試験はoffscreenを使い、
引数なしのデスクトップ起動と通常のイベントループを検証していなかった。
GUI用subsystemを使い、通常起動ではoffscreen/minimalの継承を解除する。
CLI診断は親の出力を復旧し、リダイレクトした自己試験ログを保持する。

追加した通常起動試験は、引数なしでQApplication::execへ入り、Windowsプラットフォーム、
タイトル、可視・非最小化、ネイティブ露出、画面内の配置、描画画像を検査する。
Windows環境とoffscreenの残った環境の両方を起動し、検査専用の子プロセスだけ正常終了させる。
開発版はCTest、配布版はpackage-v2から必須実行し、通常起動証拠の欠落をpublishで拒否する。
既存の利用中アプリは終了しない。Windows画面取得ツールは2回タイムアウトしたため、
それによる目視確認を完了証拠とはしない。アプリ自身が通常イベントループで記録した起動画面を検査した。

## ツールの調査と検証範囲

全168コマンドを実際のActivateCommandから起動し、状態・入力ペイン・対象待ち・時間を記録した。
全入口の未選択画面を個別に撮影し、マニュアルの各ページへ登録した。入口点検は成功し、
Windows画面での最終撮影も行った。これは空入力での入口確認であり、大きな実モデルの計算時間の保証ではない。
形状生成・異常入力・Undo/Redo・保存・出力は全体UI/コア試験で別途検証する。
角加工の2コマンドは実装に合わせ、即時命令からツールのメタデータへ修正した。
解析棚が角加工・作図・測定の入力棚を隠す優先順位を修正し、全作図ツールの棚判定と実際の切替を回帰試験へ加えた。
解析を明示的に開く操作では入力を中断せず解析棚を表示し、次の道具選択でその道具の入力へ戻る。

## マニュアル

全168機能の準備・入力・数値・実行方法・取消・症状別確認を個別に記載。
方式例は78、全168機能に新しい入口実画面を追加した。実例画像と入力待ち画面、模式図を区別する。
準備用の7手順、パノラミック投影、ライトの終端までの押し出し、ソリッドトリムの写真付き実例を結ぶ。
角加工の旧即時実行手順を直し、スイープ・回転体・ロフト立体の準備座標と入力役割を細分化した。
HTMLの全機能対応、画像・リンク・アンカー・構文整合と、生成元からの再生成一致を検査する。
ブラウザー描画の目視確認と静的検査を同じものとは扱わない。

配布の最終判定は `out/verification/desktop-manual-release3-20261018/result.json`。
起動前後・入口の途中確認は `out/desktop-repair-20261018/` に保全した。

## 最終結果

Windows全体ゲート195項目は失敗・skipなし。開発ビルドと配布版で各515件のUI試験が成功し、
従来版の自己試験も成功した。通常Windows起動は両方で必須確認した。
全体CTestは1448.20秒（配布版717.07秒、開発版UI674.41秒を含む）、従来版自己試験は10.31秒。
入口画像はWindows上で撮影し、168入口の最大所要時間は143msだった。
途中の全体実行は配布スクリプトのPATH問題を直すため中断し、そのログは保全した。
再実行時に残った自分の終了済み実行のロックだけを所有PID確認後に除去した。
完成判定は上記release3の成功証拠を使い、中断・ロック競合の実行を成功扱いしない。
