# 面展開仕様(2026-09-02 オーナー合意)

このCADの肝である面展開機能の合意仕様。実装はこの文書に従う。
既存の展開4系統(従来方式 / 多面体 / 曲げ紙 / 製作用大部材)は、この新パイプラインへ統合・整理していく。

## パイプライン(3段構成)

**完成品モデル(自由曲面可) → 部材近似モデル → 展開図(型紙)**

- 前提: プラ板・紙は基本的に1軸方向にしか曲げられない。よって展開の入り口は、
  完成品モデルを「1部材=基本1軸曲げ」の部材の集合へ近似し直す工程である。
- **部材近似モデルは第一級の設計対象。** 内部処理ではなく、ユーザーが見て、境界を編集し、保存できる。
- 例(ペットボトル): 口元円筒 / 肩2帯 / 胴円筒 / 裾帯 の5部材へ近似。
  円筒帯の展開は長方形、すぼまる肩帯の展開は扇環状(バナナ形)になる。

## 展開図の幾何学的な正しさ

- 展開図は辺の**実長**と面上の**実距離**を保存する。その結果、輪郭は自然に曲線になる。
  長方形へ均してはいけない。
  - 上辺がせり出し下辺が内側の帯は、展開図では上辺が長く下辺が短い=扇状に曲がる。
  - 3D上の辺の凹凸・曲線は、展開図では帯幅の変化=上辺・下辺の曲線として現れる。
- 近似の誤差(二重曲率を1軸曲げに均したずれ)は隠さず、数値(最大/RMS偏差)と表示で見せる。

## 部材の結合展開

部材近似モデル上で**隣接する任意個数の部材を選択**すると、一枚(の板/紙)から再現できる
「つながった1つの展開図」を出力する。結合部の境界は型紙上の曲げ線として残る。

## 合意事項

1. **派生が基本、選択で独立化。** 部材近似モデルは元モデルの編集に追従して再生成される。
   ユーザーが選んだ時だけ独立化できる(.kcd書き出し等)。
   近似の粗さ・分割の細かさはユーザー設定可能。設定項目が増える場合は専用の設定ウィンドウを出してよい。
2. **二重曲率は部材近似の過程で吸収する。** 近似モデルと同じ条件・同じ設定で処理し、専用の別機構は作らない。
3. **精度はユーザー指定とオートの両方**を用意する。
4. **境界は自動+手動。** 自動提案に加え、既存の任意の線を境界に指定でき、新規に境界線を引ける。
5. **型紙の組立支援は部材番号+山折り/谷折り表示まで**(設計メモを兼ねる)。のりしろ等は作らない。
6. **治具設計との接続は保留**(検討中。決まるまで実装しない)。
7. **.kcd の前方互換対応は不要**(オーナー明言。旧ビルドで新ファイルが開けないのは許容)。

### 2026-09-04 追加合意(積層・面入力・可動折り線)

8. **近似の入力は「面 または 板材」**。面入力では厚み未定のまま近似し、
   「この曲げ状態を板材化」の時点で初めて厚みを指定する。板材入力も従来どおり残す
   (厚み・可変厚を板材化へ引き継げる)。
9. **積層(プラ板重ねによる段差再現・補強)は両方の作り方を支持する**:
   (a) 完成品は外皮のみ描き、法線オフセット派生面(部分範囲可・元に追従)から積層板を作る。
   (b) 完成品モデルに全層を直接描く。
   どちらで作った板材にも**積層関係**(どの板の上に・どちら側に・何層目か)を属性として
   付けられ、型紙には部材番号に加えて積層記号(例: 3-L2)を出す。目標段差高さと使用板厚から
   層数を提案する計算支援を付ける。**段差の自動検出・自動分解はしない**。
10. **折り線(内部レール)は個別に曲げられる可動折り線**とする。各折り線は
    **角度(度)と進行度(%)を相互に編集**でき(片方を変えるともう片方も追従表示)、
    全体スライダーは全折り線を一括で動かすマスターとして残す。個別の折り状態は
    実体化・型紙の山谷・STL/STEP出力へ反映し、**.kcd に保存する**(開き直しても継続)。
    任意ワイヤーを折り線にしたい場合は「そのワイヤーを境界に指定した近似モデル」として
    統一的に扱い、板材へ直接ヒンジ属性を付ける別機構は作らない(合意事項2と同方針)。
11. **近似モデルの出力方式は選択制**: 同一.kcd(既定。派生の線・面はグループ
    「近似:<名前>」の中に生成される) / 別.kcd / STL/STEP。曲げ状態の実体化を
    同一.kcdへ出す場合も、生成物は「近似:<名前>」配下の子グループへまとめる。
12. **治具は近似の線へ接続して作る**(保留だった合意6の方向決め): 治具の基準は
    近似モデルの境界レール等の派生ワイヤ。派生名(「<名前>_境界N」等)は安定させ、
    治具が名前参照で追従できるようにする。

## UI方針

- **3D表示はモード切替+重ね表示。** 1つの3D空間のまま「完成品 / 部材近似 / 重ね(半透明)」を
  ワンタッチで切り替える。モードに応じて使えるツールも切り替わる。
- **型紙は「3D+専用型紙ビュー」。** 生成物は従来どおり3D空間の作業平面上の編集可能なワイヤとして
  残しつつ、部材番号・山谷・寸法を整理して見る専用の2D型紙ビュー(タブ)を追加する。印刷プレビューを兼ねる。

### セット(グループ)

線の増加(近似モデルの境界線、型紙ワイヤ、治具の基準線…)への対策としてセットを導入する。

- 派生物(部材面・境界線・型紙ワイヤ)は自動で「近似:○○」「型紙:○○」等のセットに属する。
  モデル一覧はセット単位のツリーとし、セット一括の表示制御を行う。手動でのセット作成・移動も可能。
- 近似モデルの境界・断面・稜線を「ワイヤーとして取り出す」抽出コマンドを用意する。
  取り出し時に**派生(追従)か独立コピーか**を選べる(治具の基準線には独立コピーが向く)。
- セットは **表示 / 参照のみ / 非表示** の3状態を持つ。「参照のみ」は薄色表示で
  スナップ・測定の対象になるが、選択・編集はできない(誤編集防止)。
- モード切替(完成品/部材/重ね/将来の治具)は、セット表示状態のプリセットとして実装する。
- 名前の一意性と名前文字列参照の仕組みは変えない。セットは表示・操作の属性に留める。

## 実装状況

- v1(2026-09-02〜): 板材を入力とする部材近似モデル(自動+手動パラメータ境界、派生再生成、.kcd)、
  セット(3状態の保存と一覧。ビューポートは表示/非表示のみ有効)、部材ごとの型紙生成(番号・山谷)、
  専用型紙ビュー、隣接部材の結合展開(範囲合併)。実装方針は ADR 0019。
- v1.1(2026-09-01〜): 近似の実形状化(角ばったルールド面+三角形単位の厳密展開、
  帯ごとのクアッド行進+剛体合わせ)、型紙⇔折り曲げのスライダー(型紙ビュー/メイン3Dビュー)、
  元板材の開口(窓・ライト)の部材面・部材板材への投影(境界をまたぐ開口は型紙表示のみ)、
  曲げ状態の実体化と出力(`PartFoldState`: 任意の曲げ具合 0〜100% を同一.kcd/別.kcd/STL/STEPへ。
  0%は開口も実穴になる平面配置)。
- v1.2(2026-09-04〜): 面を直接入力にする経路(合意8、`part_model_surface`、板材化時に板厚指定)、
  可動折り線(合意10、`part_model_fold`、折り線ごとの角度⇄%相互編集、実体化・出力へ反映)、
  実体化の「近似:<名前>」配下への子グループ化(合意11)、
  積層=重ね板(合意9、`plate_laminate`、Plate の下駄オフセット、同面は幾何追従・別面は関係記録、
  層数提案つきUI)。
- 未着手: ワイヤ指定の手動境界(=可動折り線 段階B)、「参照のみ」の選択禁止、
  重ね表示の半透明化、抽出コマンドの派生/独立選択の拡充、境界をまたぐ開口の部材ごと分割(縁欠き)、
  型紙への積層記号(現状は命名 <土台>_L2 で代替)、部材近似モデルの型紙ビュー内での折り角表示。
