# 部品モードのボタン ── 全部の役割と使用例

部品モードは **工程5「形をつくる」** です。
線(ワイヤー)から **面** を作り、面から **立体(部品)** を作ります。

```
線 ──→ 面(形状ガイド) ──→ 立体(部品)
 │           │                  │
 │           └ 厚みを付ける ────┘
 └─────── 押し出し ─────────────┘
 └─────── かごから ─────────────┘
```

**面と立体は別のものです。** 面は厚みのない皮、立体は中身のある物です。
プラ板は面に厚みを付けたものなので、この道具では **面を先に作る** のが基本です。

---

## 右の「部品」の棚

上に **いま何を選んでいるか** が出ます(「選択: 閉じた輪郭 1 / 面 2」)。
押す前に、そこを見てください。足りなければボタンは灰色です。

### 欄

| 欄 | 何に効くか |
| --- | --- |
| **押し出しの距離** | 「押し出し」の距離。板厚としても使います |
| **板厚** | 上と同じ値です(打ちやすいように2か所に出しています) |
| **厚みの付け方** | 「面に厚みを付ける」で、面のどちら側へ伸ばすか。**外側**=法線の向き、**内側**=逆、**中央**=半分ずつ |
| **面を離す距離** | 形状ガイドの「離した面」を作るときの距離 |
| **回転体の角度** | 「回転体」で回す角度。360 で一周 |
| **治具のすき間** | 治具が面から離れる距離。0 なら面にぴったり |
| **治具の厚み** | 当て板の厚み。**正なら面の表側、負なら裏側**。0 にはできません |

## ボタン(上から順に)

### 押し出し

**閉じた輪郭を、まっすぐ動かして立体にします。**

| | |
| --- | --- |
| 選ぶもの | **閉じた輪郭を1つ以上**(矩形・円・閉じたポリライン) |
| 出来るもの | 部品(立体)。チェック次第で輪郭のワイヤーも |
| 断り | `閉じた輪郭を1つ以上選んでください。` / `EXT-002 開いた輪郭からは部品を作れません。` |

窓で決めること:

- **押す向き** ── 普通は「作業平面に垂直」。「X方向」「選んだ線の向き」なども選べます
- **どこまで** ── 距離 / 左右対称 / 両方向に別々の距離 / 選んだ面まで / 全部貫く
- **部品(立体)を作る** ── これが立体
- **押し出し先の輪郭を作る** ── 反対側の輪郭がワイヤーとして残ります
- **側面の境界を作る** ── 側面の縦線がワイヤーとして残ります
- **部品どうしの演算** ── 新しい部品 / 選んだ部品へ足す / 選んだ部品から引く

> **使用例(立方体)**: 正面に 20×20 の矩形を引き、距離 20 で押し出す。
> 下2つのチェックを入れると、辺が12本そろいます。→ `立方体を作る.md`
>
> **使用例(窓を抜く)**: 側板の部品を作ってから、窓の矩形を選んで
> 「部品どうしの演算」を **選んだ部品から引く** にして押し出す。
> 板を貫くよう「全部貫く」にすると、板厚を変えても抜けたままです。

### 面に厚みを付ける

**厚みのない面を、プラ板のような板にします。**

| | |
| --- | --- |
| 選ぶもの | **形状ガイドの面を1つ以上** |
| 使う欄 | 板厚、厚みの付け方 |
| 出来るもの | 部品(立体) |
| 断り | `形状ガイドの面を1つ以上選んでください。` |

> **使用例**: 車体の曲面を形状ガイドで作り、板厚 `0.5`、厚みの付け方 **内側** で
> 厚みを付ける。内側にするのは、**外側の面を設計寸法どおりに保つ** ためです。
> 外側にすると、車体が板厚のぶん太ります。

### 面を平面まで立体に

**面と、選んだ平面のあいだを埋めて立体にします。**

| | |
| --- | --- |
| 選ぶもの | **形状ガイドの面1つ + 作業平面1つ**(ちょうど) |
| 出来るもの | 部品(立体) |
| 断り | `KER-T004 面が相手の平面をまたいでいます。` |

厚みが場所によって変わる立体ができます。面が平面をまたいでいると、
どちら側を埋めるのか決まらないので断ります。

> **使用例**: 前頭部の曲面と、運転台の床面(作業平面)のあいだを埋めて、
> 中身の詰まった塊にする。そこから窓を引いて抜きます。

### 回転体を作る

**断面を軸のまわりに回して面を作ります。**

| | |
| --- | --- |
| 選ぶもの | **断面の線を1本目、軸の直線を2本目**(この順で) |
| 使う欄 | 回転体の角度 |
| 出来るもの | 形状ガイド(面。立体ではありません) |
| 断り | `REV-E002 軸は直線 1 本にしてください。` / `REV-E005 断面が軸の上にあります。` |

**選ぶ順が意味を持ちます。** 1本目が断面、2本目が軸です。

> **使用例**: 煙突・ドーム屋根・タンク車の鏡板。
> 半円を引き、その横に縦の直線を引いて、角度 `360` で回します。
> 立体にしたければ、そのあと「面に厚みを付ける」。

### 治具を作る

**面に当てるための当て板を作ります。**

| | |
| --- | --- |
| 選ぶもの | **形状ガイドの面を1つ** |
| 使う欄 | 治具のすき間、治具の厚み |
| 出来るもの | 当たり面(すき間が 0 でなければ)+ 当て板。**ひとまとまりで1回で戻せます** |
| 断り | `JIG-E002 治具の厚みは 0 にできません。` |

**厚みの符号で側が決まります。** 正なら面の表側、負なら裏側。

> **使用例**: 曲面のプラ板を貼るとき、内側から支える型。
> すき間 `0`、厚み `-3` にすると、面の裏側に 3mm の当て板ができます。
> これを 3D プリンタで出して治具にします。

### ワイヤー群から部品

**閉じたかごになっている線から、直接立体を作ります。**

| | |
| --- | --- |
| 選ぶもの | **ワイヤーを3本以上**(閉じたかごになること) |
| 出来るもの | 部品(立体)。閉じた塊ごとに1つ |
| 断り | `GEO-S003 端がつながっていない線があります。` / `GEO-S005 作った立体が閉じていません。` |

端の座標がずれていると閉じません。

> **使用例**: 図面から座標を起こした12本の辺で直方体を作る。→ `立方体を作る.md`
> 押し出しで作れない形(上下で断面が違う塊)にも使えます。

### 足す / 引く

**2つの部品を、くっつける / くり抜きます。**

| | |
| --- | --- |
| 選ぶもの | **部品をちょうど2つ**。**選ぶ順が意味を持ちます**(1つ目が土台、2つ目が道具) |
| 断り | `KER-B003 2つの部品は触れていないので、何も変わりません。` / `KER-B004 引き切って何も残りませんでした。` |

離ればなれになる足し算、引き切ってしまう引き算は断ります。

> **使用例(足す)**: 車体と屋根を別々に作って1つにする。
> **使用例(引く)**: 車体から窓の箱を引いて窓を抜く。
> 抜く箱は板厚より **長く** 作ってください。ぴったりだと面が重なって失敗します。

### 現在状態を固定

**「何から作ったか」を切り離して、形だけにします。**

| | |
| --- | --- |
| 選ぶもの | **派生したものを1つ**(投影した線、押し出した部品など) |
| 出来るもの | 独立した実体 |

固定すると、元を直しても付いてこなくなります。

> **使用例**: 曲面へ投影した窓の線を固定してから、手で形を整える。
> 固定しないと、投影の元を直したときに整えた形が消えます。
>
> **固定は戻せません**(「元に戻す」では戻せますが、保存して開き直すと戻せません)。
> 作り方を残しておきたいものは固定しないでください。

## 右のもう1枚 ── 「形状ガイドの役割」の表

**面を作るための表です。** 線に「役割」を与えて、その組み合わせから面を作ります。

| ボタン | すること |
| --- | --- |
| **面の作り方** | 8通りから選ぶ(平面 / ルールド / ロフト / 案内付きロフト / 曲線網 / 境界埋め / 離した面 / 回転体) |
| **選択を表へ** | 選んだ線を、新しい行として表に入れる |
| **選択を既存行へ追加** | いま選んでいる行に、線を足す(1つの役割に複数の線) |
| **行を上へ / 下へ** | **並び順が面の形を決めます**(ロフトは表の順に断面を通ります) |
| **行を削除** | その行を表から外す(線は消えません) |
| **向きを反転** | その行の線の向きを逆にする。**ねじれた面が直ります** |
| **表から面を作る** | 表のとおりに面を作る |
| **表を空にする** | 表を全部消す(線は消えません) |

> **使用例(ロフト)**: 車体の断面を前から後ろへ3本引く。
> 1本ずつ「選択を表へ」で入れ、作り方を **ロフト** にして「表から面を作る」。
> **面がねじれていたら、どれかの行の「向きを反転」を押します。**
> 断面の向きが揃っていないと、面が8の字にねじれます。

## 順番に迷ったら

```
1. 線を引く(作図モード)
2. 面にする    ── 役割の表 →「表から面を作る」、または「回転体」
3. 立体にする  ──「面に厚みを付ける」(板)
                   「押し出し」(閉じた輪郭から直接)
                   「面を平面まで立体に」(詰まった塊)
                   「ワイヤー群から部品」(かごから)
4. 組み合わせる ──「足す」「引く」
5. 製作モードへ
```

**押せないボタンは、カーソルを置くと何を選べばよいか出ます。**
押しても断られません ── **構えて待ちます。** 相手を選べば続きます(`Esc` でやめます)。
