# ADR 0009: 実寸PDFは自動用紙向きと重なり付きページ分割を行う

## 状態

採用

## 決定

- 選択板材の展開輪郭を画像化せず、QtのベクターPDFへmm基準で描画する。
- 用紙はA4またはA3とし、上下左右へ10 mmの工作余白を確保する。
- 用紙方向を自動にした場合は、縦と横の必要ページ数を比較して少ない方を選ぶ。同数なら部品と印刷範囲の縦横比が近い方を選ぶ。
- 一枚へ収まらない場合は、ユーザー指定量を重ねて行列状に分ける。標準の重なりは5 mmとする。
- 隣接ページの重なり部分へ、同じ展開座標を示す十字と円の位置合わせ目印を描く。
- 一列または一行だけで収まる方向は、その方向の印刷範囲中央へ部品を置く。
- 全ページの下部へ正確な100 mm尺度線、ページ番号、列番号、行番号を付ける。
- PDF内の表示文字はフォント埋め込みへ依存せず、単純な線文字として描く。
- PDF保存は一時ファイルを完成させてから置き換え、途中までのファイルを残しにくくする。

## 理由

鉄道模型の側板や屋根はA4一枚を超えることがある。PDFビューアやプリンタードライバー任せで分割すると、余白や自動縮小によって実寸が崩れやすい。CAD側で印刷範囲、重なり、共有目印を決めれば、家庭用プリンターでも同じ型紙を組み立てられる。

100 mm尺度線は、ドライバーが「用紙に合わせる」を適用した場合に誤差を実測するために必要である。文字を線へ変換するのは、配布先のフォント環境による文字化けや黒い四角を避けるためである。

## 制限

- プリンタードライバー側の拡大縮小は制御できないため、印刷後に尺度線を確認する必要がある。
- 複数部品を同じ用紙へ詰めるネスティングは未実装。
- プリンター固有の印刷不能領域、トンボ、裁ち落としは個別設定していない。
