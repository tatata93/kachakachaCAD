# ADR 0013: 丸い角は外周V字切れ込みを選べるようにする

## 背景

二方向曲面を帯へ完全分割すれば形状精度は上げられるが、部品数と接着線が増える。車体前面の丸い角、箱形車体のフィレット、円錐に近い収束部は、外周からダーツ状の切れ込みを入れて余る材料を閉じることで、一体の紙や薄板として近似できる。

## 決定

- 自動処理は「帯に完全分割」「V字切れ込み」「先端R付きV字切れ込み」から明示的に選ぶ。
- V字方式は一枚の展開外周を維持し、切れ込みを外周輪郭そのものへ組み込む。
- 切れ込み間隔、板幅に対する深さ、V字の開き角、先端半径、反応する最小曲がり角を利用者が指定する。
- 開口または手動切れ目と重なる候補は反対側へ移し、両側とも干渉する場合は生成しない。
- 先端Rは展開外周へ円弧点列として入れ、SVG、DXF、PDF、CAD内の展開3D板で同じ輪郭を使う。
- 外周へ組み込んだV字は `RELIEF_CUT` へ重複出力しない。切断機が同じ辺を二度通らないためである。
- 元の3D板は変更しない。組立3D確認では切れ込み位置だけを赤線で重ねる。
- 手動の完全分割線が登録されている場合は完全分割を優先する。

## 結果

部品数を抑える一体板と、形状精度を優先する完全分割を工作方法に応じて選べる。V字方式は伸縮なしの数学的な厳密展開ではないため、最大推定ずれの警告は維持する。実材の曲げやすさと切れ込み設定を確認してから製作へ使う。
