選択・移動

具体例: 説明図の矢印を移動する

準備

場面に矢印を1本置く

操作手順

  1. 選択・移動を選ぶ
  2. 矢印を押す
  3. 移動ハンドルまたは端をドラッグする

設定: モデル本体の移動とは別

結果を確認

説明書の矢印位置だけが変わる。

取消・やり直し

未確定入力をEscで取り消します。道具を終えるときは選択(V)または別の道具へ切り替えます。 確定済みの文書変更はCtrl+Z、やり直しはCtrl+Yです。保存・書出し済みのファイルはUndoの対象ではありません。

進めない場合

文書がありません。

対象欄と3Dの強調を照合し、必要な線・面・部品を各役割へ指定します。処理中は計算表示を確認し、取消が可能な処理は取消を使います。

Windows版の操作画面

instructions.move。図の設定と縮尺は例です。方式ごとの制限、プレビューと確定済み結果の区別を確認してください。
