近似の方式を切り替える

具体例: 次に作る近似の方式を変える

準備

近似を作成する前に行う

操作手順

  1. 近似の方法を切り替えるを押す
  2. 次回方式の状態表示を確認する
  3. 近似を新しく作る

設定: 帯近似と面分類を循環

結果を確認

次に作るモデルの方式が変わる。既存モデルの方式は変わらない。

取消・やり直し

ダイアログの取消、またはペインの取消を使います。即時操作には未確定段階がありません。 確定済みの文書変更はCtrl+Z、やり直しはCtrl+Yです。保存・書出し済みのファイルはUndoの対象ではありません。

進めない場合

次に作る近似モデルの方式を、帯へ近似し直す(V1方式)と、

対象欄と3Dの強調を照合し、必要な線・面・部品を各役割へ指定します。処理中は計算表示を確認し、取消が可能な処理は取消を使います。
