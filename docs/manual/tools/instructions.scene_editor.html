画像エディター

具体例: 車体の組立場面を作る

準備

車体と屋根のモデルを用意する

操作手順

  1. 画像エディターを選び場面を追加する
  2. 現在のモデルを選ぶ
  3. 使用部品にチェックしてこの場面に配置を押す
  4. 視点と部品の位置を整える

設定: 場面ごとに3D状態を保持

結果を確認

部品を配置した場面を作れる。用紙への配置とは別に編集する。

取消・やり直し

ダイアログの取消、またはペインの取消を使います。即時操作には未確定段階がありません。 確定済みの文書変更はCtrl+Z、やり直しはCtrl+Yです。保存・書出し済みのファイルはUndoの対象ではありません。

進めない場合

文書がありません。

対象欄と3Dの強調を照合し、必要な線・面・部品を各役割へ指定します。処理中は計算表示を確認し、取消が可能な処理は取消を使います。
