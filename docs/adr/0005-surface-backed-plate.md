# ADR 0005: 板材は元の面と製作属性を保持する

## 状態

採用

## 決定

- 板材は三角形メッシュや独立したソリッドへ変換せず、元の面を参照する。
- 板厚、厚み方向、材質を板材の製作属性として保持する。
- 厚み方向は、元の面から外側、元の面を中央、元の面から内側の3種類とする。
- 元の断面ワイヤーを編集した場合、面、投影ワイヤー、板材の順に再計算する。
- 元の面を非表示にしても依存関係は残し、モデル一覧から再表示できるようにする。

## 理由

プラ板や紙の部品として作れるかを判断するには、見た目の厚みだけでなく、基準となる面、実際の板厚、材料が必要になる。元の面との関係を保てば、後から展開可能性、曲げ方向、分割、切断用出力を追加しても設計意図を失わない。

## 現在の制限

- 閉じた投影ワイヤーによる開口は扱う。面同士の接合はまだ行わない。
- 複数断面ロフトは隣接断面を直線的に補間する。
- 展開可能性は近似分類まで扱う。曲げ方向表示、手動分割、実際の展開、1:1板材出力は今後追加する。
