# 画像を面に貼る（2026-10-04 オーナー依頼）

## 操作
作図の画像ツール → PNG/JPEG/BMPを読む → 任意の作業面・面・ソリッドのフェイスを選ぶ。
現在の作業面もボタンで採用可能。事前選択とツール先行を両方扱う。
右ペインの画像上で基準点を指定し、主3D画面で配置先の基準点を指定する。
画像上の2点とCAD上の2点で縮尺を合わせる。縦横比を保つ。数値の幅・回転・不透明度も編集可能。
Enterで確定、Escで取消。下見だけで文書を変更しない。選択した画像の再編集を同じツールで行う。

## 貼り方
- 平面: 画像を平面に配置。
- 投影: 指定位置の接平面の向きから面へ投影。画像外は透明、面の境界と穴で切る。
- 面に沿う: 面のUVに沿って貼る。自由曲面のUVは均一な実長ではなく伸縮が生じるため説明を表示。
  円筒等の周期面はUVの継ぎ目を持つ。表示は面の三角形による近似で、幾何や型紙を変更しない。
曲面の長さ合わせはCAD側2点の直線距離を基準にする（曲面上の測地距離ではない）。

## 保存と整合
新しいImage要素/CreateImage定義。PNGデータ、画像寸法、貼付座標系、縮尺・回転・基準点、
投影/面沿い、面に貼る場合の確定時BRepを保存する。パス参照ではなく画像を内包。
貼付先は確定時の位置・形状を固定して保持し、元部品の編集には自動追従しないことをUIで明示する。
画像は図形へ変換しない。STL/STEPは色付き画像を表せないため選択出力時に理由を示す。
Undo/Redo・削除・表示切替・グループ・KCD往復を扱う。空画像、ゼロ距離、面に当たらない点は拒否し理由を出す。

## 検証予定
平面・斜面・円筒の投影/面沿い、非中央基準点、2点縮尺、回転、不透明度、取消と再編集、
Undo/Redo、元画像削除後の保存再読込、グループ非表示、前後関係、通常/Win95と狭幅を確認。
