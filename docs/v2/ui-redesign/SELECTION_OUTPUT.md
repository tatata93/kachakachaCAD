# 選択出力と共通配置（2026-10-02）

オーナー依頼。WP-11の出力UI、製作の同一／別KCD生成との共通配置。
状態: 仕様・実装中。PC未検証。

- モードに依存しない「選択を出力」。3Dと左一覧の選択を同じ入力へ取り込む。
- 出力対象の名前と種類を表示。混在した非対応対象を黙って除外しない。
- STL、STEP、別KCD2、同一KCDへの独立コピーを選択する。
- STLは三角形の形状出力、STEPはBRepの立体・面・線を保持する。点／線だけのSTLは不可。
- 厚みなしの面は厚みなしと明示する。勝手に厚みを足さない。
- 配置は元の位置（既定）または基準点を指定した面上の位置へ。元形状を変形しない。
- 配置元の向き、配置先の面法線・面内方向から剛体変換する。数値と画面で点を指定する。
- 曲面では配置点の接平面へ剛体配置する。面内方向と法線は数値でも変更できる。
- STL/STEPは独立した回転・拡大可能な3Dプレビュー。保存するものと同じ形状を使う。
- プレビュー・取消は文書とファイルを変更しない。同一文書の確定は1回のUndoで戻す。
- 独立コピーの立体と面はFreezeDerivedのBRepを正本とし、表示三角形を正本にしない。
  ワイヤー・点・作業平面は従来のネイティブ定義で保存する。元への追従なしを明記する。
- 製作の生成にも同じ配置画面を使う。出力モードのみに閉じない。

試験: 選択先行／道具先行、3D／左一覧、混在対象、配置の剛体性、プレビューと出力の一致、
同一KCD Undo/Redo、別KCD保存再読込、STL/STEP内容の再読込、生成側の配置。
