# ねじれ帯の厚み付けの対応範囲

2026-10-11。原点から10mm間隔の2～3列、幅5mm、内側厚み0.8mmの最小形状で検査した。
ねじれ量だけを変え、大きな貨車全体を使わずに原因を切り分けた。

## 対応と安全な拒否

- 平面の折れ帯は、既存の交差面による接合を使う。
- 単一のねじれた双一次面と、法線が滑らかにつながる冗長な分割面は、汎用オフセットを使う。
- 非平面の面が法線の不連続な折れ目でつながる帯は、現在の汎用オフセットでは正しい接合を保証できないため、部品を作らず理由を返す。帯を折れ目で分割して別部材にするか、平面部材へ近似する。

拒否を追加した根拠は、2面の帯の0.0003mmのねじれでも、STEP再読込で体積が
80.239252から63.544353mm³へ変わったこと。既存のSTEP検査はこの出力を正しく拒否した。
STLも細かさ0.002mmで80.3589mm³となり、ソリッドが閉じているという判定だけでは
出力互換性を保証できなかった。誤差の許容値は緩めていない。

OCCTの単純オフセットが、共有された入力の辺へ側面の補助曲線を追加する副作用も見つかった。
計算前にトポロジーと幾何を複製し、入力BRepを変更しないようにした。

## 検証

`v2_kernel_warped_thicken_tests` は、平面折れ帯、0.0003/0.01/0.2mmのねじれ折れ帯、
0.2mmの単一ねじれ面、滑らかな2区間のねじれ面を比較する。
対応する形では、元の面への独立した距離、法線方向の厚み、STEP再読込、
STLの三角形から再計算した符号付き体積を検査する。
元面上のゼロ距離交点を法線交差計算が取りこぼす場合があるため、元面保持は点‐面距離で確認する。
実際の97列の帯についても、拒否後のBRepとキャッシュ数の不変性を確認する。

重い取消試験は、安全に早期拒否されるようになった帯から、参照形状に基づく滑らかな壺へ変更した。
文書読込では、未対応の帯を含む履歴の失敗も元文書・Undo・保存先を置き換えない。
この最小形状の検証は内側0.8mmについてのもので、任意の自由曲面や全厚みの成立を示すものではない。
