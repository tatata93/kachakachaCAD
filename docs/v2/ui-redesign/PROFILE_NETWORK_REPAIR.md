# 輪郭ネットワークの認識修正（2026-10-09）

対象はWP-14の面・押し出し入力認識。115モデルの報告を受け、既存命令の入力解釈を修正する。

- 線の途中へのT字接続、実3D交点、分岐、同一Wire内の非連続部分を調べる。
- 平面上で線に囲まれた小区画を候補にする。行き止まりで閉領域を失わない。
- 曲線は元の種類と形を保持し、認識のための分割で文書の線を書き換えない。
- 平面が異なる線を投影してつながったことにしない。非平面輪郭には面生成・厚み付けの手順を案内する。
- 面生成のおまかせは単一Entityを単一断面と決めつけない。成立しないロフトを推奨する場合は理由と代替入口を示す。
- 内側クリックの候補と確定形状を一致させる。共有線を持つ別領域を黙って追加しない。
- 交差、逆向き、穴、重複線、開線、異なる平面、曲線を含むケースを回帰検査する。

実ファイルと背景画像は読み取り専用で調査し、リポジトリには含めない。
検証結果はTASK_LEDGERへ追記し、未確認の項目を検証済みにしない。

実装上の区別:
- 平面区画は実交点で一時分割し、辺をたどって検出する。円弧・ベジェは曲線のまま保持する。
- 内側クリックはワイヤーIDだけでなく区画の内点を持つ。押し出しは `profileSeeds` を保存する（旧文書は全区画）。
- 面の境界は元のSegment UUIDとパラメータ区間・向きを保存する。元のワイヤー全体へ置き換えて再生成しない。
- 役割推定で成立しない空間線網は、全入力を使える閉区画が得られる場合に限り、区画ごとの面へ切り替える。
  曲面は近似と表示し、カーネルで全区画の生成に成功してから確定する。
- 空間線網の代替推定は既存の24辺上限を維持する。開線や離れた線を捨てて成功扱いにしない。
- 穴へつながる行き止まりの枝は、閉輪を分離して除外する。外周から穴へ飛ぶ不連続な境界を作らない。

範囲: 空間線網の代替生成は独立した閉区画の集合を求める補助。閉じた立体ケージの全フェイス復元を保証しない（従属する閉輪を除外する）。立体化には既存のワイヤー群から部品を使う。

## 2026-10-10 面にするへの接続

`surface.from_lines` も選択ゼロで専用ツールを起動し、3Dの追加・解除ごとに再計画する。Escと取消は入力だけを戻す。失敗した面生成はトランザクションを戻してから場面を再構築し、ツールと入力を保持する。
非連続Wireは各Segmentの実接続を使う既存ネットワーク検出へ接続し、元ワイヤーを変更せず区間参照を保存する。当初の代替検出は自動・G0・24区間・全入力使用に限定していた。以下の「未使用区間と実形状プレビュー」で面にするの条件と選択肢を更新する。
G0外周だけの境界面は、生成できたCoons補間面を再度plate fittingしない。再 fittingが面を大きく折り返すケースを修正。初期Coons用の円弧も四辺面と同じ精度の非有理近似にし、入力偏差の既存検査を通す。内部ガイドやG1/G2を指定した面の拘束は省略しない。
試験: HP-LF-11（帯の実ボタン、追加クリック、Enter、Esc後の再選択）、kernel_fill/segmented_roof_stays_inside_its_boundary_envelope（境界偏差と表示メッシュの範囲）、任意実ファイル用HP-LF-115（生成・Undo/Redo・画像・別名保存）。元ファイルは変更しない。

## 2026-10-10 未使用区間と実形状プレビュー

「面にする」では閉区画を作れた場合、同じWire内の未使用枝があっても区画を提示する。未使用区間の名前・数を棚へ明示し、元の線は保持。役割分類の既存APIは全入力使用条件を維持し、黙って入力を捨てない。連続ポリラインの中間接続にも区間ネットワークを使う。平面の入れ子の輪は穴・島として扱い、穴の線の方向で面積が変わらないようカーネル側でも方向を正規化する。

輪郭だけで成功とせず、確定と同じカーネルで面を計算して3Dに表示する。計算中、下見OK/最大ずれ、生成不可/理由を区別。複数候補では作る面のチェック、作り方、張り方（近似：標準/平坦優先/丸み優先）を変更して比較できる。張り方は四辺面と4辺以上のG0境界面で利用する。各候補は別解の完全列挙ではなく、既存の生成方式の選択肢。境界条件のみで内部形状が一意に決まるとはしない。

計算はイベントループに予約し、処理前に状態を再描画する。バックグラウンド計算ではないため、重いOCCT計算中の操作応答は今後の課題。入力変更・Esc時は予約と一時面を破棄。プレビューでは文書を変更せず、カーネルの一時形状も解放する。24区間上限とG0の範囲は維持する。
