# 押し出しの終端面・中央面までの延長

## 問題と変更

ライトの投影面から中央のフェイスまで押す際、ライトが中央フェイスの有限な境界の外側にあると、従来の「選んだ面まで」は到達しないと判定する。これは距離の不足ではなく、終端面の範囲の問題だった。

「終端の平面を延長して使う」を追加した。平面フェイスを選び、この設定を有効にすると、その支持平面まで押し出す。元の有限面まで止める動作も残す。曲面の延長には使えない。

押し出し・ネイティブフェイス押し出し・曲面押し出しで共通の「終端面の向き」を提供する。自動、元の面と同じ向き、選んだ面と平行、角度入力を選べる。距離と方向から独立した設定で、選んだ基準面の向きは値として保存する。両方向押し出しでは正方向側の終端に適用する。貫通には終端がないため任意角度指定は拒否し、距離か面までを案内する。

今回のライトでは、押す面を選択 → 範囲を「選んだ面まで」→ 中央の平面フェイスを選択 →「終端の平面を延長して使う」を有効 → 終端面の向き「自動」の順で、中央面と同じ位置・角度で終わる。正負の終端オフセットも使える。

- 曲面押し出し：円筒上の輪郭から平面の先端を生成し、位置・体積・境界を確認。
- 保存：新規設定の往復と、既定値を省略して従来サンプルとの互換性を維持。

## 制限

- 終端指定／任意角度の通常押し出し経路はソリッド・面出力を対象とし、独立ワイヤー併出は明示的に未対応とする。
- 曲面を向きの基準に選ぶと、クリック点の接平面の向きになる。
- 曲面押し出しの「元の面と同じ向き」は従来の法線オフセット面。曲がった形をそのまま平行移動する指定とは異なる。
- 複数の非共面輪郭を一括で任意角度の先端にする構成は未対応。対応不能な形状を黙って置き換えない。
