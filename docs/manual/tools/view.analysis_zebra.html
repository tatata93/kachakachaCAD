ゼブラ

具体例: 面のつなぎ目を縞で確かめる

準備

接続する曲面を2枚用意する

操作手順

  1. ゼブラを押す
  2. 境目で縞の向きを確認する
  3. 再度押して解除する

設定: 反射縞の簡易表示

結果を確認

面の膨らみや接続の不連続を見つける手掛かりになる。

取消・やり直し

ダイアログの取消、またはペインの取消を使います。即時操作には未確定段階がありません。 確定済みの文書変更はCtrl+Z、やり直しはCtrl+Yです。保存・書出し済みのファイルはUndoの対象ではありません。

進めない場合

ゼブラ(反射の縞)を入れる・消すを切り替えます。棚は開かないので、面を作りながら

対象欄と3Dの強調を照合し、必要な線・面・部品を各役割へ指定します。処理中は計算表示を確認し、取消が可能な処理は取消を使います。

view.analysis_zebra。図の設定と縮尺は例です。方式ごとの制限、プレビューと確定済み結果の区別を確認してください。
