グリッドを消す

具体例: グリッドだけを消して輪郭を見る

準備

通常線と補助線を用意する

操作手順

  1. グリッドだけ消すを選ぶ

設定: グリッド非表示、補助線は維持

結果を確認

輪郭と補助線が残る。

取消・やり直し

ダイアログの取消、またはペインの取消を使います。即時操作には未確定段階がありません。 確定済みの文書変更はCtrl+Z、やり直しはCtrl+Yです。保存・書出し済みのファイルはUndoの対象ではありません。

進めない場合

グリッドだけ消します。形は変わりません。

対象欄と3Dの強調を照合し、必要な線・面・部品を各役割へ指定します。処理中は計算表示を確認し、取消が可能な処理は取消を使います。

Windows版の操作画面

view.stage_no_grid。図の設定と縮尺は例です。方式ごとの制限、プレビューと確定済み結果の区別を確認してください。
