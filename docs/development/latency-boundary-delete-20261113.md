# 曲面生成・文書読込の待ち時間と境界ワイヤーの削除

## 使い方

「厚み」などでソリッドと境界ワイヤーを同時に生成します。左一覧でソリッドを選び、Deleteを押すと、確認に「同時に生成した境界ワイヤーも削除」が出ます。既定はオフです。オンにするとワイヤーが一覧と3Dビューの赤表示に加わります。元の面と作図ワイヤーは保持します。一回のCtrl+Zで削除を戻せます。

由来はファイル内のIDで記録するので、改名と再読込でも対応します。由来を記録していない旧ワイヤー、および複数のソリッドを作る押し出しで個別の由来を確定できないワイヤーは、一覧で明示的に選び足してください。

## 実測と判断

Windows Release構成。`115投影.kcd2` は複製を使用し、原本のSHA256 `84c716b3e6af1ae8f87da4ee4df92226ef326b03e1e44f8c6ce7f84152125ede` は維持した。個々の値は同一PC・指定の試行の実測で、すべての形状に対する上限ではない。

| 操作 | 比較元 | 変更後 | 条件 |
|---|---:|---:|---|
| 面プレビュー後の確定 | 112 ms | 32 ms | 平面のUI操作。確認済みの面を移し、核の追加生成は1回→0回 |
| 穴付き面プレビュー後の確定 | 60 ms | 29 ms | 内外の輪郭を左一覧からCtrl選択。核の追加生成は1回→0回 |
| 初回読込 | 50.21 秒 | 32.31 秒 | 同一EXEで曲面切り出しの逐次・高速経路を比較。空のキャッシュから開く |
| 内訳：曲面切り出しの交差・接合 | 28.89 秒 | 11.59 秒 | 同じ9回の交差演算。境界距離・形状の検査は維持 |
| 元ファイルを開いた後の厚み付き版 | 78.41 秒 | 23.12 秒 | 旧公開版更新4対、評価再利用の重点確認版。17件の計算済み形状を再利用 |
| 同じ厚み付き版を再度開く | 1.89 秒 | 1.60 秒 | 両方とも文書全体のキャッシュが有効 |

別名にした版の読込は4.88秒で、18件の形状を再利用した。元版・厚み付き版・同じ内容の再読込では、旧公開版と元12/13形状のメッシュSHA256、ID、表示状態とグループを照合した。改名版で変わったエンティティ表示名は1件。曲面切り出しの同一EXE比較でも元12形状の表示メッシュは一致した。

再利用は全定義と参照先、許容差、実装の一致を条件とし、転送結果の内容・形状を検査する。壊れた結果や変更した形状は通常の生成へ戻る。ファイル形式の変更なし。プレビューの再利用は対象と文書が一致している場合だけ行う。

厚みの計算は複雑な入力でおよそ10〜18秒の例が残った。体積積分の重複を省く試作と、自己交差検査の候補範囲を絞る試作は一貫した改善がなく撤回した。既存の安全検査は維持した。

## 重点検証

- `HP-GL-` 6件：穴付き面の下見と確定、取消、別版の読込、破損時の再構築、変更した部品だけの再計算。
- `HP-DEL-` 15件：削除対象の切り替え、取消、元輪郭と元面の保持、改名・再読込、Undo/Redo。
- `HP-LF-` 19件と曲面関連CTest 3件。添付由来ファイルの同条件比較。
