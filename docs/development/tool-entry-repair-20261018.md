# ツール入口の復旧（2026-10-18）

ユーザーの優先指示に従い、詳細マニュアルの増補を保留し、操作可能な配布版の復旧を先行した。

## 原因と修正

- 使用中ツールの再クリックは入力保持だけで終了し、表示設定などへ切り替わった右ペインを復帰しなかった。押し出し等の設定ペインを復帰する。作業面は設定棚を維持する。
- 面編集の再選択でも設定棚を復帰する。面作成中の回転面ボタンは方式切替として扱い、旧プレビューを確定しない。
- ワイヤー全体の角加工には専用の開始経路がなく、3Dクリックによる部分辺がそのまま演算へ渡っていた。辺同士とワイヤー内の角を切り替え、下見と明示確定を揃えた。
- ワイヤー内の角加工は各ワイヤーを個別に評価する。通常の2辺加工は区間選択を保持し、未加工の兄弟区間を残す。ソリッドやサーフェスの境界表示はワイヤー加工に取り込まない。
- 結合・接線接続等の対象待ちで前の作図ツールが残っていた。作図を終了して対象待ちペインを表示し、選択対象・個別解除・全解除・確定・取消を提供する。
- 頂点限定と番号の変更でも角加工の下見を更新し、空入力でもEscを受け付ける。

- 旧作図の未確定点から対象待ちへの移行、対象の追加／個別解除、結合の確定。
- 表示設定から押し出し・作業面・面編集・回転面のペインへ戻す操作、部品だけを選択してワイヤー角加工を開く操作。
