全体表示

具体例: モデル全体を画面に収める

準備

離れた位置に2つの形を描く

操作手順

  1. 全体表示を押す

設定: 表示中の要素が対象

結果を確認

全ての表示形状が画面に入る。モデルの寸法は変化しない。

取消・やり直し

ダイアログの取消、またはペインの取消を使います。即時操作には未確定段階がありません。 確定済みの文書変更はCtrl+Z、やり直しはCtrl+Yです。保存・書出し済みのファイルはUndoの対象ではありません。

進めない場合

見えているものがありません。

対象欄と3Dの強調を照合し、必要な線・面・部品を各役割へ指定します。処理中は計算表示を確認し、取消が可能な処理は取消を使います。

view.fit_all。図の設定と縮尺は例です。方式ごとの制限、プレビューと確定済み結果の区別を確認してください。
