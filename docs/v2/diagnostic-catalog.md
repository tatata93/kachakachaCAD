# 診断コードの台帳


`Diagnostic` の `code` は、画面の文言ではなく **これ** で識別する。
日本語の本文で分岐してはならない。本文は直すが、コードは直さないためである。

**この表とソースが食い違うと `tests_v2/diagnostic_catalog_tests.cpp` が失敗する。**
表に無いコードを新しく使うこと、どこからも出ないコードを表に残すこと、
同じコードを2度書くこと、日本語の一文を空にすること ── どれも機械が落とす。
契約書(geometry-contract.md / fabrication-contract.md)が挙げているコードが
表から消えることも落とす。まだ作っていないものを、消して見えなくしないためである。

「種別」はそのコードを出すときの `Severity`。
場面によってエラーにも警告にもなるコードは、両方を書く。
`未実装` は「契約が定めているが、まだ出すところが無い」印で、
どの作業でいれるかを一文に書く。
