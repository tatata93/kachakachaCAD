初心者向けの進み方

  1. 右上「1 平面」で、作図したい位置と向きを確認します。
  2. 「2 作図」で線・円・断面を描きます。左下の水色欄だけを見れば、次に置く点が分かります。

  4. 板材または治具を選び「4 出力」で1:1図面、STL、STEPを保存します。

3D上の辺を回転軸にする

  1. 「選択」で直線ワイヤーを1本選びます。
  2. 「基準線に設定」を押します。作業平面タブの基準線名が変わります。
  3. 作り方を「軸まわりに回転」にし、「回転軸に使用」を押します。
  4. 基準平面と角度を入力し、「この向きで見る」で確認後、「平面を作成」を押します。

3点は一直線上に置けません。法線ベクトルや軸方向も長さ0にはできません。エラー時は3点または方向値を見直してください。

5. 点グリッド

補助線を大量に描かず、JWCADのような一定間隔の点を目安に作図します。大きい点が主点、小さい点が副点です。主点は狙いやすく、副点は点間隔に応じて弱く吸着します。点へ常時強制的に丸めることはありません。

作図面
「作図」タブ最上部で平面を選び、「正対」。
表示
「点グリッド」の「表示」をオン。
主点間隔
「スナップ」行へ大きい点の間隔。例は 1.00 mm。
副点
主点のみ、1/2、1/3、1/4から選択。1/4なら候補間隔は主点間隔の4分の1です。
数値基準
基準X/Yへ点列の開始座標。車体中心を半ピッチずらすなら両方 0.5 mm。
弱い吸着
「スナップ」をオン。格子点へほぼ重ねると薄い丸が出ます。丸がない位置は自由位置のままです。

図形上の点へグリッドをドラッグして合わせる

  1. 「画面で基準を合わせる」を押します。
  2. 中央画面で、動かしたい大きい主点または小さい副点を左ボタンで掴みます。
  3. ボタンを押したまま、基準にしたいワイヤーの端点または制御点へ移動します。近づくとその点へ正確に吸着します。図形点がない場所へ自由に置くこともできます。
  4. 左ボタンを離します。点列全体が移動し、新しい値が基準X/Y欄へ入ります。
  5. やり直す場合はもう一度実行。途中で止める場合は Esc。原点へ戻す場合は「基準を 0, 0 に戻す」です。

基準値は作図面内のX/Yで、世界座標のXYZではありません。副点が画面上で密集しすぎる倍率では小点だけを一時的に省略します。主点は約4px以内、副点は画面上の点間隔に合わせた約0.75～2.25px以内だけ吸着するため、主点・副点の間にも自由に線を引けます。

交点・端点・作図点へ正確に合わせる

  1. 「スナップ」をオンにします。
  2. 交差する2本の線、既存端点、作図点の近くへカーソルを移します。通常は交点が約7px、作図点・端点が約6px以内で候補になります。
  3. 交点は×、作図点は四角、端点は丸、格子点は薄い小丸が表示されます。構造上の点と格子が同時に候補になる場合は、交点・作図点・端点を優先します。
  4. 記号が出ている間に左クリックすると、その候補の正確な座標を使います。記号がなければクリックした任意位置を使います。
  5. 始点を置く前に右クリックすると、14px以内の交点・作図点・端点だけを広めに探して始点にします。格子点はこの右クリック探索へ含めません。
  6. 候補が近すぎて任意位置を選べない時は、Ctrlを押しながらクリックします。押している間だけ候補表示と吸着を完全に止めます。

右クリックは入力前なら近傍点から開始、入力後なら従来どおりポリライン・スプラインの完了または途中操作の取消です。「作図点」はワイヤーや面にはならない位置基準で、左の一覧から選択・非表示・削除でき、保存して開き直した後もスナップに使えます。

正確な長さ・角度で直線を引く

  1. 「直線」を選び、中央画面で始点だけをクリックします。マウスを動かすと、長さ・角度欄がカーソルのそばへ追従します。
  2. クリックせず、そのまま数字または ( を打ち始めます。入力は自動で長さ欄へ入り、例えば (180/2)*3 は270 mmになります。
  3. Tabで角度欄へ移り、作図面の横を0°、縦を90°として角度を入力します。
  4. Enter。式を計算した実寸の終点で直線が完成します。

使用できる式は + - * / ( )、小数、指数表記、円周率 pi です。入力欄内の Esc は数値編集だけを抜け、続けて Esc を押すと作図全体を取り消します。右パネルの実寸欄も同じ式に対応します。

円弧を両端と半径で決める

  1. 「円弧」を選び、方式を「両端＋半径」にします。
  2. 始点、終点の順に中央画面でクリックします。
  3. カーソルが半径欄へ移るので数値または計算式を入力します。半径は両端距離の半分以上が必要です。
  4. 「左へ膨らむ / 右へ膨らむ」を選び、青い予告を確認して「この円弧を作成」。

始点から方向を決めて円弧を生やす

  1. 方式を「始点＋接線/法線方向」にし、円弧を生やす始点をクリックします。既存線上ならスナップ記号を確認して置きます。
  2. 角度基準を「接線角」または「法線角」にします。角度は作図面の横方向が0°、縦方向が90°です。
  3. 方向角と半径を入力し、円弧量を「中心角」または「円弧長」から選びます。
  4. 「左へ曲がる / 右へ曲がる」を選びます。法線角は選んだ曲がる側の円弧中心を向く方向です。
  5. 青い予告と始点の接線ガイドを確認して「この円弧を作成」。

中心角と円弧長を切り替えると、現在の半径を使って値を相互変換します。入力済みの値は 円弧長 = 半径 × 中心角(rad) の関係を保ちます。既存曲線へ滑らかに追従させ続けたい場合は、作成後に「接線接続」または「曲率接続」も設定します。

作図中の補助操作

  • Shiftを押しながら直線・ポリライン: 水平または垂直へ固定。
  • Shiftを押しながら矩形: 正方形へ固定。
  • Ctrlを押しながらクリック: その点だけ完全にスナップを解除。Ctrl+Shiftなら吸着なしと水平・垂直/正方形拘束を併用。
  • 入力前に右クリック: 近くの交点・作図点・端点を始点にする。
  • 「補助線として作図」: スナップ・寸法基準には使うが、面や切断図へ入れない。
  • Esc または「取消」: 入力中の点を破棄。
  • ホイール・中ドラッグ・右ドラッグ: 作図中も拡大縮小・平行移動できます。

「作図」タブ内で「選択」に戻さず左クリックすると、現在の作図道具の点が追加されます。選びたいときは V を押してください。「面」「出力」など担当外のタブへ移ると、安全のため自動で選択モードへ戻ります。

トリム・延長を続けて使う

  1. 編集タブで「トリム」または「延長」を選びます。事前選択は不要です。
  2. 中央画面で対象の線・曲線へマウスを置きます。トリムは消える区間が赤、延長は増える区間が緑になります。
  3. 予告が正しければ左クリックします。道具は終了しないため、別のワイヤーも続けて処理できます。
  4. 終了は右クリックまたは Esc。間違えた操作は1回ごとに Ctrl+Z で戻せます。

境界には、現在の3D画面に表示されている線・曲線を使い、画面上の見かけではなく実際の3D位置で交差を求めます。トリムで2交点の間を指すと中央区間だけが消えて2本へ分かれ、端側を指すと最寄り交点まで短くなります。延長は指した側の先で最初に交わる有限ワイヤーまで伸びます。

直線、開いたポリライン、円弧、ベジェ、B-splineを元の種類と精度を保って処理します。円は2交点でトリムして円弧にできます。円そのものの延長と、閉じたポリラインの直接トリムはできません。投影線・板厚位置線は派生元の平面図を編集します。

複数線をまとめて処理

  • 結合: 端点がつながる直線・ポリラインを順番に複数選択し「結合」。
  • 2線を交点まで: 交わる、または延長すれば交わる直線を2本選び「2線を交点まで」。両方を同じ交点へトリムまたは延長します。
  • 一致解除: 関係のあるワイヤーを選び「一致解除」。付随する滑らか接続も解除します。
  • 滑らか解除: ワイヤーを選び「滑らか解除」。端点一致は残し、G1/G2だけ解除します。

17. 1:1図面・展開図・3Dモデルを出力する

作業平面の1:1 SVG / DXF

実行

用途
平らなプラ板・紙への印刷、レーザー加工、他2D CADへの受け渡し。単位mm、1:1です。

選択板材の1:1展開図

  1. 板材を1枚選び、「形状に合わせて展開を補正する」をオンにします。
  2. 「組み立て方」で「一枚を優先（無理な箇所は分割）」または「部品へ分割して接着」を選びます。二方向に丸い板は伸縮なしの一枚展開が成立しないため、前者でも組立可能な片へ自動的に分かれます。
  3. 「切れ目の方向」で、上下へ走る「縦だけ」、左右へ走る「横だけ」、最も細かく追従する「縦横を併用」を選びます。加工を簡単にするなら片方向、形状精度を優先するなら併用から試します。
  4. 「立体再現度」を1から10で指定します。低い値は部品と折り目が少なく加工が簡単になり、高い値は数を増やして元形状へ近づけます。
  5. 丸い角、フィレット、円錐状の収束を切れ込みで寄せる場合は「必要箇所のV字切れ込みを許可」をオンにします。分割部品にも適用されます。
  6. 切れ込み形状は「鋭いV字」または「形状追従の曲線切れ込み」を選びます。曲線方式はVの谷底へRを付ける機能ではなく、元曲面上の経路を展開して左右の切断辺そのものを曲線にします。
  7. 「切れ込み深さ」は外周から部品幅の何%まで切るか、「V字の開き角」は閉じたときに絞る量、「切れ込み曲線追従」は元曲面の曲がりを切断辺へ反映する割合です。
  8. 通常の折り目・切れ込み間隔は立体再現度から自動決定されます。刃物や材料の都合で間隔を固定するときだけ「折り目・切れ込み間隔を個別指定」をオンにします。
  9. 緩い曲面へ切れ込みを増やしたくない場合は「反応する最小曲がり」を大きくします。まず2°から確認してください。
  10. 「組立3Dで折り目・切れ目を表示」と「展開から組立まで3D表示」をオンにします。「組立過程」を0%へ動かすと平面、途中は折り上げ中、100%は元形状へ合う完成位置です。パネルは折り線を軸に剛体回転し、途中で辺の長さは変わりません。
  11. 3Dモデルを回し、角張り、隙間、窓・ライト穴との干渉を確認します。開口内のパネルは組立表示と3D出力から除かれます。
  12. 必要なら手動分割線を追加します。手動分割後も各部品内の必要箇所へ曲線切れ込みを生成できます。
  13. 直接切断データなら「展開SVG」または「展開DXF」。紙へ印刷するならA4/A3とページ重なりを指定して「1:1 PDF」。
