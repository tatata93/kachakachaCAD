# INVENTOR_PROCEDURE — 作図の道具を Inventor のスケッチの手順と突き合わせる

オーナー指示(2026-09-23): 「作画に用いる機能はすべて Inventor と同じことが同じ手順でできるようにしろ」。
この表は、作図モードの道具 1 つずつについて **Inventor のスケッチでの手順** と **この CAD の手順** を並べ、
違いを直した順に記録する。STATUS: SAME(同じ手順)/ FIXED(この指示で直した。commit)/ DIFF(まだ違う。どこが)/
NONE(Inventor に無い道具。そのまま)/ BLOCKED(作れない。理由)。

Inventor の手順は「道具を押す → 線の上にポインタを置くと結果が先に見える → 押すと作られる → 道具は構えたまま
(Esc / 右クリックの完了 で終わる)」が骨格。この CAD もこの骨格にそろえる。

## GPT版の面生成（2026-09-24）

NONE: オーナー指定の独立した面生成入口。帯でGPT版を押す → 外周/内部線または断面を拾う →
一覧で調整 → 面のプレビューと標本偏差 → 確定。取消は文書を変更しない。
Inventor同等との主張はしない。詳細は [GPT_SURFACE.md](GPT_SURFACE.md)。

2026-09-25: GPT版は外周/内部線の自動判別を既定とし、候補切替と番号・色・矢印からの修正を追加。Inventorとの対応はNONEのまま。

## 製作近似 GPT版（独立追加）
製作の近似帯でGPT版→形状ガイドの面を押す（事前選択も可）→許容偏差・部材数・最小幅・方向→下見→確定。
型紙まで進む場合は「確定して型紙へ」。未達なら確定できず、最大/RMSと条件変更の案内を表示する。
既存の近似方式やInventorの展開をそのまま使う機能ではなく、独立した柱面への近似。

## 近似の間隔を自動調整
製作→近似で従来の帯近似またはGPT版を開き、「間隔を自動調整（急な曲がりを細かく）」をオンにする。従来版は指定枚数（0なら許容から自動）、GPT版は最大部材数を指定し、最小幅と偏差を確認して近似する。手動境界との併用は拒否。上限に達しても等間隔へ戻さず、未達の偏差を表示する。

枚数指定の帯近似は最小幅より細くても下見を出す。警告の実幅を確認して確定するか、枚数を0にして幅優先に切り替える。候補Cは角と枚数指定によらず1枚の比較用。

## 近似から選択部材を生成する（2026-09-30）
近似の確定時にワイヤー／近似面も欲しい場合は「確定時」の欄を指定する。後から生成する場合は、
対象部材を3Dで選ぶか番号を指定し、曲げ状態を当て、「生成するもの」と「生成先」を選んで現在状態を生成する。
対象部材が空なら全体、別kcd2なら生成物だけを独立保存する。短辺も含む閉じた輪郭を生成する。

## 2026-10-06 全ツールの操作統一（オーナー指定・進行中）
対象は連続操作だけでなく、事前選択、対象の追加・解除、部分要素の選択、
数値入力、プレビュー、反転、適用、右クリックまで全CommandCatalogとする。
Inventorに対応する操作は公式手順に合わせる。製作近似・画像・説明書など固有の操作も
同じ「対象→条件→下見→適用」の原則に揃える。Escはオーナー指定を優先して道具を維持する。
まず丸め後の別角で未選択の辺や画像を失う経路を修正する。対象外の幾何・画像を
変更せず、半径を維持して次の角を選べること、取消・Undoで復元できることを受入条件にする。
同じ編集経路を使う面取り・分割・接続・変形も部分選択の保持を検査する。
全ツールの一致は未確認。個々の実装・試験結果を記録してから一致と判定する。
参考: [Inventor 2026 2D形状・丸め・面取り](https://help.autodesk.com/cloudhelp/2026/ENU/Inventor-Help/files/GUID-D489CE6D-7299-4211-A43A-F3580A4BA357.htm)
（半径を維持して続けて対象を選ぶ。InventorのEsc終了だけは本製品の指定と異なる。）


### 共通操作の入口（2026-10-06追加決定）
- 上部バー・メニュー・右ペインのツール一覧は同じ起動経路を使う。実行中の同じツールを選び直しても確定しない。選んだ対象と設定を保つ。
- 右クリックは全ツールでコンテキストメニューを開く。開いただけでは入力取消・測定消去・確定・ツール終了を行わない。
- メニューの「適用」はEnter、「入力を取り消す」はEscと同じ経路。「ツールを終了」は明示的に選択へ戻す。
- 作図中は直前の点を戻せる。測定では明示的な「測定をクリア」を使う。
- 候補が重なるときは候補一覧も保持する。メニューを閉じただけでは選択集合を変えない。
- 各ツール独自の役割（輪郭、軸、終端など）、数値、向き、プレビューは維持し、入口と確定を混同しない。
- 既存の内部実行APIとUI起動を区別する。内部の確定処理をツール選択ボタンから直接呼ばない。
参考: [Inventorプロパティパネル](https://help.autodesk.com/cloudhelp/2027/ENU/Inventor-Help/files/GUID-3E5505B9-9F60-43A0-BF32-97D183B91A70.htm)、
[Inventor右クリックメニュー](https://help.autodesk.com/cloudhelp/2026/ENU/Inventor-Help/files/GUID-4B081B74-45EA-451E-84BE-9FFE0E2ACAE3.htm)。
放射状のマーキングジェスチャー、個別ツールの未達操作は別途検証し、この変更だけで全機能一致とはしない。

### 曲面上の輪郭を盛り上げる・辺を加工する（2026-10-06）
- 部品→作成→曲面押し出し。支持面→閉じたワイヤーを選び、高さを入力。高さ反転は1ボタン。
- 抜き勾配と斜め押し出しは独立ボタン。両方有効にできる。斜め方向は作業面基準の方位を指定。
- プレビューを更新してEnter。取消は設定を残して対象入力を消す。確定後も次の支持面を選べる。
- フィレット/面取りでは辺を複数追加、再クリックで解除。半径/距離を変更し下見後確定。
- どちらも面＋ワイヤー、ワイヤーのみ、立体のみの生成を選ぶ。ワイヤーのみは元の立体を変更しない。
- 曲面押し出しの補間は近似。独立固定形状であり、Inventorの履歴パラメータ編集とは異なる。
- 1支持面・1閉輪郭。穴/複数面/鋭角の抜き勾配、可変半径フィレット/非対称面取りは未対応。
参考: [Inventor Emboss](https://help.autodesk.com/cloudhelp/2024/ENU/Inventor-Help/files/GUID-E6848555-B274-4858-8401-84E260771E84.htm)、
[Inventor Fillet](https://help.autodesk.com/cloudhelp/2025/ENU/Inventor-Help/files/GUID-590A8760-FFBB-41C8-8169-6B7002207884.htm)。

### 2026-10-06 合意した作図面と加工平面の分離
新規作図は現在の作図面を保持し、Esc・編集・確定で解除しない。既存の線の編集・測定・変形では作図面外の対象を選択できる。形状自身から平面が定まるR/C・トリム等はその幾何で計算し、作図面を切り替えない。
オフセットは対象から加工平面を自動推定。一直線で一意でない場合は現在の作図面の向きを候補とする。適合しなければ右ペインで現在面／登録済み平面を選び、3Dの結果を確認して確定する。非平面の入力は投影してごまかさない。任意平面を使う場合も作図面の変更は不要。
移動・回転・測定は作業面選択を前提にしない。回転軸、投影先、平面までの終端など操作そのものの入力は引き続き明示する。フェイスで作図は既存の専用操作を維持。

### 2026-10-07 小数入力と格子への吸着
寸法欄は入力途中の0や小数点を値として即時反映しない。Enter/Tab/欄を離れることで適用し、値を変更したEnterではプレビューを確認してから次のEnterで形状確定する。格子の吸着は最大4 logical px、表示間隔の30%以内に限定し、保持余裕も小さくする。端点・交点の吸着範囲とSキーによる一時解除は維持する。

### 2026-10-09 分岐した曲線から面・押し出し
