# ADR 0012: 二方向曲面は切断可能な紙片へ分けて展開する

## 背景

二方向に曲がる面は、伸縮なしでは一枚の平面へ正確に展開できない。従来は一枚の格子を近似展開した後に切れ目を描いていたため、切れ目を増やしても展開誤差と外周は変わらず、実際のペーパークラフト部材になっていなかった。

## 決定

- 元の板材は面、板厚、開口、投影ワイヤーの関係で保持し、三角形を主編集対象にしない。
- 展開時だけ一時的な折りメッシュを作る。
- 利用者が縦、横、縦横併用から切断方向を選ぶ。片方向は帯、併用は組立可能な小片へ分ける。
- 各帯内部の三角形接続は木構造として展開し、辺長を保つ。
- 立体再現度1から10を、帯幅と折りメッシュ密度へ変換する。高い値ほど紙片と折り線が増える。
- 登録済み開口が複数の片を横切る場合は片ごとに切断輪郭を分け、組立3Dでは開口内のパネルを除く。
- 任意の投影ワイヤーを分割線として登録できる。線が横切る折り接続を切り、独立した紙片へ分ける。
- 途中で止まるスリットは従来の展開切れ目として別に保持する。
- SVG、DXF、PDF、CAD内の展開3Dモデルは、すべての紙片外周を出力する。
- 平面0%から完成100%まで、木構造の折り線を軸に各パネルを剛体回転する。途中状態でも辺長を変えない。
- スライダーの任意位置を局所板厚付きの板へ変換し、全片または選択した一片だけをCADモデル、STL、STEPへ出力できる。

## 結果

再現度と工作量の交換条件を利用者が明示的に選べる。自動分割後も元の3D板は変更されず、必要な位置だけ手動分割線で調整できる。展開用三角形は通常は派生表示に留め、「この曲げ状態を3Dモデル化」を実行した場合だけ通常の三角形輪郭・平面・板として保存するため、ワイヤーと面を中心に編集する製品方針も維持される。
