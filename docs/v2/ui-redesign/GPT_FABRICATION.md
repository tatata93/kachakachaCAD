# 製作近似 GPT版

2026-09-25 オーナー指示: 既存の近似とは独立したGPT版を製作モードへ追加する。
対象工程は完成形の面から、切って一方向に曲げられる少数の部材と型紙を得るところ。
元の面・線は変更しない。表示三角形を近似入力や型紙の正本にしない。

## 操作と生成

製作 → 近似 → GPT版。面を選び、許容偏差・最大部材数・最小幅・板厚を指定する。
自動は二方向の候補を比較し、許容内・部材数・最大偏差の順に選ぶ。方向は手動で選べる。
B-Rep上の内点と本来の外周を読み、各部材を一方向曲げ可能な柱面へ近似する。
外周を矩形に置き換えず、型紙では断面の実長と母線方向の長さを保持する。
最大/RMSの標本偏差と部材数を下見に表示し、許容未達では確定不可とする。
離れた候補や対応不能な入力を無視しない。入力変更は下見を無効化する。
確定は1回のUndo。CreateFabricationModelDefinition.method=2として元面UUIDと条件を保存し再生成する。
既存の方式0/1へ落とさない。型紙配置・SVG/DXF等の出力経路は共通データへ接続する。

柱面は断面曲線と母線方向が正本。組立率は断面の接線角を積分して変え、座標の線形補間をしない。
二重曲率の残差を隠さず、必要な分割を追加する。限界に達したら部材数・幅・許容の変更を案内する。
自動の多数の小片化はしない。開口や複雑な外周を安全に対応できない条件は理由付きで拒否する。
外部AI通信はない。「GPT版」は独立した算法と操作の名称。

## 受入

AT-GPT-F001: 平面・柱面・二重曲率・非矩形外周の部材と型紙、最大/RMS、部材上限と最小幅。
AT-GPT-F002: 下見/取消で文書不変、確定/Undo/再読込の一致、型紙出力、0/30/100%の実長。
HP-GPT-F01: GPT版の入口から面選択・下見・確定・保存再読込・型紙までのWindows画面試験。
未達・非対応範囲と実施した検証環境はTASK_LEDGERと引継ぎへ記録する。
