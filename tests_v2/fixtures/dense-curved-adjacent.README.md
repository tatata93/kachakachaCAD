# 隣接する密な曲面ソリッド

`dense-curved-adjacent-right.kshape` と `dense-curved-adjacent-left.kshape` は、
利用者の添付モデルから通常のUIで作成・厚み付け・切欠き加工し、独立コピーした
2部品の、Boolean workerへ実際に渡された未変更のBRep本文である。
表示メッシュや名前、元ファイルのパスは含まない。

2026-11-08の更新7で、この2個を選び「足す」を使う実UI操作が180秒上限に達した。
結合と整理は約2秒だが、C0連続性で分割した検査用コピーが体積照合に失敗し、
元の高次数スプラインの自己交差検査へ戻っていた。元のノットで先に分割した
解析コピーは、同一の閉鎖性・体積・外形・自己交差の検査基準を満たす。
保存する形状は検査用コピーへ置き換えない。

回帰試験は実入力の結合、回転・移動と入力順序反転、時間上限、単一連結性、
元BRepのバイト不変、STEP出力を確認する。自己交差・開いた殻・反転・
非連結・複数工具・曲面上の矛盾した空の共通部分は既存の負例も継続する。
