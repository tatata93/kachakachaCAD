# 近似の分割間隔を自動調整（2026-09-29）

対象は従来の帯近似とGPT版近似。既存命令の設定として追加し、新命令は増やさない。
`adaptiveSpacing` を保存する。省略時は false とし、既存ファイルの結果を維持する。

オンでは近似偏差の大きい区間を優先して二分する。急な曲がりを細かく、緩い領域を広く残す。
最小幅と最大部材数を守り、上限で等間隔へ戻さない。従来版の指定枚数はこのモードでは
不等間隔で配分する枚数となる。0なら許容偏差まで増やす。角での境界は保持する。
手動境界との併用や、角・最小幅・指定枚数が両立しない条件は理由を表示して拒否する。
GPT版は標本偏差と接合隙間を評価し、許容未達の確定を拒否する従来の条件を維持する。
近似であり、偏差の標本値を全域の保証とは呼ばない。

受入試験: 局所的な急曲率で不等間隔となること、同じ部材数で偏差が改善する例、
最小幅/上限/手動境界の扱い、保存・再読込、両方の棚、型紙と組立の回帰試験。
