# V2で物を作る手順

プラ板と紙から鉄道模型を作るまでを、押すボタンと入れる数字の順に書きます。
各工程のあたまに **「なぜそうするか」** を置きます。
そこを飛ばすと、断られたときに何を直せばよいか分からなくなります。

この文書は実装と一緒に更新します。**まだ画面から押せないところは、そう書いてあります。**
できないことを、できたことにしません。

---

## 0. いま何が動くか

| 工程 | 画面から通しでできるか |
| --- | --- |
| 1. 縮尺を決める | **できます**(「数」の棚で分母と実寸を入れると模型の寸法が出ます) |
| 1b. 数を決める(板厚・面取り量・型紙の余白) | **できます**(式が書けます) |
| 2. 基準を置く(作業平面・グリッド) | **できます**(標準面3つ、グリッドの刻みと原点) |
| 3. 作図(線を引く) | **できます** |
| 4. 直す(分割・結合・端点一致・接線/曲率接続・面取り・丸め・トリム・延長・面へ投影) | **できます** |
| 4b. 測る | **できます**(長さ・半径・両端・2本の間の距離と角度) |
| 4c. 見え方(正対・表示設定・作業中グループ) | **できます** |
| 5. 形をつくる | 押し出し・かごから部品・形状ガイド(断面ロフト)・**足す/引く** ができます |
| 6. 製作(部材へ割る) | **平らな部品と、展開できる曲面(形状ガイド)ができます**。伸ばさないと平らにできない面は断られます |
| 6b. 固定(作り方への依存を切る) | **できます** |
| 7. 型紙と書き出し | **できます**(ワイヤー・型紙・部材・部品・文書。立体は STL / STEP) |

**台帳のコマンドは全部つながりました。**
「まだ入っていません」と言うものは1つもありません
(自己診断の「未接続のコマンドが1つも無い」が毎回それを確かめます)。

**押せないコマンドは、隠さずに灰色で見せ、理由を出します。**
たとえば何も選ばずに「押し出し」を押すと「閉じた輪郭を1つ以上選んでください。」と出ます。
選び直すと、押せる形は **すぐ付いてきます。** 押し直す必要はありません。

押せない理由は、こう出ます。

```
閉じた輪郭を1つ以上選んでください。
```

**黙って何も起きない、ということはありません。** 押せたのに動かないのが
いちばん困るので、必ず理由を言います。

## 1. 縮尺を決める

### 思想

**実物の寸法から始めます。** 模型の寸法から始めると、あとで縮尺を変えたときに
全部を測り直すことになります。実物 20000mm を 1/87 にすると 229.885…mm です。
この端数を丸めないでください。丸めた瞬間、隣の部材と 0.1mm 合わなくなります。

この道具は **原寸(mm)で持ちます。** 型紙も原寸で出します。
「紙に入らないから縮める」ということはしません。縮めたら型紙ではありません。

### 手順

1. 実物の寸法を書き出す(例:全長 20000、車体高 3000、窓幅 1200)
2. 縮尺の分母で割る(1/87 なら 87)
3. 割った値をそのまま入力する

電卓は要りません。**数値入力の欄に式が書けます。** `20000/87` と打てば
`20000/87 = 229.8850574713 mm` と出ます。全角で打っても通ります。

割り算を手で書かなくても、右の「数」の棚に
**縮尺の分母** と **実寸** を入れれば、その下に模型の寸法が出ます。
手で計算していると、桁を1つ間違えても気づけません。

**縮尺は 1:1 PDF にも刷られます。** 刷った紙だけを見た人にも伝わるようにです。

## 1b. 数を決める

### 思想

**変えられない数は、使えないのと同じです。**
押し出しの厚みが 0.5mm の決め打ちだったころ、プラ板を使い分けられませんでした。

守っていることが3つあります。

1. **式で書けます。** `0.3*2` も `20000/87` もそのまま通ります。
   電卓を出して打ち直すと、打ち間違いが混ざります。
2. **範囲の外は断ります。** 板厚 0mm は切れないし、100mm はプラ板ではありません。
   **黙って近い値へ寄せません。** 寄せると、頼んだ値と違う物が出来ます。
3. **断っても前の値は消えません。** 打ち間違えた瞬間に値が消えると、
   何だったか思い出せなくなります。

### 手順

右の「数」の棚で、値の欄を直接打ち替えます。

| 名前 | 既定 | 範囲 | どこに効くか |
| --- | --- | --- | --- |
| 板厚(押し出しの距離) | 0.500 | 0.05〜20 mm | 「押し出し」で出来る部品の厚み |
| 面取り量 / 丸め半径 | 1.000 | 0.01〜100 mm | 「C面取り」「R丸め」の量 |
| 型紙の余白 | 5.000 | 0〜50 mm | 「選んだワイヤー」を出すときの紙の余白 |
| 展開で許すずれ(mm) | 0.100 | 0.001〜5 mm | 曲がった面を平らにするときの許容。**通るか通らないかを決めます** |
| 縮尺の分母(1/◯) | 87 | 1〜1000 | 模型の寸法の計算と、**1:1 PDF に刷る縮尺の注記** |
| 実寸(mm) | 20000 | 0〜1000000 mm | 模型の寸法の計算 |

いちばん下の **「= 模型の寸法」** の行は、打ち替えられません。
上の2つから計算して出るだけの行です。
`17500+2500` のように式で打てるので、図面から読んだ寸法をそのまま足せます。

範囲の外を打つと、帯と「知らせ」に `UI-P002` と、
**どこからどこまでか** と **なぜその範囲なのか** が出ます。

## 2. 基準を置く

### 思想

**線は必ずどこかの平面の上にあります。** 平面を決めずに引くと、
あとで「この線はどの面の上か」が誰にも分からなくなります。
V1はここが曖昧で、面を張ろうとして初めて食い違いに気づくことがありました。

起動した直後は **XY平面**(床)が作業平面になっていて、グリッドが出ています。
側面図を描くなら、下の「作業平面を作る」で YZ を出してください。

### 手順

**作業平面を作る** — 「基準(P)」→「作業平面を作る」

押すたびに標準面が1つできて、そのまま作業中になります。
押す順に **XY(床) → YZ(側面) → ZX(正面)** と回ります。

側面図を描きたいなら、YZ が出るまで押してください。
作った平面は **文書に入ります。** 画面の飾りではないので、保存すれば残ります。

**作業中の平面を切り替える** — 平面を選んでから「基準(P)」→「作業平面を使用」

**選ばずに押すと「作業平面を1つ選んでください。」と出ます。**
どれを作業中にするのかは、選ばないと決まりません。

**グリッドの刻みを変える** — 「基準(P)」→「グリッド」

押すたびに **1 → 2 → 5 → 10 → 20 mm** と回ります。模型でよく使う刻みだけです。

**グリッドの原点を動かす** — 「基準(P)」→「グリッド原点を移動」

押すと、帯に「動かす先を1回押してください」と出ます。
**画面を1回押すと、そこへ原点が移ります。** Esc でやめられます。

原点を動かすのは、部品の角を (0, 0) にしたいときです。
そうしておくと、寸法をそのまま図面から読み写せます。

グリッドは **文書に入りません。** 見え方の都合だからです。
入れてしまうと、保存したものを開いた相手の画面のグリッドまで変わってしまいます。

- グリッドは既定で **10mm間隔**、副点は **1/2**(=5mm)です
- 画面を拡大縮小するとグリッドの見え方が変わります。
  **副点は画面上で 6px より狭くなると自動で消えます。**
  出したままにすると点が多すぎて、どれに吸着したのか分からなくなるためです

### 数字を変えると何が変わるか

| 変えるもの | 変わること |
| --- | --- |
| グリッド間隔 10mm → 5mm | 吸着できる位置が倍に細かくなる。拡大しないと副点が消える |
| 副点 1/2 → 1/4 | 主点の間に3点入る。より細かい位置に吸着できる |

## 3. 作図(ここは通しでできます)

### 思想

**曲線は曲線のまま持ちます。** 円弧を折れ線にしません。
折れ線にすると、型紙に出したときに角ができ、切ったときに分かります。
円は円のまま、B-splineはB-splineのまま最後まで持ちます。

もうひとつ。**引いた線は、すぐ次の吸着の相手になります。**
V1はここが繋がっておらず、引いたばかりの線の端点に吸着できませんでした。

### 3-1. 直線を引く

1. 道具箱の **「直線」** を押す(または `L`)
2. 画面をクリック → 1点目が置かれる
3. マウスを動かす → 途中の形が破線で出る
4. もう一度クリック → 線が確定する

### 3-2. 長さと角度を数字で決める

2点目を置く前に **数字を打ち始めてください。** カーソルの横に入力欄が出ます。

作業平面の上では、欄は4つです。

| 欄 | 意味 | 主要欄 |
| --- | --- | --- |
| 長さ | 1点目からの距離 | **○(最初にここへ焦点が来ます)** |
| 平面内角度 | 作業平面の上での角度(度) | |
| du | 平面の横方向の差 | |
| dv | 平面の縦方向の差 | |

作業平面の外では7つ(長さ / dX / dY / dZ / 世界Xとの角度 / Y / Z)になります。

- `Tab` で次の欄、`Shift+Tab` で前の欄
- `Enter` で確定、`Esc` でやめる
- 式が書けます。`(180/2)*3` → `(180/2)*3 = 270 mm`

**大事な決まり:確定した欄はマウスで動きません。** 打っている途中の欄も動きません。
動くのは、まだ触っていない欄だけです。
「長さを決めて、角度だけマウスで探す」ができます。

### 数字を変えると何が変わるか

| 入れる | 起きること |
| --- | --- |
| 長さ `40` だけ | 40mmの円周上をマウスが動く。向きだけ探せる |
| 長さ `40` + 角度 `30` | 完全に決まる。マウスを動かしても変わらない |
| du `30` + dv `40` | 長さ50mm・角度53.13度に自動で決まる |
| 長さ `40` + du `50` | **断られます**。40mmの線でdu50mmは作れない |

最後のとき、こう出ます。

```
UI-C005 その長さでは形が決まりません。
```

**最後に変えた欄だけが確定しません。** 全部消えるわけではないので、
その欄だけ打ち直してください。

### 3-3. 吸着

近くに端点・中点・交点・中心があると、そこへ吸います。何に吸ったかは名前で出ます。

- `Shift` を押している間だけ吸着が止まります
- 吸着の範囲は **高優先6px・低優先8px** です(画面上の距離)

### 3-4. 途中でやめる・戻す

| 操作 | すること |
| --- | --- |
| `Esc` | いま置いている点を全部捨てる。**文書は変わりません** |
| `Backspace` | 1つ前の点だけ消す |
| `Ctrl+Z` | 確定した操作を1つ戻す |
| `Ctrl+Y` | やり直す |

### 3-5. 円・円弧

- **円**(`C`):中心をクリック → 半径。欄は「半径」「直径」。どちらか入れれば決まります
- **円弧**(`A`):3点。欄は「半径」「中心角」「円弧長」

半径 `20` と中心角 `90` を入れると、円弧長は自動で `31.4159…mm` になります。
逆に円弧長 `31.4159` と半径 `20` を入れれば中心角が決まります。
**3つのうち2つを決めれば残りが決まります。3つとも矛盾させると断られます。**

### 3-6. 選ぶ

1. 道具箱の **「選択」**(`Esc`)
2. 線をクリック

| 押しかた | すること |
| --- | --- |
| そのまま | それだけを選ぶ |
| `Shift`+クリック | 足す |
| `Ctrl`+クリック | 入っていれば外す、無ければ足す |
| `Alt`+クリック | 外す |

**選んだ順は変わりません。** これは形状ガイドの役割が選んだ順で決まるためです。
順が変わると、作られる面が変わってしまいます。

## 4. 視点

### 思想

**視点を変えても文書は変わりません。** 見る向きを変えただけで形が変わったら、
何を作っているのか分からなくなります。

### 手順

右上の操作板を使います。2系統あります。

**輪(3本、視点に追従して傾く)** — モデルの軸まわりに回します。

| 輪 | 軸 |
| --- | --- |
| 赤 | モデルのX |
| 緑 | モデルのY |
| 青 | モデルのZ |

**輪は線のどこを押しても掴めます**(線から5px以内)。矢印を狙う必要はありません。
押した場所に近いほうの向きへ回ります。

**画面基準の矢印(位置は動かない)**

| 場所 | すること |
| --- | --- |
| 下の2つ | 左へ・右へ回す |
| 右の2つ | 上へ・下へ回す |
| 上の2つ | 画面のまま回す(ロール) |
| 左上の家 | 等角ビューへ戻す |

キューブの面(上/下/前/後/右/左)を押すと、その面に正対します。

### 数字を変えると何が変わるか

| 操作 | 回る量 |
| --- | --- |
| 押して離す | 15度 |
| 押したまま引きずる | 1pxあたり 0.25度 |
| `Shift`+引きずる | 1pxあたり 0.05度(細かい) |
| `Ctrl`+引きずる | 1pxあたり 1度(粗い) |

**離した瞬間に近い向きへ吸い付きません。** 89度まで回しても90度へ寄せません。
「だいたい合っている」を勝手に「ぴったり」にしないためです。

`F` で全体表示になります。

### 3-7. 線を直す

線を **選んでから** 「編集操作(W)」のメニューを押します。**選んだ順に意味があります。**
1本目が「直す線」、2本目以降が「相手」です。

| 操作 | 何が起きるか | 要る本数 |
| --- | --- | --- |
| 分割 | 1本目を、相手との交点で切り分ける | 2本以上 |
| 結合 | つながっている線を1本の並びにする(向きもそろえる) | 2本以上 |
| 端点一致 | 近い端どうしを**中点で**合わせる。両方が同じだけ動く | 2本 |
| 接線接続 | つなぎ目で向きがそろっているかを見る | 2本 |
| 曲率接続 | さらに曲がり具合もそろっているかを見る | 2本 |
| C面取り | 角を平らに落とす | 2本 |
| R丸め | 角を円弧で丸める | 2本 |

**片方だけを動かしません。** 端点一致は両方を半分ずつ寄せます。
片方だけ動かすと、その線だけが設計からずれるためです。

**種類を変えてまでそろえません。** 直角に交わる2本を接線接続しようとすると断ります。

```
GEO-E013 つなぎ目で向きがそろっていません。
接線接続にするには、つなぎ目で向きがそろっている必要があります。
いまは 90.0 度ずれています。先に片方を回すか、丸め(R)でつないでください。
```

**何度ずれているかを言います。** 言わないと、どれだけ回せばよいか分かりません。

円弧やB-splineの端は動かしません(`GEO-E011`)。端を引っぱると途中の形まで
変わってしまうためです。先にトリムか延長で長さを合わせてください。

使い切った線は消えます。ただし **下流で使われていたら消しません。**
そのときは表示だけ消して、形は残します。黙って消さないためです。

### 4-8. トリム / 延長(**できます**)

**思想。** どこを切るか、どちら側へ延ばすかは **押した場所で決まります。**
選んだものだけでは決まりません。だから **1回だけ押す場所を聞きます。**

聞いている間は帯に「押してください」と出ます。
**黙って待ちません。** 黙って待つと、押しても何も起きないように見えます。
**Esc でやめられます。** やめられないと、押すまで何もできなくなります。

1. 線を2本選ぶ。**1本目が直す線、2本目が境界** です
2. 「トリム(X)」または「延長(E)」を押す
3. 帯の指示にしたがって1回押す
   - トリム: **捨てる側** を押す
   - 延長: **延ばしたい端の近く** を押す
4. 1本目だけが直ります。**境界にした線は残ります**

### 4-8b. 動かす / 複製する / 鏡に映す / 回す(**できます**)

**思想。** どれだけ動かすか、どこを鏡にするか、何度回すかは
**画面で点を置いて示します。** 数字を先に決めさせません。
プラ板の上で「ここからここまで」と指すのと同じ形にしてあります。

**元の線を残すかどうかは、道具ごとに決まっています。**
残すかどうかを毎回聞くと、押し間違いが増えます。

| 道具 | 置く点 | 元の線 |
| --- | --- | --- |
| 移動 | 2点(どこから、どこへ) | **消えます** |
| コピー | 2点(どこから、どこへ) | **残ります** |
| ミラー複製 | 2点(鏡にする線) | **残ります** |
| 回転 | 3点(中心、始まりの向き、終わりの向き) | **消えます** |

1. 動かしたい線を選ぶ
2. 道具箱から「移動」「コピー」「ミラー複製」「回転」のどれかを押す
3. 表のとおりに点を置く
4. 置き終わった瞬間に変わります。帯に「移動: 20mm」のように出ます

**鏡と回転の向きは、いまの作業平面で決まります。** 視点ではありません。
視点で決めると、画面を回しただけで結果が変わってしまいます。

**断られかた。**

- 同じ場所を2回押した → 「動かす距離がありません。」
- 鏡の2点が同じ場所 / 作業平面に垂直 → 「鏡の線が決まりません。」
- 中心と重なる点を置いた / 向きが同じ → 「回す角度が決まりません。」

どれも **何も作らずに断ります。** 0mm 動かしたことにはしません。

**Shift を押しながらだと、移動とコピーは水平・垂直に固定されます。**

**掴んで動かすこともできます。** 道具を選ばなくてかまいません。

1. 選択道具(V)で線を選ぶ
2. **選んだ線の上を押して、そのまま引きずる**
3. 破線で行き先が出ます。Shift を押している間は水平・垂直に固定されます
4. 離すと、そこへ移ります

押して離しただけでは動きません(4px 未満は「押しただけ」として扱います)。
**選び直しはこれまでどおりできます。**

### 4-9. 面へ投影(**できます**)

**思想。** 落とすときに **線の種類を勝手に変えません。**
直線は直線のまま、ベジエとスプラインは制御点を落とせば同じ次数のままです
(射影は一次変換なので、これは近似ではありません)。

円と円弧だけは違います。**斜めの面へ落とすと楕円になります。**
楕円は V2 の線の種類にありません。折れ線で近似すれば通せてしまいますが、
それは「円を落とした」ことにならないので `GEO-E017` で断ります。
面が円の面と平行なときだけ、円のまま落ちます。

1. 落としたい線を選ぶ
2. 「面へ投影」を押す
3. いまの作業平面へ落ちます。**元の線は残ります**
   (消すと、どの面へ落としたのかが後から誰にも分からなくなります)

| 番号 | 意味 |
| --- | --- |
| `GEO-E017` | 斜めの面へ落とすと楕円になります |
| `GEO-E018` | 落とす先の面が決まっていません |
| `GEO-E019` | 落とすと点になります(線が面に垂直) |
| `GEO-E020` | 落とす線がありません |

1本でも落とせなければ、**全部やめます。** 半分だけ落ちた形は返しません。

## 4b. 測る

### 思想

**測り方を先に選ばせません。**
V1 は「2点距離」「3点角度」…とモードを選んでから拾わせました。
選び間違えると拾い直しです。

V2 は逆です。**選んだものから、測れることを全部出します。**
1本選べば種類・長さ・半径・両端・dX/dY/dZ。
2本選べば、それに加えて **いちばん近いところ** と **接線の角度**。
選ぶ手間が減るぶん、間違えようがありません。

### 手順

1. 道具箱の「選択」で線を選ぶ(複数選べます)
2. 「測定(M)」を押す
3. 右に「測る」の棚が出て、測れることが並びます
4. 選び直すと、棚は **すぐ付いてきます**。押し直す必要はありません

### 出るもの

| 見出し | 意味 |
| --- | --- |
| 種類 | 直線・円弧・円・ベジエ・スプライン |
| 長さ | 線に沿った長さ |
| 半径 / 直径 | **円と円弧にだけ出ます。**直線には出ません |
| 始点 / 終点 | 座標 (x, y, z) |
| 両端の距離 | 端から端までの直線距離。長さとの差が「曲がっているぶん」です |
| dX / dY / dZ | 両端の座標の差 |
| 長さの合計 | 2本以上選んだとき |
| いちばん近いところ | 2本選んだときの最短距離 |
| 触れているか | 許容差の内なら「触れています」と言います |
| 中ほどの接線の角度 | 2本選んだとき、それぞれの中ほどの接線どうしの角度 |

**桁は3桁でそろえます。** そろえないと、変わった桁に気づけません。
**半径を持たないものに半径を出しません。** 出すと、その値を信じてしまいます。

## 4c. 見え方(形は変わりません)

### 思想

**見やすくしただけのつもりで、寸法を変えてはなりません。**
ここに並ぶものは、どれも文書の中の形を1mmも動かしません。

| コマンド | すること |
| --- | --- |
| 選択に正対 | 選んだ **作業平面** の正面から見ます。選んでいなければ理由が出ます |
| 表示設定 | 押すたびに 3段で回ります。**グリッドも補助線も出す → グリッドを消す → 補助線も消す → 元へ** |
| 作業中グループ | 選んだものが入っているまとまりを作業中にします。何も選ばずに押すと **外れます** |

押すたびにどこへ行くかが決まっているので、目当ての見え方へ戻すのに
何度も押して探す必要はありません。

## 5. 形をつくる

### 思想

**面が張れるかどうかを、面を張る前に判定します。**
V1は張ってみて初めて失敗が分かり、何が悪いのか言えませんでした。
V2は先に調べて、**どの線が、どれだけ離れているか** を番号つきで言って断ります。

もうひとつ。**足りない役割を勝手に埋めません。**
「近い線があるからこれだろう」と当てにいくと、意図と違う面ができます。
足りないものは足りないと言います。

### 5-1. 押し出し(いちばん単純な作り方 — **できます**)

閉じたワイヤーを選び、厚みを与えて板にします。

1. 道具箱の「選択」で **閉じたワイヤー** を選ぶ
2. 「形(M)」→「押し出し」(`Shift+E`)

**作業平面の法線方向へ、「数」の棚の「板厚」ぶん** 押し出します。
はじめは 0.5mm(プラ板の定番)です。1b章で変えられます。
できると帯にこう出ます。

```
押し出し: 厚み 0.5 mm の部品を作りました(体積 1234.5 mm3)。
```

**体積を言います。** 言わないと、狙った板厚になったか確かめられません。

出来た部品は **辺で表示されます。** まだ面を塗っていないので、
「立体ができた」と見た目で言い切らないためです。

**形そのものは文書に持ちません。** 持つと、元の線を直したのに形が古いまま、
という食い違いが起きます。文書は「どう作ったか」だけを持ち、形は作り直します。
だから保存して開き直しても、作り方が残ります。

### 5-1a2. 形状ガイド(断面から面 — **できます**)

**思想。** V1 は「選んだ順が入力の順」だったので、選び直すたびに面が変わりました。
V2 は役割の表を持ち、**選択とは切り離します。**

1. 断面にしたい線を **2本以上** 選ぶ(選んだ順が断面の順になります)
2. 「形状ガイド(G)」を押す
3. 帯に「◯で断面◯枚から面を作りました。線からのずれは最大 ◯ mm です」と出ます

**作り方は断面の数で決まります。**

| 断面の数 | 作り方 | なぜ |
| --- | --- | --- |
| 2本 | ルールド(渡すだけ) | 2本ではなめらかに通す余地がありません |
| 3本以上 | ロフト(なめらかに通す) | ルールドだと真ん中の断面が捨てられます |

**ずれを黙って飲みません。** 出来た面が入力の線を通っていなければ `GEO-G008` で断ります。
断面が1枚だけなら「断面が2つ以上要ります」と言って、何もしません。

### 5-1b. ワイヤー群から部品(**できます**)

箱状に組んだ線を3本以上選び、「形(M)」→「ワイヤー群から部品」。

- かごが閉じていないと断ります
- **1つの閉じた殻 = 1つの部品** です。2つの殻をまとめて1つの部品にはしません。
  まとめると、片方だけ消す・厚みを変えるができなくなります

### 5-1c. 板の厚みをどちらに付けるか(まだ選べません)

| 厚みの付け方 | 意味 |
| --- | --- |
| 外側 | 線が板の内側の面になる |
| 中央 | 線が板の真ん中を通る |
| 内側 | 線が板の外側の面になる |

**ここが効くのは組み合わせたときです。** 0.5mm厚のプラ板で箱を作るとき、
外側で揃えると外寸が設計どおりになり、内側で揃えると内寸が揃います。
どちらが正しいかは作るものによります。**だから勝手に決めません。**

### 5-2. 形状ガイド(曲がった面)

複数の線に「役割」を割り当てて面を作ります。

1. 線を選ぶ
2. 「形(M)」→「形状ガイド」
3. 右の表で、選んだ線を役割の行へ入れる

作り方によって要る役割が変わります。

| 作り方 | 要る役割 |
| --- | --- |
| ロフト | 断面が2つ以上 |
| スイープ | 断面1つ + 経路1つ |
| 境界面 | 境界の線が3〜4本 |

- 表の行の色は、画面の中の線の色と同じです。**どの線がどの役割かが両方で見えます**
- 行は入れ替えられます。順が面の形を決めます
- 方向も反転できます。逆向きの線が混ざると面がねじれます

役割が足りないときは、こう出ます。

```
UI-R009 面を作るための行がそろっていません。
```

本文に **どの役割が足りないか** が書いてあります。

### 5-3. ワイヤー群から部品

閉じたかご(箱状に組んだワイヤー)から、面を全部張って中身のある立体にします。

- かごが閉じていないと断られます(`GEO-S005`)
- 面を張ったあと殻が2つ以上に分かれていたら断られます。1つの部品にならないためです

---

### 5-3. 足す / 引く(**できます**)

**思想。** **何も変わらなかったら、成功したことにしません。**
触れていない2つを足しても体積は変わりません。それを「足しました」と言うのが
V1 の悪癖でした。V2 は `KER-B003` で断ります。

引き切って何も残らないときも `KER-B004` で断ります。
消えた部品を持ち続けると、選べるのに何も無いものが一覧に並びます。

1. 部品を **ちょうど2つ** 選ぶ。**1つ目が土台、2つ目が相手** です(選んだ順で決まります)
2. 「足す」または「引く」を押す
3. 帯に「体積が ◯ mm3 から ◯ mm3 になりました」と出ます
4. 使い切った2つは **隠れます**(消しません。消すと作り方をたどれなくなります)

| 番号 | 意味 |
| --- | --- |
| `KER-B002` | 選んだ部品の立体が見つかりません |
| `KER-B003` | 触れていないので何も変わりません |
| `KER-B004` | 引き切って何も残りません |

## 6. 製作(平らな部品はできます)

### 思想

**立体は「作れる形」とは限りません。**
二重に曲がった面は、平らな板からは作れません。切れ目を入れるか、分割するしかありません。
V2はここを **先に検査します。** 検査を通らないものは型紙にしません。

もうひとつ大事なこと。**組立状態を変えても、辺の長さは変わりません。**
0%(平ら)・30%(途中)・100%(組んだ状態)を行き来しても、
変わるのは形だけです。長さが変わったら、それは型紙として使えません。

### 手順(いまできること)

1. 一覧か画面で **部品を1つ**、または **形状ガイドを1つ** 選ぶ
   (選んでいないと「部品か形状ガイドを1つ選んでください。」と出ます)
2. 「製作(B)」→ **「製作モデルを作る」**
   - 平らな部品なら、帯に「製作部材を1枚作りました」と出ます
   - 曲がっていると `FAB-P004` で断られ、**何mm曲がっているか** が出ます
3. 「製作(B)」→ **「型紙を作る」**
   - 帯に「型紙を1ページ作りました」と出ます
   - ここまで来ると、右の「書き出し」に **「いまの型紙(1)」** が現れます
4. 「組立状態」を押すと **0% → 30% → 100% → 0%** と回ります。
   ただし **折り角度がまだ決まっていないので、形はまだ動きません。**
   帯にもそう出ます。動かないのを不具合だと思わせないためです

**順を飛ばすと言います。** 製作モデルを作らずに「型紙を作る」を押すと、
帯に「先に製作モデルを作ってください」と出ます。黙って何もしないことはしません。

### 開口(窓)と折り線を入れる

**役割は選びません。線の形で決まります。**

| 線の形 | 役割 | 型紙でどうなるか |
| --- | --- | --- |
| **閉じた輪** | 開口(窓) | 切り抜きます |
| **閉じていない線** | 折り線 | **切りません。**折るところとして別の層に出ます |

1. 線を選ぶ
2. 「製作(B)」→ **「境界の役割」**
3. 帯に「◯◯ に開口を1つ入れました」または「◯◯ に折り線を1本入れました」と出ます
4. **型紙はもう一度作ってください**(入れた形で並べ直すためです)

折り線を切る線と同じ層に出すと、**折るところが切り抜かれます。**
だから層を分け、折り線だけは閉じません。

**どの部材に入るかは選びません。** 窓は、それが描かれている壁のものです。
外周と同じ平面に載っているかで決まります。
どの部材の面にも載っていない線は、**近いほうへ寄せずに断ります。**
寄せると、頼んでいない壁に穴が開きます。

### 曲がった面を型紙にする

**5-1a2 で作った形状ガイドを選んで**「製作モデルを作る」を押すと、
その面を展開して部材にします。平らな部品と混ぜて、1枚の型紙に並べられます。

**約束は1つ。伸縮させません。**
展開図の上での長さは、立体の上での長さと一致していなければなりません。
一致させられない面は `FAB-P005` で断ります。**近い形へ均して成功にしません。**

- **円筒や円錐のように一方向にだけ曲がった面** は展開できます
- **球のように二重に曲がった面** は展開できません。**平らにすると何mmずれるか** を出します
- 通るか通らないかは、「数」の棚の **「展開で許すずれ」** が決めます。
  0.5mm まで許すなら通る面が、0.01mm しか許さないなら通りません。
  **どちらも正しいので、どちらかを黙って選びません。**

### まだ入っていないところ

- **切れ目**(展開できない面を1枚のまま吸収するための切り込み)は、
  まだ入っていません。
  **帯に分けても解決しないことを確かめました。** 曲がりは面の内側にあるので、
  細く切っても内側の曲がりは減りません(減ったように見えるのは、
  細くしすぎて確かめる点が無くなったときだけです)。
  そのため、いまは分ける道も入れていません
- 折り線の **角度** はまだ決められません。組立状態を入れるときに決まります。
  いまは山折りとして記録するだけです
- 展開できない面へ **切れ目を入れて分ける** 道は、まだ画面から通っていません

## 6b. 固定(**できます**)

### 思想

**固定は「作り方への依存を切る」ことです。**
作り方をたどれるのは良いことですが、元の線を直すと下流が全部作り直されます。
**もう直さないと決めたもの** は固定しておくと、うっかり元を触っても形が動きません。

**固定しても元は消しません。隠すだけです。**
消すと、どうやって作ったのかを二度とたどれなくなります。

### 手順

| コマンド | すること |
| --- | --- |
| 「現在状態を固定」(作られたものを選んで) | その線を、作り方に付いていかない形にします。元は隠れます |
| 「製作」→「現在状態を固定」 | いまの部材を、**型紙と同じ形の線** にします |

部材を固定すると、型紙の座標そのままで線が置かれます。
置き直さないのは、型紙で見えている形と1mmも違わせないためです。

### 数字を変えると何が変わるか

| 変えるもの | 変わること |
| --- | --- |
| 組立状態 0% → 100% | 形が平らから組んだ形へ。**辺の長さは変わらない** |
| 忠実度 3 → 9 | 近似の刻みが細かくなる。最大偏差が **単調に減る** |
| 板厚 0.3 → 0.5mm | 折るときの逃げが増える。切れ目の幅も変わる |

忠実度を上げると偏差が増えることは **ありません。** 増えたらそれは不具合です。

## 7. 型紙と書き出し

### 思想

**0バイトのファイルを残しません。**
検査に通ってから、はじめて中身を作ります。先に作ると、断られたときに計算が無駄になります。
書いている途中で失敗しても、前のファイルは読める形で残ります。

そして **実寸で出します。** 紙に入らないからといって縮めません。

### 手順(選んだワイヤー、または作った型紙 — いまできます)

1. 道具箱の「選択」で、型紙にしたい線を選ぶ
2. 右の「書き出し」を見る。「選んだワイヤー(2)」のように件数が出ます
3. 「どの形式で」から選ぶ

| 対象 | 出せる形式 |
| --- | --- |
| 表示している部品 | STL / STEP |
| 選んだ部品 | STL / STEP |
| 選んだ製作部材 | STL / STEP / SVG / DXF / 1:1 PDF |
| いまの型紙 | SVG / DXF / 1:1 PDF |
| 選んだワイヤー | SVG / DXF / 1:1 PDF |
| この文書 | kcd2 |

**「いまの型紙」には、6章で作った型紙が出ます。**
**「選んだ部品」「表示している部品」を STL / STEP で選ぶと、押し出しなどで作った立体が出ます。**
**「選んだ製作部材」は、SVG / DXF / PDF なら型紙、STL / STEP ならもとの部品の立体が出ます。**

立体を持っていないものを立体で出すことはできません。そのときは `EXP-013` で断り、
「先に『形』→『押し出し』などで作ってください」と言います。
**空のファイルは残しません。**

4. **「出す先を選ぶ…」** でファイル名を決める
5. **「出す」** を押す

### 断られかた

| 番号 | 意味 | 直しかた |
| --- | --- | --- |
| `EXP-015` | 出すものが選ばれていません | 先に選ぶ。**表示・非表示では決まりません** |
| `EXP-016` | 書き出す先が決まっていません | 「出す先を選ぶ…」を押す |
| `EXP-017` | その形式では出せません | 一覧で選べる形式に変える |
| `EXP-018` | 同じ名前のファイルが既にあります | 「上書きしてよい」を押すか、別名にする |

**出す先を変えると、上書きの承諾は取り消されます。** 別のファイルへの承諾ではないためです。

### 出るもの

- **SVG**:円弧は円弧コマンドで出ます。折れ線にしません
- **DXF**:`ARC` / `SPLINE` で出ます
- **1:1 PDF**:原寸。座標変換を使いません。印刷して直接使えます
- **同じ入力からは同じバイト列が出ます。** 版管理に載せられます

### 通しで一本(プラ板から作るときの本筋)

閉じた四角を引く → 押し出す → 部品を選ぶ → 製作モデルを作る → 型紙を作る
→ 「いまの型紙」+「1:1 PDF」→ 出す先を決める → 出す。

この一本は自己診断の
「引く→押し出す→部材→型紙→PDFまで通る」で、毎回ビルドのたびに確かめています。
壊れたら PC のビルドが赤くなります。

## 8. 断られたときの読み方

### 思想

**画面の文言で分岐しません。番号で識別します。**
文言は直しますが、番号は直しません。だから困ったときは番号で探せます。
番号の全一覧は `docs/v2/diagnostic-catalog.md` にあります(154件)。

### よく出るもの

| 番号 | 意味 | まず見るところ |
| --- | --- | --- |
| `GEO-W001` | となりあう線がつながっていません | 端点を吸着させ直す |
| `GEO-W003` | 端点がぴったり合っていません | 本文に **どれだけ離れているか** が出ます |
| `GEO-W004` | ワイヤーが自分自身と交わっています | 交差しているところを分割する |
| `UI-C005` | その長さでは形が決まりません | 最後に入れた欄だけ打ち直す |
| `UI-R009` | 面を作るための行がそろっていません | 本文の足りない役割を埋める |
| `UI-V007` | 相対軸で回すには部品を1つ選んでください | 部品を選ぶ |

### 重い処理

100msを超える計算には、途中でやめる道が出ます。
**やめても文書は変わりません。**

## 8b. マウスとキー(V1と同じにしてあります)

**手が覚えた操作を変えません。** V1で身についた押し方がそのまま通るようにします。
V2で新しく足したものだけ、V1が使っていないキーへ置きました。

### マウス

| **右ボタンでドラッグ** | 画面を移動 |

| ホイール | 拡大縮小 |
| 左ボタン | 選ぶ / 点を置く / 操作板を掴む |
| **右クリック(動かさずに)** | 道具ごとに違う(下記) |

**右クリック(動かさずに離したとき)**

| 道具 | すること |

| 選択 | メニューを出す |
| ポリライン(2点以上) | **そこで確定** |
| スプライン(4点以上) | **そこで確定** |
| その他(作図の途中) | 作図をやめる |
| その他(まだ1点も置いていない) | 選択道具へ戻る |

### 押している間だけ効くキー

| キー | すること |
| --- | --- |
| **Ctrl** | **吸着を止める。** 吸着したくないところに置けます |
| **Shift** | **水平・垂直へ固定。** 矩形なら正方形へ固定 |

### Esc

**必ず「選択道具・何も選んでいない」で終わります。**
ただし一足飛びではなく、**やりかけを1つ取り消してから** 戻ります。

1. 視点を掴んでいる → 掴むのをやめる
2. 押す場所を待っている → 待つのをやめる
3. 数値入力が開いている → 閉じる
4. 作図の途中 → 作図を捨てる
5. そのうえで、選択を解除して選択道具へ戻る

1回のEscで全部消すと、どこまで戻ったのか分からなくなります。
逆に取り消すだけで戻らないと、Escを押したのに道具を持ったままで、
次のクリックで意図しない線が出ます。

| **十字** | 作図道具 |
| **開いた手** | 掴めるものの上(操作板・キューブ) |
| **握った手** | いま掴んでいる |
| **指差し** | 押す場所を待っている |
