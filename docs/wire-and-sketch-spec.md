# ワイヤーとスケッチ仕様

## 目的

ワイヤーは、このCADで面・板・部品を作るための中心データである。

ユーザーは以下のどちらでもワイヤーを作れる。

- 3D空間で直接、始点と終点などを数値指定する。
- 作業平面上で2D作図し、その結果を3Dワイヤーとして配置する。

## 直線ワイヤー

3D直線ワイヤーは、始点と終点で決まる。

```text
始点: X=0, Y=0, Z=0
終点: X=2, Y=7, Z=4
```

内部的には以下のようなデータとして持つ。

```text
Wire
- kind: Line
- control points:
  - (0, 0, 0)
  - (2, 7, 4)
```

## 曲線ワイヤー

曲線は、始点と終点だけでは形が決まらない。必ず追加条件を持つ。

初期実装では Cubic Bezier を扱う。

```text
Wire
- kind: CubicBezier
- control points:
  - start
  - control1
  - control2
  - end
```

将来的に追加する候補:

- 3点円弧
- 通過点スプライン
- NURBS / B-spline
- 接線条件付き曲線
- G0/G1/G2 接続条件

円と中心＋半径＋開始角＋角度の円弧は初期実装に含める。

## 作業平面上のスケッチ

作業平面上では、2D座標で作図する。

```text
u: 平面内の横方向
v: 平面内の縦方向
```

例えば、X=10の作業平面に以下の線を描く。

```text
始点: u=2, v=3
終点: u=5, v=7
```

作業平面の座標系に従って、3D上では以下のワイヤーになる。

```text
始点: X=10, Y=2, Z=3
終点: X=10, Y=5, Z=7
```

## 作業平面との関係

作業平面はワイヤーを生む場所であり、ワイヤーを閉じ込める箱ではない。

ワイヤーは常に3D形状として保存する。そのうえで、編集用のメタデータとして作成元平面と平面ポリシーを持てる。

```text
Free3D
- 完全に自由な3Dワイヤー
- 作業平面に拘束されない

ReferenceOnly
- 作成元の作業平面を覚えている
- 2D再編集の基準として使える
- 既定値
- 平面外へ動かすことは妨げない

LockedToPlane
- 作成元の作業平面上に固定する
- 正確な2D作図を保ちたい補助線や寸法基準に使う
```

将来のUIでは、ワイヤーごとに以下を切り替えられるようにする。

```text
平面拘束なし
作業平面を編集基準として使う
作業平面に固定する
```

重要な方針:

**所属ではなく、拘束・参照として扱う。**

## 初期実装範囲

- 3D直線ワイヤー
- 3Dポリライン
- 3D Cubic Bezier
- 3D円
- 3D円弧
- 作業平面上の2D直線を3Dワイヤーへ変換
- 作業平面上の2D Cubic Bezierを3Dワイヤーへ変換
- 作業平面上の円・円弧を3Dワイヤーへ変換
- ワイヤーの作成元平面と平面ポリシー

## 実装上の注意

- ワイヤーは三角形メッシュではない。
- 画面表示で分割線分が必要になっても、元データは曲線として保持する。
- OCCTへ渡すときは、できるだけ曲線・エッジ・ワイヤーとして変換する。
- STL用メッシュ化は出力時だけにする。

## 保留事項: 面上ワイヤー

ライト穴などで必要になる `Surface Wire` / `Curve on Surface` / 曲面投影ワイヤーは、実装前にユーザーへ確認する。

現時点では仕様を固定しない。
