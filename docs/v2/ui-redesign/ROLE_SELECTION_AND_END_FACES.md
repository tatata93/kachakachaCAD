# 役割別入力と終端面（2026-10-15）

オーナー指示に基づくUI修正。WP-08を主担当とし、終端オフセット・選択フェイスの保存に必要な最小の幾何/保存拡張を含む。

## 操作契約

複数入力を持つ道具では、役割名、選択開始、現在の対象、解除を同じ場所に表示する。
複数対象の役割は追加選択と個別解除を提供する。別役割の選択や数値を消さない。
3Dと左ペインから同じ役割へ入力し、役割色と選択中の表示を合わせる。
既存の順序・向き・連続性等の専門設定は維持する。点クリック型の入力も現在の役割を明示する。

## 終端面

押し出しは作業平面、サーフェス、ソリッドの単一フェイスを直接終端に選べる。
終端を未指定のときは最初の作業平面を勝手に採用しない。
終端オフセットはmm、正は押し出し方向の奥、負は手前。終端形状を押し出し方向に平行移動する。
法線方向の一定距離とは区別し、欄の説明に明記する。0は選択面そのもの。

ソリッドフェイスは選択時の厳密BRepを保持し、一時的な面番号を保存しない。
UIに「選択時の形を保持」と示す。元立体変更への自動追従を装わない。
通常のサーフェス/作業平面は従来どおりUUID参照で再生成する。
旧ファイルでは新オフセット0、保存面なしとして読む。Undo/保存/再生成で同じ結果を保持する。

## 受入

役割切替で他入力を保持、追加/個別解除/全解除、3D/ツリー選択、Esc取消を確認する。
押し出しは平面/曲面/ソリッドフェイス、正負/0オフセット、小数、方向反転、到達不能、
プレビュー/確定、Undo、保存再読込を試験する。面まで厚み等の対象制限も確認し、未対応を成功扱いしない。
適用ツールの一覧と未解決事項は開発検証記録に残す。
