# ADR 0032: 開口と切り欠きを保持した曲面の製作近似

2026-10-28 オーナー指示。状態: 実装中。

## 決定

曲面の車体側面・前面を、複雑な外周、端へ開いた窓、複数の穴を維持して製作近似する。
ADR0030の「穴付き曲面を拒否する」制限を置き換える。矩形を穴へ被せることは引き続き禁止。

支持曲面のUV評価と、実際の材料領域（先頭が外周、残りが穴）を別々に運ぶ。
専用の製作入力APIを追加し、押し出し用FaceBoundaryOfの平面限定契約は変更しない。
非平面境界はUVと3Dの標本誤差を検査し、原曲線・原本ファイルを変更しない。
帯の範囲と材料領域の共通部分を取り、凹外周、穴が境界へ開く切り欠き、分離領域を区別する。
1枚指定では連結している材料を1枚にする。標本の三角形を部材へ分割しない。
非連結の材料を見かけだけ1枚にせず、その理由と実枚数を示す。

型紙は各帯の等長展開へ外周・穴を写す。平面への単純投影は展開と呼ばない。
下見、0/途中/100%の線・面・厚み付き部品は同じ境界写像を使う。
誤差目標を超える1枚案は超過を明示し、枚数上限を無断で増やさない。

## 実装境界

段階1はWP-09: カーネルの製作領域入力と、純粋なUV領域切り分け・展開写像。
段階2はWP-10: 既存製作UI、下見、固定生成、型紙、保存・履歴と実モデル受入へ接続。
公開する入力型・関数と試験は同段階で文書化する。OCCT型をコアへ出さない。
保存するのは元参照と既存製作設定であり、新しい生成物を保存正本へ追加しない。

## 受入

- 1枚の円筒曲面上の複雑穴・複数穴・端の半円切り欠きを保持し、解析弧長と母線長で展開を検査。
- 凹外周の帯切り分け、穴が帯境界へ開く例、材料が分離する例、内周消失・不正入力を検査。
- 添付115投影のコの字窓と閉じた側窓を含む曲面で、1枚、型紙、生成面・厚みを確認。
- 0/30/100%の辺長、開口、100%再組立位置、最大/RMS偏差、保存再読込・Undo/Redo・取消復帰。
- Windows全体・配布版検証・通常起動後に配布。実印刷・材料弾性は別の実物検証とする。
