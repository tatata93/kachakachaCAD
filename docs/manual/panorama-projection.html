正面と側面の2枚から
パノラミック窓を投影する

正面の窓形状と側面へ回り込む部分を別々の作図面に描き、それぞれ異なる方向から車体へ投影します。この例では、正面・角のR・側面の3面をまたぐ1つの閉じた通常ワイヤーを作ります。

画像はWindows版の実画面です。自動UI試験で右ペインの方向ボタン、プレビュー、確定、Undo／Redo、保存・再読込を実行しました。模式図や生成画像ではありません。

1. 車体と2枚の作図面を用意する

先に投影先となる車体の面またはソリッドを作ります。次に正面の手前と側面の外側へ作図面を置き、それぞれで窓の外周の一部を描きます。この例の単位はmmです。

作図面位置と描く範囲投影方向
正面作図面Y＝−5。窓の上辺・下辺・左端。X＝−4〜5、Z＝−1〜1。＋Y（0, 1, 0）
側面作図面X＝10。窓の上辺・下辺・奥端。Y＝5〜10、Z＝−1〜1。−X（−1, 0, 0）

各作図を四角く閉じません。2つの開いた外周を、投影後に合わせて1周にします。つなぎ目に余計な縦線を描くと、その線も投影されます。車体や座標の向きが違うモデルでは、方向をそのモデルに合わせて変えてください。

2. 元ワイヤーを入れ、正面側の方向を設定する

  1. 「作図 → 編集 → 面へ投影」を選びます。
  2. 「①元ワイヤーを選ぶ」で正面側と側面側の外周を追加します。3Dビューまたは左ペインで選べます。
  3. 右ペインの元ワイヤー一覧で正面側の行だけを選びます。右ペイン内を下へスクロールし、設定欄の「Y方向」を押します。この例では＋Yが車体へ向かう方向です。

3. 側面側の方向を別に設定する

一覧で側面側の行だけを選び、右ペイン内を下へスクロールして「X方向」→「方向を反転」を押します。正面側は＋Yのまま、側面側だけ−Xになります。各行に表示される方向を確認します。「作業平面の法線方向」でも設定できますが、そのときの作業平面と正負を確認してください。

4. 投影先を選び、つながりを確認する

  1. 「②投影先を選ぶ」を押し、車体の正面・R・側面を追加します。ソリッドなら必要なフェイスを選びます。
  2. 出力を「ワイヤーのみ」、ワイヤー形式を「通常ワイヤー」に設定します。読み取り専用で残したい場合は、もう一方の投影ワイヤー形式を選びます。こちらも投影時点の結果を保持し、元の形を変更しても自動再投影しません。
  3. 「プレビューを更新」を押します。紫が投影元、緑が投影先です。窓の上下がRを回り込み、側面の上下へつながることを確認します。

離れた端点を勝手につなぐ機能ではありません。正面側と側面側の端が、投影後に同じ位置へ届くように描きます。輪郭が開いていたら、向き・投影先の不足・接続端点を修正してください。許容誤差を大きくして隙間を隠す手順ではありません。

5. 確定して保存する

「確定」またはEnterで生成します。通常ワイヤーは投影位置に残る独立した編集対象です。曲面上の輪郭なので、通常ワイヤーにしても平面へ平らにはなりません。元の作図や車体は保持します。Ctrl+Zで生成を戻せます。

操作練習用の入力モデル ／ 確定済みモデル

この手順の範囲と、ライトを押し出すときの出力

この手順は窓の外周ワイヤーを生成します。車体への穴開けやガラスの面生成は別の操作です。「面＋ワイヤー」での投影は、それぞれの投影元が閉じた平面輪郭であることが必要です。この例の開いた正面・側面の2本から、窓の面まで一括生成する操作には対応していません。

押し出しの「出力プリセット」では「ソリッドのみ」「ワイヤーのみ」「ワイヤー＋ソリッド」を選べます。開始側の輪郭・押し出し先の輪郭・側面ワイヤーは個別にオン／オフできます。曲面入力や「選んだ面まで」でも使用でき、斜めに切られた終端の実際の輪郭を出力します。円を斜めに切った楕円など、通常の円で表せない曲線は許容偏差内の滑らかな曲線で保持します。

ワイヤーだけでは立体や穴はできません。足す・引くで立体を加工するときは「ソリッド／面」も有効にしてください。
