# 最低限の完成形と検証状況

## 完成の定義

このCADの最低限の完成形は、次の2系統を一つのプロジェクト内で最後まで実行できる状態とする。

### プラ板・紙工作

1. 任意の作業平面へ断面図や平面図を正確に描く。
2. 断面ワイヤーから車体の面を作る。
3. ライト穴などを別の平面図から投影する。
4. 面を板材として定義し、製作可能な大きさへ分割する。
5. 外周、穴、ユーザーが決めた部品境界を含む1:1型紙を出力する。

### 3Dプリント部品・治具

1. ワイヤーと面から閉じた3D部品または治具を作る。
2. 板材との隙間や肉厚を数値で指定する。
3. 3Dプリント可能性を検査する。
4. 選択した部品だけをSTLへ、CAD形状をSTEPへ出力する。

PDFの装飾、一般的なソリッドCAD並みの全機能、自動で大量分割する機能は、この最低限の完成条件に含めない。

## 現在つながっている工程

- 任意配置・任意角度・3点指定・オフセットによる作業平面。
- 作業平面への正対と、3D空間内での直接2D作図。
- 直線、ポリライン、矩形、円、3点・両端＋半径・始点＋方向の円弧、ベジェ曲線、通過点B-spline。
- 選択した直線・ポリライン・ベジェ・B-spline・円・円弧の点やハンドルを3D画面で直接編集し、1操作単位でUndoできる。
- 作図中の長さ、角度、幅、高さ、半径の実寸入力。
- グリッド、端点、水平、垂直、正方形への一時スナップ。
- 複数ワイヤーの3D直接選択、移動、回転、コピー、ミラー、分割、結合。
- 直線、ポリライン、円、円弧の平行オフセット複製と3Dプレビュー。
- 3D上で直線部分・端側を直接指す赤/緑プレビュー付きトリム・延長、2線を同じ交点へ合わせる操作、C面取り、R丸め。
- 閉輪郭から平面、2断面からルールド面、複数断面からロフト面。
- 平面図から面へのライト穴投影と、元図・面への追従。
- 面の板材化、板厚、材質、厚み方向、ライト穴開口。
- 板材の展開可能性判定、手動2分割、折り線・手動/自動切れ目、1:1 SVG / DXF / PDF、展開ワイヤーと3D板の生成。
- 曲面の外側・内側を選べる、成形クリアランスと肉厚付き治具Body。
- Open CASCADEによる閉じたB-Rep検査、最小肉厚検査、選択治具のSTL / STEP出力。
- 保存形式のバージョン判定、安全な上書き、60秒間隔の自動保存、異常終了後の復元。
- 保存、再読込、Undo / Redo、表示切替、配布フォルダからの起動。

## 最低限完成の判定

最低限の完成条件に対する状態を以下とする。

### 1. 正確な作図: 完了

- 補助線、直線の長さ・角度・水平・垂直、円と円弧の半径を維持できる。
- 異なる開ワイヤーの端点一致、ベジェ・円弧のG1接線接続、ベジェのG2曲率接続を維持できる。
- 2点間、任意3点角度、点・線・平面間、ワイヤー間、曲線半径、接線角、曲率法線角、線・平面角、平面角を3D空間で測定し、対応する値を参照寸法として残せる。

### 2. 前面曲面と投影: 完了

- 3断面以上を通り、断面位置で長手方向の接線が連続する三次ロフトを使う。
- 元断面の編集から、曲面、投影ライト穴、板材、治具を依存関係順に再生成する。
- 投影計算は直前の解を次点の初期値に使い、完成確認モデルを実用時間で読み込む。

### 3. 成形治具Body: 完了

- 元曲面、使用範囲、外側・内側、成形クリアランス、肉厚を編集データとして保持する。
- 元曲面の法線方向に接触面と背面を作り、四周を閉じた治具として表示・選択・更新できる。
- 軽量コアを正本にし、三角形メッシュは編集データへ保存しない。

### 4. 3Dプリント出力: 完了

- Open CASCADEで治具を滑らかな断面群から閉じたSolidへ再生成する。
- B-Repの妥当性、閉形状、正の体積、必要最小肉厚を出力前に検査する。
- STLは出力時だけ指定精度でメッシュ化し、STEPはB-Rep形状として保存する。
- 日本語を含む保存先でも安全に出力する。

### 5. 板材工作と長時間作業: 完了

- 0.5 mmなどの板厚、材質、厚み方向を保持し、ライト穴付きの複数パネルへ手動分割できる。
- 平面板・一方向曲げ・二方向曲面を判定し、1:1 SVG / DXF / PDF型紙を出力できる。
- 保存形式の将来バージョンを拒否し、従来のバージョンなしファイルも読み込める。
- 編集中は自動保存し、通常終了できなかった作業を次回起動時に復元できる。

## 完成確認モデル

`examples/railway-nose-acceptance.kcd` を最低限完成の受入モデルとする。

- 5枚の断面作業平面。
- 曲率の異なる上部・下部を持つ前面。
- 左右のライト穴と窓境界を平面図から投影。
- 2枚の0.5 mmプラ板パネル。
- 0.15 mmクリアランス、3.0 mm肉厚の前面成形治具。

自動試験はこのモデルを読み込み、曲面、投影、板材、治具の依存関係を確認する。さらに治具をSTL / STEPへ出力し、両方を再読込して、STEPのB-Rep妥当性まで確認する。Qtの画面試験では同じモデルを開いてスナップショットを保存する。

## 最低限完成後の拡張

以下は有用だが、今回の鉄道車両前面を製作する最低限完成には含めない。

- 楕円、閉じたNURBS、一般数値拘束ソルバー、スプラインの厳密オフセット。
- 縦横ガイドを使うネットワーク面と、一般曲面同士の連続条件。
- 一般部品のComponent階層、ローカル座標、複数配置、ブーリアン、スイープ。
- 複数Bodyの一括STL / STEP出力。
- 切断線・曲げ線・接合線属性、任意曲線分割、材質別の曲げ代。
- 作業平面・部品のロック、Undo履歴一覧、大規模な実車1両分の性能試験。

- 自動ネスティング。
- 全自動の板分割。

- アセンブリ拘束や干渉解析の高度化。
