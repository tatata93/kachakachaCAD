# ADR 0034: 曲線の操作単位と元位置を保つ輪郭の写し

状態: 採用（2026-11-20、オーナーの修正指示）。

オフセット曲線は計算用の区間数にかかわらず滑らかな曲線のまとまりを1対象として選ぶ。直線、角、不連続や別のワイヤーを同じまとまりにしない。面取りなど通常の辺選択でも同じ単位とし、明示的な点や個別区間の入力は保持する。

一様Bスプラインを任意位置で切ると端だけは元の一様ノット構造で表せない。新たな保存型や近似を追加せず、既存の厳密なベジェ端区間と一様Bスプライン内部区間の最大3区間で保持し、UIはこれを1つの滑らかな曲線として操作する。接線・曲率の判断にはBスプラインの解析的な導関数を使う。

輪郭の写しは元の3D位置と形の保持を既定とする。作図面への投影は明示操作とし、どれだけ動くかを下見で示す。面に描くための基準と、曲線そのものの移動を混同しない。元面の境界との一致、穴・複数輪郭、傾いた平面と曲面、取消と保存を検査する。

WP-04の厳密範囲と補正を先に検証して限定所有を終了し、WP-08の選択・輪郭コピー・実UI検証へ所有を移す。

追加受入: 離れた線も延長上の交点からC面取り・R丸めできる。平行・実3Dでねじれた線は無断で投影せず、理由と作図面への投影入口を示す。接平面を含む現在の作図面へ、選択し直さず正対・逆対・水平合わせできる。
