# ADR 0035: 外形と開口の輪郭を共に通る曲面

状態: 採用（2026-11-27、オーナーの開口面修正指示）。

新しく張る境界面では、開口の輪郭も曲面の形状を決める入力とする。外形だけから作った曲面へ、別の位置にある開口を押し付けて拒否したり、平面化して位置を変えたりしない。外形・開口の曲線を変えず、既存の内部ガイド拘束を再利用して両方を通る支持曲面を求め、その曲面から開口を切り抜く。最大/RMS偏差と既存の拒否条件は維持する。

元の支持面を明示した場合は、その面を別の曲面へ置換しない。複数の接続面を使う場合も、選んだ領域の境界と開口が成立する組だけを採用する。外形が元の面の自由境界と厳密に一致している場合は、その境界を投影カッターで再切断せず保持する。内側の開口だけを切り抜き、元の形状・曲率・ワイヤー・UUIDを保つ。僅かでも小さい別の領域を選んだ場合は、その指定位置で切り抜く。

新しい曲線型、保存形式、公開signature、依存ライブラリは追加しない。面の投影に使う表示折線を編集正本へ戻さない。再現データのライト開口と窓枠の帯、複数穴、面の継ぎ目、部分領域、元面保持、下見/確定、取消、Undo/Redo、保存再読込を検査する。
