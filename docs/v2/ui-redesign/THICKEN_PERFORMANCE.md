# 曲面の厚み計算と操作中の応答

2026-10-13。対象は部品の「厚み」と共通の形状検査・表示境界。
保存形式、形状ガイド、材料近似の幾何方式は変更しない。

## 操作

厚みの下見を計算する間も3D表示と厚みの設定欄を操作できる。
設定または対象を変更すると、その下見用の計算プロセスを取り消し、最新の入力で計算する。
古い入力の結果は採用しない。計算中に文書を置換・編集するコマンドは引き続き遮断する。
厚み欄と共通の数値欄の通知が往復しても、同じ入力で下見を二重更新しない。
計算を取り消しても元の面・確定済みの部品は変更せず、設定変更で再試行できる。
完了した下見をEnterで確定し、確定のためだけに同じ精密検査をもう一度走らせない。

検査済みの同じ面・厚み・配置・対象平面・許容誤差に戻ったときは結果を再利用する。
元のネイティブBRepと入力JSONのSHA256を照合し、文書IDやライブ形状ハンドルをキャッシュしない。
上限は4結果かつ16 MiB。失敗・取消・復元できなかった結果は保存しない。
キャッシュした結果も復元時の形状検査を通す。

## 計算と正本保持

- オフセット面や細かいB-spline区間の体積・重心を、元の面の位置と導関数から区間ごとに積分する。
  8点/12点Gauss則の差で再分割し、積分全体で相対誤差1e-8（絶対下限1e-10）を検査する。
  表示用メッシュや近似面に置き換えて体積を測らない。
  対応する領域はUV矩形と平面上のトリム。曲面上の任意トリム・穴などは従来のOCCT積分へ戻す。
- 閉鎖性・位相の不正を先に判定し、不正な結果へ高価な体積積分を走らせない。
  単一ソリッドの体積を二重に測らない。自己交差検査は保持し、OCCTの並列実行を使う。
- オフセット距離が局所曲率半径を超えることを検出した場合、折り返す厚みとして先に拒否する。
  区間内の標本で折り返しを見つけなかったことを、形状の合格判定には使わない。
  生成後の閉鎖性・正の体積・自己交差検査は省略しない。
- OCCTの表示メッシュ生成は面・辺の共有表現を書き換えるため、独立した形状コピーにのみ行う。
  表示したあと正本が復元不能になる問題を修正する。計算子プロセスで作って捨てていた表示メッシュも削除する。
  曲面への画像貼付も親と同じ表示コピーから面・UVメッシュを取得する。
  元の正本に表示メッシュが残ることへ依存しない。画像下見の一時形状とツールの貼付先コピーは解放する。

## 検証

自動試験の通常経路は、道具を選択し、3Dの面を拾って実際の設定欄を変更する。
添付文書の任意試験だけは、文書内の形状ガイドIDで対象を指定する。
入力文書の上書きはしない。以下はWindows実機の自動検証であり、手動受入や全形状の保証ではない。

- `HP-TH-08`: 計算中の視点操作、0.35 mm外側への変更、旧計算取消、同じ検査済み設定の再利用、
  最新入力だけの確定、Undo/Redo。
- `HP-TH-05〜07`: 実際の計算子プロセスの取り消し・異常終了、元文書・形状保持、再試行。
- `kernel_thicken_quality_tests`: 細かいノットの円筒オフセットと解析解の符号付き体積・重心の照合、
  任意回転/平行移動、向き反転、表示前後のネイティブBRepのバイト一致と復元。
  画像の頂点が親の表示面と一致すること、下見の反復で形状キャッシュが増えないことも検査する。
  局所曲率による拒否は外側/内側/中央、元の法線反転で検査する。
  円筒・花瓶・折れた帯・平面まで・STEP/STLなどの既存品質検査も維持する。
- `HP-TH-OWNER`: 環境変数 `KACHACAD_THICKEN_TEST_FILE` で指定した添付文書を読み取り、
  中央6 mmの拒否、計算中の外側0.5 mmへの変更、下見、再利用、確定、Undo/Redo、保存再読込。
  任意の撮影先は `KACHACAD_THICKEN_TEST_OUTPUT`。実機の絶対パスはソースへ固定しない。

## 添付モデルの実測と残る制限

2026-10-13、`115面.kcd2`の右側屋根の境界面を通常Windows画面で試験した。
重複更新を除いた本体では、中央6 mmは308 msで局所折り返しを報告。
外側0.5 mmの初回は35,162 msで体積293.689 mm3の部品を生成し、
数値設定を0から0.5へ戻した下見は493 ms。Undo/Redoと別の一時文書への保存再読込が成功した。
元文書のSHA256は作業前後で不変。

最終ソース `b032bdce5` はWindowsの全191検査、本体・配布版の操作試験各438件、旧CADの自己試験をすべて通過。
配布用exeと本体exeのSHA256が一致。厚み品質10件、画像貼付3件、厚み操作8件も成功した。

初回の複雑な曲面の自己交差検査には依然時間がかかる。
今回の修正は全形状で瞬時に完了する保証ではなく、操作を止めないこと、無効条件を早く知らせること、
重複した計算を避けることと正本保持の改善である。形状の安全検査を省略して高速化しない。
重量級モデルの常時60 fps、任意の曲面・穴・トリム、Linux/cloudはこの試験の対象外。


## 反対面を補正する選択（2026-10-13、ADR 0031）

一定厚みの元の挙動を保持し、「反対面を補正」を明示選択できる。
一方向付けの元面は立体の皮としても保持する。中央付けは元面を中央参照として両側に新しい面を作る。
法線変位を空間上で滑らかにしてネイティブB-splineを作り、側面を閉じる。
対応点の法線距離の範囲と、理想法線オフセットからの最大/RMS位置偏差を標本で表示する。
指定値を実際の最短壁厚として表示しない。穴・任意トリム・周期面の補正は明示拒否する。
厳密な一定厚みで成功する面には補正を適用しない。

密なC0継ぎ目は解析コピーのみC1区画へ分け、位相・体積・外接範囲を照合して全体の自己交差を検査。
元の正本と確定する形は書き換えない。解析コピーが照合できなければ従来の検査へ戻る。
生成後の閉鎖性・正のネイティブ体積・自己交差の検査を省略しない。

ソースd7663563e、Windows全191/191、本体・配布版操作各442/442、旧CAD自己試験終了0。
添付115面の配布版実操作は内側0.5 mmの初回26,641 ms/再利用1,342 ms、
中央0.5 mmは21,985 ms/1,298 ms。再利用時の計算子起動0。
確定・Undo/Redo・保存再生成・数値の見切れ検査も成功。元ファイルと211件の元Feature定義を保持。
詳細・誤差・制限はTASK_LEDGERの厚み補正項を参照する。

## 初回計算の追加改善と生成対象（2026-10-13、実装前契約）

厚み・平面まで厚み・シェル・治具の右ペインに「ソリッドのみ／ワイヤーのみ／両方」を置く。
既存文書と従来の初期値はソリッドのみ。曲面押し出しは既存の同等選択を維持する。
ワイヤーは検査済みの出来上がりのネイティブ境界から作る独立した通常ワイヤーであり、
表示用三角形の辺を文書へ保存しない。これは押し出し・立体フィレットの出力と同じ規則。
ワイヤーのみでは新しい部品を保存せず、シェルの元部品も隠さない。
両方では部品と境界ワイヤーを同時生成し、一回のUndoで全て戻す。
生成対象だけの切替では幾何計算を再実行せず、検査済みの下見を使う。
取消・失敗時は元面や元部品に変更を加えず、一時ネイティブ形状を解放する。

115面の右屋根・内側0.5 mm補正の初回を区間計測した。26,206 msのうち
自己交差検査22,196 ms、解析コピーの外接範囲照合2,609 ms。
法線・反対面・偏差計測・縫合・体積は合わせて約1,200 ms。
改善対象は密なネイティブ曲面の交差解析である。元の正本・確定形・安全検査を保持し、
解析形状の表現を変更する場合は位相・体積・範囲・誤差を照合し、照合不能時は従来処理へ戻す。

受入: 平面・円筒・密な自由曲面・穴・反転法線・回転配置・不正自己交差、
厚みの各配置と平面まで、シェルの全出力、生成対象切替の計算回数、Undo/Redo、保存再読込。
初回と再利用の時間を区別してWindowsで実測し、添付文書は上書きしない。
