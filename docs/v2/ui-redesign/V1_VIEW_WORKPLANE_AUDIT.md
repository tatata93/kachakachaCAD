# V1とV2の視点・作図面調査（2026-10-09）

ソースの実装を比較した結果。下記は機能の存在確認であり、全方式の今回のPC目視確認ではない。

| 操作 | V1 | V2の現在 |
| --- | --- | --- |
| 3点を通る作業平面 | 選択した作図点3個を優先。未選択なら座標3組 | 作業面→作業平面→3点を通る。選択点または数値3組 |
| 平面を作らず入力した向きへ正対 | 作業平面パネルの「この向きで見る」。作成と同じ入力を使用 | 同じボタンは未移植。選択に正対、作業面に正対は別に存在 |
| 複数の点・線から正対 | 作業平面入力の3点＋「この向きで見る」。選択に正対は対象種別に応じる | Ctrlで作図点や線を選び「選択に正対」。法線不明時は選択点群から向きを推定、中央と倍率も合わせる。作図面は変更しない |
| 平面へ正対／そこで描く | 表示方向と作業平面を操作 | 正対と作業中の平面を分離。今回、上部に平面内／3D作図を追加 |
| 標準面、点＋法線＋横方向 | あり | あり |
| 平面から距離、点を通る平行面、平行2面の中央 | あり | あり |
| 直線軸で傾ける、2直線を含む | あり | 辺まわりに角度、2辺を含む |
| 点を通る直線直角面 | 専用方式あり | 同名の専用方式なし。位置と向きの数値指定で構成可能 |
| 経路上の指定位置で直角 | 0〜100%の位置 | 点で曲線に直角、0〜1の位置 |
| 曲面近傍の接平面 | 面＋点を選択、近傍パラメータを探索 | 点を通り接する／辺を通り接する。方式ごとの入力条件はUI表示に従う |
| 全方式に共通のオフセット・面内X軸傾斜 | あり | 距離／角度は該当方式に限定。全方式共通の追加入力はない |
| 保存した基準線を平面の回転軸へ使用 | 基準線グループの「回転軸に使用」 | 基準線指定はあるが、このパネルの同名ボタンはない |
| キューブ・リング・選択に正対 | あり | キューブ・外側の回転操作・選択／反対側から正対。立体全体は向きを保持して中央・倍率を調整 |

「3点から向きを決める」「その方向で見る」「そこを作図面にする」は別の操作。
V2ではまずCtrlで非一直線上の作図点3個を選び「選択に正対」で向きを確認できる。
その面に描くときは「作業平面を作る→3点を通る→作ったら作業中にする」を使い、上部を「平面内」にする。
ワイヤーは平面に所属させず、平面を変えても既存形状は動かさない。
