名前を変える

具体例: 線に用途の名前を付ける

準備

直線を1本作る

操作手順

  1. 左一覧で線を選ぶ
  2. 名前を変えるを押す
  3. 前面上端と入力する

設定: 表示名: 前面上端

結果を確認

表示名だけが変わり、参照や幾何形状は保たれる。

取消・やり直し

ダイアログの取消、またはペインの取消を使います。即時操作には未確定段階がありません。 確定済みの文書変更はCtrl+Z、やり直しはCtrl+Yです。保存・書出し済みのファイルはUndoの対象ではありません。

進めない場合

一覧で選んでいるものの名前を変えます。形は変わりません。

対象欄と3Dの強調を照合し、必要な線・面・部品を各役割へ指定します。処理中は計算表示を確認し、取消が可能な処理は取消を使います。

entity.rename。図の設定と縮尺は例です。方式ごとの制限、プレビューと確定済み結果の区別を確認してください。
