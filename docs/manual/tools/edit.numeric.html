数値で編集

具体例: 直線の長さを0.25mmへ直す

準備

直線を1本作る

操作手順

  1. 直線を選び数値で編集を開く
  2. 長さ欄の置き直すを有効にする
  3. 0.25mmを入力して確定する

設定: 長さ0.25mm

結果を確認

直線が指定長さへ更新される。

取消・やり直し

ダイアログの取消、またはペインの取消を使います。即時操作には未確定段階がありません。 確定済みの文書変更はCtrl+Z、やり直しはCtrl+Yです。保存・書出し済みのファイルはUndoの対象ではありません。

進めない場合

選んだ作業平面(原点・法線・平面内X)や線(点・中心・軸・半径・角度)の数値を

対象欄と3Dの強調を照合し、必要な線・面・部品を各役割へ指定します。処理中は計算表示を確認し、取消が可能な処理は取消を使います。
