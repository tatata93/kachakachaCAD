# ADR 0010: 編集可能BodyとOCCT出力境界

## 状態

採用

## 決定

成形治具Bodyの正本は、元曲面、曲面範囲、外側・内側、成形クリアランス、肉厚とする。通常編集では三角形メッシュやOpen CASCADE形状を保存しない。

STL / STEP出力時は、Bodyの接触面断面をOpen CASCADEのB-spline曲線へ変換し、滑らかな接触面をロフトする。その面へ指定肉厚を付けて側面まで閉じ、B-Rep妥当性、閉じた外殻、体積、最小肉厚を検査する。

STLの三角形は検査済みSolidから出力時だけ生成する。STEPは同じSolidをB-Repとして保存する。

## 理由

- 断面や元曲面の編集へ治具を追従させられる。
- 通常操作を軽く保ち、主編集対象がメッシュになることを防げる。
- STLとSTEPが別形状にならず、同じ検査済みSolidから得られる。
- Open CASCADE依存を境界層へ閉じ込め、作業平面・ワイヤー・面・板材のコアを独立してテストできる。

## 却下した案

### 治具を三角形メッシュとして保持する

出力は容易だが、寸法編集、曲面追従、STEP出力に不利なため採用しない。

### 閉じた断面群を直接Solidロフトする

追加平滑化なしでは微小な境界不正が残り、平滑化すると出力待ち時間が長くなった。接触面を先に作ってOpen CASCADEの厚み付けを使う方が、高速で有効な閉Solidを得られた。
