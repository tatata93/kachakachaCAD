# 全UIのエルゴノミクス点検（2026-10-04）

## 対象と判断
現行V2の全モードの入口、右ペイン、作図の作り方、左ツリー、3D視点操作、
出力と補助ダイアログを対象に、コードの配置・サイズ・説明・確定の経路を点検した。
全操作の人によるユーザビリティ試験ではない。旧V1のUI全面改修は対象外。
模型製作の「道具→対象→条件→プレビュー→確定」と事前選択を維持する。

参考: [Microsoft iconography](https://learn.microsoft.com/en-ie/windows/apps/design/signature-experiences/iconography)、
[Windows design basics](https://learn.microsoft.com/en-us/windows/apps/design/basics/)、
[W3C target size](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum)、
[W3C icon contrast](https://www.w3.org/WAI/WCAG21/Techniques/general/G207)。
Webの24 CSS px基準は操作領域の設計参考であり、Windowsアプリの適合認証を意味しない。

## 共通の修正
- 文字だけの道具を、独自のベクター線画＋日本語名へ変更。作図の形を直接示す。
  アイコンだけにしない。円・直線・円弧・矩形・ベジェ・スプライン・編集操作を区別。
- 上部と右ペインで同じアイコンを使い、作図メニューにも共有。カテゴリは文字タブを維持。
- 円の中心半径/直径/3点、円弧の指定方法も線画で補助。押されたカードと未選択を区別。
- 道具は上部32、右ペイン36、作図カード52論理px以上の高さ。
  共通スタイルのボタン/数値/選択欄28、チェック/ラジオ24以上。高DPIはQtの論理座標で対応。
- 狭い画面の道具行を折り返し、右端の道具が画面外へ出るのを防ぐ。
- 検索で除外した道具をレイアウトから外し、結果のカテゴリに空行が残る問題を修正。
- 確定・取消は32px以上の高さに揃える。文字・キーボード案内を保持し、長い確定名の横幅を圧迫しない。
- Win95も同じサイズ基準。立体枠と押下表現は維持。図はテーマの文字色を使い、無効表示にも対応。
- 作り方付きの上部ボタンにも命令台帳から説明を付ける。

## 領域別の点検
| 領域 | 観察・判断 | 対応 |
|---|---|---|
| 作図・部品・製作・出力の上部 | 多くの短い文字ボタン、横一列 | 共有アイコン、文字維持、折り返し、焦点移動 |
| 未選択の右ペイン | 検索後に隠した行がレイアウトへ残る | 除外をレイアウトから外し圧縮、アイコン共有 |
| 作図・曲線の方法 | 同じ小さな文字カードで形が分からない | 線画と説明、押しボタン枠、選択状態 |
| 面・面編集・四辺面 | 入力役割、必要線数、未対応理由が既にある | 説明/役割分け保持、共通ターゲット寸法適用 |
| 移動・配列・面取り・部品 | 多数の数値欄、確定位置 | 共通サイズと固定フッター、既存対象先行/後行維持 |
| 押し出し・厚み・Boolean・分割 | 対象役割と結果が重要 | 入力役割/プレビュー/確定の既存分離維持、共通寸法 |
| 製作・曲げ・型紙 | 条件が多く視線移動が大きい | 既存のツール別表示とスクロールを維持、共通寸法 |
| 画像貼付・配置 | 3D上の基準点指定を右側の説明で誘導 | 3Dの直接指定と貼付後編集を保持、共通寸法 |
| 作業面・グリッド・数値・測定 | 単位、作り方による欄の切替 | 単位/必要条件/スクロールを保持、入力欄サイズ統一 |
| 左ツリー | 階層/カテゴリ/再帰選択/ドラッグ | 既存の分類アイコンを保持、形状ツールとは別の意味 |
| 3D視点・リング | 画面内への収まり、クリック/ドラッグ区別 | 既存FitViewGadgetsIntoScreenと閾値を保持、独自操作の再設計はしない |
| 出力・配置・プレビュー | 対象/形式/場所、出力前の確認 | 現行の対象保持/3Dプレビューを保持、共通入力サイズ |
| メニュー・選択ダイアログ | 操作名とショートカット、標準確定 | 作図の共通アイコン、共通サイズ、既存ショートカット保持 |
| 通知・説明・状態行 | 折返しと無効理由が判断に必要 | 既存理由を保持、上部の方法ボタンにも説明追加 |

## 検証
実装 `258aaa103`。Windows `_GO.cmd` 全185/185、通常版・配布版GUI各398/398、旧CAD自己診断終了0。
Windows通常画面HP-ERGO 3/3（全4モード全カテゴリ・通常/Win95・1000/1280幅、実可視領域も検査）、
関連する面作成/境界面の個別回帰試験と構造・曲線サンプリング試験成功。
初回の5件の回帰（最小幅、自己交差の丸め誤差、T字接点の曖昧な試験クリック）を修正後、全体再検証で成功。
通常/Win95の作図と折返し画面を画像確認。Linux/cloud・全DPIの網羅・オーナー受入は未実施。

## 残る制限
- 図は幾何学的な代表形。すべてのコマンドに固有の絵を付けたわけではなく、同種の面/立体は共用する。
- 入力欄の全組合せ、極端なフォント倍率、全ディスプレイ倍率の対話操作は網羅していない。
- 長い日本語カードや補助欄の整理は、具体的な切れ/隠れが確認されたものから直す。
- スクリーンリーダーの全経路検証とユーザによる理解時間の測定は未実施。

回帰対策: 点列化した三角形が浮動小数点の丸めで自己交差扱いになる問題を、離れた線分の範囲判定で修正。回転300例を追加。境界面GUI試験は配置確定後に投影し、T字の端点が重なる中央を避けて線の内側を選ぶ。
