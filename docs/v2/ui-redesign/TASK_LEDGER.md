### 2026-09-21 オーナー報告の 4 件(実機で見つかった本物の不具合)
1. **「スナップしてるのに 90 度になっていない」** — 点の吸着(端点・グリッド)はあったが、**向きの吸着が無かった**。1px 狙いを外すと -89.95 度の線が黙って文書へ入る。→ `SnapDirectionToRightAngle`(core、許し 1.5 度)を足し、**点の吸着先が無い自由な点のときだけ** 長さを変えずに直角へ寄せる。Shift の固定は今までどおり。S や「スナップ」を切っているときは寄せない。試験: core `constraint / ほぼ直角の向きは直角へ寄る`、人の道 `HP-AC-01`。
2. **「長さと角度を指定しても線が引けない」** — 原因は 2 つ。(a) **Tab が打った字を捨てていた**(`FocusNextField` が焦点を動かすだけ)。案内どおり「長さを打ち Tab で角度へ移って Enter」と操作すると長さが消え、角度だけでは形が決まらないので何も起きなかった。→ `LockAndFocusNextField`(打った値を確かめて留めてから移る。空の欄は素通り、読めない値は移らずに理由を出す)。(b) **角度の欄に単位なしで打った数がラジアン扱い**だった。90 と打つと 90 ラジアン(約 5156 度)。欄の表示は度なので、打つほうも度で読む(`rad` と書いたときだけラジアン)。試験: core `cursor_input / Tabは打った値を留めてから隣の欄へ移る`、`expression / 角度の欄の単位なしの数は度として読む`、人の道 `HP-AC-02`。
4. **「ほかの線の延長線だとグリッドが反応しない」** — 吸着の順位で **延長線がグリッドより強かった**(SnapEngine.h に「暫定・オーナー判断待ち」と書いてあった置き場所)。格子を狙っているのに、近くの線の延長と重なっただけで格子から外れた点が入る。→ 延長線は「線」の案内、グリッドは「点」。点を採る(延長線をグリッドの下、自由点の上へ)。試験: core `snap / 延長線と重なってもグリッドの点を採る` と順位の固定表。
3. **「拡大したときにグリッドが消えている箇所がある」** — グリッドを **原点を中心にした決まった大きさの塊** で引いていたため、原点から離れて拡大すると画面の端から消えていた。→ 画面の四隅を作業平面へ戻して見えている範囲を測り(`VisibleGridRangeUV`)、その範囲のぶんだけ引く(`GridLineRangeFor`、core)。本数の上限は安全弁として残す。試験: core `grid / 見えている範囲のぶんだけ線を引く`。
