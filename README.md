# kachakachaCAD

kachakachaCAD は、鉄道模型製作用のワイヤーフレーム／板材CADです。

目的は、画面上で形を作るだけではなく、プラ板・紙・3Dプリント部品・3Dプリント治具として実際に製作できるデータへつなげることです。

## 中核コンセプト

**3D空間内に自由に紙を置いて、その紙の上に正確な2D図面を描けるCAD。**

この「紙」が作業平面です。正面、側面、上面だけでなく、任意角度、辺との角度指定、3点指定、オフセット指定などで作成できます。

## 技術方針

本命構成は以下です。

```text
言語: C++20
UI: Qt 6
CADカーネル: Open CASCADE Technology
数値計算: 自前の軽量ベクトル型(将来Eigen検討)
ビルド: CMake
```

軽量な編集コアを正本とし、Open CASCADE形状は治具検査とSTL/STEP出力時に再生成します。通常編集では三角形メッシュを保持しません。

## 現在の骨格

```text
src/core/      UIに依存しない幾何・モデルの中核
tests/         小さな検証テスト
scripts/       開発用スクリプト
docs/          方針・仕様・作業手順
```

現在のコアでは、作業平面、3Dワイヤー、平面上の2D作図、滑らかな複数断面ロフト、平面図から面への投影、板材、開口、手動分割、実寸展開、クリアランスと肉厚を持つ雄型・雌型治具を扱います。Open CASCADEで治具を閉じたB-Repとして検査し、STLとSTEPへ出力します。

## 最初の確認

PowerShell で以下を実行します。

```powershell
.\scripts\doctor.ps1
.\scripts\check.ps1
```

`check.ps1` は構成、ビルド、テストをまとめて実行します。Windows では Visual Studio Build Tools 2022 を優先して使います。

## 画面で確認

本命のQtデスクトップ版を起動します。

```powershell
.\scripts\run-cad.ps1
```

ビルド後は `build-msvc2022-x64\Debug\kachakacha_cad.exe` を直接ダブルクリックしても起動できます。必要なQt/Open CASCADE DLLと画面プラグインは、ビルド時にEXEと同じ場所へ自動配置されます。

既存プロジェクトを開いて起動する場合:

```powershell
.\scripts\run-cad.ps1 -Project examples\first-check.kcd
```

Qt版では、画面からプロジェクトの新規作成・読み込み・保存、作業平面、直接作図、選択物の点・ハンドル編集、寸法拘束、移動・回転・コピー・ミラー、分割・結合・トリム・延長、端点一致、G1/G2接続、C面取りとR丸め、ロフト面、平面図投影、板材と開口、曲面板材の手動分割、成形治具、1:1型紙とSTL/STEP出力、Undo/Redoができます。保存は安全な置換方式で、編集中は60秒間隔の自動保存と異常終了後の復元を行います。

起動直後は右側の「作図」タブと直線ツールが開きます。「作図面」で3D空間内の紙を選ぶと真正面へ向き、3D画面をクリックまたはドラッグして作図できます。作図点、直線、ポリライン、矩形、円、円弧、4点ベジェ曲線、4点以上を通るスプラインを直接作成できます。円弧は、始点・通過点・終点の3点方式、始点・終点の後に半径と膨らむ側を指定する方式、始点から接線角または法線角・半径・中心角または円弧長を指定する方式を選べます。最初の点を置くとカーソル付近へ実寸入力欄が現れ、数字や `(` を打ち始めるだけで長さへ入り、`Tab` で角度など次の欄、`Enter` で確定できます。`(180/2)*3` のような四則演算、括弧、`pi` も使用できます。ポリラインとスプラインは「完了」、入力開始後の右クリック、または入力欄を選んでいない状態の`Enter`で確定し、`Esc`で途中入力を取り消します。交点、作図点、端点は数pxの扱いやすい範囲、主点グリッドはやや狭く、副点グリッドは点間隔に応じたごく狭い範囲だけ薄い記号を表示して吸着します。構造上の点と格子が近い場合は構造上の点を優先します。`Ctrl`を押している間は完全に吸着せず、入力前に右クリックすると14px以内の交点・作図点・端点を探して始点にできます。数値入力は独立した「数値入力」タブに残し、作成後のB-splineを選ぶと制御点と制御線が3D画面に現れ、編集タブから座標を修正できます。

起動時の視点は3Dです。3D画面右上のビューキューブは「上」「正」「右」の面をクリックして標準方向へ正対でき、キューブのドラッグで視点を回転できます。下の「3D」をクリックすると斜めの3D視点へ戻ります。線・面・板材・作業平面を選び「選択に正対」を押すと、その対象が最も見やすい向きに回転して画面中央へ拡大表示します。作業平面タブでは、平面の作成と同じ方法・オフセット・角度を入力し、「この向きで見る」を押すと作業平面をプロジェクトへ追加せず視点だけを正対できます。

3D画面またはモデル一覧で `Ctrl` を押しながら複数の線を選択できます。加工タブでは、選択した2本が直線A/Bへ自動設定されます。A/B欄の「3D選択」を押してから線をクリックし、1本ずつ割り当てることもできます。

編集タブの「移動」「コピー」は、選択したワイヤーの基準点と移動先を3D画面で順に指定します。「回転」は中心、角度の基準点、回転先の3点を指定し、「ミラー複製」は作図面上で軸の2点を指定します。いずれも確定前の形を破線で表示し、複数選択したワイヤーをまとめて処理します。「分割」はワイヤーを1本選択して線上をクリックします。「トリム」は事前選択なしで消したい線・曲線部分へマウスを置き、赤い予告区間をクリックします。端区間は交点まで短くなり、2交点間を指すと中央だけを削除して2本へ分かれます。「延長」は伸ばしたい端側へマウスを置き、緑の予告を確認してクリックすると、その方向で最初に交わる表示中の線・曲線まで伸びます。直線、開いたポリライン、円弧、ベジェ、B-splineを元の種類と精度のまま処理し、境界にも表示中の各種ワイヤーを使えます。どちらも連続実行でき、右クリックまたはEscで終了します。端点が連続する直線・ポリラインを複数選択して「結合」を押すと、1本のポリラインになります。2本の直線を選択して「2線を交点まで」を押すと、短い場合は延長し、交差部分が余る場合は両方を同じ交点へ合わせます。

直線を1本だけ選んで「基準線に設定」を押すと、通常選択とは別に基準線として保持し、3D画面上へ緑色の破線と「基準」を表示します。その後で対象ワイヤーを選び直して「ミラー複製」を押すと、表示中の作図面内で基準線を軸に即時複製します。同じ基準線を作業平面タブの「回転軸に使用」から任意角度の平面作成にも利用できます。

「面」タブでは、3D画面で閉じたワイヤー1本を選んで平面を、断面ワイヤー2本を選んで曲面を、車体の前から後ろの順に3本以上選んでロフト面を作成できます。ライト穴などは別の作業平面へ円や輪郭を作図し、投影先の面と平面図を選んで「選択ワイヤーを面へ投影」を押します。投影結果は元の平面図と面へ関連付けて保存され、元の断面や平面図を編集すると追従します。面を選択し、板厚、厚み方向、プラ板・紙・真鍮などの材質を指定して板材へ変換できます。作成後の板材は3D画面で直接選び、同じ欄で板厚・方向・材質を変更できます。同じタブの「断面と外形ガイドから面（Gordon面）」では、外形の稜線などになるワイヤーを選択に追加しておくと、断面ワイヤー2本以上とそのガイドを両方厳密に通る面を作成できます。ロフト面と違い、指定した外形線からずれない曲面になります。

同じ「面」タブで曲面を選び、「外側の型／内側の型」、成形の隙間、治具厚、必要最小肉厚を指定すると成形治具を作れます。治具は3D画面で直接選択でき、元の断面を直すと曲面とともに再生成されます。「出力」タブで治具を1個選ぶと、閉形状・体積・最小肉厚を検査してSTLまたはSTEPへ保存します。STL用三角形は出力時だけ生成します。

ライト穴を作る場合は、板材1枚と、その板材の面へ投影した閉じた輪郭を3D画面で複数選択し、「開口に追加」を押します。穴を戻す場合も同じ対象を選んで「開口から外す」を押します。板材を選択すると、平面板、一方向曲げ、二方向曲面の近似判定も情報欄へ表示します。

二方向曲面を工作用の部品へ分ける場合は、板材を1枚選び、「板材を分割」で断面内または車体長手方向と位置を指定します。スライダーへ連動した赤い線で切断位置を確認してから、一回の操作で2部品へ分割します。分割後も両部品は元の面へ追従し、ライト穴は含まれる側だけへ引き継がれます。分割線が穴を横切る場合は実行しません。`examples\curved-panel-light-holes.kcd` で4断面の外板、左右のライト開口、その間で分けた0.5 mmプラ板を確認できます。

一連の完成確認には `examples\railway-nose-acceptance.kcd` を開きます。5断面の前面曲面、ライト穴、窓境界、2枚の0.5 mmプラ板、クリアランス付き成形治具が入っています。

モデル一覧のチェックを外すと、作図用の平面、作図点、断面ワイヤー、面、板材を個別に隠せます。3D画面で複数選択して `Ctrl+H` でも非表示にでき、`Ctrl+Shift+H` ですべて戻せます。非表示状態もプロジェクトへ保存されます。

「情報」タブの測定では、任意2点の3D距離とXYZ差、3点で作る3D角度、ワイヤー全長、円・円弧の半径、点・ワイヤー・作業平面間の距離、線・曲線の接線角、曲線の曲率法線角、平面角を3D画面から直接測れます。測定後に候補から値を選んで「寸法を残す」と、参照寸法が3D画面とモデル一覧へ残り、参照したワイヤーや作業平面の編集へ追従します。参照寸法一覧のチェックで表示を切り替え、選択して削除できます。

「出力」タブでは、作業平面と対象を選び、面上のワイヤーをミリ単位の1:1 SVGまたはDXFへ保存できます。面上の全ワイヤーをまとめて出す方法と、3D画面で選択したワイヤーだけを出す方法を選べます。円・円弧・ベジェ・B-splineは0.01 mmの許容差で出力用の線へ変換します。選択した面から外れているワイヤーは混入させず、選択出力の場合はエラーとして知らせます。

板材の切断図は、3D画面またはモデル一覧で板材を1枚選び、「出力」タブの「展開SVGを保存」または「展開DXFを保存」から作成します。分割した板材はその部品の範囲だけが外周になり、所属するライト穴も開口レイヤーへ入ります。平面板は元輪郭をそのまま使い、曲面板は板厚中央を一時的に展開します。画面には最大推定ずれを表示し、二方向曲面または0.10 mmを超える近似図は保存前に確認します。

紙へ直接印刷する場合は、同じ欄でA4またはA3とページの重なり量を選び、「1:1 PDFを保存」を押します。用紙の縦横は必要ページ数が少なくなる向きを自動選択します。大きい部品は位置合わせ目印付きの複数ページに分かれ、各ページ下部へ100 mmの尺度線が入ります。印刷時はプリンター側を「実際のサイズ」または100%にし、最初に尺度線が100 mmであることを確認します。

単体で起動できる配布フォルダを作る場合:

```powershell
.\scripts\package-cad.ps1
```

作成後は `out\kachakachaCAD\kachakacha_cad.exe` を直接起動できます。
同じフォルダへ完成確認モデル、レビュー用の前面成形治具STL / STEP、完成確認画面も作成します。配布処理は全自動試験と、配布フォルダ内の実行ファイルによる再出力に成功した場合だけ完了します。
`START_REVIEW.cmd` をダブルクリックすると、完成確認モデルを開いた状態で起動します。

## 開発用ビューア

最小ビューアを起動します。

```powershell
.\scripts\run-viewer.ps1
```

表示された画面では、ワイヤーや作業平面をクリックして選択できます。右側の情報パネルの一覧から名前をクリックしても選択できます。選択した対象は強調表示され、名前、種類、平面ポリシー、座標、概算長さなどが表示されます。
選択中の対象は、`A`/`D` で X 方向、`W`/`S` で Y 方向、`Q`/`E` で Z 方向に移動できます。通常は 0.5mm、`Shift` を押しながらなら 5mm、`Ctrl` を押しながらなら 0.1mm ずつ動きます。
`C` で選択中の対象を複製、`Delete` または `Backspace` で削除、`Ctrl+Z` で Undo、`Ctrl+Y` または `Ctrl+Shift+Z` で Redo できます。
`Ctrl+S` で現在の表示内容を `out` フォルダへ `.kcd` として保存できます。
`Tab` で次の対象を選択、`Esc` で選択解除、`1`、`2`、`3` でサンプル切り替え、マウスドラッグで回転、ホイールでズームできます。

数値で定義したプロジェクトを開く場合:

```powershell
.\scripts\run-viewer.ps1 -Project examples\first-check.kcd
```

画像だけ確認する場合:

```powershell
.\scripts\snapshot-viewer.ps1
```

プロジェクトを `.kcd` として書き出す場合:

```powershell
.\scripts\export-project.ps1 -Project examples\first-check.kcd -OutputPath out\first-check-export.kcd
```
