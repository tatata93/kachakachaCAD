# Qt の当て木(雲での型検査だけに使う)

雲の側には Qt が入らない(apt が 403 を返す)。そのため V2 の画面のコードは、
PCへ送ってからでないと「組めるかどうか」が分からなかった。
core の関数名を1つ間違えるたびに、PCとの往復(約5分)を1回無駄にしていた。

ここに置いてあるのは Qt の *宣言だけ* の当て木である。実装は無い。
`-fsyntax-only` で画面のコードを通し、

  - core の関数名・引数・戻り値の取り違え
  - include のつけ忘れ
  - Qt がマクロにしている語(slots など)を名前に使ってしまう間違い

を雲の側で捕まえる。当て木に無い Qt の関数を使うと、ここが落ちる。
そのときは当て木へその宣言を足す。落ちること自体が「新しい Qt の関数を使った」
という知らせなので、黙って通り抜けることはない。

**当て木は Qt の代わりではない。** 本物の組み立てと試験は PC の Qt 6.9.2 で行う。
