# 重量級モデルの軽量化（2026-10-05）

## 目標と現状

目標は操作中60fps（1フレーム16.7ms）。**未達**。平均値だけでは達成としない。
115系の全1,083立体・363,796表示三角形を維持し、編集正本・保存・STL/STEPの精度は変更しない。

## 変更

- Qt OpenGLによる面・稜線の永続GPUバッファ、同じ材質の描画まとめ。
- グリッド・作業面・文字・操作表示を含めてGPUで描画。最後にQWidgetへ転送する。
- グリッドは画面での垂直間隔に基づき、密集して読めない線だけを抑制。スナップ座標は変更しない。
- GPUが使えない環境とoffscreen試験は従来のCPU描画。画像・解析面の合成も既存CPU経路を維持。
- スナップ交点はポインタ近傍だけを計算。保守的な曲線包囲判定、直線・平行投影の円の解析的な最寄り点、直線交差を追加。
- 面・立体の選択は視線と包囲箱で候補を絞ってから、従来の三角形選択を実行。
- 再生成時の全作図シーンの反復コピー、表示キャッシュの不要な複製、UUID文字列からの全件探索を削減。
- `KACHACAD_SOFTWARE_RENDER=1` でCPU描画を選べる。`KACHACAD_TRACE_RENDER=1` は描画・スナップの内訳を標準エラーへ記録。

## 計測条件と結果

Windows実機、NVIDIA GeForce GTX 1060 6GB。Releaseビルド。
ウインドウ1800×1000、計測時ビューポート1168×820。
`tools/modeling/benchmark.py` に `KACHACAD_PERFORMANCE_ONLY=1` を指定。
対象 `samples/series115-heavy/series115-1000-1-80.kcd2`。
回転120フレームには初回アップロードを含む。マウス移動は10位置でスナップ・選択・描画を含める。
同期描画の処理時間であり、ディスプレイの実提示fpsを測る試験ではない。

| 計測 | 結果（全体試験前の計測） |
| --- | --- |
| 読込・形状再生成 | 8.001秒 |
| 回転120フレーム | 合計1.111秒、平均9.26ms |
| 回転p95 / 最大 | 13.22ms / 74.21ms |
| マウス移動＋描画 | 17〜34ms |

従来の全車回転平均587msは12フレームの別計測。今回の120フレームと条件が異なるため、厳密な倍率比較には使わない。
