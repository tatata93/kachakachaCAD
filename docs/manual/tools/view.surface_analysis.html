面の解析

具体例: 曲面の曲がり方を見る

準備

ロフト面を1枚作る

操作手順

  1. 面を選ぶ
  2. 面の解析を開く
  3. 解析の種類を切り替える

設定: ゼブラ・曲率・縦横線・ずれ

結果を確認

面上に解析結果が表示される。解析色は形状変更ではない。

取消・やり直し

ダイアログの取消、またはペインの取消を使います。即時操作には未確定段階がありません。 確定済みの文書変更はCtrl+Z、やり直しはCtrl+Yです。保存・書出し済みのファイルはUndoの対象ではありません。

進めない場合

ゼブラ・平均曲率・ガウス曲率(可展性)・U/V 線・曲率コーム・境目の連続・入力線からのずれで

対象欄と3Dの強調を照合し、必要な線・面・部品を各役割へ指定します。処理中は計算表示を確認し、取消が可能な処理は取消を使います。

Windows版の操作画面

view.surface_analysis。図の設定と縮尺は例です。方式ごとの制限、プレビューと確定済み結果の区別を確認してください。
