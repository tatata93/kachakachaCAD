作業平面を使用

具体例: 側面の紙へ作図を切り替える

準備

side_YZ作業面を表示する

操作手順

  1. 左一覧でside_YZを選ぶ
  2. 作業平面を使用を押す
  3. 正対して線を引く

設定: 選択面内の作図を使用

結果を確認

新しい線が側面の平面内にできる。既存ワイヤーの所有関係は変わらない。

取消・やり直し

ダイアログの取消、またはペインの取消を使います。即時操作には未確定段階がありません。 確定済みの文書変更はCtrl+Z、やり直しはCtrl+Yです。保存・書出し済みのファイルはUndoの対象ではありません。

進めない場合

作業平面を1つ選んでください。

対象欄と3Dの強調を照合し、必要な線・面・部品を各役割へ指定します。処理中は計算表示を確認し、取消が可能な処理は取消を使います。

Windows版の操作画面

workplane.set_active。図の設定と縮尺は例です。方式ごとの制限、プレビューと確定済み結果の区別を確認してください。
