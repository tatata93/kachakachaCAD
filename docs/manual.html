kachakachaCAD 操作マニュアル

鉄道模型のワイヤー、曲面板、開口、治具を一つの3D空間で作る

目次 最初の確認 視点操作 点グリッド 作業平面 作図と選択 3D板を作る 板厚方向 窓・ライト開口 板材の分割 STL / STEP出力 保存と復旧 困ったとき

最初の確認

1. 断面ワイヤーを作図
2. ワイヤーを複数選択
3. 3D板を直接作成
4. 必要部分を出力
  1. review-model.kcd を開くと、前面窓と左右ライトが開口された車体前面、後部板材、成形治具を確認できます。
  2. 3D画面ではクリックで1個選択、Ctrl+クリックで追加選択します。
  3. 右上のキューブで上・正面・右・角視点へ切り替えます。
  4. 右側の「面」タブで板材を作り、「出力」タブで選択部分だけをSTLまたはSTEPへ保存します。

作業平面は「3D空間内に自由に置ける紙」です。平面を作らず向きだけ合わせたい場合は、作業平面タブの正対操作を使います。

点グリッド

「作図」タブの点グリッドは、補助線を毎回引かずに一定間隔で位置を決めるための基準点です。

  1. 「間隔」で点の間隔を指定します。
  2. 「基準 X」「基準 Y」で点列の開始位置を作図面内座標として指定します。
  3. 「スナップ」を有効にすると、表示中の点グリッドと既存ワイヤー端点へ吸着します。
  4. 基準位置を戻すときは「基準を 0, 0 に戻す」を押します。

作業平面

標準平面のほか、点と法線、任意の3点、既存平面からのオフセット、軸まわりの回転で作れます。どの方法でもオフセット距離と傾きを追加できます。

平面を作らず向きだけ使う

入力した平面条件で「この向きに正対」を実行します。断面確認だけならモデル一覧に平面を増やす必要はありません。

作図と選択

直線、ポリライン、矩形、円、3点円弧、ベジェ、B-splineを3D画面上で直接作図できます。線へマウスを置くと色が変わり、制御点と選択対象を確認できます。

任意ワイヤーから3D板を作る

  1. 3D画面で断面ワイヤーを作成します。
  2. Ctrl+クリックで、車体の前から後ろへ順番に選択します。
  3. 「面」タブで板名、始端板厚、終端板厚、方向、材質を指定します。
  4. 「選択ワイヤーから3D板を直接作る」を押します。
選択作られる形
閉じた1本輪郭内の平板。板厚は一様です。
2本2断面を結ぶ曲面板。
3本以上選択順に通るロフト曲面板。

「終端まで板厚を変化」を有効にすると、最初の断面から最後の断面まで板厚が連続的に変わります。途中で分割しても、分割位置の板厚を両部品が引き継ぎます。

可変板厚の板そのものはSTL / STEPへ出力できます。可変板厚と曲面上の開口を同じ板へ設定した立体出力は現在未対応です。窓やライト穴が必要な板は、現段階では一定板厚で作成してください。

板厚方向と板厚位置ワイヤー

面または板材を選ぶと、中央付近に「+ 法線」矢印が表示されます。

  • 「+側へ」は元の面から矢印側へ全板厚を付けます。
  • 「中央」は元の面の両側へ板厚の半分ずつ付けます。
  • 「-側へ」は矢印と反対側へ全板厚を付けます。

板材1枚と、その元の面へ投影したワイヤーを選択し、「板厚位置にワイヤーを作る」を使うと、+側表面、板厚中央、-側表面へ派生ワイヤーを作れます。板厚や元の面を変更すると追従します。

窓・ライト開口

  1. 正面図などの作業平面に閉じた窓・ライト輪郭を描きます。
  2. 輪郭と投影先の面を選び、「選択ワイヤーを面へ投影」を実行します。
  3. 板材1枚と閉じた投影輪郭を選び、「開口に追加」を押します。

開口をまたぐ位置で板材を分割することはできません。先に分割線を窓の外へ移すか、各板材用の閉じた輪郭へ分けてください。受入モデルの前面窓は、板材の継ぎ目を窓の後方へ移して完全な開口にしています。

板材の分割

分割する板材を3D画面で選択し、断面内方向または長手方向と位置を指定します。赤い破線プレビューを確認してから2分割します。CADが勝手に多数の小片へ分けることはありません。

任意部分のSTL / STEP出力

  1. 板材または治具を3D画面で直接選択します。複数はCtrl+クリックです。
  2. 「出力」タブの対象を「3D画面で選択した部分」にします。
  3. STLまたはSTEPを保存します。登録済みの窓・ライト開口も立体から切り抜かれます。

車体全体が必要なときは「表示中の3Dモデル全体」を選びます。不要な部品を一時的に隠せば、見えている板材と治具だけをまとめて出力できます。

形式用途
STL3Dプリンター、スライサー。保存時だけ高精度メッシュへ変換します。
STEP他CADとの形状交換。板材と治具を閉じたB-Rep立体として保存します。
SVG / DXF / PDFプラ板や紙の1:1切断図・展開図。

保存と復旧

プロジェクトは.kcdへ保存します。作業中は定期的に自動保存され、異常終了後の次回起動時に復旧候補が表示されます。元に戻す・やり直すは通常のCtrl+Z、Ctrl+Yです。
