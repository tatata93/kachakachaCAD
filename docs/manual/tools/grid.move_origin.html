グリッド原点を移動

具体例: 部品の角をグリッド原点にする

準備

角(10,5,0)を持つ矩形を作る

操作手順

  1. グリッド原点を移動を選ぶ
  2. 矩形の角を指定する

設定: 原点(10,5,0)

結果を確認

グリッドの基準位置が移る。ワイヤーの世界座標は変わらない。

取消・やり直し

未確定入力をEscで取り消します。道具を終えるときは選択(V)または別の道具へ切り替えます。 確定済みの文書変更はCtrl+Z、やり直しはCtrl+Yです。保存・書出し済みのファイルはUndoの対象ではありません。

進めない場合

グリッドの原点を、作図点や幾何点へ合わせます。

対象欄と3Dの強調を照合し、必要な線・面・部品を各役割へ指定します。処理中は計算表示を確認し、取消が可能な処理は取消を使います。

Windows版の操作画面

grid.move_origin。図の設定と縮尺は例です。方式ごとの制限、プレビューと確定済み結果の区別を確認してください。
