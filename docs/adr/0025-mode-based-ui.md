# ADR 0025: モード方式UI(ADR 0021 段階B)

## 状態

採用(2026-09-04)。実装済み。オーナー指示による全面再構成。

## 決定

1. **Esc = 選択モード・何も選ばれていない状態**(他CADの慣行)。作図中なら取り消しも行う。
   `CadViewport::SetEscapeRequestedCallback` → 選択ツール+選択解除。
2. **ビューナビゲータの画面固定矢印(オーナー用語「絶対回転」)もつかんで回す**:
   下段はマウス左右、右列は上下に追従して連続回転。クリック15°も維持。
3. **上部モード切替**(2段目、新規/開く/保存の下): ① 作図 / ② 面・板材 / ③ 近似モデル / ④ 出力。
   正対・選択・測定+作図面コンボ+スナップは**常時表示**(同じ段)。
   3段目以降は選択中モードのツール列に切り替わる:
   - 作図: 平面を作る+直線〜スプライン・作図点・完了/取消/直接変形(移動〜基準線)/加工列。
     **作図モードに限り右パネル(スケッチ)にも道具ボタンのグリッド**(QAction同期)。
   - 面・板材: 面を作成/ゴードン面/面へ投影/板材化/厚み位置のワイヤ/ライトケース/成形治具。
     パラメータは右パネル(面・板タブ)。
   - 近似モデル: ツール列なし。右パネル=部材タブ。
   - 出力: ツール列なし。右パネル=出力タブ(対象と形式の選択)。
   右パネルのタブとモードは双方向に同期(`SetWorkMode`/`SyncWorkModeToTab`、再入ガード)。
   旧ワークフローボタン(1平面〜4出力)は撤去(互換のため非表示で保持)。
4. **測定結果は別ウィンドウ**(非モーダル、測定ツール起動時に表示。設定メニュー・表示タブからも開ける):
   - 測定値(情報タブと同じ内容)。
   - 選択中の線の詳細: 円・円弧=半径/円周(弧長)/中心点、ベジェ・スプライン=制御点一覧、その他=長さ。
   - 「中心点に作図点を作成」「制御点・通過点に作図点を作成」ボタン(名前は `<線名>_中心` /
     `<線名>_制御点N`、重複時は連番)。
5. **メニューバー「設定」**: ショートカット一覧ダイアログ、表示・線の設定(表示タブへ)、
   測定結果ウィンドウ。
6. **表示タブ「ウィンドウの表示」**: モデルパネル/作図と編集パネル/操作ガイド/
   測定結果ウィンドウのチェックボックス。

## 検証方法

セルフテストに追加: Escで選択モード+選択解除、モード切替でツール列と右パネルが追従、
測定ウィンドウが円の半径・中心を表示し中心点を作図点化できる。
linux-core → Windows 実機ビルド → 17テスト → 起動 → スクリーンショット確認。
