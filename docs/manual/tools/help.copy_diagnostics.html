診断情報をコピー

具体例: 問題を調べるための診断をコピーする

準備

エラーや不具合が起きた状態を保つ

操作手順

  1. 診断をコピーを押す
  2. テキストエディターに貼り付けて内容を確認する

設定: 図面そのものは送信しない

結果を確認

バージョンや直近の診断内容をコピーできる。

取消・やり直し

ダイアログの取消、またはペインの取消を使います。即時操作には未確定段階がありません。 確定済みの文書変更はCtrl+Z、やり直しはCtrl+Yです。保存・書出し済みのファイルはUndoの対象ではありません。

進めない場合

いまの道具・右の棚・カーソル・吸着・選択を短い文にして貼り板へ入れます。

対象欄と3Dの強調を照合し、必要な線・面・部品を各役割へ指定します。処理中は計算表示を確認し、取消が可能な処理は取消を使います。

Windows版の操作画面

help.copy_diagnostics。図の設定と縮尺は例です。方式ごとの制限、プレビューと確定済み結果の区別を確認してください。
