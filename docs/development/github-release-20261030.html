他のPCから最新版をダウンロードして使う

2026-10-30。検証済みトリム修正版をGitHub Release v0.1.0-20261030 として公開し、Latestに設定した。

最新版Windows ZIPをダウンロード ／ この版の公開ページ

  1. kachakachaCAD-windows-x64.zip をダウンロードする。
  2. ZIPを右クリックし「すべて展開」する。
  3. 展開したフォルダの kachakacha_cad_next.exe をダブルクリックする。
  4. 説明書は OPEN_MANUAL.cmd または manual.html から開く。

Windows x64向け。Qt・Open CASCADE・Visual C++ランタイムを同梱し、開発ツールの導入を不要にした。 EXEだけを取り出さず、DLLやplatforms等も同じフォルダに残す。
