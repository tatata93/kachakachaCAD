# CAD修正・改善の依頼記録

この欄は主担当がユーザーの文章・画像・モデルから埋める。オーナーに全項目の記入を要求しない。
不明は推測で埋めず「未確認」とし、必要な情報だけ質問する。

## 依頼と担当

- 依頼ID・GitHub Issue:
- 依頼元のチャット:
- 種類: 手動で発見した不具合 / 継続改善 / 性能 / 模型の製作
- 優先度とユーザーの作業目的:
- 状態: 未着手 / 担当中 / 検証待ち / 統合待ち / 統合済み / 要対応
- 実装担当PC:
- 統合担当:
- 基点ブランチ・完全なSHA:
- 作業ブランチ・対象WP・変更範囲:
- 実行期間・利用上限・一区切りの条件:

## 再現と受入

- 入力モデルの版・SHA256・受渡方法（原本と複製を区別）:
- 起動したCADの版・配布物・ハッシュ:
- 直前のツールと入力モード:
- 選択経路: 3Dビュー / 左一覧 / その他
- 操作順序、Ctrl等の修飾キー、クリックした対象:
- 現在起きていること:
- 期待する動作:
- 変える対象:
- 残す形状・参照・表示・未編集部分:
- 合格条件:

## 検証の証拠

- 修正前の失敗と記録先:
- 修正後の同じ操作と記録先:
- 前後のツール、取消、Undo/Redo、保存再読込:
- 一般化した形状での確認:
- 精度・形状保全・性能の比較条件と実測:
- 実画面での操作: 成功 / 未実行 / 失敗（具体的なエラー）
- 重点 / 全体 / 配布物 / 通常起動それぞれの実行IDと結果:
- 実行したHEADと、検証したバイナリ・配布ZIPの同一性:

## 統合と残件

- 変更コミット・push先・PR:
- 統合先SHAと統合後の検証:
- 公開状態・配布ページ・起動方法:
- まだできていないこと:
- 次に進む条件:

失敗・中断・未確認を成功へまとめない。重点検証を完成配布版と表示しない。
同じ依頼を別PCへ移す場合は、担当の交代と停止済みの元実行を確認してから状態を変更する。
