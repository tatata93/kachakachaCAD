# Wire-first V2 UI操作仕様

## 1. 画面構成

V2の通常画面は次の5領域から構成する。

```text
┌ メニュー / 共通操作 / モード切替 / 現在の作業平面・作業中グループ ┐
├ モデル一覧 ┬──────────────── 3Dまたは型紙ビュー ────────────────┬ 作業内容 ┤
│            │                                                     │          │
│            │                                                     │          │
├ 操作ガイド ┴─────────────────────────────────────────────────────┴──────────┤
└ 状態、座標、スナップ種別、再計算状態、単位                                      ┘
```

- 左上: モデル一覧。
- 左下: 現在ツールの操作ガイド。現行の考え方を維持する。
- 中央: 3Dビューまたは型紙ビュー。
- 右: 選択または実行中コマンドの作業内容。
- 上: モードと高頻度コマンド。
- 下: 短い状態表示。長い説明は置かない。

ページ全体をカードで分割しない。右パネル内も入れ子カードを使わず、見出し、区切り線、フォーム、
表、ボタン列で構成する。

## 2. 上位モード

上位モードは4つだけにする。

| モード | 主な操作 |
| --- | --- |
| 作図 | 点、平面、線、円弧、曲線、トリム、延長、接続、寸法 |
| 部品 | 形状ガイド、押し出し、ワイヤー群から部品、Boolean |
| 製作 | 製作近似、境界役割、型紙、組立確認、現在状態を固定 |
| 出力 | 対象選択、検査、STL/STEP/SVG/DXF/PDF |

共通操作はモードを切り替えても常時表示する。

```text
新規、開く、保存、Undo、Redo、選択、測定、全体表示、正対、
作業平面、作業中グループ、スナップON/OFF
```

- `UIX-001`: モード切替で選択を消さない。
- `UIX-002`: 現在の選択で実行できないコマンドはdisableし、理由をツールチップへ表示する。
- `UIX-003`: モード変更だけでFeatureを作成、削除、再計算してはならない。
- `UIX-004`: 旧種類名を選ぶコンボボックスを置かない。

## 3. コマンド状態

全コマンドは共通状態機械を使う。

```text
Idle
 -> AwaitingSelection
 -> EditingParameters
 -> PreviewValid | PreviewInvalid
 -> Evaluating
 -> Committed
 -> Idle
```

- Esc 1回: 現在コマンドの未確定操作を取消し、選択モードへ戻る。
- Esc 2回目相当の別処理を作らない。
- Enter: 有効プレビューを確定。
- Space: 入力中の向き、側、候補を切り替える。
- Backspace: 多点作図の最後の点だけ戻す。
- Ctrl+Z/Ctrl+Y: commit済み操作だけUndo/Redo。
- Evaluating中はCancelを表示し、Escでもcancelできる。
- PreviewInvalidのEnterは無視せず、右パネルと左下ガイドへ理由を出す。

## 4. 操作ガイド

左下の操作ガイドは全ツールで次を表示する。

```text
ツール名
現在: 今何を待っているか
1. 完了済み手順
2. 現在手順を強調
3. 次の手順
確定: Enter / 左クリック
取消: Esc
選択数と不足条件
```

例:

```text
押し出し
現在: 閉じた輪郭を1つ以上選択
1. 輪郭を選ぶ
2. 距離または対象を決める
3. 出力を選んで確定
選択 3本 / 閉輪郭 1 / 隙間 0
```

- 内部実装の説明は書かない。
- エラー時は「失敗しました」だけで終えず、対象名、距離、必要な修正を短く表示する。
- 「詳しく見る」でDiagnostic一覧と該当箇所へのズームを開く。

## 5. 選択

### 5.1 基本

- 左クリック: 最上位候補を1つ選択。
- Ctrl+左クリック: 選択を追加/解除。
- 空白ドラッグ左から右: 完全に囲んだ対象。
- 空白ドラッグ右から左: 触れた対象。
- 空白クリック: 選択解除。
- モデル一覧と3D選択は常に同期する。
- 非表示は選択不可。参照表示はスナップ/測定可、編集選択不可。
- 選択フィルタは点、ワイヤー、形状ガイド、部品、製作部材を複数ONにできる。

### 5.2 近傍候補

右クリックは14px以内の候補一覧を出す。各行に種類、表示名、サブ要素、距離を表示する。

```text
交点: 前面上線 x 中心断面    2 px
端点: 前面上線               3 px
曲線上: 屋根外形             4 px
主グリッド点                 6 px
```

右クリックをコンテキストメニューだけに専有せず、最上段へ近傍候補を置き、その下に対象操作を置く。

## 6. スナップ

### 6.1 既定優先順位

同じ8px範囲内では次の順にする。

1. 実3D交点
2. 端点
3. 中心点
4. 作図点
5. 接点/垂足
6. 中点/四半点
7. 曲線上最近点
8. 主グリッド点
9. 副グリッド点
10. 作業平面上の自由点

グリッドが幾何交点や端点を奪ってはならない。距離が大きく違う場合は、優先度より画面距離を優先し、
高優先候補の有効範囲は6px、低優先候補は8pxとする。

### 6.2 表示

- 候補に入ったら外径10pxの空円を表示する。
- 確定候補は外径16px、線幅2pxで表示する。
- ラベルに `交点`、`端点`、`中心`、`主点`、`副点`、`曲線上` を表示する。
- 吸着によってポインタ画像を飛ばさず、幾何プレビューの始終点だけ候補位置へ置く。
- Shiftを押している間は全スナップと方向拘束を無効にし、ラベルへ `スナップなし` を表示する。
- Shiftを離すと直ちに戻す。トグルにはしない。

### 6.3 グリッド

```text
主点間隔: 数式入力可能なmm
副点: なし | 1/2 | 1/3 | 1/4
原点: X,Y,Z
向き: 現在作業平面
```

- 主点は直径4px、副点は直径2px。
- 副点の濃度は主点の55%。
- ズームアウト時は最小画面間隔6pxを下回る副点を省略する。
- 「グリッド原点を移動」は原点ハンドルをドラッグし、通常スナップで任意点へ合わせる。
- 数値入力とドラッグは同じ設定を更新し、Undo可能にする。
- 1/3は主点間に2個、1/4は3個の副点を置く。
- 保存値は作業平面上のUV原点とし、UIでは換算したXYZとUVを同時表示する。XYZ入力は平面上へ
  `modelLinearMm` 内で載る場合だけ受け付ける。
- 作業平面の再計算では原点UVを保って追従する。参照切れ時に別平面へ勝手に移さない。

## 7. カーソル連動数値入力

### 7.1 共通

最初の幾何入力後、カーソルから16px右下に小型入力列を表示し、最初の主要寸法欄へ自動フォーカスする。
同じ内容を右パネルにも表示する。

- 入力中もマウス移動でプレビューは更新する。
- 数値を確定した欄はロックされ、マウス移動で変えない。
- Tab/Shift+Tabで欄移動。
- Enterで現在欄を評価し、必要欄が揃っていればFeatureを確定。
- Escでコマンド取消。
- 入力列が画面外へ出る場合はカーソル左または上へ自動配置する。
- 数式と評価値を同時表示する。例: `(180/2)*3 = 270 mm`。

### 7.2 直線

作業平面:

```text
長さ
平面内角度
du
dv
```

3D直接作図:

```text
長さ
dX
dY
dZ
世界X/Y/Zとの角度
```

最初の入力値に応じて解く。過剰拘束または矛盾時は該当欄を赤表示し、最後の変更だけcommitしない。

### 7.3 円と円弧

- 円: 中心を指定後、半径へフォーカス。
- 3点円弧: 始点、通過点、終点。
- 両端+半径: 始点、終点、半径、膨らむ側。
- 始点+方向: 始点、接線または法線角、半径または接線角、中心角または円弧長。
- Spaceで膨らむ側または法線側を切り替える。
- 半径不足など解がない場合は必要最小半径を表示する。

## 8. 作図モード

ツール列:

```text
作図点
直線
ポリライン
矩形
円
円弧
Bezier
スプライン
トリム
延長
分割
結合
端点一致
接線接続
曲率接続
C面取り
R丸め
```

### 8.1 作図点

- 自由点、スナップ点、XYZ数値、作業平面UV数値で作る。
- 円中心、円弧中心、曲線制御点、測定点から作れる。
- 点を作った後も作図ツールは継続し、Escで終了する。

### 8.2 トリム/延長

- 対象にホバーすると変更後を色付きプレビューする。
- トリムは削除部分を赤、残る部分を通常色。
- 延長は追加部分を緑。
- 境界候補が複数なら右クリック候補一覧またはSpaceで切替。
- 直線と曲線を同じコマンドで扱い、別ツールへ分けない。

### 8.3 作業平面

利用者向け名称と入力:

| 名称 | 入力 |
| --- | --- |
| 基準の向き | XY/XZ/YZ |
| 距離をあけて平行 | 平面または平面Face+距離 |
| 点を通り平行 | 平面+点 |
| 2面のまんなか | 平行な2面 |
| 円筒の中心 | 円筒状Face |
| 辺を軸に傾ける | 辺+基準面+角度 |
| 3点を通す | 非一直線の3点 |
| 2辺を含める | 同一平面上の2辺 |
| 辺を通り面に接する | 辺+曲面 |
| 点を通り面に接する | 点+曲面 |
| 点で曲線に直角 | 点+曲線 |

Inventor/Fusionの名称をそのまま複製せず、入力条件が分かる日本語にする。
実行不能な組合せは必要条件と選択済み条件を右パネルへ表示する。

## 9. 部品モード

ツール列:

```text
押し出し
ワイヤー群から部品
形状ガイド
面へ投影
足す
引く
現在状態を固定
```

### 9.1 押し出し

右パネル順序:

1. 入力輪郭
2. 方向
3. 終端
4. 出力
5. 部品演算
6. 結果プレビューと検査
7. 確定

入力輪郭欄は、選択された複数線分を論理輪郭ごとに表示する。

```text
輪郭1  閉  5線分  穴0  有効
輪郭2  開  3線分        ワイヤー出力のみ
輪郭3  閉  1円          有効
```

出力チェック:

```text
[ ] 押し出し先の輪郭
[ ] 側面の境界線
[ ] 部品
```

部品を選ぶと「新規 / 選択部品へ足す / 選択部品から引く」をsegmented controlで表示する。
対象部品は3Dで明示選択する。近傍から自動選択しない。

### 9.2 ワイヤー群から部品

1. ワイヤーまたはグループを選択。
2. 「閉じた立体輪郭を探す」。
3. 候補を半透明色分け表示。
4. 未解決辺を赤、2回利用辺を緑、過剰辺を紫で表示。
5. 候補が複数なら一覧から1つ選択。
6. 名前と用途を指定。
7. 検査成功後に確定。

失敗時は「部品にできません」の下に、閉じていない辺数、非平面輪郭、分岐、自己交差を件数と位置付きで示す。
アプリを終了させてはならない。

### 9.3 形状ガイド

右パネルは役割テーブルを使う。

| 役割 | 番号 | 線数 | 接続 | 方向 | 元ワイヤー |
| --- | ---: | ---: | --- | --- | --- |
| 外形U | 1 | 3 | 有効 | 正 | arc_1 + line_2 + arc_3 |
| 外形U | 2 | 2 | 有効 | 逆 | ... |
| 断面 | 1 | 2 | 有効 | 正 | ... |
| 断面 | 2 | 4 | 有効 | 正 | ... |

ボタン:

```text
選択を新しい外形へ
選択を新しい断面へ
選択を既存行へ追加
行を上へ / 下へ
行を削除
自動整列を再実行
```

- 1行が1つの論理WireChainで、複数線分を持てる。
- 断面順、方向、対応基準点を表で編集できる。
- 両端が外形へ接続していることを接続列に表示する。
- 3D上で表の行を色分けし、端点と進行矢印を表示する。
- methodをPlanar/Ruled/Loft/Guided/Gordon/Boundary fillから選ぶと、必要役割だけ表示する。
- 不足している役割をガイドに具体表示する。

## 10. 製作モード

右パネルは1本の手順として並べる。

```text
1 元部品と範囲
2 作り方: 1枚 / 少数 / 完全分割 / 混合
3 再現度と偏差
4 曲げ方向
5 切れ目
6 手動境界
7 生成
8 部材一覧と誤差
9 型紙 / 組立確認
10 現在状態を固定 / 出力へ
```

### 10.1 元部品

- Partを1つ以上明示選択する。
- Subshapeを部分選択できる。
- 周辺接続ワイヤーを「参照として追加」できる。
- 近似する範囲、形状維持範囲、無視する範囲を色分けする。

### 10.2 設定

- 再現度は1から10のsliderと数値最大偏差mmを併記。
- 部材数上限と最小幅を数値入力。
- 切れ目ON/OFFはcheckbox。
- 切れ目方向は `自動 / U / V / 両方`。
- 切れ目形状はmenu。
- 設定変更後は自動debounce再計算せず、「プレビュー更新」を押す。軽い表示だけ即時更新してよい。
- 長い処理は進行率、現在段階、Cancelを表示する。

### 10.3 生成結果

部材表:

| 使用 | 番号 | 種類 | 最大偏差 | RMS | 切れ目 | 状態 |
| --- | ---: | --- | ---: | ---: | ---: | --- |
| check | 1 | 円筒帯 | 0.08 mm | 0.03 mm | 0 | 有効 |

- 行選択で3D部材を強調。
- 任意の行だけ型紙、固定、出力対象にできる。
- 微小部材、偏差超過、開口欠損は警告アイコンと詳細を持つ。
- パネル数だけを成功の根拠にしない。

### 10.4 手動境界

既存または新規Wireを選び、役割を次から割り当てる。

```text
完全分割
折り線
切れ目
開口
つなげておく
切断禁止
曲げ方向
```

割当後に対象線を色と線種で表示し、凡例を常時出す。

### 10.5 組立確認

- 0から100%のmaster slider。
- 数値欄で0.1%単位入力。
- Fold一覧で角度と個別進行度を編集。
- 0%、現在%、100%のボタンは移動コマンドであり、自動吸着設定ではない。
- 元完成品、製作モデル、重ね表示をsegmented controlで切替。
- 寸法保持違反、接着辺gap、自己交差をビュー上に表示。
- 「現在状態を固定」は現在の値を名前付きで固定する。出力は `ワイヤーのみ / 部品のみ / 両方` の
  segmented controlで選ぶ。
- ワイヤー出力は `境界 / 折り / 切れ目 / 開口` をチェックで絞り、既定は全てONとする。
- 部品出力を選ぶ場合は `接着して1部品 / 部材ごと` と板厚位置を指定する。
- 両方を選んだプレビューでは、生成予定ワイヤーを部品境界へ重ね、一致検査の結果を表示する。

## 11. 出力モード

### 11.1 対象

```text
全ての表示部品
選択した部品
選択した製作部材
現在の型紙
選択したワイヤー
```

既定は `選択した部品`。選択0なら実行不可で理由を表示する。
非表示かどうかだけで対象を決めない。

### 11.2 形式

- Part: STL、STEP
- Wire/Pattern: SVG、DXF、1:1 PDF
- FabricationModel: 現在の組立状態をWire、Part、または両方へ固定してから各形式へ出力
- Project: `.kcd2`

出力ボタンの直前に検査結果を表示する。

```text
対象 3部品
閉じたソリッド 3/3
開口 8
最小肉厚 0.20 mm
現在の組立率 30.0%
警告 0
```

問題がある対象だけを除外して続行する場合は、除外一覧を明示し、利用者の確認を必要とする。

## 12. 測定ウィンドウ

非モーダルで3Dビュー操作を妨げない。

- 2点: 距離、dX/dY/dZ、XY/YZ/ZX、軸角度。
- 3点: 内角、方向付き角度、法線。
- 要素: 長さ、半径、弧長、接線、法線、曲率。
- 選択履歴を直近10件まで保持。
- 値をクリックするとコピー。
- `この位置に作図点`、`中心へ作図点`、`制御点へ作図点`。
- 測定結果は参照であり、形状を動かさない。

## 13. ビュー操作

### 13.1 マウス

- 中ボタンドラッグ: 注視点まわりのorbit。
- Shift+中ボタンドラッグ: pan。
- wheel: cursor位置を中心にzoom。
- ダブルクリックwheel相当または全体表示ボタン: fit。
- 慣性回転なし。ボタンを離したら停止。
- 選択中Partが1つならorbit中心の既定候補にするが、勝手にカメラを移動しない。

### 13.2 ビューキューブ

- キューブ面クリック: 正面/背面/上/下/左/右へ正対。
- 辺/角クリック: 等角方向へ正対。
- キューブ本体ドラッグ: カメラ姿勢を連続回転。
- キューブも画面内で同じ姿勢変化を示す。
- ドラッグ中に90度へ吸着しない。
- release後に自動roll補正しない。
- 正対クリックだけが離散方向を使う。

### 13.3 XYZ回転矢印

切替:

```text
絶対軸: 世界X/Y/Z
相対軸: 選択PartのローカルX/Y/Z
```

- 各軸矢印をdragして連続回転。
- 感度は0.25deg/pixel。
- Shift併用は0.05deg/pixel。
- Ctrl併用は1.0deg/pixel。
- クリックは15deg回転。90deg固定ではない。
- 数値欄へ任意角度を入力できる。
- カメラだけを回し、モデル座標を変更しない。
- 相対軸対象がないときはdisableし、理由を表示する。

## 14. 表示設定

表示モード:

```text
輪郭
シェーディング
輪郭+シェーディング
ワイヤーフレーム
曲率
製作誤差
```

利用者は次を変更できる。

- ワイヤー種類ごとの色、線幅、実線/破線/一点鎖線。
- 選択、ホバー、参照、エラーの色。
- Partの面色、透明度、輪郭線。
- 形状ガイドの面色、透明度、等パラメータ線。
- 背景色、作業平面色、主/副グリッド色。
- 点サイズ、スナップリングサイズ。
- fold/cut/opening/boundaryの線種と色。

設定はthemeとは別に保存する。色コントラストが不足する組合せには警告する。

## 15. Windows 95テーマ

- Windows 95テーマは既定テーマとして維持する。
- Windows標準配色の灰色、立体境界、角のあるボタン、古典的menu/toolbar/tab/scrollbarを使う。
- 角丸、半透明blur、gradient、巨大見出し、カードUIを使わない。
- アイコンは16x16または24x24の統一pixel gridに合わせる。
- disabled、pressed、default、focusの各状態を区別する。
- High DPIではnearest-neighborでアイコンを崩さず、文字と操作領域はDPIに合わせて拡大する。
- 外観themeのコードにモデリング状態や幾何分岐を入れない。
- 標準themeへ切り替えても配置、文言、機能、最小サイズを変えない。

## 16. エラーとクラッシュ防止

- geometry/kernel例外はCommand境界でDiagnosticへ変換する。
- `catch (...)` で成功扱い、空形状返却、無言継続をしてはならない。
- recoverable errorでアプリを終了しない。
- 作成失敗時は選択と入力値を維持し、修正して再実行できる。
- 問題箇所へズームする操作を提供する。
- 連続3回同じ失敗が起きても状態を破壊しない。
- 保存前、出力前、Part commit前に検証する。
- 致命的内部エラーは自動保存回復ファイルを別名で作り、元ファイルへ上書きしない。

## 17. 初心者向け受入シナリオ

説明書を読まず、操作ガイドだけで次を完了できること。

1. 矩形を寸法入力で描き、20mm押し出してPartを作る。
2. 円を重ね、貫通で引いて穴を作る。
3. 複数の円弧と直線から閉輪郭を作り、形状ガイドを作る。
4. 複数線分の2断面と2ガイドから曲面を作る。
5. ワイヤー群から閉じたPart候補を選ぶ。
6. Partの曲面範囲を製作近似し、30%組立状態をSTEPへ出す。
7. 選択した1部材だけの型紙を1:1 PDFへ出す。
