画像を貼る / 編集

具体例: 図面写真の100mmをCADの100mmに合わせる

準備

長さが分かるPNG/JPEGを用意する

操作手順

  1. 画像を貼るツールで画像を選ぶ
  2. 貼る作図面と位置を指定する
  3. 画像の基準2点とCAD側の基準2点で長さを合わせる

設定: 基準の実長: 100mm

結果を確認

画像の位置・向き・大きさを調整できる。選択した画像は同じツールで再編集する。

取消・やり直し

未確定入力をEscで取り消します。道具を終えるときは選択(V)または別の道具へ切り替えます。 確定済みの文書変更はCtrl+Z、やり直しはCtrl+Yです。保存・書出し済みのファイルはUndoの対象ではありません。

進めない場合

文書がありません。

対象欄と3Dの強調を照合し、必要な線・面・部品を各役割へ指定します。処理中は計算表示を確認し、取消が可能な処理は取消を使います。
