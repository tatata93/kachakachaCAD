同一KCDへ出力

具体例: 部品を同じ文書の別位置へ配置する

準備

箱の部品を作る

操作手順

  1. 箱を選ぶ
  2. 同じKCDへ出力を開く
  3. 配置基準点と配置面を指定して確定する

設定: 出力先: 同じ文書

結果を確認

元を残して現在形状のコピーができる。1回の取消で戻せる。

取消・やり直し

ダイアログの取消、またはペインの取消を使います。即時操作には未確定段階がありません。 確定済みの文書変更はCtrl+Z、やり直しはCtrl+Yです。保存・書出し済みのファイルはUndoの対象ではありません。

進めない場合

選択形状の独立コピーを配置します。

対象欄と3Dの強調を照合し、必要な線・面・部品を各役割へ指定します。処理中は計算表示を確認し、取消が可能な処理は取消を使います。

output.copy。図の設定と縮尺は例です。方式ごとの制限、プレビューと確定済み結果の区別を確認してください。
