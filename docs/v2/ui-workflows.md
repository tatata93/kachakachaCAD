# V2 UI ワークフロー

## 1. 適用規則

画面、カーソル、選択、ToolSession、キー操作の規範は `ui-ux-integrated-spec.md` に従う。
この文書は各作業で「何を、どの順に選び、何が生成されるか」を固定する。

全ワークフローに次を適用する。

1. 標準順は `ツール -> 対象 -> 値 -> プレビュー -> 確定`。
2. 有効な事前選択がある場合は同じ入力として取り込む。
3. Ctrlで同じオブジェクト内を含む複数サブ要素を選べる。
4. 入力はInput色、結果はPreview色で表示する。
5. Enterで確定、Escで1段戻る、戻れなければ取消。
6. 入力オブジェクトは削除しない。
7. 失敗は理由番号、問題箇所、修正方法を表示する。

Ctrl追加は実行中ツールへの入力に使い、任意選択・削除への切替を兼ねない。
ツール入力を保った任意選択は「選択・削除」ボタンで明示的に始める。
右ペインに入力が一時停止中であることと選択件数を示し、「元の入力へ戻る」
（Esc/Enterも同じ）と「選択を入力に使う」を区別する。停止中の確定操作を無効にする。

## 2. 共通画面

### 2.1 コマンド開始

利用者はメニュー、上部道具バー、右クリックメニュー、ショートカットのいずれかからCommandIdを開始する。
入口が異なっても同じToolSessionを使う。

開始時に右プロパティへ次を表示する。

- ツール名
- 必要な入力役割と件数
- 取り込み済み対象
- 数値または選択式パラメータ
- 診断
- 確定、取消

ビューポート左上には `ツール名` と `次に選ぶもの` だけを表示する。

### 2.2 コマンド切替

別のツールを選んだ場合、未確定プレビューを破棄して前のToolSessionを終了する。
前のツールの入力色、カーソル近傍値、数値欄、押下表示を残さない。
通常選択は、新ツールの入力に適合する場合は取り込み、適合しない場合も選択集合として保持する。

### 2.3 事前選択

必要な型と個数を満たす場合は直ちにプレビューへ進む。不足している場合は取り込める対象だけをInputへ移し、
残りをビューポートから選ばせる。過剰または不適合な対象は勝手に削除せず、取り込まなかった理由を表示する。

## 3. 選択とHover

### 3.1 通常選択

- 点、端点、線分、連続鎖、面、部品、製作モデル、作業平面を個別に選べる。
- Ctrlで追加と解除を行う。
- 矩形選択は左から右で完全内包、右から左で交差を含む。
- 空白クリックは選択解除。ただしToolSession中は入力を取消さない。

### 3.2 重なり候補

Hoverは最上位候補だけを強調する。Tabで候補を巡回し、Alt+クリックで奥の候補を選ぶ。
右クリック候補一覧には種類、表示名、所属グループを表示する。

### 3.3 スナップ

端点/作図点、交点、中点/中心/四分点、最近点、垂足/接点、グリッドの順を基本とする。
現在ツールに適合する候補を優先し、クリックまでは確定しない。
Sを押している間はスナップを解除し、Shiftは方向拘束に使う。

## 4. 作図

### 4.1 直線

1. `直線` を開始する。
2. 始点を選ぶ。空間点、作図点、端点、交点、作業平面上の任意点を使える。
3. 終点を指示する。
4. 距離、水平角、仰角をカーソル近傍または右プロパティで入力できる。
5. Enterで1本確定する。連続作図では確定点を次の始点にする。

Shiftは現在の作図基準に対する水平、垂直、XYZ軸、既存線方向の候補を拘束する。

### 4.2 ポリライン

直線と同じ入力を繰り返す。Backspaceで最後の頂点だけを戻す。
始点へスナップした場合は閉じる候補を明示し、Enterまたはダブルクリックで完了する。

### 4.3 作図点

1. `作図点` を開始する。
2. 3D位置をスナップ、XYZ、選択点からの相対距離で指定する。
3. 必要な数だけ配置し、Escで終了する。

作図点はワイヤーと同様に作業平面へ所有させない。

### 4.4 円

中心+半径、3点、2点直径を選ぶ。方式選択後に必要点を順に取り込み、半径または直径を式入力する。

### 4.5 円弧

次の方式を持つ。

- 3点
- 両端+半径
- 始点+接線/法線方向+半径または角度+中心角または円弧長

段階名と入力済み点を常に表示する。解が複数ある場合はカーソル側の解をPreviewにし、
Tabで反対解へ切り替える。

### 4.6 BezierとB-spline

Bezierは端点と制御点、B-splineは通過点を順に指定する。
Backspaceで最後の点を戻し、右プロパティで次数、閉曲線、接線条件を設定する。

## 5. ワイヤー編集

### 5.1 トリム

2026-10-29オーナー指定: 「元の線を残す」は既定オフ。オフは赤い下見区間だけを
既存ワイヤーから除き、変更前の形状のコピーや非表示ワイヤーを追加しない。オンは変更前の
形状を表示したまま独立した結果を追加する。ワイヤーを対象とする区画トリムも同じ。
部分編集は元Entityと未編集SegmentのUUIDを保ち、分かれた鎖の未編集線分・寸法参照を
正しい結果へ引き継ぐ。完成済みのR・曲線を、過去の入力履歴だけを理由に連鎖削除しない。
線全体を消し真の参照先も削除する場合だけ、削除一覧と3D強調で承認・取消を選ぶ。
参照面・立体は再計算し、不成立時は編集全体を取り消す。承認した編集は1回のUndo/Redoとする。

1. `トリム` を開始する。「元の線を残す」は既定オフ。
2. 消したい区間へカーソルを置く。実際の3D交点・Rの接点・重なり区間の端で区切る。
3. 赤い下見が消したい区間だけになっていることを確認する。重なりはTabで候補を替える。
4. クリックして下見どおりに適用する。周囲を残し、別の区間へ続けて操作できる。

共有する複数出力を他の出力へ影響せず編集できない場合は明示的に拒否し、変更しない。

直線、円弧、Bezier、B-splineの組合せを扱う。交点がない場合は延長交点を勝手に使わない。

### 5.2 延長

1. `延長` を開始する。
2. 延長先の境界を選ぶ。
3. 延長する端部を選ぶ。
4. 交点または指定距離までのPreviewを確定する。

### 5.3 分割、結合、接続

- 分割: ワイヤーと分割点または交差対象を選ぶ。
- 結合: 2本以上の接続可能なワイヤーを順序付きで選ぶ。
- 端点一致: 移動させる端点と基準端点を選ぶ。
- 接線接続: 2本の接続端を選び、どちらを変形するか指定する。
- 曲率接続: 接線接続に加えて曲率連続条件を指定する。

結果の向き、変更範囲、元位置を同時にPreviewする。

## 6. 作業平面

作業平面の方式はCommandとして選び、必要対象を後から取り込む。

| 方式 | 入力 |
| --- | --- |
| 標準面 | XY / XZ / YZ |
| オフセット | 基準平面 + 距離 |
| 3点 | 同一直線上でない3点 |
| 2平面の中間 | 平行な2平面 |
| 角度 | 基準平面 + 回転軸 + 角度 |
| 点を通る平行面 | 基準平面 + 点 |
| エッジを通る角度面 | エッジ + 基準平面 + 角度 |
| 面へ接する平面 | 曲面 + 接点 |
| 点を通る法線面 | 曲線 + 曲線上の点 |

作成後に名前と表示を設定する。作業平面の削除や切替で既存ワイヤーを削除または移動しない。

### 面から作図を始める

「面で作図」は形状ガイドの面とソリッドの表面を同じ手順で扱う。面を選んで起動するか、道具を先に起動して3Dビューで面を1回指す。面指定中はワイヤーや作業面を候補にせず、重なる面はホバーとTabで確認する。左一覧から単一の平らな形状ガイドを選んだ場合はその面を直接使う。曲面は接点を決めるため3Dビューでクリックする。複数フェイスを持つ形状や複数対象は3Dビューで1枚を指定する。
選んだ面そのものを作図基準として使い、別の作業平面を文書に追加しない。上部の「作図面」に面の名前を表示し、標準面・作業平面と切り替えられるようにする。同欄から3Dビューで面を指定する入口も設ける。基準の面番号と接点は操作中だけ保持し、再読込・元形状の変更で失効した場合は有効な標準面へ戻す。選んだ位置を画面中央に置き、全体表示で小さかった面には近づく。ユーザーが既に拡大している倍率は引かず、グリッド間隔も変えない。グリッドの表示・スナップを有効にして直線作図へ進む。面に対するグリッドの角度・間隔・原点も既存のグリッド設定で変更する。
境界は元の幾何曲線を参照し、端点や他のワイヤーとの実3D交点を作図入力に使えること。内側の境界も同じ規則とする。「平面ワイヤのみ」表示でも作図基準の面と境界は残し、独立した編集ワイヤーを勝手に追加しない。画面上だけの交差、別の奥行きの線を実交点として選ばない。基準を切り替えるときは入力途中の点を取り消し、確定済みの線は移動・削除しない。
曲面はクリック位置の接平面で作図し、そのことを表示する。元の面やソリッドと輪郭・穴は変更しない。
面の境界をオフセットするなど独立した編集線が必要な場合は、上部の「輪郭を作図面へ」から明示して写す。現在の作図基準の面を優先し、下見では文書を変更しない。「現在の作図面へ投影する」を既定とし、元の3D境界からの投影距離の最大値・RMS（標本）を表示する。非平面の輪郭を元の形状のまま平面と偽らず、投影を外した場合は元の3D位置で写す。変換できない曲線は理由を示して確定しない。
面の外側と内側の各閉輪郭はそれぞれ1本の編集ワイヤーとして写し、元の面・部品・線・表示を変更しない。「写してオフセット」は既定値で即確定せず、写した線を選択した状態で距離と加工平面の下見へ進める。取消は無変更、写しの確定は1回のUndoで戻す。作図面上に写した輪郭と新しく引いた線の実交点を作図に使えること。
「作業面を作る」の棚でも「面から位置・向きを指定」を押し、同じ面選択で下見を作る。選択だけでは文書を変更せず、名前と数値を調整して「平面を作る」で確定する。選んだ面姿勢は数値欄の表示桁で丸めず保持する。取消と別ツールへの切替で面指定を解除する。

### 投影先を指定する

「面へ投影」の投影先はサーフェス、ソリッドのフェイス、作業面とする。入力役割の切替で候補を絞り、面指定中はワイヤーを除外してホバーとTabを使えるようにする。作業面は種類の切替後、3Dビューの枠・中心か左一覧から指定する。ソリッド全体は投影先のフェイスを特定しない。
面は実際の境界と穴で投影を切り取り、作業面は表示枠に関係なく選んだワイヤー全体を平面へ写す。計算用の平面範囲は曲線の制御点包絡・円の保守的包絡と投影変換から組み立て、表示サイズを使わない。元の面とワイヤーは変更せず、選択フェイス番号は操作中だけに使う。作業面と既存面を混ぜた複数対象、方向・巻付け・最近点、閉領域の面出力、Undo・再読込を確認する。

## 7. 形状ガイド

### 回転面の軸を円から指定する

回転面の「断面」へ回す形状線を、「軸」へ直線または円・円弧を別々に指定する。円・円弧は中心と法線から軸を決め、追加の中心線ワイヤーは生成しない。軸は断面として回さない。「回す角度」を入力するか「一周」で360°にし、下見後に確定する。角度欄は入力欄の上に表示する。元の線は保持し、面だけを1回のUndoで戻せること。直線軸と複数断面の既存経路も維持する。任意の輪郭から形状を推測する機能ではなく、選んだ形状線の回転面とする。

### 7.1 閉輪郭から

1. `閉輪郭から形状ガイド` を開始する。
2. 自動鎖認識またはCtrl選択で輪郭を構成する複数線分を取り込む。
3. 閉鎖、平面性、自己交差、内外輪郭を検査する。
4. 面の向きと境界をPreviewして確定する。

### 7.2 2断面または複数断面

1. `断面から形状ガイド` を開始する。
2. 断面1、断面2、必要なら追加断面を役割ごとに取り込む。
3. 各断面は1本または接続した複数線分でよい。
4. 順序、方向、対応点をPreviewで調整する。
5. 連続性と最大偏差を確認して確定する。

### 7.3 外形と断面

1. `外形・断面から形状ガイド` を開始する。
2. 外形ガイドを2役割以上追加する。各役割は複数線分でよい。
3. 断面ガイドを1役割以上追加する。各役割は複数線分でよい。
4. 両端が接続する形、外形と断面が交差する形を含め、交点と方向を検査する。
5. 役割表で並び替え、反転、削除を行い、Previewを確定する。

## 8. 部品作成

### 8.1 押し出し

1. `押し出し` を開始する。
2. 閉輪郭または形状ガイドを選ぶ。複数輪郭を同時に選べる。
   線上は通常クリックで個別の入力を追加・解除し、線のない内側は領域単位で選ぶ。
   下見が出た後も穴の境界を追加できる。入力収集中は選択を制御点移動に取り違えない。
3. 方向を法線、作業平面法線、XYZ、選択エッジから指定する。
4. 距離を数値、対称、両側別、選択面まで、貫通から指定する。
5. 出力を `部品 / 形状ガイド / ワイヤー / 部品+ワイヤー` から選ぶ。
6. Booleanを `新規 / 足す / 引く` から選ぶ。部品以外では表示しない。
7. Previewを確定する。
8. 確定後も押し出しを維持し、次の面・輪郭を選ぶ。前の下見と選択枠は残さない。

ワイヤー出力は複製輪郭と対応接続線だけを作る。入力は残し、`生成後に入力を隠す` は任意とする。

### 8.2 閉空間から部品

1. `閉空間から部品` を開始する。
2. `境界を手動指定` または `閉空間を検索` を選ぶ。
3. 検出された領域を一覧と3D強調で確認する。
4. 隙間、重複、自己交差、非多様体がなければ確定する。

複数の閉空間が見つかった場合は、作る領域を複数選択できる。非連結結果は別部品に分ける。

### 8.3 厚みを付けて部品化

1. `厚みを付けて部品化` を開始する。
2. 形状ガイドまたは部品の面を選ぶ。
3. 片側、反対側、両側、選択面までを選ぶ。
4. 厚さと方向を入力する。
5. 自己交差と最小曲率半径を検査し、Previewを確定する。

UI、ツリー、診断で `板材化` と呼ばない。

## 9. 製作用近似

### 9.1 近似モデルを作る

1. `製作用近似` を開始する。
2. 元の部品または形状ガイドを選ぶ。
3. 接続を保つワイヤー、面、開口を追加選択する。
4. 大きな連続部材の優先度、再現度、最大部材数、最小幅、切れ目の向きと可否を設定する。
5. 部材、切れ目、折り線、最大/RMS偏差をPreviewする。
6. 元モデルと別オブジェクトとして確定する。

元モデルを変更した場合は製作モデルを再評価する。製作モデル側の手動境界は明示Featureとして保持する。

### 9.2 組立確認

1. 製作モデルを選び `組立確認` を開始する。
2. 全体組立率0から100%または個別折り角度を変更する。
3. 境界一致、実長、開口位置、干渉、未接続部を表示する。
4. 任意状態で `現在状態を固定` を選ぶと、独立したワイヤー、形状ガイド、部品を必要に応じて作る。

途中状態で寸法を拡大縮小せず、剛体回転と規定した曲げ変形だけを使う。

### 9.3 型紙

製作モデルまたは選択部材から型紙を作る。部材境界、切断線、折り線、切れ目、開口、基準寸法を表示する。
現段階でのりしろは作らない。

## 10. 測定

### 10.1 2点

2点を選ぶと全長、dX、dY、dZ、XY/XZ/YZ投影距離、各軸との角度を同時表示する。

### 10.2 3点

頂点を含む3点を選び、内角と補角、基準平面への投影角度を表示する。

### 10.3 線と曲線

線分、円弧、Bezier、B-splineの任意の組合せを選ぶ。指定位置の接線角度と法線角度、
最短距離、交点がある場合は交点を表示する。

測定結果から作図点または基準方向を作れるが、明示した場合だけDocumentへ追加する。

## 11. 出力

1. `出力` を開始する。
2. 選択、グループ、部品、製作モデル、型紙から対象を指定する。
3. STL、STEP、SVG、DXF、1:1 PDFのうち適合形式を選ぶ。
4. 対象数、単位、実寸、閉鎖性、偏差、ページ分割を検査する。
5. 問題がなければ保存する。

選択部品だけ、任意の組立率で固定した部品だけを出力できる。STLとSTEPは同じ検査済みB-Repを使う。

選択出力の「別のKCD2とまとめて新規保存」では、既存KCD2を選び、その文書へ現在の選択形状の
独立コピーを加えた新しいファイルを保存する。既存文書の履歴・グループ・参照・資産は保つ。
プレビューは追加する形状を示し、既存文書はファイル名と対象数で確認する。配置は共通の配置欄で指定する。
元の両ファイルと同じ保存先は拒否し、読み込んだ後に既存ファイルが変わった場合も再選択を求める。
中止や読込・保存失敗は元の文書とファイルを変更しない。通常の別KCD2出力は新規文書へのコピーのままとする。

## 12. 実用受入シナリオ

1. 作業中グループを `ER前頭部` にする。
2. 複数作業平面へ独立した輪郭と断面ワイヤーを作図する。
3. 複数線分から成る外形と断面を使い、ER1/初期ER2の1/87形状ガイドを作る。
4. 6枚窓の閉輪郭を投影し、開口を含む形状ガイドを作る。
5. 厚みを付けて部品化し、理想モデルを保存する。
6. 前面を少数の大きな部材へ製作用近似する。
7. 屋根肩だけに必要な切れ目を入れ、窓とライト開口が保たれることを確認する。
8. 組立率0、30、100%で実長が一致することを測る。
9. 30%状態を固定し、選択部品をSTLとSTEPへ出力する。
10. 型紙をSVG、DXF、1:1 PDFへ出力する。

この流れをツール先行で完走でき、同じ対象を事前選択して開始しても同じ結果になることを受入条件とする。

### 回転面の生成物（2026-11-19）

回転面の「生成物」で「面のみ／ワイヤのみ／面＋ワイヤ」を選ぶ。既定は面のみ。ワイヤーは端の円・円弧と回転した形状線を生成し、一周では反対側の形状線を生成する。元と同じ位置の線は重複させない。下見を同じ選択へ反映し、ワイヤのみでは文書に面を追加しない。面＋ワイヤは1回の確定とUndoにまとめる。

曲線のオフセットでは、下見に偏差上限と標本RMSを表示する。元の曲線は残し、許容差を超える場合は理由を示して確定しない。
