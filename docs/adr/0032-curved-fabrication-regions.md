# ADR 0032: 開口と切り欠きを保持した曲面の製作近似

2026-10-28 オーナー指示。状態: 採用。検証記録は `docs/development/curved-material-results-20261028.html`。

## 決定

曲面の車体側面・前面を、複雑な外周、端へ開いた窓、複数の穴を維持して製作近似する。
ADR0030の「穴付き曲面を拒否する」制限を置き換える。矩形を穴へ被せることは引き続き禁止。

支持曲面のUV評価と、実際の材料領域（先頭が外周、残りが穴）を別々に運ぶ。
専用の製作入力APIを追加し、押し出し用FaceBoundaryOfの平面限定契約は変更しない。
非平面境界はUVと3Dの標本誤差を検査し、原曲線・原本ファイルを変更しない。
帯の範囲と材料領域の共通部分を取り、凹外周、穴が境界へ開く切り欠き、分離領域を区別する。
1枚指定では連結している材料を1枚にする。標本の三角形を部材へ分割しない。
非連結の材料を見かけだけ1枚にせず、その理由と実枚数を示す。

型紙は各帯の等長展開へ外周・穴を写す。平面への単純投影は展開と呼ばない。
下見、0/途中/100%の線・面・厚み付き部品は同じ境界写像を使う。
誤差目標を超える1枚案は超過を明示し、枚数上限を無断で増やさない。

## 実装境界

段階1はWP-09: カーネルの製作領域入力と、純粋なUV領域切り分け・展開写像。
段階2はWP-10: 既存製作UI、下見、固定生成、型紙、保存・履歴と実モデル受入へ接続。
公開する入力型・関数と試験は同段階で文書化する。OCCT型をコアへ出さない。
保存するのは元参照と既存製作設定であり、新しい生成物を保存正本へ追加しない。

## 受入

- 1枚の円筒曲面上の複雑穴・複数穴・端の半円切り欠きを保持し、解析弧長と母線長で展開を検査。
- 凹外周の帯切り分け、穴が帯境界へ開く例、材料が分離する例、内周消失・不正入力を検査。
- 添付115投影のコの字窓と閉じた側窓を含む曲面で、1枚、型紙、生成面・厚みを確認。
- 0/35/100%の辺長、開口、100%再組立位置、最大/RMS偏差、保存再読込・Undo/Redo・取消復帰。
- Windows全体・配布版検証・通常起動後に配布。実印刷・材料弾性は別の実物検証とする。

## 統合時の精度と操作

UVの進み方は長さ比ではないため、実3D境界を帯三角へ対応付けてから展開する。
下見はその三角形を直接描き、毎回のBoolean切り抜きは行わない。
生成時に支持四辺形がねじれていれば同じ2枚の平面B-Repを使い、別の双線形曲面を作らない。
空帯は材料無しとして記録し、矩形へ戻さない。平面部材の開始位置は実部材数で決める。
同じ帯の分離片を別々の進行度で曲げる操作は今回は行わず、全片選択を案内する。
複数の元面を接続して全体1枚へする処理は追加せず、ボタンにも面ごとの指定と明記する。

製作済み境界が1枚の支持曲面上にある場合は、切断用立体とのBooleanで境界を再近似せず、
同じ3D曲線の面上表現から直接B-Rep外周と穴を作る。細かな折れを含む帯の穴付き厚みは、
同じ材料領域の表裏と開口側壁から閉じたB-Repを作り、通常の体積・閉殻検査を維持する。
レール標本は許すずれの1割を予算として実偏差を報告し、同一直線上の冗長標本を除去する。
表示用三角形の追加で形状安全検査のキャッシュを失わないよう、正本の幾何・位相・向き・位置と
許容差を照合し、表示三角形だけはキャッシュキーに含めない。

外周だけのコの字切り欠きも穴付き領域と同じ厚み経路で処理する。UVの外接範囲だけで
矩形と判定しない。戻り曲げの側壁の向きは、全体の投影面積ではなくUVの巻方向と
元の面の向きから決定する。元の境界と一致しないソリッドは成功にしない。

ねじれた帯を平面B-Repへ構成した場合は、共有頂点に接するオフセット平面の交点を解く。
全隣接面に対する法線厚み残差をモデル許容内で確認し、内部共有辺には側壁を作らない。
外周と穴の自由境界だけを塞ぎ、通常の閉鎖性・体積・自己交差の出力検査を維持する。
交点が不定、非多様体、接合不成立の結果を成功にしない。実際の曲げ姿勢を画面へ収める
表示範囲調整には、元形状だけでなく展開プレビューのレールも含める。

1枚の帯で母線がほぼ平行な場合、残りの近似誤差予算内で母線を共通方向へ近似する。
調整による最大標本距離を近似の最大偏差へ加算し、その同じ帯を改めて等長展開する。
誤差予算が足りなければ元レールを保ち、許容値を増やさない。元曲面は変更しない。
これにより微細なねじれ三角形のオフセット接合を避ける。型紙・下見・面・部品は
調整後の共通形状を使い、生成時だけ形をすり替える処理にはしない。
平面群の解析的接合が成立しない場合は、既存の汎用オフセットと同じ安全検査へ戻す。
