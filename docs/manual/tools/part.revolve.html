回転体(立体)

具体例: 半径5mmの円形部品を回転体で作る

準備

軸から5mm離れた矩形断面と直線軸を用意する

操作手順

  1. 回転体を選ぶ
  2. 断面と軸を各欄へ追加する
  3. 角度360度、新規を選んで確定する

設定: 360°。軸をまたがない断面

結果を確認

軸の周囲を一周したソリッドができる。

取消・やり直し

ダイアログの取消、またはペインの取消を使います。即時操作には未確定段階がありません。 確定済みの文書変更はCtrl+Z、やり直しはCtrl+Yです。保存・書出し済みのファイルはUndoの対象ではありません。

進めない場合

閉じた輪郭を1つ以上と、回転軸にする直線を選んでください。

対象欄と3Dの強調を照合し、必要な線・面・部品を各役割へ指定します。処理中は計算表示を確認し、取消が可能な処理は取消を使います。

part.revolve。図の設定と縮尺は例です。方式ごとの制限、プレビューと確定済み結果の区別を確認してください。
