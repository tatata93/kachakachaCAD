# V1 の操作系と、V2 でどうなっているか

V1 の `src/apps/cad/CadViewport.cpp` と `MainWindow*.cpp` を読んで書き出したもの。
**憶測は入れていない。** 各行に V1 側の根拠を付けてある。

いちばん下に「V2 で消えているもの」をまとめた。

---

## 1. マウス

### 1-1. 移動・回転・拡大

| 操作 | V1 | V2 のいま |
| --- | --- | --- |
| **中ボタンでドラッグ** | **画面を移動(パン)** | **無い** |
| **右ボタンでドラッグ** | **画面を移動(パン)** | **割り当てない**(`ui-ux-integrated-spec.md` §5.2)。引きずっても画面は動かず、献立も出ない |
| **Shift + 中ボタンでドラッグ** | **軌道回転(オービット)** | **無い** |
| ホイール | 拡大縮小 | 拡大縮小(同じ) |

V1 の根拠(`CadViewport.cpp`):

- `mousePressEvent` 5798行 `orbitInteraction_ = 中ボタン && Shift`
- `mouseMoveEvent` 6294行 `dragButton_ == 右 || dragButton_ == 中` → `target_` を動かす(パン)
- 同 6292行 `if (orbitInteraction_) OrbitViewByPixels(dx, dy)`
- `wheelEvent` 6777行 `pow(1.0015, angleDelta)`、0.25〜400 px/mm に制限

**どちらも画面の中心を軸に拡大する。** カーソル位置を軸にはしない(V1・V2とも)。

### 1-2. 左ボタン

| ところ | V1 | V2 のいま |
| --- | --- | --- |
| ビューキューブ | 掴んで回す / 面を押すと正対 | 同じ |
| リング(軸まわり) | 掴んで連続回転 | 同じ |
| 画面固定の矢印 | 掴んで回す(下段=左右、右列=上下) | 同じ |
| **選択ギズモの矢印・リング・中心** | **掴んで移動・回転** | **無い** |
| **選んだ物そのもの** | **掴んで画面に平行に移動** | **無い** |
| **ワイヤーの制御点** | **掴んで動かす**(9px以内) | **無い** |
| **グリッド原点の点** | **掴んで動かす**(14px以内) | 押す場所を1回聞く形。掴んで引きずるのではない |
| 何もないところ | 選択 / 作図の点を置く | 同じ |

V1 の根拠: `mousePressEvent` 5820行(ギズモ)、5869行(制御点)、5845行(グリッド原点)、
5895行(選んだ物を掴む)。

### 1-3. 右ボタン(動かさずに離したとき)

**V1 は道具ごとに意味が違う。** V2 は道具に関係なく「道具を終える」だけ。

| 道具 | V1 の右クリック |
| --- | --- |
| 選択 | **コンテキストメニューを出す**(`contextMenuEvent` 6758行) |
| 測定 | 測定を消す |
| 2点を線で結ぶ | 1点目を取り消す |
| 端点一致 / 接線 / 曲率 | 拾ったものを取り消す |
| トリム / 延長 | 道具を抜ける |
| 面取り(コーナー) | 1点目を取り消す。無ければ **Enterと同じく一括適用** |
| 分割 | 作図を取り消す |
| ポリライン(2点以上) | **確定する** |
| スプライン(4点以上) | **確定する** |
| その他の作図(1点も置いていない) | **近くの点から引き始める**(吸着点を拾って1点目にする) |
| その他の作図(途中) | 取り消す |

根拠: `mouseReleaseEvent` 6478〜6625行。

### 1-4. 修飾キー

| キー | V1 | V2 のいま |
| --- | --- | --- |
| **Ctrl(作図中)** | **吸着を一時的に止める**(`SnapPoint` 3234行) | **無い。** `S` で入切するだけ |
| **Shift(作図中)** | **水平・垂直へ固定。矩形なら正方形へ固定**(`ApplyDrawingConstraint` 3322行) | **無い** |
| Ctrl または Shift(選択中) | 選択に足す / 外す(6633行) | Shift=足す、Ctrl=入替、Alt=外す |

V2 は選択の修飾キーだけ V1 より細かいが、**作図中の Ctrl と Shift が丸ごと無い。**

### 1-5. カーソルの形

V1 は状態でカーソルを変える(`setCursor` 15か所)。

| 状態 | 形 |
| --- | --- |
| 選択道具 | 矢印 |
| 作図道具 | **十字**(`DrawingCrossCursor` 994行) |
| 掴んでいる | 握った手 |
| 掴めるところの上 | 開いた手 / 指差し |
| 制御点の上 | 四方向矢印 |

**V2 はカーソルを一度も変えない。** 掴めるかどうかが手元で分からない。

## 2. キーボード

### 2-1. Esc(オーナー指摘の点)

**V1 の Esc は必ず「選択道具・何も選んでいない」で終わる。**

`CadViewport::keyPressEvent` 6667行〜、および `MainWindow.cpp` 265行:

```
// 他CAD同様: Esc = 選択モード・何も選ばれていない状態へ。
SetViewportTool(ViewportTool::Select);
UpdateSelections({}, true);
```

Esc は段階を踏む。**まず「いまやりかけていること」を1つ取り消し、そのうえで選択へ戻る。**

1. ギズモを引きずっている → 引きずりを中断(確定しない)
2. グリッド原点を引きずっている → 中断
3. 制御点を引きずっている → 中断
4. 測定中 → 測定を消す
5. 2点を線で結ぶ / 端点一致 / 接線 / 曲率 / 面取り → 拾ったものを消す
6. トリム / 延長 → 道具を抜ける
7. それ以外 → 作図を取り消す
8. **そのうえで、必ず選択道具へ戻り、選択を空にする**

**V2 の Esc は 7 だけ。** 選択道具へも戻らないし、選択も残ったまま。
(`V2Viewport::keyPressEvent`: `CloseCursorInput(); CancelTool();`)

### 2-2. Enter

V1: 作図を確定(`FinishDrawing`)。V2: 数値入力の欄を確定して作図を終える。ほぼ同じ。

### 2-3. 数字を打ち始めると数値入力が開く

V1 は `0123456789.+-(pP` のどれかを打つと数値入力が始まる(6660行)。
V2 も同じ(打った文字がそのまま欄に入る)。

### 2-4. 道具のショートカット ── **V2 と食い違っている**

| キー | V1 | V2 のいま | |
| --- | --- | --- | --- |
| `V` | **選択** | (無し) | **消えた** |
| `D` | **作図点** | (無し) | **消えた** |
| `L` | 直線 | 直線 | 同じ |
| `P` | ポリライン | ポリライン | 同じ |
| `R` | 矩形 | 矩形 | 同じ |
| `C` | 円 | 円 | 同じ |
| `A` | 円弧 | 円弧 | 同じ |
| `B` | **ベジエ** | (無し) | **消えた** |
| `S` | **スプライン** | **スナップ入切** | **意味が違う** |
| `I` | **端点一致** | (無し) | **消えた** |
| `T` | **接線接続** | **トリム** | **意味が違う** |
| `Shift+T` | **曲率接続** | (無し) | **消えた** |
| `M` | 測定 | 測定 | 同じ |
| `X` | **トリム** | **押し出し** | **意味が違う** |
| `E` | 延長 | 延長 | 同じ |
| `Esc` | (上記のとおり) | 選択 | 意味が違う |
| `F` | (無し) | 全体表示 | V2で追加 |

根拠: `MainWindow.cpp` 832〜846行。

`S` `T` `X` の3つは、**V1で手が覚えた操作が V2 では別のことをする。**

### 2-5. その他のショートカット

| キー | V1 | V2 のいま |
| --- | --- | --- |
| Ctrl+N / O / S / Shift+S | 新規 / 開く / 保存 / 名前を付けて保存 | 同じ |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直す | 同じ |
| **Delete** | **選んだものを消す** | **無い** |
| **Ctrl+H** | **選んだものを隠す** | **無い** |
| **Ctrl+Shift+H** | **全部표示する** | **無い** |
| **Ctrl+1 / 2 / 3** | **表示モード切替(設計 / 完成 / 単独)** | **無い** |
| **F2** | **一覧で名前を変える** | **無い** |

根拠: `MainWindow.cpp` 1163〜1170行、345行。

## 3b. 取り込んだもの(2026-09-09 時点)

済んだものは印を付ける。何が残っているかを、この表だけで分かるようにする。

| # | 中身 | 状態 | どこ |
| --- | --- | --- | --- |

| 2 | Shift+中ボタンで軌道回転 | **済** | `V2ViewportInput.cpp` OrbitByPixels |

| 5 | 作図中の Shift で水平・垂直・正方形 | **済** | `modeling/DrawingConstraint.h` |

| 7 | 右クリックの意味が道具ごとに違う | **一部** | 選択=メニュー、ポリライン/スプライン=確定、測定=消す、途中=取り消し。残りは「1点も置いていない作図での『近くの点から引き始める』」だけ |

形を変える計算(`TranslateCurve` ほか)は最初からあったので、
足りなかったのは「置いた点が何を意味するか」を決めるところだけである。

### 3-1. まず直すべきもの

1. **中ボタンドラッグで画面を移動できない。** V1では中でも右でも移動できた。
   いまの V2 は画面を動かす手立てが無い(全体表示に戻すしかない)。
2. **Shift+中ボタンで軌道回転できない。** 視点は操作板からしか回せない。
3. **Esc が選択へ戻らない。** 道具を取り消すだけで、道具も選択もそのまま残る。
4. **作図中の Ctrl(吸着を一時停止)が無い。**
5. **作図中の Shift(水平・垂直・正方形に固定)が無い。**
6. **カーソルが変わらない。** 掴めるかどうかが手元で分からない。

### 3-2. 次に直すもの

7. **右クリックの意味が道具ごとに無い。** とくに
   「ポリライン/スプラインを右クリックで確定」と
   「選択中の右クリックでメニュー」は毎回使う。
8. **`S` `T` `X` の意味が V1 と違う。** 手が覚えたものが別のことをする。
9. **`V`(選択)、`D`(点)、`B`(ベジエ)、`I`(端点一致)、`Shift+T`(曲率)が無い。**
10. **Delete で消せない。**

### 3-3. その後

11. 選んだ物を掴んで動かす / ギズモ(矢印・回転リング)
12. ワイヤーの制御点を掴んで動かす
13. Ctrl+H / Ctrl+Shift+H(隠す・全部出す)
14. Ctrl+1/2/3(表示モード)
15. F2(一覧で名前を変える)
