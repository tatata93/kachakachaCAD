# UI-P1-003 worker report

## Implementation

- V2Viewportに候補一覧と現在位置を一か所で保持する循環状態を追加しました。
- 点と曲線は`CollectPickCandidates`、形状は`CollectMeshHits`から集めます。
- `Tab`と`Shift+Tab`は表示候補だけを循環し、通常選択を変更しません。
- 通常クリックは表示中候補、`Alt+クリック`は次の奥候補を選択します。
- ポインタが別位置へ移るか候補順が変わると先頭へ戻ります。
- 同一ワイヤー内の線分候補も個別に強調表示します。
- 形状メッシュを`SetShapeViews`時にキャッシュし、Hoverごとの全三角形複製を避けます。
