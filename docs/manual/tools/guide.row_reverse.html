向きを反転

具体例: 断面の向きの食い違いを直す

準備

2本の断面を役割表へ入れる

操作手順

  1. 向きが逆の行を選ぶ
  2. 向きを反転を押す
  3. 下見のねじれを確認する

設定: 始点・終点の対応をそろえる

結果を確認

行の使用方向が反転する。原曲線の幾何は保つ。

取消・やり直し

ダイアログの取消、またはペインの取消を使います。即時操作には未確定段階がありません。 確定済みの文書変更はCtrl+Z、やり直しはCtrl+Yです。保存・書出し済みのファイルはUndoの対象ではありません。

進めない場合

役割表の行を1つ選んでください。

対象欄と3Dの強調を照合し、必要な線・面・部品を各役割へ指定します。処理中は計算表示を確認し、取消が可能な処理は取消を使います。

Windows版の操作画面

guide.row_reverse。図の設定と縮尺は例です。方式ごとの制限、プレビューと確定済み結果の区別を確認してください。
