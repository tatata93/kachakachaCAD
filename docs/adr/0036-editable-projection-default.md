# ADR 0036: 面投影の既定は編集可能なワイヤー

状態: 採用（2026-11-27、オーナー指示）。

「面へ投影」「巻き付け投影」のワイヤーの残し方は、既存の「通常ワイヤー（編集可能）」を既定とする。方向・巻き付け・最近点の各方式で同じ扱いにし、面＋ワイヤーの出力でも変えない。元の線と面を保ち、投影位置と滑らかな曲線をそのまま独立したCreateWireとして確定する。制御点やトリム等の通常編集に使え、後の元形状変更へ自動追従する参照ではないことを案内する。

既存の「投影結果（読み取り専用）」は明示して選べる。ProjectWireの依存と読み取り専用の契約、保存済み投影の扱いは変えない。取消で選択方式を黙って戻さず、下見と確定の形を一致させ、1回のUndoと再読込を検査する。公開API・保存形式・新しい曲線型は追加しない。
