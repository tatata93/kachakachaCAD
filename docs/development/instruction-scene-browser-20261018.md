# シーン一覧から用紙へ配置する操作（2026-10-18）

基点633a2b1ce、WP-08内のUI変更。元CAD、幾何コア、KCIの保存形式は変更しない。

- 説明書モードの左側へ、作成済みシーンの縮小画像と名前を縦に並べる。
- 画像エディターでは一覧のシーンを選ぶと編集する。
- 用紙編集では一覧でシーンを選び、用紙をクリックすると3D参照の図を配置する。
- 左側に「シーンを編集」「用紙へ配置」を置き、どちらの画面からも移れるようにする。
- シーン追加・複製・名前変更・削除・Undo・別ファイル読込後も一覧を同期する。
- 取消やUndoで以前の配置予定が残らず、削除済みシーンを用紙へ置かない。
- 縮小画像は表示範囲のシーンを遅延生成して再利用し、一覧操作で全モデルを毎回描画しない。
- 説明書中はCADの一覧を隠し、他モードへ戻ると元の表示状態を戻す。

別経路の点検では、メニュー・帯・検索・ショートカット・モード往復を確認する。
作図ショートカットの重複と、表示操作で入力途中の道具が終了する問題を再現し、
必要な修正と回帰を同じUI所有範囲で行う。実行資源は主担当が管理し、調査担当は読み取りのみ。

重点回帰で実操作イベントと保存・Undo・参照UUIDを確認し、完成候補を固定してWindows全体ゲート、
開発版/配布版UI、通常起動を行う。結果・配布先は完了時に追記する。
