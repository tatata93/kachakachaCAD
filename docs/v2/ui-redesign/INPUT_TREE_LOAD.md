# 数値入力・ツリー状態・KCD読込（2026-10-13）

## 決定と実装

- 数値の直接入力は完成した値をEnterまたはフォーカス移動で適用する。
  `0.`、`-0.`の途中で形状の計算や欄の再表示を起こさない。
  共通のV2NumericSpinBoxを全ツールの小数欄に使用し、計算中の入力も同じ扱いにする。
  押し出しの正側・逆側の距離は小数3桁へ統一。角度や枚数の精度はそれぞれの意味を維持。
- 面に付ける幾何的な厚みを、製作時の板厚設定から分離する。
  ThickenThicknessMmは0〜1000 mm、0は下見解除用で確定不可。
  板材のExtrudeDistanceは従来の0.05〜20 mmを維持。0.025 mmの形状入力を板材上限・下限で拒否しない。
- グリッド間隔の式は、入力を完了してから適用する。近似の手動境界は、
  変更時に古い下見を直ちに無効化し、有効な入力へ更新されたら再計算する。
- 左ツリーの開閉は表示名ではなくUUID・カテゴリ・結果の役割で保持する。
  表示切替、名前変更、文書更新で全展開しない。グループ内の同名カテゴリは別々に保持する。
  検索は一致する祖先を一時的に開き、解除時に元の開閉へ戻す。
  閉じたカテゴリ内の選択に対するスクロールで、祖先を勝手に開かない。
  非表示は文書のEntity/Group設定を正本とし、ツリー再構築で書き換えない。
- KCDの保存後と再構築成功後に、正確なネイティブBRepと製作計算結果をローカルに保持する。
  読込はKCD全バイト・実行ファイル・同梱OCCT DLLのSHA-256が一致する場合だけ再利用する。
  キャッシュ自体のSHA-256・サイズ・転送形式・参照UUIDも検査する。
  古い版、変更ファイル、破損キャッシュは全再構築へ戻る。失敗・取消結果は保持しない。
  編集履歴や添付画像はKCDを正本とし、キャッシュには編集を保存しない。
  最大8件・合計512 MiB、1件256 MiBまで。約136 MBの詳細模型も保存できる容量枠とする。
  上限を超える場合はキャッシュせず再構築し、ハッシュ照合・内容検証は省略しない。
  設定を変えた初回読込は再構築が必要。
  読込専用子プロセスでは表示用メッシュを作らず、表示側で一度作る。

## 厚みの「折り返し」について

外面の半径5 mmから内側へ1 mm付けると内面が4 mmになる、というオーナーの理解は正しい。
ただし対象のどこかに1 mmより小さい内向きの局所曲率半径があれば、同じ厚みのオフセットは
そこで潰れて向きが反転する。「折り返し」はその意味であり、通常の半径差を否定していない。

添付モデルの左右屋根ネイティブ面をGeomLProp_SLPropsで独立に測定したところ、
内向きの局所曲率半径はそれぞれ約0.153382 mmだった。中央0.5 mmは内側へ0.25 mm付けるため
この限界を超える。元の面を変形したり厚みを黙って薄くしたりせず、理由を表示して拒否する。
外側・中央・内側ボタンには元の面の位置と半径差の例を説明するツールチップを追加。

## 検証項目

- HP-NUM：Normal / Windows95で実ツール欄へ0.025をキー入力。途中値の未適用とEnter適用を確認。
- HP-TH-08：実計算中に0.035をキー入力し、最新条件だけが確定・Undo/Redoされることを確認。
- HP-XP-05：カテゴリ・入れ子グループの開閉、非表示、検索解除、Undo/Redoを実ツリーで確認。
- HP-OPEN-06：保存直後の再利用、入力変更による無効化、破損検出と再構築、元KCDのバイト保持。
- 任意のHP-OPEN-OWNER：添付KCDの初回と再利用読込時間、形状数・編集履歴・元ファイル保持を計測。

検証対象 `f5819d34d`。Windows `scripts/check.ps1 -Preset windows-msvc` 全191/191、
本体・配布版の自動操作各441/441、旧CAD `--self-test` 終了0。指定ブランチへpush済み。
本体と配布版exeのSHA-256が一致。通常／Windows95のキー入力試験は自動操作であり、
手動受入・全DPI・Linux/cloud・常時60fpsを検証したものではない。

厚み品質試験11/11に、元の円筒面半径5 mmを外面として保持し、内側1 mmで
半径4 mm・解析体積と一致するネイティブソリッドを作る回帰試験を追加。
元面のBRepバイトが不変であることも確認した。

添付屋根の一定厚みの内側オフセットには自己交差があり、厳密モードの拒否は維持する。
その後オーナーが補正方式を承認し、ADR 0031に従って「反対面を補正」を追加した。
内側0.5 mm・中央0.5 mmはネイティブ安全検査、実ツールの確定・Undo/Redo・保存再生成を通過。
指定厚みと、対応点の法線距離・位置偏差の標本結果を区別して表示する。
全体Windowsゲートの結果と範囲はTASK_LEDGERの厚み補正項を参照する。

## 添付モデルの読込実測

同じWindows PCで115面.kcd2を読み取り専用で開いた。初回12,704 ms、再利用3,530 ms（約72%短縮）。
11個のネイティブ形状と編集履歴が一致し、元ファイルのSHA-256も不変。
表示メッシュの重複を除く効果だけを比較した子プロセスの初回再構築は、直前の配布版11,854 ms、
今回9,831 ms。キャッシュがない初回には依然計算が必要で、全形状を瞬時に開く保証ではない。
