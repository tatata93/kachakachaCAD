1. 最初に知ること

このCADでは、3D空間に紙（作業平面）を置き、その紙へ正対して2D作図し、複数のワイヤーから面と板を作るのが基本です。

1. 作業平面を決める
2. ワイヤーを描く
3. 面・板・開口を作る
4. 図面・立体を出力
場所役割
上のツールバー新規・保存・元に戻す・全体表示・設計/完成形/選択だけ表示・作図・変形をすぐ実行します。
左「モデル」上端の検索欄で部材名や種類を絞り込みます。チェックで3D表示を切り替え、行のクリックで選択します。
左下「操作ガイド」消えない手順表示です。水色の欄が次の1操作、その下が全手順です。「詳しい手順」で、このマニュアルの該当箇所を直接開きます。
中央「3D画面」作図、選択、直接変形、測定を行います。選択中は橙色、マウスを置いた候補は色が変わります。
右上「1 平面～4 出力」基本工程へ直接移動します。初心者はこの4ボタンを左から順に使えば、8タブを暗記する必要はありません。
右「作図と編集」作図、作業平面、数値入力、編集、加工、面、出力、情報の詳細タブです。

初心者向けの進み方

  1. 右上「1 平面」で、作図したい位置と向きを確認します。
  2. 「2 作図」で線・円・断面を描きます。左下の水色欄だけを見れば、次に置く点が分かります。
  3. 断面を選び「3 面・板」で面、板厚、開口、治具を作ります。
  4. 板材または治具を選び「4 出力」で1:1図面、STL、STEPを保存します。

作業平面は「3D空間内に自由に置ける紙」です。紙を保存せず、その向きから見るだけにもできます。

3D上の辺を回転軸にする

  1. 「選択」で直線ワイヤーを1本選びます。
  2. 「基準線に設定」を押します。作業平面タブの基準線名が変わります。
  3. 作り方を「軸まわりに回転」にし、「回転軸に使用」を押します。
  4. 基準平面と角度を入力し、「この向きで見る」で確認後、「平面を作成」を押します。

3点は一直線上に置けません。法線ベクトルや軸方向も長さ0にはできません。エラー時は3点または方向値を見直してください。

5. 点グリッド

補助線を大量に描かず、JWCADのような一定間隔の点へ吸着して作図します。

作図面
「作図」タブ最上部で平面を選び、「正対」。
表示
「点グリッド」の「表示」をオン。
間隔
「スナップ」行の間隔へ、例として 1.00 mm。
基準
基準X/Yへ点列の開始座標。車体中心を半ピッチずらすなら両方 0.5 mm。
吸着
「スナップ」をオン。カーソルが点や既存端点へ吸着します。

「基準を 0, 0 に戻す」で原点基準へ戻せます。基準値は作図面内のX/Yで、世界座標のXYZではありません。

6. 2D作図

最初に「作図面」を選ぶと自動で正対します。以後は中央の3D画面を紙として直接クリックします。

道具クリックする順番確定
直線 L始点 → 終点2点目で完成。始点後に長さ・角度を入れ「寸法で確定」も可。
ポリライン P始点 → 折れ点を順番にEnter、右クリック、または「完了」。
矩形 R対角の1点目 → 対角の2点目2点目で完成。1点目後に幅・高さを数値確定可。
円 C中心 → 円周上の点2点目で完成。中心後に半径を数値確定可。
3点円弧 A始点 → 円弧上の通過点 → 終点3点目で完成。
ベジェ B始点 → 制御点1 → 制御点2 → 終点4点目で完成。
スプライン S通過点を4点以上Enter、右クリック、または「完了」。

正確な長さ・角度で直線を引く

  1. 「直線」を選び、中央画面で始点だけをクリックします。
  2. 「実寸で確定」の長さへ 8.307 mm などを入力します。
  3. 角度へ作図面の横を0°、縦を90°として入力します。
  4. 「寸法で確定」または Enter。指定値の終点で直線が完成します。

作図中の補助操作

  • Shiftを押しながら直線・ポリライン: 水平または垂直へ固定。
  • Shiftを押しながら矩形: 正方形へ固定。
  • 「補助線として作図」: スナップ・寸法基準には使うが、面や切断図へ入れない。
  • Esc または「取消」: 入力中の点を破棄。
  • ホイール・中ドラッグ・右ドラッグ: 作図中も拡大縮小・平行移動できます。

「作図」タブ内で「選択」に戻さず左クリックすると、現在の作図道具の点が追加されます。選びたいときは V を押してください。「面」「出力」など担当外のタブへ移ると、安全のため自動で選択モードへ戻ります。

8. 編集・拘束

点・制御点をマウスで動かす

  1. Vで「選択」にします。
  2. ワイヤーをクリックして制御点を表示します。
  3. 動かす点を左ドラッグします。作業平面に固定されたワイヤーは、その平面上で動きます。
  4. 誤った場合は Ctrl+Z。

座標・半径・平面を数値編集

開く

実行

直線の長さ・角度を保持

  1. 直線を1本選びます。
  2. 「直線の寸法を保持」で長さまたは平面内角度の「固定」をオンにします。
  3. 値を入力します。水平は「水平 0°」、垂直は「垂直 90°」でも指定できます。
  4. 「変更を適用」。以後、端点を動かしても固定値が維持されます。

複数線をまとめて処理

  • 結合: 端点がつながる直線・ポリラインを順番に複数選択し「結合」。
  • 交点まで: 交わる、または延長すれば交わる直線を2本選び「交点まで」。各線を交点へトリムまたは延長します。
  • 一致解除: 関係のあるワイヤーを選び「一致解除」。付随する滑らか接続も解除します。
  • 滑らか解除: ワイヤーを選び「滑らか解除」。端点一致は残し、G1/G2だけ解除します。

10. 交差線のC面取り・R丸め

C面取り

  1. 「加工」タブで加工種類を「C面取り」にします。
  2. 直線A横の「3D選択」→ 中央で1本目をクリック。
  3. 直線B横の「3D選択」→ 中央で2本目をクリック。
  4. 各線の「残す側」を自動・始点側・終点側から選びます。
  5. A/Bの切戻し距離を入力し、「C面取りを作成」。

R丸め

  1. 加工種類を「R丸め」にします。
  2. C面取りと同じ手順で直線A/Bと残す側を指定します。
  3. 半径を入力し、「R丸めを作成」。

2本が現在交差していなくても、延長交点と指定距離・半径から加工できる場合があります。結果が反対側へ出るときはA/Bの「残す側」を明示してください。

14. 車体から飛び出すライトケースを作る

作業平面の1:1 SVG / DXF

設定

実行

用途

選択板材の1:1展開図

  1. 板材を1枚選びます。
  2. 「折り線間隔」を指定します。二方向曲面をペーパークラフト状に組む場合は「二方向曲面へ自動切れ目」をオンにし、切れ目の深さを指定します。
  3. 「組立3Dで折り目・切れ目を表示」をオンにします。元の完成位置に折り目が青い破線、手動・自動の切れ目が赤い線で表示されます。間隔や深さを変えると3D表示も更新されます。
  4. 3Dモデルを回して、窓・ライト穴・部材境界に切れ目が衝突せず、組み立てやすい位置か確認します。
  5. 展開精度の警告、折り線数、切れ目数、最大推定ずれを確認します。

FOLD曲面を近似する折り線。SVG/PDFでは破線、DXFでは専用レイヤーです。

19. 困ったとき

状態対処
視点を変えたいのに形状を選んでしまう自由回転は Shift+中ドラッグ。平行移動は中または右ドラッグ。左ボタンは選択・作図専用です。

2Dにしか見えない作図面へ正対している状態です。右上「3D」または黄色い角ボタンで斜め視点へ戻します。
車体が横倒しキューブ上の左回転・右回転矢印で90°ずつ回します。

ロフトがねじれる断面の始点・進行方向を揃え、前から後ろの順で選択し直します。

20. 現在の制限と実用上の回避方法

制限現在の回避方法
