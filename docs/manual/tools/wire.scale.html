スケール

具体例: 20mmの線を2倍にする

準備

線A(0,0)→(20,0)を作る

操作手順

  1. スケールを選ぶ
  2. 線Aを選ぶ
  3. 倍率2を入力し、中心(0,0,0)を指定する

設定: 倍率2

結果を確認

中心からの距離が2倍になり、線の長さが40mmになる。

取消・やり直し

未確定入力をEscで取り消します。道具を終えるときは選択(V)または別の道具へ切り替えます。 確定済みの文書変更はCtrl+Z、やり直しはCtrl+Yです。保存・書出し済みのファイルはUndoの対象ではありません。

進めない場合

ワイヤーを1つ以上選んでください。

対象欄と3Dの強調を照合し、必要な線・面・部品を各役割へ指定します。処理中は計算表示を確認し、取消が可能な処理は取消を使います。

倍率

準備: 20mmの直線

  1. 対象を選ぶ
  2. 倍率2を設定
  3. 中心(0,0)を指定

確認: 長さ40mmになる

基準の2点

準備: 長さ20mmの直線

  1. 対象を選ぶ
  2. 中心(0,0)
  3. 基準点(20,0)
  4. 行先(10,0)

確認: 基準寸法が10mmになる
