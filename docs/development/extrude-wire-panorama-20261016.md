# 押し出しワイヤー出力・確定時の再計算・複数図面投影

## 変更内容

- 曲面を押し出す場合、面・線・点を終端にする場合、終端の角度を指定する場合にも、開始輪郭・終端輪郭・側面の辺を独立ワイヤーとして生成する。
- ワイヤーのみ／ソリッドのみ／両方の出力を既存右ペインで選べる。ワイヤーのみの場合はBooleanによる立体加工をしない。
- ネイティブBRepの面・辺の履歴から開始／終端を識別し、切断後の実際の辺を使う。表示メッシュを編集用ワイヤーへ変換しない。
- 直線・円・円弧の形式は保ち、斜め終端の楕円等は既存の有理曲線変換と偏差上界による分割を使用する。変換できない場合に黙って辺を捨てない。
- 確定前に押し出しハンドルを閉じ、文書変更に伴う選択通知から同じ計算へ再入しないようにした。検証済みのプレビュー形状を文書へ移譲し、成功時の全形状再構築をやめた。失敗・ロールバック時は再構築を維持する。
- 表示メッシュをプレビューと確定で再利用する。一時Boolean形状の破棄時は対応メッシュも破棄する。
- 正面／側面の入力行ごとに異なる投影方向を指定する既存機能を、3面をまたぐ閉輪郭の自動UI試験で確認し、画像付き手順書と練習モデルを追加した。

## 検証の範囲

幾何試験は47件。新しい試験は円形・穴付き輪郭を水平／斜めの終端へ押し出し、閉輪郭、元形式の保持、ソリッド表面との一致、終端平面との一致を検査する。

重点UI試験では、終端指定のワイヤーのみ／両方／終端のみ、曲面投影したライトからのワイヤーのみ／両方、取消・保存再読込、押し出し確定後の継続操作を検査した。正面／側面2図面の投影では、閉輪郭、正面・角のR・側面への所属、Undo／Redo、保存再読込を検査した。

ユーザーの `115面.kcd2` は読み取り、別ディレクトリへ結果を保存した。実モデルの試験は6個のライトの投影・押し出しと中央面の3D選択を含む。元ファイル非変更、閉じた出力可能ソリッド、終端の中央平面からのずれ0.001mm以内を検査した。中央面への押し出しはワイヤーも同時生成し、プレビューと確定結果が同じネイティブハンドルであることを確認する。
