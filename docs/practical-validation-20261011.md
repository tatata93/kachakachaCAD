## 検証の範囲

編集可能なワイヤーと履歴を正本とする。写真の見栄えだけでは成功としない。
面生成、厚み付け、近似、展開、再組立、個別部材と結合体の STL/STEP、保存再読込を
別々に検査する。GUI の入力欄・候補・確定・出力ダイアログを経由する可視 Qt 試験を使う。
対象選択の一部は ID を注入しており、外部マウス操作を通した手動試験とは区別する。

元の配布実行可能版、ソース、差分、未追跡物の保存先は作業フォルダーの
`baseline-6c7b39f/`。後続の失敗でこの基準版を上書きしない。

## 発見した不具合と検証

| 問題 | 修正・根拠 | 現在の範囲 |
| --- | --- | --- |
| 閉ソリッドが内向きでも絶対体積で成功扱い | 閉ソリッドを外向きへ統一。符号付き体積、BRep 妥当性、自己交差を検査 | 幾何試験と円筒・円錐・缶の部分モデル |
| 微小な巻き縁へ大きい厚みを与え、自己交差する | 不可能なオフセットを拒否。見本の巻き縁は別の実体として作る | 不正入力は失敗として保存 |
| パネル頂点の許容差が 1mm まで広がる | モデルの幾何許容差を使用 | 0.8mm 板厚の試験 |
| 固定した近似面の法線が逆 | 元の面の向きを曲げ状態へ引き継ぐ | 円筒外半径 16mm を維持 |
| 直線帯に数百の不要な辺が残る | 対応する両レールが完全に直線のときだけ端点へ整理 | 円筒の実用試験が約245秒から約17秒 |
| STEP の再読込でソリッドが失われる | 出力前に STEP を再読込し、個数・符号付き体積・外接寸法を比較 | 読込後0ソリッドになる旧出力を拒否 |
| 折れ帯の厚み付け後、和演算で体積が減る | 平面四辺形の帯をマイター接合で厚み付け。Boolean の物理的体積範囲を検査 | 缶1/4の結合体が閉鎖・正体積 |
| ロフトの後部が意図せず膨張 | 対応する平行 Bézier 断面の補間を形状保持方式へ変更 | 元断面一致・剛体移動・外接寸法の回帰試験。反転検査を追加中 |

外部 STL 検査の閉鎖性だけでは自己交差なしとは認定しない。
面法線方向のレイ検査も、角や隣接壁に影響される標本検査であり、全域最小肉厚の証明ではない。

## 見本と精度の扱い

| 見本 | 参照 | 注意 |
| --- | --- | --- |
| 115系 | ユーザーの既存写真・図面、公開された車両諸元 | 細部は写真推定。既存画像は出典不明のため再配布しない |
| N700系 | 日本車輌の N700 紹介 | 車体長27100・幅3360・車体高3600mm。断面は写真推定 |
| タキ1000 | 日本オイルターミナルの車両写真、二次資料の諸元 | 偏心した膨らみを残す。台車・手すり等の細部寸法は推定 |
| スプレー缶 | KURE 5-56 320ml | 公表163×直径66mm。見えない肩・底・弁構造は模式的 |
| 複雑な壺 | Met 24.85 / 447776、Public Domain 写真 | 高さ330×直径160mm。写真輪郭を使い、文様は対象外 |
| Oloid 比較モデル | Keenan Crane Model Repository、CC0 | 作者の無料データ。元単位不明のため最大長80mmへ明示的に換算 |

出典 URL、権利条件、取得ファイル、Library 画像 ID は作業フォルダーの
`references/sources.json` に記録する。写真推定から作った CAD 面に対する近似誤差と、
実物に対する精度を同じ数値として報告しない。

円筒・円錐の解析形状は工程の対照試験であり、実物写真を使う5つの見本の代替ではない。
小さい巻き縁・台車・手すり・ノズル等は、板材近似が適さない理由を記録し、
編集可能な実体として残して別途出力・接合・スライスを検査する。

## 再現する入口

Windows の通常ビルドは既存の `scripts/check.ps1 -Preset windows-msvc -Config Release`。
本体は `build-msvc2022-x64/Release/kachakacha_cad_next.exe`。
検証用 `tools/run_practical.py --fixture <native.kcd2> --output <directory>` は可視 GUI を起動し、
工程ごとの PNG・ネイティブファイル・STL・STEP・UTF-8 ログを別フォルダーへ保存する。
`tools/practical_*_fixture.py` は編集可能な見本を生成する開発用入口であり、一般利用者向けUIではない。

解析用 Python ライブラリと Bambu Studio は開発検査だけに使用し、CAD 実行時の依存には追加しない。
Bambu の A1/0.4mm/PLA/0.2mm 設定は再現用の仮定であり、利用者の所有プリンタを推定しない。
オフラインのスライスまでで、プリンタ接続・送信・実印刷は行わない。
