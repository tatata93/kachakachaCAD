全ツールへ戻る

選択に正対

具体例: 傾いた面を正面から見る

準備

傾けた作業面か平らなフェイスを用意する

操作手順

  1. 面を選ぶ
  2. 選択に正対を押す

設定: 面の向き・中心・大きさに合わせる

結果を確認

面を正面から見られる。形状自体は移動しない。

取消・やり直し

ダイアログの取消、またはペインの取消を使います。即時操作には未確定段階がありません。 確定済みの文書変更はCtrl+Z、やり直しはCtrl+Yです。保存・書出し済みのファイルはUndoの対象ではありません。

進めない場合

作業平面・立体の面・面・線のどれかを選んでください。

対象欄と3Dの強調を照合し、必要な線・面・部品を各役割へ指定します。処理中は計算表示を確認し、取消が可能な処理は取消を使います。

view.align_selection。図の設定と縮尺は例です。方式ごとの制限、プレビューと確定済み結果の区別を確認してください。
