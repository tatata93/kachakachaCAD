# 作図・画像・測定の操作点検（2026-10-05）

## V1とV2の円弧

コード根拠: V1 `MainWindowPanels.cpp` と `MainWindow::UpdateArcConfiguration`、
V2 `V2DrawingDock.cpp` と `ToolController.cpp`。

| 操作 | V1 | V2（今回修正後） |
|---|---|---|
| 3点・両端と半径・始点接線 | あり | あり |
| 中心・始点・終点 | 専用モードなし | あり |
| 曲がる側 | 左右の選択欄 | 法線反転ボタン。両端半径と始点接線に適用 |
| 接線角／法線角の選択 | あり | 独立欄は未実装。クリックした方向を接線にする |
| 方向角の数値指定 | 作業面水平0度の角度欄 | V1同様の独立欄は未実装 |
| 中心角／円弧長の切替 | 半径に応じて値を換算 | 中心角のみ。円弧長の独立入力は未実装 |

V1に一押しの反転ボタンがあったとは確認していない。左右選択欄は確認できた。
今回の反転は始点と接線を維持して曲がる側を変える。作業面自体の向きは変更しない。同じ2点方式で反転・半径を変更しても入力済み始点を保つ。

## 測定・対象を後から選ぶ操作

測定ツールは起動できていたが、クリックが点を記録する処理だけを通っていた。
選択測定・面積は線の選択、要素測定は線と位置の選択、2点・3点は点の記録へ分岐する。
Ctrlで複数を選択可能。2点／3点測定の完了後は次のクリックから新しい組を測る。
左ツリーからの選択と事前選択は維持する。右クリックは測定消去。

V1 `MainWindowMeasure.cpp` は2点間について3D距離、符号付きXYZ差、
XY/XZ/YZ投影、各軸との角度を表示する。単一ワイヤについては長さ、半径、
接線・法線などを表示するが、「底辺・高さ」という専用表示は確認できなかった。
V2へ直線と2点間の作業面U方向の底辺、V方向の高さ、面外の高低差、投影長を追加。
成分長は絶対値。既存XYZ差は符号を維持。面外に傾く線では底辺・高さだけでは
3D長さを表せないため、高低差も併記する。曲線に直線の三角形の説明は適用しない。

ほかに、数値編集開始時に前の作図ツールを終了し、対象をクリックできるようにした。
選択不足で待機する棚の命令も前の作図ツールを残さない。測定・画像・数値編集の
実操作経路を点検したもので、全コマンドの全組合せを網羅したとはしない。

## Jw_cad画像操作との比較

参照: [Jw_cad公式配布](https://www.jwcad.net/download.htm)の8.25a付属
`Jw_cad.chm` の「編集／画像編集」。10.03.6の配布も確認したが、同版のヘルプは
使用した展開ツールが対応せず未確認。Jw_cadをインストール・実行しての比較ではない。

公式ヘルプの画像フィットは画像2点→配置先2点。回転ありでは2点を一致させ、
回転なしでは元の範囲の長い軸に合わせて拡大縮小・移動し、縦横比を維持する。
従来のV2は倍率のみ変更していたため、基準点の移動・回転と回転有無の選択を追加。
基準点・4点の入力は主3Dビュー。画像編集ツールを先に開いてから画像を選ぶ操作も追加。
既存のドラッグ移動、左右反転、透明度、確定前取消、保存・Undo/Redoは維持する。

平面のフィットは貼付面座標で計算。異なる平面の2点や重複点、回転なしでは
対応不能な方向を黙って無視しない。曲面UV方式は局所UVの尺度で合わせる近似であり、
曲面上の測地距離を一致させる機能ではない。
Jw_cadのトリミング・透過色・外部画像の相対パス管理は今回の移植範囲外。
KCD2では画像を常に同梱する。Jw_cad完全互換とは表記しない。
