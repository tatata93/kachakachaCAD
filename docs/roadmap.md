# 開発ロードマップ

最低限の完成判定と残工程は `docs/minimum-usable-completion-plan.md` に固定する。

## 現在試せる実用範囲

- 自由配置した作業平面への正対と直接2D作図。通過点を4点以上指定する3次B-splineにも対応する。円弧は3点、両端＋半径、始点＋接線/法線角＋半径＋中心角/円弧長の3方式を選べる。作成後は直線・ポリライン・ベジェ・B-spline・円・円弧の点やハンドルを3D画面で直接動かし、数値編集で仕上げられる。作図中はカーソル追従欄へ数値または計算式を直接入力できる。
- 模型と同じ姿勢で回る右上の視点キューブ。面・8角への正対、つかんだ量だけの連続回転、絶対/相対X/Y/Z軸の15°回転とShiftによる5°微調整、選択した線・面・板材・作業平面への正対、向きを変えない全体表示に対応。
- 3D画面での2点間距離、XYZ差、投影距離、任意3点の3D角度、線・曲線の全長と半径、点・ワイヤー間およびワイヤー同士の最短距離、接線角、曲線の曲率法線角、線と平面・平面同士の角度測定。必要な値は参照寸法として保存し、形状編集へ追従させられる。
- スナップや寸法基準には使えるが、面・投影・開口・切断出力には混ざらない補助線。通常線との切替、保存、Undo / Redoに対応。
- JWCAD型の点グリッド。大きい主点に対して1/2・1/3・1/4間隔の小さい副点を表示・スナップし、数値指定または格子点から図形点へのドラッグで基準位置を合わせられる。
- 3D画面でマウス下のワイヤーと端点を青く強調し、選択線、基準線、補助線を色と線種で識別。
- 表示タブで通常線・補助線・面・板材・背景・主点・副点の色、線の太さ・線種、塗りの透明度を調整し、個人設定として次回起動へ保持。
- 直線の端点一致と固定長・固定角を同時に解決。両端を固定したときに条件が矛盾する場合は、形状を変更せず追従側の線名を表示して拒否する。
- 3D画面で固定側と追従側の端点を順に指定する一致拘束。モデル一覧と3Dマークで関係を確認し、選択ワイヤーから解除できる。
- 直線・円弧・ベジェ・B-splineなどの端点から、追従側ベジェ・B-spline・円弧へ滑らかにつなぐG1接線拘束と、追従側ベジェの曲率までそろえるG2拘束。3Dで端点を順に指定し、固定側の編集へ追従する。
- 端点一致・G1・G2を交互に解くため、直線→円弧→ベジェのような接続連鎖も元の編集から末端まで追従する。ベジェの両端G1/G2も条件が成立すれば保持し、成立しない円弧などの両端接続は線名付きで拒否する。
- 3D画面での複数選択、移動、回転、コピー、ミラー複製、平行オフセット複製。
- 直線・ポリライン・円弧・ベジェ・B-splineの分割と、連続する直線・ポリラインの結合。
- 線・曲線部分を3D上で直接指すトリムと、端側を指して最初の表示境界まで伸ばす延長。直線、開ポリライン、円弧、ベジェ、B-splineを元の種類と精度のまま処理し、表示中の曲線も境界に使う。削除区間は赤、追加区間は緑で事前表示し、連続実行と1操作単位のUndoに対応。2直線を事前選択して同じ交点へ合わせる操作、C面取り、R丸めも併存する。
- 閉じたワイヤーから平面、2断面から曲面、3断面以上からロフト面を作成し、3D画面で直接選択。
- 別の作業平面に描いたライト穴などを面へ投影し、元図・面の編集へ追従。
- ライト最前面の閉じた輪郭を、輪郭法線・基準線・任意XYZ方向で車体面まで投影し、根元輪郭と飛び出すケース側面を一括生成。元輪郭と車体面の編集へ追従。
- 面を板厚・材質・厚み方向を持つ板材へ変換。
- 面へ投影した閉じた輪郭を板材の開口として追加・解除。
- 板材を平面、一方向曲げ、二方向曲面へ近似分類。
- 曲面板材を断面内または長手方向の任意位置で2分割し、開口と元面への追従を維持。
- 選択した板材を板厚中央で展開し、外周、ライト穴、折り線、手動切れ目を1:1 SVG / DXFへ出力。二方向曲面は再現度指定のペーパークラフト紙片へ分け、任意の投影線で紙片数を追加調整できる。
- 展開結果を任意作業平面上の編集可能なワイヤー群と、切り幅付きスロットを持つ厚み付き3D板として生成。
- 展開条件から生成した折り線と手動・自動切れ目を、選択した元板材の組立位置へ重ねて3D確認。
- 選択板材をA4/A3の1:1 PDFへ出力。自動用紙向き、複数ページ分割、重なり目印、100 mm尺度線に対応。
- 曲面から外側・内側、成形クリアランス、肉厚を指定した成形治具を作り、3D画面で直接選択・更新。
- 選択治具をOpen CASCADEの有効な閉Solidとして検査し、STL / STEPへ出力。
- モデル一覧の名前・種類フィルター、チェックボックスと3D選択からの表示・非表示、設計/完成形/選択だけの一時表示モード。
- 作業平面上のワイヤーを1:1のSVG / DXFへ出力。
- プロジェクト保存、Undo / Redo、配布フォルダからの単体起動。

## Phase 0: 土台

- リポジトリの方針文書を固定する。
- C++20 / CMake の最小構成を作る。
- UIに依存しない幾何コアを作る。
- 作業平面の数学モデルをテスト可能にする。

## Phase 1: 作業平面とワイヤー

- 3D空間内の作業平面。
- 3点指定、点＋法線、面＋オフセット、辺＋角度。
- 作業平面上の2D座標と3D座標の相互変換。
- 作図点、直線、ポリライン、円、円弧、ベジェ、3次B-spline。（作図点の保存・選択・表示切替と、交点・端点・格子点を含む弱いスナップを実装済み）
- 作業平面上の直線・曲線から3Dワイヤーを作る。
- 補助線。（破線表示、通常線との切替、保存、Undo / Redo、形状生成・切断出力からの除外を実装済み）
- 参照寸法。（2点・ワイヤー・作業平面の距離、全長、半径、角度を測定結果から保存し、形状編集への追従、3D表示、表示切替、削除、Undo / Redoへ対応済み）

## Phase 2: 作図編集と拘束

- 移動、回転、コピー、ミラー。
- オフセット、トリム、延長、分割、結合。
- 交差する2直線のC面取り、R丸め、任意プロファイル面取り。
- 作図中の実寸入力と一時拘束。（長さ・角度・幅・高さ・半径、水平・垂直・正方形を実装済み）
- 作成後も関係を保持する拘束寸法。（直線の長さ・作業平面内角度・水平・垂直、円・円弧の半径、異なる開ワイヤー間の端点一致を実装済み）
- G0/G1/G2 の接続条件。（G0端点一致、追従側ベジェ・円弧のG1接線接続、追従側ベジェのG2曲率接続を実装済み）

## Phase 3: 面

- 閉じたワイヤーから平面。（実装済み）
- 境界面。
- ルールド面。（2断面の曲面として実装済み）
- ロフト面。（選択断面を通り、断面位置で長手方向の接線が連続する三次補間として実装済み）
- ネットワーク面。
- サーフェスの可視化と3D直接選択。（実装済み）
- 平面図から面へのワイヤー投影と依存関係の保存。（実装済み）
- 投影ワイヤーを断面にしたルールド面と、面・投影の依存順再計算。（飛び出すライトケースとして実装済み）

## Phase 4: 板材工作

- 面を板として定義。（基本実装済み）
- 板厚、材質、板厚方向。（基本実装済み）
- 一方向曲げ。
- 展開可能性の判定。（ガウス曲率による近似分類を実装済み）
- 曲げ方向表示。
- 手動分割。（断面内・長手方向の基本分割を実装済み）
- 半自動分割。
- 投影輪郭による板材開口。（基本実装済み）
- 板厚中央を基準にした実寸展開と誤差評価。（基本実装済み）
- 曲面法線変化からの折り線、手動途中切れ目、二方向曲面の複数紙片展開、任意投影線による追加分割。（基本実装済み）
- 展開外周・開口・折り線・切れ目からCADワイヤーと3D板を生成。（基本実装済み）

## Phase 5: 出力

- SVG / DXF。（作業平面図と選択板材の実寸展開を実装済み）
- PDF。（選択板材のA4/A3実寸印刷とページ分割を実装済み）
- STEP / STL。（選択治具の閉Solid検査、出力時メッシュ化、STEP B-Rep出力を実装済み）
- 選択部品のみ出力。（板材1枚と治具1個の直接選択を実装済み）
- 1:1実寸出力。（SVG / DXFを実装済み）

## Phase 6: UI完成度

- Qt 6 デスクトップUI。
- プロジェクトツリー。
- 3Dビュー。
- 作業平面に正対して2D編集。
- 作図点、直線、ポリライン、矩形、円、3方式の円弧、ベジェ曲線、通過点スプラインの直接作図。
- 選択物の寸法・状態パネル。
- 表示切替。（保存される個別表示、名前・種類フィルター、履歴を汚さない完成形/選択だけ表示を実装済み）
- 60秒ごとの自動保存と異常終了後の復元。（実装済み）
