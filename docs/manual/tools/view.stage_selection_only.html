選択だけ

具体例: 選んだ窓だけを表示する

準備

窓と車体輪郭を用意する

操作手順

  1. 窓を選ぶ
  2. 選択だけ表示を選ぶ

設定: 表示は現在の選択に追従

結果を確認

選択中の形だけが表示される。固定した局所表示とは動作が異なる。

取消・やり直し

ダイアログの取消、またはペインの取消を使います。即時操作には未確定段階がありません。 確定済みの文書変更はCtrl+Z、やり直しはCtrl+Yです。保存・書出し済みのファイルはUndoの対象ではありません。

進めない場合

選んでいるものだけを出します(V1 の「選択だけ」)。形は変わりません。

対象欄と3Dの強調を照合し、必要な線・面・部品を各役割へ指定します。処理中は計算表示を確認し、取消が可能な処理は取消を使います。

Windows版の操作画面

view.stage_selection_only。図の設定と縮尺は例です。方式ごとの制限、プレビューと確定済み結果の区別を確認してください。
