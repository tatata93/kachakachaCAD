# ADR 0007: 板材は元面の範囲を保って手動分割する

## 状態

採用

## 決定

- 曲面板材は、元の面に対する正規化範囲 `minimumU / maximumU / minimumV / maximumV` を持つ。
- `U` は断面ワイヤー内の方向、`V` は断面間・車体長手方向として画面へ示す。
- ユーザーは板材1枚、方向、位置を指定し、3D画面の予告線を確認して一回ずつ2部品へ分ける。
- 分割元の板材は2部品へ置き換える。元へ戻す操作はUndoで行う。
- 分割後の両部品は同じ元面、板厚、厚み方向、材質、表示状態を保持し、断面編集へ追従する。
- 開口は面上の位置から含まれる部品を判定して引き継ぐ。分割線が開口を横切る場合は分割しない。
- 分割範囲は `.kcd` の `plate_range` で保存する。

## 理由

二方向曲面をプラ板で作るには、接着しやすい位置を人が選び、必要な大きさだけ部品を分ける必要がある。自動分割で多数の細片を作ると工作性を損なうため、明示した位置で一回ずつ分ける。

元面の範囲として保持すれば、分割後も断面変更へ追従し、同じ面を重複コピーして形状関係を失わずに済む。

## 制限

- 現段階の分割線は元面の `U` または `V` が一定の線に限る。
- 任意に描いた曲線による分割方法は、工作時の指定方法をユーザー確認してから決める。
- 任意に描いた分割曲線を実寸展開へ反映する機能は未実装。
