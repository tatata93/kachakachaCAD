# 製品原則(2026-09-02 オーナー確認済み改訂)

## 一言で言うと

**完成品のモデリングから型紙・治具・出力までを一続きにする模型製作CAD。主戦場は鉄道模型。**

## 目指すもの

- プラ板へ手で線を引く時間を減らし、同じ部品を高精度に量産できるようにする。
- 複雑な電車前面、側板、屋根はもちろん、ガンプラのような自由曲面の模型も同じ空間で設計できる。
- 基本フロー: **完成品をモデリングする → 部材近似モデルへ変換する → 型紙(面展開図)を出す →
  必要な治具はユーザー自身が同じソフトで設計する → プラ板・紙・3Dプリンタで作る。**
- 治具の自動生成は補助機能。治具はモデルと同格の、ユーザーが設計する対象である。
- 2D図面、3Dワイヤー、面、部材近似、板、型紙、治具、出力を一続きの作業にする。
- スケールに主対象は無い(テストケースはHO/Nでよい)。将来はモデル全体のn倍拡大や、
  「この線をXmmにして全体を等倍で追従させる」参照寸法基準のスケーリングを行う。
- 最終的に他人へ配布する。依存ライブラリは配布自由なライセンスに限る。

## 最重要イメージ

**3D空間内に自由に紙を置いて、その紙の上に正確な2D図面を描ける。**
**同時に、3D空間上でも任意の点・交点から任意の箇所へ直接線を引ける。**

「紙」=作業平面は、正面・側面・上面だけでは足りない。任意の角度、任意の3点、選択した辺との角度、
面からのオフセットなどで作れる必要がある。その紙の上の正確な2Dと、紙に縛られない3D直接作図の
両輪で複雑な立体物をモデリングする。面取り(C面・R面、任意半径)も2D・3Dの両方で行える。

## 主役となる編集対象

点 / 線 / 円 / 円弧 / 曲線 / 補助線 / ワイヤー / 面 / 部材近似モデル / 板 / 型紙 / Body / 部品 / 治具

## 現段階では優先しないこと

以下は**永久の禁止ではない**(将来はやる)。ただし今は実装せず、これらに向けて設計を歪めない。

- 三角形メッシュをユーザーの主要編集単位にすること。
- 押し出しとブーリアンだけで作る一般的なソリッドCADの機能一式。
- アセンブリ拘束・干渉解析の高度化、本格製図(図枠・表題欄)、自動ネスティング。

## 恒久の原則(変えない)

- 工作できない見た目だけの形状を作らない。実際に作れることを常に優先する。
- 自動分割で人間が作れない細切れ部品を大量生成しない。少数の大きな部材+手動介入が原則。
- 2D CADと3D CADを分けてしまわない。

## 模型製作として大事な判断

- その面はプラ板・紙として切り出せるか。どの部材は一方向曲げで作れるか。
- どこで切れば(どこを部材境界にすれば)接着しやすいか。
- 治具に載せたときに位置決めできるか。
- 1:1で印刷・切断できるか。誤差は数値で把握できているか。
