# 実用手順(UI 再構築後の V2 の使い方)— 2026-09-19

どの道具も同じ文法: **帯で道具を押す → 右の欄に「作り方」と入力の欄が出る → 3D で対象を押す(押し直すと外れる)→ 下見を見る → Enter で確定 / Esc でやめる**。
下の状態行と 3D 左上の HUD に「次に何をするか」が出る。右の欄の見出しの下にも同じ一文が出る。

## 1. 線を引く(作図モード)
- 帯「基本作図」→ 線 / 円 / 円弧 / 矩形 / 多角形 / 点。右の欄の「作り方」カードで決め方(円弧なら 3点 / 始点・終点・半径)を選ぶ。
- 押せないカード(3点円、中心・始点・終点の円弧、通過点スプライン…)は核に無い。理由はツールチップと状態行。
- 編集(トリム/延長/分割/結合/オフセット)・変形(移動/回転/ミラー/コピー)も同じ欄。配列は帯「変形」→ 直線配列/円形配列 → 右の欄で個数と間隔 → 確定。
- 作業面: 帯「作業面」→ 作業面 → 右の欄で作り方(12 通り)。欄を変えると 3D に平面の下見(40mm 四方)が出る。「平面を作る」で文書へ。

## 2. 面を作る(作図モード → 帯「面作成」)
- 平面 / ルールド面 / ロフト面 / ガイド付きロフト / 境界面 / 曲線網。押すと右の欄が構え、3D で線を順に押す(欄の「ここへ選ぶ」で断面/ガイドを切り替え)。下見 → Enter。
- 離した面・回転面は「その他の作り方」。

## 3. 立体にする(部品モード)
- 押し出し: 閉じた輪郭の内側か面を押す → 右の欄で 範囲(距離/左右対称/両方向別々/選んだ面まで/全部貫く)・方向(7 通り)・演算・出力 → Enter。From とテーパーは核に無い(押せない形)。
- 厚み: 帯「作成」→ 厚み → 3D で面を押す → 作り方(外側/中央/内側/平面まで)→ 下見 → Enter。
- 足す・引く: 土台 → 相手 の順に部品を押す → 下見 → Enter。
- 回転体・ロフト立体・スイープは押せない(理由つき)。回転面は作図の「面作成」で作ってから「厚み」。

## 4. 近似と部材(製作モード)
- 近似: 帯「近似」→ 3D で面か立体を押す → 作り方(標準/少部品優先/精度優先/手動条件)→ 候補 A/B/C(部材数・最大誤差・方式)→ 下見 → Enter。
- 部材編集: 3D で部材(元の面/立体の面)を押すと「対象部材」に番号が入り、PART N の札が出る → 分割 / 結合 / 切れ目 / 半径(AUTO/LOCK)。
- 曲げ状態: スライダ 0〜100 と 0/25/50/75/100 の基準値。組立率を打って当てるのと同じ道。
- 展開: 自動展開 / 基準辺指定(対象部材の番号が基準)→「展開」で A4 の型紙。複数部材配置・展開先(紙以外)・表裏反転は核に無い。
- 生成: 現在状態 / Flat 0% / Target 100% のカードで固定物を作る。「輪郭 Wire」は線だけ。

## 5. 出す(出力モード)
- 帯「書き出し」→ 出力を検査 → STL / STEP / SVG / DXF / PDF 原寸。右の欄で「何を出すか」「どの形式で」→ 出す先を選ぶ → 出す。

## 一覧(左)
- 文書 → 原点 / 作業面 / グループ / ワイヤー / 面 / 立体 / 近似 / 生成物。◉ で 1 つずつ出し隠し。3D と一覧の選択は両方向に同期。
- 右クリック: 名前を変える / 選択を隠す / すべて表示 / 選択に正対 / グループへ移動 / グループ化 / コピー / 削除 / 測定 / プロパティ。消せないときは「これを使っているものがあるので消せません。先に ◯◯ を…」と理由が出る。

## 測定(全モード)
- 上の帯「測定」か作図の「測定」カテゴリ。線を引いている途中でも重ねられ、Esc で元の道具へ戻る(HUD に「測定中(Esc で直線へ戻る)」)。
