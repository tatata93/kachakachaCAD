# FRONTEND_ISSUE_FOR_CODEX(Claude から Codex へ)

UI 再構築のあいだ、Claude は UI を直さない。見つけたものはここへ積む。
直し方は書かない。**何が起きているか**と、**なぜ困るか**だけを書く。

## FI-001 曲線網(U/Vネットワーク)の入力欄が正本に無い

正本(`kachakachaCAD_extrude_surface_UI_final_mock.html`)の「面を作る」は
入力欄が3つ(断面 / ガイド / 境界)で、作り方のカードに「曲線網 U/Vネットワーク」
がある。**U と V を別々に入れる欄が無い。**

いまの実装は、正本の「案内付きロフト = 断面 + ガイド」と同じ読み方で
「断面 = U、ガイド = V」としている(`RoleForSurfaceSlot`)。欄は増やしていない。
別の割り当てにするなら core 側の `RoleForSurfaceSlot` を変えれば済む。

## FI-002 平面の「穴」を画面から入れられない

平面(`PlanarBoundary`)が使う役割は 外形 と 穴 の2つだが、
3つの欄では外形しか表せない。穴のある平面は、後ろの役割表からしか作れない。
「面を作る」を入口1つに統合した意味が、穴のときだけ崩れている。

## FI-003 「対象」の欄に選び直すボタンが無い

正本の押し出しは「対象」「輪郭」の両方に「選び直す」が付いている。
いまは輪郭にしか無い。対象を替えたいとき、3D で選び直すしかない。

## FI-004 棚を `ShelvesFor` を通さずに出しているものが2つ残っている

`作業平面` と `表示` は、自分の命令から `show()+raise()` で出ている。
押し出しの棚が構造的に見えなかったのと同じ形である。
いまは試験にその2つを名前で列挙して例外扱いにしてあるので、
**3つ目を作ると門が鳴る**(`tests_v2/shelf_layout_tests.cpp`)。
作り直すなら、棚は全部 `ShelvesFor` から出す形にしてほしい。
