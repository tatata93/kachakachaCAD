# はじめての1枚 ── 15分で、窓のある側板を型紙にする

説明書(`作り方.md`)は全部を書いてあるので長いです。
**これは「最後まで通す」ためだけの紙です。** 通せば、この道具の形が分かります。

作るのは **1/87 の側板を1枚** ── 実物 5000mm × 3000mm、窓4つ、プラ板 0.5mm。
出来上がりは A4 に原寸で入ります(57.5mm × 34.5mm)。

> 押す場所は **太字**。打つ数字は `このように` 書きます。
> 断られたら、帯(画面のいちばん下)に理由が出ます。読んでから直してください。
> **黙って何も起きないことはありません。**

---

## 0. 画面の見かた(30秒)

```
┌──────────┬──────────────────────────┬──────────┐
│ 作ったもの  │                          │  いま使って │
│ (一覧)    │      3D 画面              │  いる道具の │
│  ┌絞り込み│   (ここに描く)            │  設定      │
│  │原点    │                          │ (右の棚)  │
│  │ ...    │                          │          │
├──────────┤                          │          │
│ 手順      │                          │          │
└──────────┴──────────────────────────┴──────────┘
                     知らせ(エラー)
                     帯(いま何をすればよいか)
```

- **上の1段目** = モード(作図 / 部品 / 製作 / 出力)+ 正対・選択・測定・作図面・まとまり・吸着
- **上の2段目** = そのモードで **そこから始めるもの** だけ
- **右の棚** = いま選んでいる道具の設定。道具を変えると中身も変わります
- **帯** = いま何をすればよいか。困ったらここを読む

---

## 1. 縮尺と板厚を決める(1分)

右の棚を **「数」** にします(出ていなければ、上の「表示」→…ではなく、
右の札に「数」があります)。

| 欄 | 打つ値 | なぜ |
| --- | --- | --- |
| 縮尺の分母 | `87` | 1/87(HO)。ここを決めると実寸から模型寸法が出ます |
| 実物の寸法 | `5000` | 側板の長さ(mm)。下に `57.471…` と出ます |
| 押し出しの距離 | `0.5` | プラ板の厚み |

**端数を丸めないでください。** 57.5 に丸めた瞬間、隣の板と 0.03mm 合わなくなります。

---

## 2. 側板の外形を引く(2分)

1. モードは **「作図」**、作図面は **top_XY**(上の帯のコンボ。最初からこれです)
2. 道具は **「矩形」**
3. 3D 画面で1回押す → 幅と高さの欄がカーソルの脇に出ます
4. 幅 `57.471`、高さ `34.483` と打って `Enter`

> 57.471 = 5000 ÷ 87、34.483 = 3000 ÷ 87 です。
> 「数」の棚の **実物の寸法** に `5000` と打つと 57.4713 が、`3000` と打つと 34.4828 が出ます。
> **打つ前に、その数を見てください。** 暗算しないほうが間違えません。

画面に四角が出ます。**線が太く明るくなるところにカーソルを置くと、それが掴めます。**

---

## 3. 窓を1つ引いて、4つに並べる(3分)

窓は 実物 800 × 1000mm、**間隔(ピッチ)は 実物 1100mm** にします。
1/87 では 窓 `9.195` × `11.494`、ピッチ `12.644` です。

1. **「矩形」** のまま、側板の **左寄りの中** に1つ引きます
2. 1回押したあと、幅 `9.195`、高さ `11.494` と打って `Enter`
3. 道具を **「選択」** に戻し、いま引いた窓を押して選びます
4. 上の2段目の **「直線に並べる」**
5. 窓が出たら:
   - 個数(元を含む) `4`
   - 下の値の意味 **「端から端まで」**
   - X `37.931`、Y `0`、Z `0`

**窓が4つ並びます。** 37.931 ÷ 3 = 12.644mm 間隔 ── 手で割らなくて構いません。
「1つ分の間隔」を選んで X に `12.644` と打っても同じです。

4つ分の幅は 37.931 + 9.195 = **47.13mm**。側板は 57.47mm なので、
左右に 5.17mm ずつ余ります(実物 450mm)。だいたいその位置に置いてください。

> **窓の位置は目分量で構いません。間隔だけが数で決まります。** それが「並べる」ということです。
> 位置もきっちり決めたいときは、窓を選んで **「移動」** を押し、
> 2点目を打つときにカーソル脇の欄へ ずらす量 を打ちます。
>
> 4つが側板からはみ出したら、窓を引いた場所が右すぎます。
> `Ctrl+Z` で **1回** 戻ると、4つまとめて消えます。引き直してください。

## 4. 板にする(2分)

1. モードを **「部品」** にします。右の棚が **「部品」** になります
2. 3D 画面で **外形の四角** を押して選びます(窓ではありません)
3. 右の棚の **「押し出し」**
4. 窓が出たら、距離が `0.5` になっていることを確かめて **OK**

**画面に板が出ます。** 灰色に塗られ、稜線が描かれます。
塗ったところを押せば選べます。

> 出なければ、右の「グリッド」の棚の **「立体・面を出す」** が外れています。

---

## 5. 型紙にする(3分)

1. モードを **「製作」** にします
2. 板を選んで、右の棚の **「製作モデルを作る」**
3. 窓の四角を4つ選んで **「境界の役割(開口 / 折り線)」** → 開口になります
4. **「型紙を作る」**

右に **「型紙の下見」** が出ます。

- 白い四角が紙(A4)、その上が型紙です
- **黒の実線 = 切り取り線、青の破線 = 折り線、赤 = 切れ目、緑 = 窓**
- 下に「1 / 1 枚 210 × 297 mm 線 20 本」のように出ます
- **線の数が 0 なら、その紙は空です**(何か落ちています。知らせを読んでください)

---

## 6. 紙に出す(1分)

1. モードを **「出力」** にします
2. 右の棚の **「型紙の下見」** で、もう一度 紙に収まっているか見ます
3. **「1:1 PDFで保存」** → 保存先を決めます

**この PDF は原寸です。** 印刷するときに「用紙に合わせる」を **切って** ください。
切らないと縮んで出て、型紙になりません。

印刷したらプラ板に貼って切ります。ここまでが1枚です。

---

## 7. 次にやること ── 曲がった前頭部を見る

この道具の本当の相手は、**曲がった面をプラ板に展開すること** です。
平らな板だけなら、定規で引けます。

見本が入っています。**「開く」** で

```
samples/streamlined-railway-nose-1-87.kcd2
```

を開いてください。流線形の前頭部が、面と部材に分かれた状態で入っています。

見るところ:
- 左の一覧 ── 線・面・部品がどう分かれているか
- 部品モードの **形状ガイドの役割** の表 ── 面がどの線から作られているか
- 製作モードの **「製作モデルを作る」** ── 曲面が何枚の部材に割れるか
- **伸ばさないと平らにできない面は断られます。** 近い形へ均して「できた」ことにはしません
  (均したいときは、製作の棚で方式を「帯へ近似し直す(V1方式)」にします)

## 困ったとき

| 症状 | 見るところ |
| --- | --- |
| ボタンが灰色で押せない | そのボタンにカーソルを置くと、何を選べばよいかが出ます |
| 押しても何も起きない | 帯(いちばん下)を読んでください。必ず理由が出ます |
| 線が掴めない | 作図中は **作業平面の上の線しか掴みません**。選択道具に戻すと全部掴めます |
| 作った形が見えない | 「グリッド」の棚の「立体・面を出す」/「作図面を出す」 |
| どこに描いているか分からない | 作図面が薄い四角で出ています。**青緑が作業中** の面です |
| 選んだものが画面の外 | **「選択に正対」**。向き・真ん中・大きさを合わせます |
| 一覧から探せない | 一覧の上の欄に名前か種類名(「ワイヤー」など)を打ちます |

**理由には番号が付いています**(`EXT-002` など)。
番号の一覧は `docs/v2/diagnostic-catalog.md` にあります。
