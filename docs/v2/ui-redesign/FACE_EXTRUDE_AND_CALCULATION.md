# フェイス押し出し・計算表示（2026-10-13）

状態: 進行中。オーナー指示による既存操作の修正。

## 受入条件

- 押し出しを起動してからソリッドのフェイスをクリックできる。平面は既存の押し引き、
  曲面は元のネイティブ面を一方向に移動した押し出しとして扱う。局所法線に沿った厚みとは区別する。
- 曲面フェイスのプレビュー・取消では文書を変えない。確定時だけ使用する面の形状を保存し、
  Undo/Redo・保存再読込で同じ結果を復元する。未選択のフェイスを入力に混ぜない。
- 距離・方向反転・対称・両方向・面/線/点までを右ペインに出す。
  線までの斜面は線と押し出し方向から定める。平行な線は端点を指定する。
- 計算をUIスレッドから離し、時間のかかる形状作成・検査・出力・投影等に共通の計算バーを出す。
  即時に止められる既存の別プロセス計算は維持する。通常のネイティブ計算の取消は結果を破棄し、
  実行中の処理の終了を待つ。形状表の計算は直列化し、取消中も画面を更新する。
- STEPでは閉鎖性・正体積・自己交差・再読込時の形状一致を引き続き検査する。
  形状と許容誤差が同じ場合だけ検査を再利用し、量や精度を下げて速くしない。
- 取消時は新しく生成された形状を解放する。ネイティブ面・穴・傾いた線・点まで、
  取消・再実行、STEPの再読込と速度を試験する。

## 次の設計相談: 側面まで回り込む窓

現行の「巻き付け投影」は固定方向の複数面投影であり、等長の巻き付けではない。
正面/側面図から再現する方向投影、可展面への等長巻き付け、3D輪郭の最近点投影を
別の選択肢として提示する。図面による鉄道前面の窓には複数方向投影を第一候補とする。
複曲面の等長巻き付けは一般に保証できないため、形状の歪みと面からの偏差を明示する。
