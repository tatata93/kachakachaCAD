選択を局所表示

具体例: ライトだけを一時的に見る

準備

板とライトの2要素を用意する

操作手順

  1. ライトを選ぶ
  2. 選択を局所表示を押す
  3. 何もない場所を押して選択を解除する

設定: 文書の表示設定は変更しない

結果を確認

選択解除後もライトだけを表示し、隠れた板は拾わない。

取消・やり直し

ダイアログの取消、またはペインの取消を使います。即時操作には未確定段階がありません。 確定済みの文書変更はCtrl+Z、やり直しはCtrl+Yです。保存・書出し済みのファイルはUndoの対象ではありません。

進めない場合

対象を選んでください。

対象欄と3Dの強調を照合し、必要な線・面・部品を各役割へ指定します。処理中は計算表示を確認し、取消が可能な処理は取消を使います。

Windows版の操作画面

view.isolate。図の設定と縮尺は例です。方式ごとの制限、プレビューと確定済み結果の区別を確認してください。
