# ADR 0004: 面上ワイヤーは平面図または断面作図から作る

## 状態

採用

## 決定

- 車体形状の断面は、任意作業平面へ直接作図した通常の3Dワイヤーとして定義する。
- 2本の断面ワイヤーからルールド面を、3本以上からロフト面を作れるようにする。
- ライト穴などの境界は平面図として正確に作図し、対象面へ指定方向で投影する。
- 投影後のワイヤーは面上の3Dワイヤーとして保存する。
- 投影元ワイヤー、対象面、投影方向の関係を保持し、元図または断面の変更時に再計算する。

## 理由

ライト穴を最初から曲面上で数値編集するより、見慣れた平面図で位置と寸法を決めてから車体面へ移す方が模型製作の作業に近い。断面も同じ作図機能を使うため、2D作図と3D面作成を分断しない。

## 制限

- 現在の曲面はルールド面と、隣接断面を直線的に補間するロフト面に限定する。
- 曲面投影結果は3Dポリラインで表すが、元の円やベジェ曲線は平面図側に保持する。
- 複数の交点がある投影では、投影元に最も近い交点を採用する。
