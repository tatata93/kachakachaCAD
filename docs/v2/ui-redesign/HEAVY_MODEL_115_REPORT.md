# 重量級モデリング検証：115系1000番台（2026-10-05）

## 成果物と範囲

[ネイティブKCD2](../../../samples/series115-heavy/series115-1000-1-80.kcd2)、
[寸法・構成・再現手順](../../../samples/series115-heavy/README.md)。

1/80のクモハ冷房車を想定し、1,083立体、1,367元ワイヤ、2参照面、102グループを作成。
外部でレンダリングした見本ではなく、このCADの押し出し・ロフト・厚みから再生成する。
反復部品の入力はPythonでネイティブのフィーチャ定義を生成した。
全項目を人間と同じマウス操作で一から作図した試験ではない。

公式車両図の主要寸法に合わせた詳細な近似モデルであり、特定車番の完全な実測復元ではない。
床下配置、台車細部、ばね、室内、小物の寸法は近似。塗装、ガラス、銘板文字は未再現。
寸法根拠・工作上の扱いはサンプルREADMEに明記。極細部品を含むため一括造形用データとはしない。

## 重負荷モデルで見つけた問題と修正

1. **元ワイヤを非表示にすると保存後に押し出しが欠落する。**
   表示用Sceneのみから輪郭を取得していた。指定された非表示の元輪郭は有効なフィーチャ定義から
   復元するよう修正。無効化したフィーチャは復元しない。保存再読込のGUI回帰試験を追加。
2. **向きによって窓穴が埋まる。**
   穴ワイヤを入力の回り順によらず反転していた。共通平面上で穴の向きを正規化してから反転。
   XY/XZ/YZの輪郭と穴の正逆方向で、予測体積とカーネル体積の一致を回帰検証。
3. **再生成失敗の理由が無関係な古いステータスになる。**
   押し出し再生成で幾何診断を報告し、欠落した部品名と実際の理由を残す。
4. **内部の稜線が外板を透過して全車が線だらけになる。**
   面と同じ深度で稜線を描画し、面の奥の稜線を隠す（U/V格子は従来どおり）。独立ワイヤと選択/ホバーの強調は維持。
   派生スナップ線の重複描画・不要な曲線標本化も省く。
   奥の線、同一平面上の線、手前の線、画面外に大きく延びる線を回帰検証。

## 検証条件

Windows実機、MSVC Release、Qt/OCCTあり。1800×1000のアプリ内ビューポートをネイティブ描画。
このモデル専用の実行は `python tools/modeling/benchmark.py`。
通常の全自己診断に重負荷モデルを無条件で追加せず、環境変数で明示したときだけ実行する。

- 読込時に全立体が再生成され、RebuildProblemsが空であることを検査。
- 保存再読込で形状数が一致することを検査。
- 全体5方向、前面、台車・室内の局所表示を保存。
- 12フレームの回転・再描画を計時（FPS保証ではなくこの条件の実測）。
- 実際の出力処理でSTL/STEPを書き出し。
- 屋根参照面の自動間隔4部材近似、曲げ状態0/50/100%、SVG型紙、近似込み別KCDを検査。

実行ログ・STL・STEP・近似込みKCD・SVG型紙は `_claudeout/115-heavy/` に出る。
STLは351,508三角形。STEPは1,083個のMANIFOLD_SOLID_BREPと終端を確認。
STL外接寸法は250.000×36.875 mm。高さには屋根上機器と車輪フランジを含む。
これは独立した部品の集合であり、1個の融合ソリッドではない。

## 実用性の判定

約1,000部品でもモデル保持・再生成・保存・出力の経路は動く。
ただし全車・全小物を同時表示した回転描画は重い。全表示のまま快適に編集できる水準とはしない。
車体、屋根、台車、室内などのグループを局所表示し、部分ごとに作業する運用が必要。

屋根は展開可能な円筒状参照面なので、この試験の近似最大偏差は表示上0.000000 mm。
一般の二重曲面で同等の精度が得られることを意味しない。従来近似のRMSは未提供。
全車の部材化・全小物の型紙・プリンタでの実造形・走行試験は未実施。

Computer Useによる実ウインドウ取得は、再取得後も `window capture timed out` で失敗した。
したがって直接マウス操作の受入確認とは区別する。画像はCAD自身の通常Windows描画で作成。
Linux/cloud検証とオーナー目視受入も未実施。

## 検証結果

個別カーネル押し出し32/32、面描画26/26、構造16/16は成功。
Windows通常画面でHP-HEAVY 2/2成功。近似込みKCDの再生成も成功。
最終測定（1回の観測値、実使用時の速度保証ではない）:

|操作|実測|
|---|---:|
|1,083立体の読込・再生成|9.173秒|
|保存・再読込|10.045秒|
|STL出力|3.443秒|
|STEP出力|27.215秒|
|全車の回転＋描画、12回|7.039秒（平均0.587秒/回）|
|前台車の局所表示、回転＋描画12回|2.281秒（平均0.190秒/回）|

表示は363,796三角形。局所表示は軽くなるが、この条件でも滑らかな連続回転とは評価しない。
Windows全体ゲートは実行中。完了結果を追記する。
