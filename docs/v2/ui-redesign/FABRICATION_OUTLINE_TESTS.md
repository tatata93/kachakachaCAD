初回の独立検査では、曲線方向の等間隔標本が急な部分を飛ばして約1.034 mmずれるケースを検出した。幅方向の誤差表示だけでは十分でないため、曲線方向も適応標本化し、その標本誤差を表示値に加算する。元ファイルを上書きしない。

この行列は検査したパターンの証拠であり、全数学的曲面や全域の誤差上界を保証するものではない。見た目だけの推定画像は試験証拠に使わない。

全GUI検査で小さい前頭部のトリム面を拒否するケースを検出した。外形の単一区間対応を追加し、HP-GPT-F05の9枚・自動間隔・最小幅警告・型紙と、HP-GEN-04の0/37/100%生成を回帰検査する。穴やどちらのUV方向でも分岐する外形を矩形で埋めない。

追加の製作検査で、共有レールへの表示上の合わせを型紙へ流用すると幅方向に最大2.341820 mmずれることを検出した。
型紙を部材ごとの独立した等長展開へ変更し、開口の写像・幅計測を追従。5方向×両間隔の10条件で型紙輪郭の自己交差なし。
0/50/100%直前で型紙の三角形辺長差は最大1.59e-12 mm。型紙の寸法と曲げ角のみから配置した再組立で最大位置差6.41e-11 mm、継ぎ目差1.04e-10 mm。
滑らかな四辺形面と内部三角形標本のもう一方の対角線差は最大0.000103 mm。板厚ゼロ・理想曲げの計算であり、実物の板材を製作・接着して検査した意味ではない。

実データの独立標本検査（各条件22,320〜51,480点）では、縦方向12枚の等間隔で最大0.469287 mm、RMS0.101522 mm、自動間隔で最大0.094534 mm、RMS0.031028 mm。横方向は等間隔0.084119 mm、自動間隔0.046156 mm。生成12面の対応点差と保存再読込後の差は最大7.11e-15 mm。近い短区間へ誤って参照を保存する問題も検出し、許容値での探索より先に元区間との厳密対応を優先する回帰試験を追加した。
