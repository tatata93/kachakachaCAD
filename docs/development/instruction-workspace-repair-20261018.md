# 説明書エディターの再整備（2026-10-18）

対象はWP-08のQt UI。幾何コア・KCD2契約・元モデルは変更しない。
画像エディターの3D場面と用紙編集を維持し、場面はUUID参照で用紙へ置く。
KCI既存版の読込、取消、Undo/Redo、PNG/JPEG等・PDF出力を維持する。

## 操作設計

- 上段に「1 場面」「2 用紙」、追加・複製・ページ削除と名前を常設する。
- その下に現在の編集で使える道具を配置し、選択・移動へ常に戻れるようにする。
- 部品だけでなく矢印・文字も一覧で選び、選択中の文字を移動モードのまま編集する。
- 文章の配置入力と選択物の編集を分け、右ペインと配置内容を一致させる。
- 部品の取り込みチェックをモード往復で保持する。現在のモデルのワイヤも選べるようにする。
- Ctrl+Sは同じKCIへ保存し、別名保存と新規作成を区別する。
- ページ削除は参照先を説明して確認し、場面と用紙の配置参照を1回でUndoできるようにする。
- 場面からのPDFは現在の場面を用紙に収めて出力し、用紙編集では作成した全用紙を出力する。

## 必須回帰

文字入力→キャンバス→実キーUndo/Delete、古い文章の再配置、部品チェックのモード往復、
文字/矢印の選択・編集、注記のみの全体表示、ページ削除の参照とUndo、
新規/上書き/別名保存、ワイヤだけの説明図、テーマを保持したモデル読込、
白紙にしない場面PDF、複数用紙PDF、保存読込、元CADの不変を確認する。
全体ゲートと配布版/通常起動を最終判定に使い、入口点検のみで完成扱いにしない。

最初の全体試験は、非表示環境の既存文字選択試験の失敗を検出して中断した。

## 原因と修正の対応

| 原因 | 変更後の動作 |
| --- | --- |
| 場面・用紙の道具が共通の長い操作列に混在 | 編集対象ごとの常設操作列に分離し、選択・移動へ戻れる |
| 文字欄にフォーカスが残り、キャンバスのUndo/Deleteへ届かない | キャンバスクリックでフォーカスを取得し、文字欄内の編集履歴とは分離 |
| 入力欄の再生成で配置予定の文章や取り込みチェックが初期化 | 下書き・選択行・チェックを状態として保持 |
| 矢印・文字の選択後も部品用設定が表示される | 選択物ごとの設定を表示し、文字は選択・移動中も編集できる |
| ワイヤのみのモデルを空のモデルとして扱う | 描画・選択・KCI保存読込までワイヤを扱う |
| モデル読込用の非表示ウィンドウがテーマを変更 | 元のテーマを復元し、取り込みで見た目を変更しない |
| 場面でPDF出力しても未編集の用紙が対象 | 場面は現在の図、用紙は配置した全ページを出力 |
| Ctrl+Sが毎回別名保存になる | 既存KCIへ上書きし、別名保存を独立 |
| ページ削除と参照先の扱いが不足 | 対象と用紙上の参照数を確認し、一括削除・Undoで復元 |
| 複数行文字の描画と選択範囲の不一致 | 1行の既存動作を維持し、複数行の矩形描画と選択を一致 |

## 確認方法と範囲

WindowsのQtイベントによる実キー・マウス入力、ウィジェット描画画像と保存物で確認した。
OS全体のマウス操作だけを録画した試験ではない。全168コマンドの入口点検は右ペイン等の遷移を
確認するものであり、全ての任意形状の幾何計算の成功を意味しない。幾何・保存・Undo等は全体の
既存回帰ケースと併せて判定する。

実モデルの用紙PDFはPopplerで画像化し、モデル・矢印の表示と欠けがないことを確認した。
手順書は docs/manual/instruction-editor.html に実画面付きで追加した。
主編集対象を変更する幾何処理や保存形式の版上げは行っていない。
