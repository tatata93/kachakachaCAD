保存

具体例: 作った側板を同じファイルへ保存する

準備

side.kcd2を開き、線を1本追加する

操作手順

  1. Ctrl+Sを押す
  2. 初回なら保存先と名前を決める

設定: side.kcd2

結果を確認

追加した線を含む状態が保存される。

取消・やり直し

ダイアログの取消、またはペインの取消を使います。即時操作には未確定段階がありません。 確定済みの文書変更はCtrl+Z、やり直しはCtrl+Yです。保存・書出し済みのファイルはUndoの対象ではありません。

進めない場合

文書がありません。

対象欄と3Dの強調を照合し、必要な線・面・部品を各役割へ指定します。処理中は計算表示を確認し、取消が可能な処理は取消を使います。

Windows版の操作画面

file.save。図の設定と縮尺は例です。方式ごとの制限、プレビューと確定済み結果の区別を確認してください。
