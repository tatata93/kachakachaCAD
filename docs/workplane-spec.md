# 作業平面仕様

## 目的

作業平面は、3D空間内に自由に置ける作図用の紙である。

ユーザーは作業平面を選び、「この平面に正対」して2D CADのように線や曲線を描く。作図した点や線は、平面の位置と向きに従って3D空間へ配置される。

## 座標系

初期方針では以下を基本軸とする。

```text
X: 車体長手方向
Y: 車体幅方向
Z: 高さ方向
```

画面上の「右」「上」「奥」は視点で変わるため、保存データや数値入力では `X / Y / Z` を使う。

## 内部表現

```text
WorkPlane
- origin: 平面原点
- uAxis: 平面内の横方向
- vAxis: 平面内の縦方向
- normal: 法線方向
- source: 作成方法と参照元
- offset: 参照元からのオフセット
- angle: 参照元に対する角度
```

`uAxis`, `vAxis`, `normal` は正規直交基底として扱う。

## 作成方法

### 標準平面

- 正面
- 側面
- 上面

### 座標指定

- X = 任意値
- Y = 任意値
- Z = 任意値

### 3点指定

任意の3点 A/B/C を選び、その3点を通る平面を作る。

```text
origin = A
uAxis = normalize(B - A)
normal = normalize(cross(B - A, C - A))
vAxis = cross(normal, uAxis)
```

3点が一直線上に近い場合は作成しない。

### 点＋法線

通過点と法線方向を指定して平面を作る。

### 面＋オフセット

既存平面または面を選び、法線方向へ指定距離だけずらした平面を作る。

### 辺＋角度

基準辺を回転軸にして、基準平面を指定角度だけ回した平面を作る。

### 2辺指定

交差する2本の辺、または同一点から出る2本の辺で平面を作る。

### 曲線上の接平面

曲線上の位置を指定し、その接線方向を基準に平面を作る。これは後期機能とする。

## 共通調整

どの作成方法でも、作成後に以下を調整できるようにする。

- 名前
- 原点位置
- オフセット距離
- 角度
- 向き反転
- 平面内X方向
- 表示 / 非表示
- ロック

## 必須操作

- この平面に正対
- この平面に作図
- この平面へ投影
- この平面で切断
- この平面から複製
- 参照元を保持したまま再計算

## 初期実装範囲

最初のC++コアでは以下を実装する。

- 3点から平面を作る。
- 点＋法線から平面を作る。
- 平面をオフセットする。
- 任意軸まわりに平面を回転する。
- 平面上の2D座標を3D座標へ変換する。
- 3D点を平面座標へ投影する。
