# 投影面の押し出し・通常ワイヤー出力の検証

状態: 完了（2026-10-14）。検証した候補 `9fbe5ff32`。

## 修正と操作

投影の右ペインを下へスクロールし、「結果」にある「ワイヤーの残し方」で、投影結果（読み取り専用）と
通常ワイヤー（編集可能）を選ぶ。どちらも投影位置・曲線を維持する。
通常ワイヤーは既存CreateWire/Sourceとして保存し、入力への依存を持たない。

曲面のライトは「面＋ワイヤー」で投影を確定し、左ペインの面カテゴリまたは
3Dビューで投影した面を選択→押し出し→距離入力→Enter。
元の線・面・部品は保持する。面の境界をまたぐ投影領域は既存仕様どおり面ごとのパッチになる。

投影面を保存するだけで表示・押し出し用の形状一覧へ登録していなかった不具合を修正。
トランザクション成功後だけ形状の所有権を渡し、プレビュー取消で確定面を解放しない。
また、面押し出し確定中のUI再入でキャッシュが置換され、確定した部品の形状が
解放されていた不具合を修正。確定に使うプレビューを保持し、正しい所有者から部品へ渡す。
全モデルの再計算によって帳尻を合わせる方式にはしていない。
