# V2 UI ワークフロー

## 1. 適用規則

画面、カーソル、選択、ToolSession、キー操作の規範は `ui-ux-integrated-spec.md` に従う。
この文書は各作業で「何を、どの順に選び、何が生成されるか」を固定する。

全ワークフローに次を適用する。

1. 標準順は `ツール -> 対象 -> 値 -> プレビュー -> 確定`。
2. 有効な事前選択がある場合は同じ入力として取り込む。
3. Ctrlで同じオブジェクト内を含む複数サブ要素を選べる。
4. 入力はInput色、結果はPreview色で表示する。
5. Enterで確定、Escで1段戻る、戻れなければ取消。
6. 入力オブジェクトは削除しない。
7. 失敗は理由番号、問題箇所、修正方法を表示する。

## 2. 共通画面

### 2.1 コマンド開始

利用者はメニュー、上部道具バー、右クリックメニュー、ショートカットのいずれかからCommandIdを開始する。
入口が異なっても同じToolSessionを使う。

開始時に右プロパティへ次を表示する。

- ツール名
- 必要な入力役割と件数
- 取り込み済み対象
- 数値または選択式パラメータ
- 診断
- 確定、取消

ビューポート左上には `ツール名` と `次に選ぶもの` だけを表示する。

### 2.2 コマンド切替

別のツールを選んだ場合、未確定プレビューを破棄して前のToolSessionを終了する。
前のツールの入力色、カーソル近傍値、数値欄、押下表示を残さない。
通常選択は、新ツールの入力に適合する場合は取り込み、適合しない場合も選択集合として保持する。

### 2.3 事前選択

必要な型と個数を満たす場合は直ちにプレビューへ進む。不足している場合は取り込める対象だけをInputへ移し、
残りをビューポートから選ばせる。過剰または不適合な対象は勝手に削除せず、取り込まなかった理由を表示する。

## 3. 選択とHover

### 3.1 通常選択

- 点、端点、線分、連続鎖、面、部品、製作モデル、作業平面を個別に選べる。
- Ctrlで追加と解除を行う。
- 矩形選択は左から右で完全内包、右から左で交差を含む。
- 空白クリックは選択解除。ただしToolSession中は入力を取消さない。

### 3.2 重なり候補

Hoverは最上位候補だけを強調する。Tabで候補を巡回し、Alt+クリックで奥の候補を選ぶ。
右クリック候補一覧には種類、表示名、所属グループを表示する。

### 3.3 スナップ

端点/作図点、交点、中点/中心/四分点、最近点、垂足/接点、グリッドの順を基本とする。
現在ツールに適合する候補を優先し、クリックまでは確定しない。
Sを押している間はスナップを解除し、Shiftは方向拘束に使う。

## 4. 作図

### 4.1 直線

1. `直線` を開始する。
2. 始点を選ぶ。空間点、作図点、端点、交点、作業平面上の任意点を使える。
3. 終点を指示する。
4. 距離、水平角、仰角をカーソル近傍または右プロパティで入力できる。
5. Enterで1本確定する。連続作図では確定点を次の始点にする。

Shiftは現在の作図基準に対する水平、垂直、XYZ軸、既存線方向の候補を拘束する。

### 4.2 ポリライン

直線と同じ入力を繰り返す。Backspaceで最後の頂点だけを戻す。
始点へスナップした場合は閉じる候補を明示し、Enterまたはダブルクリックで完了する。

### 4.3 作図点

1. `作図点` を開始する。
2. 3D位置をスナップ、XYZ、選択点からの相対距離で指定する。
3. 必要な数だけ配置し、Escで終了する。

作図点はワイヤーと同様に作業平面へ所有させない。

### 4.4 円

中心+半径、3点、2点直径を選ぶ。方式選択後に必要点を順に取り込み、半径または直径を式入力する。

### 4.5 円弧

次の方式を持つ。

- 3点
- 両端+半径
- 始点+接線/法線方向+半径または角度+中心角または円弧長

段階名と入力済み点を常に表示する。解が複数ある場合はカーソル側の解をPreviewにし、
Tabで反対解へ切り替える。

### 4.6 BezierとB-spline

Bezierは端点と制御点、B-splineは通過点を順に指定する。
Backspaceで最後の点を戻し、右プロパティで次数、閉曲線、接線条件を設定する。

## 5. ワイヤー編集

### 5.1 トリム

1. `トリム` を開始する。
2. 切断境界となる線または曲線を複数選ぶ。
3. 削除する側をクリックする。
4. 交点と残る区間をPreview表示して確定する。

直線、円弧、Bezier、B-splineの組合せを扱う。交点がない場合は延長交点を勝手に使わない。

### 5.2 延長

1. `延長` を開始する。
2. 延長先の境界を選ぶ。
3. 延長する端部を選ぶ。
4. 交点または指定距離までのPreviewを確定する。

### 5.3 分割、結合、接続

- 分割: ワイヤーと分割点または交差対象を選ぶ。
- 結合: 2本以上の接続可能なワイヤーを順序付きで選ぶ。
- 端点一致: 移動させる端点と基準端点を選ぶ。
- 接線接続: 2本の接続端を選び、どちらを変形するか指定する。
- 曲率接続: 接線接続に加えて曲率連続条件を指定する。

結果の向き、変更範囲、元位置を同時にPreviewする。

## 6. 作業平面

作業平面の方式はCommandとして選び、必要対象を後から取り込む。

| 方式 | 入力 |
| --- | --- |
| 標準面 | XY / XZ / YZ |
| オフセット | 基準平面 + 距離 |
| 3点 | 同一直線上でない3点 |
| 2平面の中間 | 平行な2平面 |
| 角度 | 基準平面 + 回転軸 + 角度 |
| 点を通る平行面 | 基準平面 + 点 |
| エッジを通る角度面 | エッジ + 基準平面 + 角度 |
| 面へ接する平面 | 曲面 + 接点 |
| 点を通る法線面 | 曲線 + 曲線上の点 |

作成後に名前と表示を設定する。作業平面の削除や切替で既存ワイヤーを削除または移動しない。

## 7. 形状ガイド

### 7.1 閉輪郭から

1. `閉輪郭から形状ガイド` を開始する。
2. 自動鎖認識またはCtrl選択で輪郭を構成する複数線分を取り込む。
3. 閉鎖、平面性、自己交差、内外輪郭を検査する。
4. 面の向きと境界をPreviewして確定する。

### 7.2 2断面または複数断面

1. `断面から形状ガイド` を開始する。
2. 断面1、断面2、必要なら追加断面を役割ごとに取り込む。
3. 各断面は1本または接続した複数線分でよい。
4. 順序、方向、対応点をPreviewで調整する。
5. 連続性と最大偏差を確認して確定する。

### 7.3 外形と断面

1. `外形・断面から形状ガイド` を開始する。
2. 外形ガイドを2役割以上追加する。各役割は複数線分でよい。
3. 断面ガイドを1役割以上追加する。各役割は複数線分でよい。
4. 両端が接続する形、外形と断面が交差する形を含め、交点と方向を検査する。
5. 役割表で並び替え、反転、削除を行い、Previewを確定する。

## 8. 部品作成

### 8.1 押し出し

1. `押し出し` を開始する。
2. 閉輪郭または形状ガイドを選ぶ。複数輪郭を同時に選べる。
3. 方向を法線、作業平面法線、XYZ、選択エッジから指定する。
4. 距離を数値、対称、両側別、選択面まで、貫通から指定する。
5. 出力を `部品 / 形状ガイド / ワイヤー / 部品+ワイヤー` から選ぶ。
6. Booleanを `新規 / 足す / 引く` から選ぶ。部品以外では表示しない。
7. Previewを確定する。

ワイヤー出力は複製輪郭と対応接続線だけを作る。入力は残し、`生成後に入力を隠す` は任意とする。

### 8.2 閉空間から部品

1. `閉空間から部品` を開始する。
2. `境界を手動指定` または `閉空間を検索` を選ぶ。
3. 検出された領域を一覧と3D強調で確認する。
4. 隙間、重複、自己交差、非多様体がなければ確定する。

複数の閉空間が見つかった場合は、作る領域を複数選択できる。非連結結果は別部品に分ける。

### 8.3 厚みを付けて部品化

1. `厚みを付けて部品化` を開始する。
2. 形状ガイドまたは部品の面を選ぶ。
3. 片側、反対側、両側、選択面までを選ぶ。
4. 厚さと方向を入力する。
5. 自己交差と最小曲率半径を検査し、Previewを確定する。

UI、ツリー、診断で `板材化` と呼ばない。

## 9. 製作用近似

### 9.1 近似モデルを作る

1. `製作用近似` を開始する。
2. 元の部品または形状ガイドを選ぶ。
3. 接続を保つワイヤー、面、開口を追加選択する。
4. 大きな連続部材の優先度、再現度、最大部材数、最小幅、切れ目の向きと可否を設定する。
5. 部材、切れ目、折り線、最大/RMS偏差をPreviewする。
6. 元モデルと別オブジェクトとして確定する。

元モデルを変更した場合は製作モデルを再評価する。製作モデル側の手動境界は明示Featureとして保持する。

### 9.2 組立確認

1. 製作モデルを選び `組立確認` を開始する。
2. 全体組立率0から100%または個別折り角度を変更する。
3. 境界一致、実長、開口位置、干渉、未接続部を表示する。
4. 任意状態で `現在状態を固定` を選ぶと、独立したワイヤー、形状ガイド、部品を必要に応じて作る。

途中状態で寸法を拡大縮小せず、剛体回転と規定した曲げ変形だけを使う。

### 9.3 型紙

製作モデルまたは選択部材から型紙を作る。部材境界、切断線、折り線、切れ目、開口、基準寸法を表示する。
現段階でのりしろは作らない。

## 10. 測定

### 10.1 2点

2点を選ぶと全長、dX、dY、dZ、XY/XZ/YZ投影距離、各軸との角度を同時表示する。

### 10.2 3点

頂点を含む3点を選び、内角と補角、基準平面への投影角度を表示する。

### 10.3 線と曲線

線分、円弧、Bezier、B-splineの任意の組合せを選ぶ。指定位置の接線角度と法線角度、
最短距離、交点がある場合は交点を表示する。

測定結果から作図点または基準方向を作れるが、明示した場合だけDocumentへ追加する。

## 11. 出力

1. `出力` を開始する。
2. 選択、グループ、部品、製作モデル、型紙から対象を指定する。
3. STL、STEP、SVG、DXF、1:1 PDFのうち適合形式を選ぶ。
4. 対象数、単位、実寸、閉鎖性、偏差、ページ分割を検査する。
5. 問題がなければ保存する。

選択部品だけ、任意の組立率で固定した部品だけを出力できる。STLとSTEPは同じ検査済みB-Repを使う。

## 12. 実用受入シナリオ

1. 作業中グループを `ER前頭部` にする。
2. 複数作業平面へ独立した輪郭と断面ワイヤーを作図する。
3. 複数線分から成る外形と断面を使い、ER1/初期ER2の1/87形状ガイドを作る。
4. 6枚窓の閉輪郭を投影し、開口を含む形状ガイドを作る。
5. 厚みを付けて部品化し、理想モデルを保存する。
6. 前面を少数の大きな部材へ製作用近似する。
7. 屋根肩だけに必要な切れ目を入れ、窓とライト開口が保たれることを確認する。
8. 組立率0、30、100%で実長が一致することを測る。
9. 30%状態を固定し、選択部品をSTLとSTEPへ出力する。
10. 型紙をSVG、DXF、1:1 PDFへ出力する。

この流れをツール先行で完走でき、同じ対象を事前選択して開始しても同じ結果になることを受入条件とする。
