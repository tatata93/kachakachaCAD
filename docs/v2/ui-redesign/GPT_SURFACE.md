# GPT版の面生成

2026-09-24 オーナー指定。既存の面生成の操作・判定・生成処理を再利用せず、独立した入口を追加する。
「GPT版」は実装の呼称であり、外部AIへの通信やAPIキーを必要としない。

- 入口は面作成の帯と形状メニューの `surface.gpt_create`。
- 外周から張る: 1つの閉じた外周と、任意本数の内側の通る線を入力する。
  外周の順と向きは端点接続から決める。内側の線を含めて1枚の近似面を張る。
- 断面をつなぐ: 2つ以上の開いた断面または閉じた断面を一覧順に通す。
  複数ワイヤーを1断面へまとめられ、断面の順序・方向を変更できる。
  各断面の辺数はそろえる。自動反転や自動分割で対応を勝手に変えない。
- いずれも元ワイヤーを移動・削除しない。隙間は黙って閉じない。
- 全入力を検査する。役割が不適合、重複、分岐、切れた鎖、自己交差、
  外周が複数の場合は理由と修正方法を表示し、部分的な面を確定しない。
- 外周方式は近似と表示し、許容偏差を明示する。両方式とも生成した実形状から
  全入力線の標本点の最大/RMS偏差を測定する。測定失敗・許容超過は確定不可。
- 面の下見は文書外。確定は1操作、取消は変更なし。保存・再読込では同じ独立経路で再生成する。
- 保存は既存 `CreateGuideSurfaceDefinition` の参照形式を用い、`gptBuilder=true` と
  `gptToleranceMm` を保持する。既存データの既定は false。既存方式の意味を変更しない。
- 初回範囲に穴付き外周・支持面のG1/G2・ロフトの外形ガイドは含めない。
  入れた線を捨てて成功にはしない。これらは別の仕様判断が必要。

検証: 外周・内側拘束・複合断面・曲線断面・順逆・隙間・重複・不適合入力、
保存再読込、実際のボタン、プレビュー、取消、Undo/Redo。PC結果はTASK_LEDGERに実測で記録する。

## 操作

1. 作図の帯 → 面作成 → **GPT版**。選択済みのワイヤーがあれば最初の入力になる。
2. **外周から張る（近似）**: つながる外周をクリックして追加。
   形を決める内部線は **内側の通る線へ追加** に切り替えてクリックする。
3. **断面をつなぐ**: **新しい断面として追加** で断面を順に選ぶ。
   複数ワイヤーで1断面にするには一覧の行を選び、**一覧の選択行へ追加** で残りを拾う。
   上へ・下へで断面順を変え、反転で向きを変える。
4. 許容偏差を指定して **プレビュー**。色付きの面と標本偏差の最大/RMSを確認する。
   エラー時は理由を直すまで確定できない。
5. **この面を確定**。元の線は残る。確定前のEsc/取消は文書を変更しない。
   Enterは下見がないときプレビュー、下見があるとき確定。確定は1回のUndoで戻せる。

標本偏差は曲線全域に対する数学的な上界ではない。穴付き外周やG1/G2指定の入口は設けない。
