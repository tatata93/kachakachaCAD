# ADR 0014: 曲げ紙ペーパークラフトを第三の独立方式として持つ

## 背景

多面体方式は、各三角面を伸縮させず確実に展開できる一方、部品が細かく分かれ、窓やライトも面分割に従って角ばる。これは紙を滑らかに丸められる利点を使っていない。

鉄道車両の実物ペーパークラフトでは、車体側面・屋根・前面を大きな連続部材として残し、曲線の外周と開口、端から入る短い切り欠き、途中で止まるスリットを組み合わせている。紙は伸ばさず一方向へ曲げられ、二方向目の曲率は切れ目の周囲で局所的に逃がせる。

## 調査

- JR西日本の273系やくも展開図は、側面・床・反対側面を大きな一体部材とし、前面・屋根端部には曲線外周、折り線、局所部品を使っている。窓やライトは多角形セルを抜くのではなく、印刷された曲線輪郭として保持される。[JR西日本 ペーパークラフト](https://www.westjr.co.jp/fan/paper/), [273系やくも展開図](https://www.westjr.co.jp/fan/paper/assets/pdf/express/yakumo_free_01.pdf)
- 模型工房K-702の製作例と利用者提供写真では、前面を窓ごとの小片にせず、窓を含む広い部材、途中で止まるスリット、V字、細い接続部を使っている。[模型工房K-702 自作ペーパークラフト](https://ameblo.jp/kmr-express/theme-10109414569.html)
- Rhinoの公式説明では、紙を伸ばさず作れる面は一方向に直線の母線を持つ可展面であり、二方向曲面はそのまま正確には展開できない。`UnrollSrf` は可展面、`Squish` は伸縮を許す近似として明確に分かれている。[Rhino UnrollSrf](https://docs.mcneel.com/rhino/8/help/en-us/unfurl/unrollsrf.htm), [Rhino Squish](https://docs.mcneel.com/rhino/mac/help/en-us/commands/squish.htm)
- Dev2PQは主曲率・母線方向に沿う平面四角形帯へ可展面を再構成する。主曲げ方向を曲率から選ぶ根拠になる。[Dev2PQ](https://igl.ethz.ch/projects/dev2pq/)
- Shape Approximation by Developable Wrappingは、元形状を複数の可展パッチで包み、再現度とパッチ数を交換条件として扱う。[Developable Wrapping](https://igl.ethz.ch/projects/developable-wrapping/)
- Modeling Curved Folding with Freeform Deformationsは、曲線折りと可展面の滑らかな曲げを同時に扱う。曲線の切れ目や折り線を直線へ限定しない根拠になる。[Modeling Curved Folding](https://igl.ethz.ch/projects/curved-folds/)
- kirigamiの逆設計研究では、切断境界の曲率やスリット配置によって平面シートへガウス曲率を導入できることが示されている。[Boundary curvature guided shape-programming kirigami sheets](https://arxiv.org/abs/2103.11076), [Programming shape using kirigami tessellations](https://arxiv.org/abs/1812.08644)
- Pepakura Designerは面の結合・分離と組立アニメーションを持つが、基本単位は多角形面である。本方式はそれとは別に、CAD曲面と曲線開口を直接使う。[Pepakura Designer](https://pepakura.tamasoft.co.jp/pepakura_designer/overview-3d-data-to-paper-craft/)

参照した展開図や画像は設計原理の確認だけに用い、画像、意匠、車両グラフィックは本ソフトへ同梱しない。

## 決定

- `BentSheetPapercraft` を従来の `PlateFlatPattern`、多面体の `FacetedPapercraft` と別ファイル・別APIで実装する。
- UIには「曲げ紙ペーパークラフト（連続部材）」を第三方式として追加し、既存2方式を比較用に残す。
- 元板、元面、投影ワイヤーは変更しない。展開板、途中組立、完成形は派生オブジェクトとする。
- U/V方向の法線変化を積算し、変化が大きい方向を主曲げ方向として自動選択する。利用者はU/Vを明示指定できる。
- 主曲げ方向は断面弧長、弱方向は中央母線の弧長で平面座標化する。断面長の変化を外周曲線へ残し、単純な矩形へ潰さない。
- 外周と窓・ライト穴は元の投影曲線を高密度で写す。計算用三角形の境界を開口輪郭にしない。
- 自動生成は原則1枚とする。内部スリットは端と途中にブリッジを残し、紙を帯ごとに分断しない。
- V字を許可した場合は、両側から入るVとブリッジ付き一本線を交互に使う。左右のVは中央で接触させず、連続する紙幅を残す。
- 曲線Vは側辺を複数点曲線とし、曲線追従度で膨らみを調整する。Vを無効にすると一本線スリットだけを使う。
- 開口と交差するスリットは開口部分で分ける。窓やライトの中を横切る重複線を出力しない。
- 自動の一本線スリットは計算格子の辺として組み込み、切れ目の上下で頂点を分離する。先端と中央ブリッジは共有したままなので、一枚の紙を保ちながら二方向目の曲げを逃がせる。表示だけの線や点線状の穴にはしない。
- 組立スライダーは材料の三角辺長、V字の対応辺、元曲面への追従を同時に解く制約付き形状計算とする。完成時のV字対応点は同一の変数として扱い、左右を閉じた後の計算順で再び開かないようにする。これは折り順と切れ目の働きを確認する幾何計算であり、紙の剛性や曲げ戻りを解く物理シミュレーションではない。
- 0%から100%まで同じ材料座標とトポロジーを使う。切り出し材料面積は一定とし、単純な3D座標補間による拡大・縮小は行わない。
- 最大3D偏差、RMS 3D偏差、最大材料辺長誤差、V字継ぎ目位置ずれ、計算面の接続ずれ、総切断長を生成結果そのものから測る。再現度から係数で換算した推定値を形状誤差として表示しない。
- スライダー表示には短い反復回数の高速解、3Dモデル化・STL・STEP・誤差表示には収束回数を増やした保存用解を使う。
- 3D表示では局所計算用三角形の辺を隠し、一枚の滑らかな紙面として表示する。STL/STEP用の三角化は派生出力に限定する。
- のりしろは今回も生成しない。

## 結果

曲げ紙方式は「数学的に歪みゼロの多面体展開」ではない。鉄道模型工作で切り出せる一枚の曲線部材を先に作り、紙のロール曲げと局所切断で元面へ近づける方式である。残る形状差と局所寸法差は実際の再構築形状から測定して表示し、利用者は再現度や切れ目条件を変えるか、多面体方式と比較できる。
