# 投影したライトの押し出しと通常ワイヤー出力

状態: 実装済み（2026-10-14）。WP-08の投影UI・押し出し接続の補修。
全体ゲートの最終結果と配布先は `docs/development/projected-lights-verification.md` に記録する。

オーナー指示: ヘッドライトの投影後に押し出せること。投影ワイヤーの保存方法を、
既存の投影結果と、投影位置に残す編集可能な通常ワイヤーから選べること。

- 出力対象（ワイヤーのみ／面＋ワイヤー）とワイヤーの保存方法は別の設定にする。
- 既存のProjectWire + Derivedを既定として維持する。通常ワイヤーはCreateWire + Sourceで、
  入力への依存を持たず、確定済みの曲線座標と曲線種類をそのまま保存する。
- プレビュー折れ線へ変換したり、曲面上の輪郭を平面へ潰したり、不足辺を勝手に補わない。
- 曲面上の非平面輪郭の内側は、投影したネイティブ面を使って押し出す。
  ワイヤーの編集方針を変えただけで非平面輪郭が平面になるとは扱わない。
- 工程は投影→投影したライトの面を選ぶ→押し出し距離→プレビュー→Enter。
  出力や取消で元の形状・画像・表示状態を壊さず、1操作のUndo/Redoと保存再読込を維持する。

受入: 平面上の円、曲面上のライト、両方の保存方法、編集可能性、幾何不変、
閉輪郭、取消、Undo/Redo、保存再読込、添付115面のライト面の実押し出しを確認する。
試験計画では従来のライト閉輪郭検査だけで完了とせず、実際の立体と体積を検査する。
コア公開API・保存形式の新設は今回の範囲外。既存型と既存の面押し出しを使用する。

補修: 投影面を文書へ追加した後、トランザクション成功時だけ生成面の所有権を
表示・押し出し用の形状一覧へ渡す。プレビュー取消で確定済みの形状を解放しない。
面押し出しの確定でも、UI再入によるプレビュー置換から確定対象の形状を保護する。

添付115面の6円は面境界をまたぐ2円を含み、既存仕様どおり8個のネイティブ面パッチになる。
各パッチを欠けずに押し出し、閉鎖性・正体積・キャッシュ寿命・保存を検査する。
体積は元円から求めた値と測定値を報告し、指定投影許容から計算した体積差の受入目安と比較する。
この受入目安を投影全域の誤差証明とは扱わない。
