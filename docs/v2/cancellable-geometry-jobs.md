# 取消可能な厚み付け・結合計算（2026-10-11）

状態: 実装中。担当は実用検証タスク。109（7b83c3206）は別配布一式に保全済み。

UIXの長い評価の取消・進行表示と、architecture-and-data §9の不変入力を実装する。
今回の境界は厚み付けとブーリアンの未確定プレビュー。文書の書換えは従来どおりUIで確定時だけ行う。

OCCTの単純オフセットには全工程を確実に中断するAPIがない。共有キャッシュを操作中のスレッドは
強制終了しない。代わりに、本体と同じ実行ファイルの専用モードを子プロセスとして起動し、
入力形状のBRepコピーと数値設定だけを渡す。子は専用一時ディレクトリーだけに結果を出す。
文書、Undo履歴、ユーザーの保存先、本体の形状キャッシュを子と共有しない。

取消時はこの所有済み計算子だけを終了し、終了通知後に一時結果を破棄する。
他プロセスの列挙・終了、スレッド強制終了、メモリダンプは行わない。
異常終了・起動失敗・不完全な応答・取消を成功として採用しない。
進行表示は実際の処理段階と経過時間であり、根拠のない百分率を表示しない。

計算中はモーダルな取消可能表示で通常の変更操作を抑止する。イベントループは動作させる。
遅延した処理結果は文書revisionが一致するときだけプレビューへ採用する。
取消後は選択中の道具と入力を保ち、値の変更や選び直しによって再試行できる。
保存形式と幾何の精度条件は変えない。部分成功を文書へ残さない。

最初の適用範囲外: 他の面生成、履歴全体の再構築、展開、STL/STEP出力の全工程。
この範囲外まで取消可能になったとは報告しない。入力・結果BRepの転送処理時間も測定対象とする。

受入: GUIタイマー応答、計算中の取消、子終了確認、文書/キャッシュ不変、再試行と確定、
Undo/Redo、保存再読込、カーネル異常終了時の復旧、通常GUI全体・配布一式の回帰。

## 平面までの厚み付けの安全境界

従来は頂点だけで相手までの距離を測り、距離の2.5倍の法線オフセットを平面で切っていた。
傾きが大きい相手には届かない部分が残り、周期境界が途中で平面をまたぐことも見落とした。
また曲面の法線方向は場所で変わるため、一定オフセットは平面までの充填と同義ではない。

1枚の平面（平面と認定できるBスプライン面を含む）は、境界全域を相手平面座標で測り、
角度から全域に必要な押出距離を求めて切り取る。閉鎖性・体積・自己交差の検査を必須にする。
75度傾いた相手への楔の独立体積、反転した入力面、周期円境界の平面交差、STEP再読込を試験する。
曲面・折れ面の平面止めは従来の偽成功を廃止し、一定厚み指定を案内する。
一定厚みの曲面処理（円筒、回転曲線、平面で構成された折れ帯等）の対応は維持する。
歪んだ帯の一般オフセットを安全に成功させる新しい算法は今回実装しない。
