# 寸法ツールと測定の3D表示（2026-10-09）

担当範囲はWP-14の測定・注記UI。オーナー要求: Inventor相当の寸法ツール、測定結果を右ペインと3Dビューへ同時表示。

## 先行して確定する測定表示
- 測定ツールを選んでから対象を選ぶ。有効な事前選択も使える。
- 測定中の対象点・線と結果を3Dビューへ表示する。右ペインと同じ計算結果を使う。
- 2点距離、3点角度、線の長さ、半径・直径、要素間の距離・角度、面積を扱う。
- 文字はズームに依存しないサイズと背景を持ち、画面内へ収める。表示しきれない項目は右ペインへの案内を示す。
- 選択変更・測り直し・消去・文書切替で表示を更新する。ツールを離れたら一時表示を消す。文書へは自動保存しない。
- 曲線長・曲面など近似による値は既存計算の意味を変えない。

## 寸法ツールの確認事項
Inventorには形を変更する駆動寸法と参照寸法がある。現行製品契約は寸法拘束ソルバを後続候補としているため、どちらを必要とするかオーナーへ確認中。確認まで拘束方式は実装しない。
