# ADR 0003: ワイヤーは作業平面へ所有させない

## 状態

採用

## 決定

作業平面上で作図したワイヤーも、内部的には3Dワイヤーとして保存する。

作業平面との関係は「所属」ではなく、メタデータと拘束ポリシーとして扱う。

```text
Free3D
ReferenceOnly
LockedToPlane
```

## 理由

鉄道車両の前面やライト周辺では、最初は平面上で正確に描いたワイヤーを、あとから3D方向へ逃がしたり、曲面生成に使ったりする必要がある。

ワイヤーを作業平面の所有物にすると、自由な3Dワイヤーフレーム編集を妨げる。

## 実装方針

- 3D形状は常に `Wire` が持つ。
- 作成元平面は `sourcePlaneName` として記録する。
- 平面との関係は `WirePlanePolicy` で表す。
- `sketch_line` と `sketch_bezier` の既定は `ReferenceOnly` とする。

## 保留

曲面へ投影するライト穴ワイヤー、面上ワイヤー、交線から作る穴境界は、実装前にユーザーへ確認する。
