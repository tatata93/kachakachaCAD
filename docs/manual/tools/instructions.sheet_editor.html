用紙編集

具体例: A4用紙へ場面と文章を配置する

準備

画像エディターに場面を1つ作る

操作手順

  1. 用紙編集を選ぶ
  2. 用紙サイズをA4にする
  3. 場面を配置して文字を入れる

設定: 場面は3D情報を保持

結果を確認

用紙上で図と文字を編集できる。

取消・やり直し

ダイアログの取消、またはペインの取消を使います。即時操作には未確定段階がありません。 確定済みの文書変更はCtrl+Z、やり直しはCtrl+Yです。保存・書出し済みのファイルはUndoの対象ではありません。

進めない場合

文書がありません。

対象欄と3Dの強調を照合し、必要な線・面・部品を各役割へ指定します。処理中は計算表示を確認し、取消が可能な処理は取消を使います。

Windows版の操作画面

instructions.sheet_editor。図の設定と縮尺は例です。方式ごとの制限、プレビューと確定済み結果の区別を確認してください。
