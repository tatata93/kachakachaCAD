全機能マニュアル

何を作るか・どう操作するかから探す

初めて使う場合は最初の練習から始めます。各機能のページには必要な図形の準備、押す場所、設定表、確定の違い、失敗した時に戻る場所があります。

実画面で最初から完成まで

  • 正面と側面の2枚からパノラミック窓を投影
  • 投影したライトを中央面と同じ角度まで押し出す
  • 窓をくり抜いて境界ワイヤーを残す

準備用の図形から作る練習

  1. 線・面・部品を取り違えずに選ぶ
  2. 指定座標の直線・円・円弧を準備する
  3. 幅20・高さ10mmの閉じた矩形を作る
  4. 20×10×10mmの箱を作る
  5. 高さ違いの円2本から円筒状の面を作る
  6. 面から近似モデルを作り、原寸型紙へ進む
  7. 3D場面から画像入りの組立説明書を作る

部品と立体加工

  • 曲面押し出し — 1枚の円筒面上の輪郭を高さ2mm押し出す
  • 押し出し — ライトを中央面と同じ角度の端面まで伸ばす
  • 回転体(立体) — 内半径5・外半径7・高さ10mmの筒を作る
  • ロフト立体 — 大きさの違う2断面をつないだ立体を作る

  • フィレット(立体の辺) — 箱の上辺をR2で丸める
  • 面取り(立体の辺) — 箱の上辺をC1で落とす
  • 中空化（面を開けて厚みを残す） — 箱の上面を開けて肉厚1mmにする
  • 分割(立体を平面で2つに) — 箱を高さ5mmで2部品に分ける
  • 面に厚みを付ける — 半径5mmの面を外形として1mmの厚みを付ける
  • 治具を作る — 曲面に沿う当て板の治具を作る
  • 厚みの付け方 — 厚みの配置を中央へ切り替える
  • 面を平面まで立体に — 屋根面から水平な底面まで部材を作る
  • ワイヤー群から部品 — 閉じた立体ワイヤーから部品を作る
  • めり込み一覧 — 重なった2部品の干渉を調べる
  • 交わりにワイヤー — 交差する部品の境界線を残す
  • めり込みを削る — 窓の形で車体を削り境界ワイヤーを残す
  • 交わりで分割 — 交差した2部品を境界で分割する
  • 足す — 重なった2つの箱を一体化する
  • 引く — 車体を窓形の工具でくり抜く
  • 交差 — 2部品の重なる部分だけ残す
  • 部品の移動 — 部品をX方向へ10mm移動する
  • 部品のコピー — 部品をX方向へ10mm複製する
  • 部品のミラー — 部品をYZ面に対称な位置へ写す
  • 部品の回転 — 部品を原点周りに90度回す
  • 部品を直線に並べる — 同じ部品を10mm間隔に4個配置する
  • 部品を円に並べる — 部品を円周上に4個並べる
