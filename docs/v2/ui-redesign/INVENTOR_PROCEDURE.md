# INVENTOR_PROCEDURE — 作図の道具を Inventor のスケッチの手順と突き合わせる

オーナー指示(2026-09-23): 「作画に用いる機能はすべて Inventor と同じことが同じ手順でできるようにしろ」。
この表は、作図モードの道具 1 つずつについて **Inventor のスケッチでの手順** と **この CAD の手順** を並べ、
違いを直した順に記録する。STATUS: SAME(同じ手順)/ FIXED(この指示で直した。commit)/ DIFF(まだ違う。どこが)/
NONE(Inventor に無い道具。そのまま)/ BLOCKED(作れない。理由)。

Inventor の手順は「道具を押す → 線の上にポインタを置くと結果が先に見える → 押すと作られる → 道具は構えたまま
(Esc / 右クリックの完了 で終わる)」が骨格。この CAD もこの骨格にそろえる。

## 編集(Modify)

| 道具 | Inventor の手順 | この CAD(直す前) | STATUS |
|---|---|---|---|
| トリム | 道具 → 線に置くと **消える区間**(いちばん近い交点の間)が破線で見える → 押すと消える。境目は画面の全部の線。円は交点の間を消して円弧に。交点が無ければ線ごと消える。続けて押せる | 先に線を 2 本選んでから押す(1 本目が直す線、2 本目だけが境目)→ 捨てる側を 1 回押す。円は壊れる、真ん中は断る、押しても「点を置く道具ではありません」 | FIXED(4ae6ef4) |
| 延長 | 道具 → 線の端の近くに置くと **伸びる先まで**が見える → 押すと伸びる。相手は画面の全部の線 | 先に 2 本選ぶ(2 本目が相手)→ 端を押す | FIXED(4ae6ef4。選んでから押す昔の道も残す) |
| 分割 | 道具 → 線に置くと **分かれる点**(いちばん近い交点)が見える → 押すとそこで 2 本に | 先に選ぶ(1 本目を 2 本目以降で切る)→ 押すと交点全部で切れる(1 本のまま) | FIXED(4ae6ef4。選んでから押す昔の道も残す) |
| 面取り(2D) | 量を決める → 線を 2 本押す(2 本目に置いた時点で結果が見え、押すと作られる)。直線どうし・直線×曲線・曲線どうし。押した位置で角と残す側が決まる。続けて次の角 | 道具 → 2 本押す → 下見 → Enter。直線・円弧・円・ベジェの組(直線どうしは解析、曲線が混ざれば数値で接点を探す)。押した位置で角と残す側が決まる | FIXED(曲線対応・押した位置)。確定が Enter なのは残る差 |
| 丸め(2D フィレット) | 面取りと同じ(半径) | 同上(半径。接する条件は作ったあと測る) | FIXED(曲線対応・押した位置)。確定が Enter なのは残る差 |
| オフセット | 道具 → 線を押す(つながった線をまとめて)→ ポインタを動かすと側と距離が見える → 押して決める(距離は打てる) | 先に選ぶ → 数の棚に距離 → 押すと作られる(側は距離の符号) | DIFF: 押してから線を押す形にする(次の段) |
| 移動 | 選ぶ(道具の後でも先でも)→ 基点 → 行き先(打てる)。コピーの印 | 道具 → 動かすものを押す → 基点 → 行き先 | SAME |
| コピー | 同上 | 同上 | SAME |
| 回転 | 選ぶ → 中心 → 角度(ポインタで回す / 打つ) | 選ぶ → 中心 → 回す前の向き → 後の向き(角度は欄にも打てる) | SAME(点が 1 つ多いが、打つ道は同じ) |
| スケール | 選ぶ → 基点 → 倍率(打つ / ポインタ) | 選ぶ → 中心 → 倍率(欄)/ 基準の 2 点 | SAME |
| ミラー | 選ぶ → **既存の線** を鏡に選ぶ → 適用 | 選ぶ → 鏡の線を **2 点で** 引く(既存の線の端点に吸着はできる) | DIFF: 既存の線を 1 回押して鏡にできるようにする(次の段) |
| 直線パターン | 選ぶ → 方向 1(線を押す)・数・間隔(→ 方向 2) | 選ぶ → 棚で向き(2 点)・数・間隔 | DIFF: 方向を既存の線で示せるようにする(次の段) |
| 円形パターン | 選ぶ → 軸(点)・数・角度 | 選ぶ → 棚で中心・数・角度 | SAME |
| 結合 / 端点一致 / 接線でつなぐ / 曲率でつなぐ / 2 本を交点まで | Inventor では拘束(一致・接線・スムーズ)で行う。道具としては無い | 道具 | NONE |
| 角を落とす / 角を丸める(折れ線の全部の角) | 無い(角ごとに面取り/丸め) | 折れ線の全部の角を一度に | NONE |

## 作成(Create)

| 道具 | Inventor の手順 | この CAD | STATUS |
|---|---|---|---|
| 線 | 押す・押す…で **続けて** 引ける(前の終点から次が始まる)。端点から引きずると円弧 | 「直線」は 2 点で 1 本、「ポリライン」が続けて引く | DIFF: 直線でも続けて引けるようにする(次の段) |
| 円(中心) | 中心 → 半径(押す / 打つ) | 同じ(中心＋半径 / 直径 / 3 点) | SAME |
| 円(3 本の線に接する) | 線を 3 本押す | 無い | DIFF |
| 円弧(3 点) | 始点 → 終点 → 通る点 | 始点 → 通過点 → 終点(順が違う) | DIFF: 順は Inventor に合わせる(次の段) |
| 円弧(中心) | 中心 → 始点 → 終点 | 同じ | SAME |
| 円弧(接線) | 線の端点から接線で | 「始点接線・半径・中心角」 | DIFF(近い) |
| 矩形 | 2 点 / 3 点 / 中心 2 点 / 中心 3 点 | 2 角 | DIFF: 3 点と中心の作り方(次の段) |
| 多角形 | 中心 → 辺の数 → 頂点(内接 / 外接)の **正多角形** | 「多角形」= 頂点を順に押す折れ線 | DIFF: 正多角形を足す(次の段) |
| スロット | 中心 2 点 + 幅 など | 無い | DIFF |
| スプライン | 通る点(補間)/ 制御点 | 同じ(通過点 / 制御点)+ ベジェ | SAME |
| 楕円 | 中心・長軸・短軸 | 無い(文書に種類が無い) | BLOCKED |
| 点 | 押す | 同じ | SAME |
| テキスト | 文字を置く | 無い(文書に種類が無い) | BLOCKED |
| 投影 | 縁・面を押すとスケッチへ写る | 平面へ投影 / 面へ投影 / 巻き付け投影(選んで押す) | SAME(近い) |
| 面取り / 丸め(作成側) | 編集の表と同じ | 同上 | FIXED |
