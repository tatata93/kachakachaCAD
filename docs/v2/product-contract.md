# Wire-first V2 製品契約

## 1. 製品の一文定義

kachakachaCAD V2は、**3D空間または任意の作業平面へ正確なワイヤーを描き、そのワイヤーから完成品の
部品を作り、曲面部だけを工作可能な部材へ近似し、型紙・治具・任意曲げ状態の3Dデータまで出す模型製作CAD**である。

## 2. 完成時の利用者像

初心者は次の順序だけを理解すれば使えることを必須とする。

1. 作図点と作業平面を置く。
2. 直線、円、円弧、曲線で輪郭または立体の骨組みを描く。
3. 押し出し、輪郭から作成、断面から作成のいずれかで部品を作る。
4. 曲面を紙やプラ板で作る場合だけ、製作近似を作る。
5. 組立スライダーで確認し、型紙、STL、STEP、SVG、DXF、PDFを出す。

`面を板材化する`、`SurfaceをPlateへ変換する`、`Bodyだけ別出力する` という手順は存在してはならない。

## 3. 利用者向け用語

| 用語 | 意味 | 編集可否 |
| --- | --- | --- |
| 作図点 | 位置、交点、中心、制御点などを記録する点 | 可 |
| 作業平面 | 正確な2D作図を行う3D空間上の基準 | 可 |
| ワイヤー | 直線、円、円弧、曲線、複数線分の連続鎖 | 可 |
| 形状ガイド | 複数ワイヤーから作る厚みのない参照曲面 | 元入力と設定を編集 |
| 部品 | 1つの連結した閉ソリッド | 作成Featureを編集 |
| 製作モデル | 完成品を工作可能な大きな部材へ近似した別オブジェクト | 設定と手動境界を編集 |
| 型紙 | 製作部材の実長を保った2D展開結果 | 配置と注記を編集 |
| グループ | 作業対象を整理し、新規作成先を決める入れ物 | 可 |
| Feature | 部品や派生ワイヤーを作る履歴上の操作 | パラメータを編集 |

以下の語は内部実装または診断表示に限り、通常UIのオブジェクト種類として表示してはならない。

- Surface
- Plate
- Body
- Face
- Mesh
- B-Rep

## 4. 正本と派生物

- `PRD-001`: 利用者が描いた点、平面、ワイヤーとFeature設定を正本とする。
- `PRD-002`: 部品、形状ガイド、近似ワイヤー、型紙はFeatureから再生成できる派生物とする。
- `PRD-003`: 派生物を直接変形してはならない。直接編集を選んだときは `現在状態を固定` で新しい正本へ複製する。
- `PRD-004`: 元Featureの再計算に失敗した場合、直前の有効な表示を残して `古い結果` と表示する。
- `PRD-005`: 失敗時に正本を部分更新してはならない。1操作は全部成功または全部取消のどちらかである。

## 5. 部品の契約

- `PRD-010`: 1部品は1つの連結した閉ソリッドである。
- `PRD-011`: 空洞、貫通穴、止まり穴は同じ部品の内部形状として許可する。
- `PRD-012`: 演算結果が複数の非連結ソリッドになった場合、自動的に複数部品を作り、実行前プレビューで個数を示す。
- `PRD-013`: 体積が0、閉じていない、自己交差、非多様体の結果は部品として登録しない。
- `PRD-014`: 治具は `用途=治具`、完成品は `用途=完成品`、製作近似の実体は `用途=製作部材` を持つ同じ部品型である。
- `PRD-015`: 材料、色、板厚、製法、縮尺は部品または製作モデルの属性であり、幾何種類を増やさない。

## 6. ワイヤー中心のモデリング

- `PRD-020`: すべての部品作成コマンドは、入力に使うワイヤーを3Dビューとモデル一覧の両方から指定できる。
- `PRD-021`: 1つの論理輪郭、断面、ガイドは複数の直線、円弧、Bezier、B-splineの組合せでよい。
- `PRD-022`: 接続順と向きは自動判定し、プレビューで矢印表示する。曖昧な分岐だけ利用者に選ばせる。
- `PRD-023`: 閉じた輪郭、2断面、3断面以上、外形ガイド付き、断面とガイドの網の全方式で複数線分を扱う。
- `PRD-024`: 外形ガイド同士が両端で接続する場合、および各断面端がガイドへ接する場合を扱う。
- `PRD-025`: 非平面輪郭から作る曲面は一意でないため、勝手な面を作らない。選択可能な作り方を提示する。

## 7. 押し出し

- `PRD-030`: 入力は閉じた輪郭、開いた連続線、形状ガイド、またはそれらの複数選択とする。
- `PRD-031`: 出力は `輪郭ワイヤー` と `部品` のチェックボックスで指定し、両方を同時に作れる。
- `PRD-032`: 閉じた輪郭から部品を作る。開いた線だけでは部品を作らず、輪郭ワイヤーだけを作れる。
- `PRD-033`: 距離指定、対称距離、両側別距離、選択対象まで、貫通を扱う。
- `PRD-034`: 部品演算は `新規`、`足す`、`引く` を扱う。
- `PRD-035`: 入力ワイヤーを削除しない。出力は入力へ追従する。
- `PRD-036`: 数値欄は `(180/2)*3` のような四則演算と括弧を受け付ける。

## 8. 製作近似

- `PRD-040`: 完成品と製作モデルは別オブジェクトであり、重ね表示できる。
- `PRD-041`: 1部材は平面または基本1軸曲げで作れる大きな連続パネルを優先する。
- `PRD-042`: 二重曲率は、局所切れ目、V字または曲線側辺の切れ込み、追加分割を必要な場所だけに使う。
- `PRD-043`: 再現度、最大部材数、最小部材幅、切れ目の向き、切れ目可否を利用者が調整できる。
- `PRD-044`: 窓、ライト、扉などの開口を、部材境界をまたぐ場合も失わない。
- `PRD-045`: 型紙から完成状態までの組立を0から100%で確認し、全状態で実長を維持する。
- `PRD-046`: 任意の組立率と個別折り角度の状態を、部品、STL、STEPとして保存できる。
- `PRD-047`: 全部品または選択した部品だけを出力できる。
- `PRD-048`: 最大偏差とRMS偏差をmmで表示し、再現度を見た目だけで評価しない。
- `PRD-049`: 任意の組立状態から境界・折り・切れ目・開口を3Dワイヤーとして取り出し、`ワイヤーのみ`、
  `部品のみ`、`両方` を選んで固定できる。部品は別計算した近似輪郭ではなく、同時に得た境界ワイヤーと一致する。

## 9. 作図と編集

- `PRD-050`: 直線、ポリライン、円、円弧、Bezier、通過点B-spline、作図点を扱う。
- `PRD-051`: 直線と曲線のトリム、延長、分割、結合、端点一致、接線接続、曲率接続を扱う。
- `PRD-052`: 円弧は3点、両端+半径、始点+接線/法線方向+半径/角度+中心角/円弧長で作れる。
- `PRD-053`: 作図開始後は寸法欄へ自動フォーカスし、マウス位置近くでも入力値を確認できる。
- `PRD-054`: 2D作業平面作図と3D直接作図は同じワイヤーを生成し、別データ型にしない。
- `PRD-055`: 作図平面は標準面、オフセット、3点、中間、角度、接線、法線などから作れる。

## 10. スナップとグリッド

- `PRD-060`: 端点と作図点、幾何交点、曲線上の候補、グリッドの順に優先し、現在のツールが要求する型を最優先する。
- `PRD-061`: スナップ候補はホバーリングと説明ラベルで見せ、クリック時に確定する。
- `PRD-062`: Shiftは作図方向の一時拘束、Ctrlは選択集合、Sは押している間のスナップ解除に使う。
- `PRD-063`: TabまたはAltで同位置の候補を選び直せる。右クリックはコンテキストメニューと近傍候補一覧を開く。
- `PRD-064`: 主点と、1/2、1/3、1/4の副点グリッドを扱い、主点を大きく表示する。
- `PRD-065`: グリッド原点はXYZ数値入力とドラッグの両方で、任意の作図点または幾何点へ合わせられる。

## 11. 測定と視点

- `PRD-070`: 2点距離は全長、dX、dY、dZ、各座標面への投影距離、各軸との角度を同時表示する。
- `PRD-071`: 3点角度、線同士、線と曲線、曲線同士の接線角度と法線角度を測れる。
- `PRD-072`: 測定結果は作図点、中心点、制御点を作る入口を持つ。
- `PRD-073`: ビューキューブをドラッグすると視点とキューブが同じ量だけ連続回転し、離した瞬間に止まる。
- `PRD-074`: 視点を自動で勝手に回転させない。慣性回転、地平線自動補正、90度への自動吸着は既定で無効とする。
- `PRD-075`: 世界XYZと選択部品の相対XYZを切り替え、各軸の回転矢印を細かい連続角度でドラッグできる。

## 12. 出力

- `PRD-080`: 部品はSTLとSTEP、ワイヤーと型紙はSVG、DXF、1:1 PDFへ出力できる。
- `PRD-081`: STLとSTEPは同じ検査済みB-Repから作る。
- `PRD-082`: 出力前に閉鎖性、自己交差、体積、最小肉厚、選択部品数を検査し、問題を日本語で表示する。
- `PRD-083`: 1:1 PDFは用紙分割、重なり、基準寸法、ページ番号を含む。
- `PRD-084`: 保存と出力は一時ファイルへ完全に書いて検査後に置換し、失敗時に既存ファイルを壊さない。

## 13. UIの完成条件

- `PRD-090`: 固定上位モードやリボンを必須にせず、メニュー、1段の道具バー、モデルツリー、ビューポート、
  コンテキストプロパティへ統合する。未実装機能の空ボタンを置かない。
- `PRD-091`: 常設領域はモデルツリー、ビューポート、右コンテキストプロパティ、短いステータスバーを基本とする。
  ツール中の手順はビューポート左上へ2行以内で表示する。
- `PRD-092`: `ツール -> 対象 -> 値 -> 確定` を標準とし、有効な事前選択からも同じCommandを開始できる。
  不足入力だけを理由に対象選択型ツールを一律無効にしない。
- `PRD-093`: エラーは理由番号、問題箇所、直し方を表示し、ソフトを終了させず入力を修正できる状態を保つ。
- `PRD-094`: Windows 95テーマは外観スキンとして維持し、標準テーマと機能・配置・論理サイズを共通にする。
- `PRD-095`: 画面上の機能説明文を常設しない。ツール手順、ツールチップ、エラー、F1の詳細ヘルプへ分ける。
- `PRD-096`: 全対話ツールは共通ToolSessionを使い、Esc、Enter、Backspace、Ctrl+Zとプレビュー確定を統一する。
- `PRD-097`: 選択はオブジェクトだけでなく端点、線分、面、制御点、作業平面を安定ID付きで複数保持できる。
- `PRD-098`: Hover、Selected、Input、Preview、Warning、Errorを区別し、カーソルとマウス操作を
  `ui-ux-integrated-spec.md` の意味契約へ一致させる。
- `PRD-099`: 右プロパティは通常時の選択属性とツール中の入力を切り替え、カーソル近傍入力と双方向同期する。
- `PRD-100`: 100%、125%、150%、200% DPI、狭い画面、モニター構成変更で操作不能な領域を作らず、
  画面配置を復元または初期化できる。
- `PRD-101`: 利用者向け `板材` 種別、板材モード、板材化コマンドを設けない。厚さと材料は部品または製作モデルの属性とする。
- `PRD-102`: ワイヤーは作業平面またはSketchに所有されず、作業平面の切替や削除でUUIDと3D座標を変更しない。
- `PRD-103`: 内部enum、Subshape、Face、Surface、Bodyなどの実装用語を通常UIで選ばせず、利用者の作業語へ翻訳する。

## 14. 非目標

V2切替条件には次を含めない。

- 本格的なアセンブリ拘束と干渉解析
- FEA、CAM、板金のK-factor自動計算
- 自動ネスティング
- 図面枠、部品表、公差記号を含む本格製図
- サブディビジョンサーフェスを主要編集形式にすること
- 三角形メッシュを直接編集すること
- 旧 `.kcd` の読込
- のりしろの自動生成

## 15. 初回切替後の追加候補

- Booleanの共通部分だけを残す演算
- 可変断面スイープ、回転体、ロフトソリッドの高度設定
- 寸法拘束ソルバ
- 自動ネスティングとのりしろ
- 外部プラグインAPI

これらを先回りしてV2の初回実装へ混ぜてはならない。
