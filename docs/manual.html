1. 最初に知ること

初心者向けの進み方

  1. 右上「1 平面」で、作図したい位置と向きを確認します。
  2. 「2 作図」で線・円・断面を描きます。左下の水色欄だけを見れば、次に置く点が分かります。

  4. 板材または治具を選び「4 出力」で1:1図面、STL、STEPを保存します。

3D上の辺を回転軸にする

  1. 「選択」で直線ワイヤーを1本選びます。
  2. 「基準線に設定」を押します。作業平面タブの基準線名が変わります。
  3. 作り方を「軸まわりに回転」にし、「回転軸に使用」を押します。
  4. 基準平面と角度を入力し、「この向きで見る」で確認後、「平面を作成」を押します。

3点は一直線上に置けません。法線ベクトルや軸方向も長さ0にはできません。エラー時は3点または方向値を見直してください。

5. 点グリッド

補助線を大量に描かず、JWCADのような一定間隔の点を目安に作図します。大きい点が主点、小さい点が副点です。主点は狙いやすく、副点は点間隔に応じて弱く吸着します。点へ常時強制的に丸めることはありません。

作図面
「作図」タブ最上部で平面を選び、「正対」。
表示
「点グリッド」の「表示」をオン。
主点間隔
「スナップ」行へ大きい点の間隔。例は 1.00 mm。
副点
主点のみ、1/2、1/3、1/4から選択。1/4なら候補間隔は主点間隔の4分の1です。
数値基準
基準X/Yへ点列の開始座標。中心を半ピッチずらすなら両方 0.5 mm。
吸着
「スナップ」をオン。カーソルに最も近い格子点へ常に吸着し、薄い丸が出ます。交点・端点などの構造点が近くにあればそちらを優先します。自由位置に置きたいときは Ctrl を押しながらクリック。

図形上の点へグリッドをドラッグして合わせる

  1. 「画面で基準を合わせる」を押します。
  2. 中央画面で、動かしたい大きい主点または小さい副点を左ボタンで掴みます。
  3. ボタンを押したまま、基準にしたいワイヤーの端点または制御点へ移動します。近づくとその点へ正確に吸着します。図形点がない場所へ自由に置くこともできます。
  4. 左ボタンを離します。点列全体が移動し、新しい値が基準X/Y欄へ入ります。
  5. やり直す場合はもう一度実行。途中で止める場合は Esc。原点へ戻す場合は「基準を 0, 0 に戻す」です。

基準値は作図面内のX/Yで、世界座標のXYZではありません。副点が画面上で密集しすぎる倍率では小点だけを一時的に省略します。主点は約4px以内、副点は画面上の点間隔に合わせた約0.75～2.25px以内だけ吸着するため、主点・副点の間にも自由に線を引けます。

交点・端点・作図点へ正確に合わせる

  1. 「スナップ」をオンにします。
  2. 交差する2本の線、既存端点、作図点、線の中点、円・円弧の中心の近くへカーソルを移します。通常は交点が約18px、作図点・端点が約16px、中点・中心が約14px以内で候補になります。
  3. 吸着すると候補を囲む大きな丸が表示され、その内側に種別の記号(交点=×、作図点=丸、端点=四角、中点=三角、中心=丸+中心点)が出ます。格子点は薄い小丸です。構造上の点と格子が同時に候補になる場合は、交点・作図点・端点 > 中点・中心 > 格子の順で優先します。
  4. 大きな丸が出ている間に左クリックすると、その候補の正確な座標を使います。構造点が近くにないときは最寄りの格子点へ常に吸着します(任意位置はCtrl)。
  5. 始点を置く前に右クリックすると、約20〜21px以内の交点・作図点・端点だけを広めに探して始点にします。格子点はこの右クリック探索へ含めません。
  6. 候補が近すぎて任意位置を選べない時は、Ctrlを押しながらクリックします。押している間だけ候補表示と吸着を完全に止めます。

右クリックは入力前なら近傍点から開始、入力後なら従来どおりポリライン・スプラインの完了または途中操作の取消です。「作図点」はワイヤーや面にはならない位置基準で、左の一覧から選択・非表示・削除でき、保存して開き直した後もスナップに使えます。

正確な長さ・角度で直線を引く

  1. 「直線」を選び、中央画面で始点だけをクリックします。マウスを動かすと、長さ・角度欄がカーソルのそばへ追従します。
  2. クリックせず、そのまま数字または ( を打ち始めます。入力は自動で長さ欄へ入り、例えば (180/2)*3 は270 mmになります。
  3. Tabで角度欄へ移り、作図面の横を0°、縦を90°として角度を入力します。
  4. Enter。式を計算した実寸の終点で直線が完成します。

使用できる式は + - * / ( )、小数、指数表記、円周率 pi です。入力欄内でも Esc は1回で数値編集ごと作図全体を取り消し、選択解除まで戻ります。右パネルの実寸欄も同じ式に対応します。

円弧を両端と半径で決める

  1. 「円弧」を選び、方式を「両端＋半径」にします。
  2. 始点、終点の順に中央画面でクリックします。
  3. カーソルを動かすと半径と膨らむ側がライブで追従します(右パネルの半径欄にも反映)。ちょうど良い膨らみで3回目のクリックをすると確定します。
  4. 数値で決めたい場合は、半径欄へ数値または計算式(半径は両端距離の半分以上)を入力し、「左へ膨らむ / 右へ膨らむ」を選んで「この円弧を作成」。半径欄へ入力を始めるとドラッグより数値を優先します。

始点から方向を決めて円弧を生やす

  1. 方式を「始点＋接線/法線方向」にし、円弧を生やす始点をクリックします。既存線上ならスナップ記号を確認して置きます。
  2. 角度基準を「接線角」または「法線角」にします。角度は作図面の横方向が0°、縦方向が90°です。
  3. 方向角と半径を入力し、円弧量を「中心角」または「円弧長」から選びます。
  4. 「左へ曲がる / 右へ曲がる」を選びます。法線角は選んだ曲がる側の円弧中心を向く方向です。
  5. 青い予告と始点の接線ガイドを確認して「この円弧を作成」。

中心角と円弧長を切り替えると、現在の半径を使って値を相互変換します。入力済みの値は 円弧長 = 半径 × 中心角(rad) の関係を保ちます。既存曲線へ滑らかに追従させ続けたい場合は、作成後に「接線接続」または「曲率接続」も設定します。

作図中の補助操作

  • Shiftを押しながら直線・ポリライン: 水平または垂直へ固定。
  • Shiftを押しながら矩形: 正方形へ固定。
  • Ctrlを押しながらクリック: その点だけ完全にスナップを解除。Ctrl+Shiftなら吸着なしと水平・垂直/正方形拘束を併用。
  • 入力前に右クリック: 近くの交点・作図点・端点を始点にする。
  • 「補助線として作図」: スナップ・寸法基準には使うが、面や切断図へ入れない。
  • 「指定した点を作図点として残す」: ベジェ・スプラインの確定時に、クリックした通過点・制御点を作図点(線名_点N)としても作ります。
  • Esc: どこにフォーカスがあっても1回で「入力破棄 → 選択道具 → 選択解除」まで戻ります。「取消」ボタンは入力中の点だけを破棄します。
  • 作図道具の使用中は、作図面上にない線・点が自動で薄く表示されます(常時薄くしたい場合は表示タブの「作図面以外の線を常に薄く表示」)。
  • ホイール・中ドラッグ・右ドラッグ: 作図中も拡大縮小・平行移動できます。

作図は作図面に正対していなくても行えます。斜めから見た3Dビューでも、クリックは「カーソルの視線と作図面の交点」に置かれ、スナップ・予告表示も同じ位置で働きます。正対して作図した場合と結果は同じです。

「作図」タブ内で「選択」に戻さず左クリックすると、現在の作図道具の点が追加されます。選びたいときは V を押してください。「面」「出力」など担当外のタブへ移ると、安全のため自動で選択モードへ戻ります。

11. ワイヤーから面を作る

面は厚みを持たない設計面です。断面を並べて立体の外形を作り、後から板厚や治具へ展開します。

作り方は通常「自動（選択から判定・推奨）」のままで構いません。選択内容から、閉じる輪郭→平面、断面2→曲面、断面3以上→ロフト、他の線の端点が2本以上載る線が2本あればそれを外形ガイドにしたガイド付き面、と判定します。判定結果は選択のたびに面・板材タブのラベルへ表示され、作られる面が半透明のプレビューで中央画面に出ます。プレビューが出ない選択は、その理由もラベルに表示されます。判定を上書きしたいときだけ作り方を手動で選んでください。

ガイド付きでは各断面の両端を外形ガイドへ合わせます。断面はガイドの端だけでなく途中へ接続できます。また、2本の外形ガイド同士が前後両端でつながり、全体として閉じた外周になる構成も使用できます。ただし表では2本の外形を別々の行へ登録してください。「接続区間を一括選択」は外形同士と断面が集まる分岐点で止まるため、片側の外形だけを登録できます。大きなスナップ丸が出ている位置で端点を置くと確実です。作図時の微小な端点差は0.02 mmまで面生成時に接続として扱いますが、元線の座標は変更しません。断面の向きと並び、2本目ガイドの向きは自動でそろいます。ガイドから0.05 mm以上離れた断面は、誤った面を作らず接続不足として拒否します。

別々に描いた線・曲線から自由形状の平面を作る

  1. 直線、円弧、ベジェ、スプラインを組み合わせ、各端点が一周して元へ戻る輪郭を描きます。

面ができない場合は表の赤い「接続エラー」の行を選びます。端点間の隙間が0.02 mmを超えていないか、離れた線が同じ行にないか、同じ線を重ねていないか、全線が同じ作図面上にあるかを確認します。曲線は面生成時だけ0.01 mm以下の輪郭誤差で内部変換され、元の曲線は失われません。

面がねじれる場合は表の上下矢印で断面順を直してください。行内の線は端点で一続きになる必要があります。枝分かれ、同じ線の重複、自己交差した閉輪郭は誤った面を作らず、理由を表示して拒否します。補助線は面の断面に使われません。

13. 平面図を曲面へ投影し、窓・ライト穴を開ける

  1. 窓・ライトを見たい向きの作業平面を作るか選びます。
  2. 「作図」タブでその平面へ正対します。

16-2. 部材近似モデル（近似モデルモード）

完成品の面・板材を「1部材=基本1軸曲げ」の帯へ近似し直し、部材ごとの型紙・曲げ確認・板材化を行います。プラ板や紙で作れる形に落とすための中間モデルです。

作成

近似元
板材または面を選べます。面は厚み未定のまま近似し、板材化の時点で「面入力の板厚」を指定します。
分割
許容偏差から自動、または手動境界（0～1）。3D画面でワイヤーを選んで「選択ワイヤーを境界に使う」を押すと、任意の線の位置を境界＝折り線にできます。
実行
「部材近似モデルを作成」。境界レール・部材面が「近似:名前」グループに作られます。

曲げ確認（常に正しい形状）

  1. 「曲げ確認と出力」の「3Dビューで曲げ状態を表示」をオンにします。
  2. スライダーは組立アニメーションです。0%=各部材の展開形（型紙と同じ）が少し離れた位置に並び、100%で折り線ごとの角度どおりに折った状態（近似モデルの位置）へ収束します。
  3. 折り角そのものは折り線ごとの行で角度（°）⇄進行度（%）を相互に編集して指定します。折り状態は保存され、開き直しても続きから曲げられます。
  4. 一覧で部材を選ぶとその部材だけ表示されます（複数選択なら複数、未選択なら全部）。各部材の形と辺の間隔は常に正確です。

開口・出力

  1. 元の板材・面に登録した開口（窓・ライト）は、部材内に収まるものが実際の穴として近似・型紙・実体化へ写ります。
  2. 「この曲げ状態を板材化」は同じファイル内の「近似:名前」配下へ、「別の.kcdへ保存」「STL/STEP保存」は外部へ出力します。0%は型紙の平面配置（開口も実穴）です。

17. 1:1図面・展開図・3Dモデルを出力する

作業平面の1:1 SVG / DXF

設定
「出力」タブで出力面を選び、「出力面上の全ワイヤー」または「選択したワイヤーのみ」。
実行
「SVGを保存」または「DXFを保存」。
用途
平らなプラ板・紙への印刷、レーザー加工、他2D CADへの受け渡し。単位mm、1:1です。

ペーパークラフト展開（1:1）

生成方式を最初に選びます。「製作用大部材」は元形状へ少数の長い曲げ板を先に当て、各部材を一枚ずつ展開します。「曲げ紙ペーパークラフト（連続部材）」は、窓とライトを含む一枚の紙を主方向へ滑らかに丸めます。「多面体ペーパークラフト（比較用）」は角面を歪めず展開します。「曲げ帯ペーパークラフト（従来方式）」は従来のプラ板向け結果です。4方式は互いに上書きせず比較できます。ライト穴と窓は開口、短い歪み逃がしはRELIEF_CUT、部材を分ける線はSEPARATING_SEAMとして別に扱います。

製作用大部材: 近似モデルを先に作ってから展開

  1. 板材を1枚選び、「生成方式」で「製作用大部材（近似モデル→各部材を展開）」を選びます。
  2. 「最大許容3D偏差」「最小部材幅」「最大部材数」を指定します。最初は板全体を一部材として試し、実測偏差が目標を超えた部材だけ二分します。
  3. 「大部材の向き」は通常「曲率から自動」。曲面を横長の帯で構成したい場合は、プレビューを見ながらUまたはV方向へ長い部材を固定します。
  4. 自動境界は窓・ライト穴の途中を横切りません。特定位置で必ず部材を分ける場合は、面タブの「展開片の分割線」で投影ワイヤーを分割線にしてから再生成します。穴を横切る分割線や最小幅未満の部材は理由付きで拒否されます。
  5. 結果欄で部材数、完全分割線数、開口数、最大3D偏差とRMS偏差を確認します。最大偏差が目標を超えた結果は赤表示で、成功扱いにはなりません。最小幅を下げる、最大部材数を増やす、または手動境界を追加して再計算します。
  6. 「展開から組立まで3D表示」と組立スライダーで各大部材の曲げを確認します。「この曲げ状態を3Dモデル化」は、選択した部材を三角板の集合ではなく一枚の連続ロフト板として追加します。
  7. 「製作用近似モデルを別オブジェクトで作成」で100%状態を元板とは別に残します。「ペーパークラフト部品を作成」またはSVG/DXF/PDF保存では、各大部材が一つの閉じた型紙になり、窓とライトは抜き穴として残ります。

曲げ紙・連続部材の手順

  1. 板材を1枚選び、「生成方式」で「曲げ紙ペーパークラフト（連続部材）」を選びます。
  2. 「展開方針」は通常「部材優先」を選びます。これは少数の長い部材を保ち、完全分割より短い歪み逃がしを先に使います。「バランス」「精度優先」の順に切れ目候補を増やします。
  3. 「最大許容3D偏差」に工作上許せる目標値、「最小部材幅」に切れ目の間や橋として残したい幅をmmで入れます。結果欄の最大3D偏差は実際に組み直した形との比較値で、目標を超えると赤表示になります。
  4. 通常は「曲率から主曲げ方向を自動選択」を使います。断面の向きを意図的に固定するときは「U方向へ滑らかに丸める」または「V方向へ滑らかに丸める」を選びます。
  5. 「立体再現度」を上げると、滑らかな3D確認面と切れ目候補が細かくなります。展開部品を三角形へ分離する値ではありません。
  6. 「曲線Vを併用」をオフにすると、途中に紙のブリッジを残した一本線スリットだけを作ります。オンにすると、最初の強い二方向曲げ箇所へ曲線Vを使い、残りをブリッジ付きスリットにします。左右のVは中央で接触せず、紙のつながりが残ります。
  7. 「切れ込み深さ」は外周から中央ブリッジへ近づく量です。「V字の開き角」で絞り量、「切れ込み曲線追従」でV側辺の曲がりを調整します。窓やライトと交差する線は穴の部分で自動的に分かれます。
  8. 「展開から組立まで3D表示」をオンにし、「組立過程」を0%から100%へ動かします。途中状態は滑らかな局所回転場で計算するため、再現度10でも計算三角形ごとのしわにはなりません。赤線でスリットとVを確認します。
  9. 途中状態を残す場合は、30%などで止めて「この曲げ状態を3Dモデル化」を押します。計算三角形を大量の板へ変換せず、窓・ライト穴を持つ一つの連続曲面板が追加されます。100%だけを別に残す場合は「曲げ紙の完成形を別オブジェクトで作成」を押します。元板は変更されません。
  10. 「ペーパークラフト部品を作成」を押すと、配置平面へ一枚の板として追加され、窓・ライト穴と切れ目も加工形状になります。SVG/DXF/PDFから同じ1:1図を保存できます。現段階ではのりしろを生成しません。

多面体・比較用の手順

  1. 板材を1枚選び、「生成方式」でまず「多面体ペーパークラフト（新方式）」を選びます。従来結果と比べるときだけ下段の従来方式へ切り替えます。
  2. 「切れ目の方向」で、上下へ走る「縦だけ」、左右へ走る「横だけ」、曲がりの強い方向を自動判定する「縦横を併用」を選びます。
  3. 「立体再現度」を1から10で指定します。低い値は角ばりが大きい代わりに面と部品が少なく、高い値は折り目を増やして元形状へ近づきます。元の面や板は変更されません。
  4. 窓やライト穴の内側にある近似面は生成されません。したがって組立途中、完成近似モデル、STL/STEPのどの状態でも表示線ではなく実際の穴になります。
  5. 丸い角、フィレット、円錐状の収束を寄せる場合は「必要箇所のV字切れ込みを許可」をオンにします。切断辺の曲がりが「反応する最小曲がり」以上の場合だけ作られます。
  6. 切れ込み形状は「鋭いV字」または「形状追従の曲線切れ込み」を選びます。曲線方式ではVの左右の切断辺そのものが曲がります。
  7. 「組立3Dで折り目・切れ目を表示」と「展開から組立まで3D表示」をオンにします。「組立過程」を0%へ動かすと展開状態、100%で角ばった近似完成形です。途中の各面も伸び縮みしません。
  8. スライダーを例えば30%で止めて「この曲げ状態を3Dモデル化」を押すと、その角度の厚み付き面群を別オブジェクトとして保存します。同じ位置のSTL/STEPも下のボタンから保存できます。
  9. 再現度で作った100%の完成形だけを残す場合は「近似完成モデルを別オブジェクトで作成」を押します。元板は残り、派生した角面だけが追加・選択されます。
  10. 「ペーパークラフト部品を作成」は平らな展開片を配置平面へ通常のワイヤー・面・板として追加します。直接切断データならSVG/DXF、印刷なら1:1 PDFを使います。現版の新方式はのりしろを生成しません。
処理方法向く工作結果
一枚を優先接着線と部品数を減らしたい工作可能な範囲をつなぎ、伸縮なしで成立しない箇所だけ組立可能な片へ分けます。
部品へ分割して接着前頭部など形状精度を優先複数の独立した平面片。各片にも必要な切れ込みを併用できます。
鋭いV字直線切断で簡単に作りたい場合直線2辺のダーツ。切断点数を抑えます。
形状追従の曲線切れ込みフィレットやノーズの丸みを細かく寄せる場合曲面を展開した曲線を左右の切断辺へ使います。

組立3Dは派生表示で、元の編集形状を三角形メッシュへ変更しません。曲げ紙方式の結果欄には、部材数、完全分割線数、部材を分離しない歪み逃がし数、窓・ライト等の開口数、生成形状を元曲面と直接比較した「最大3D偏差 / RMS」、切り出し寸法からの「寸法誤差」、閉じるV字左右の「継ぎ目」を別々に表示します。これは再現度から換算した推定値ではありません。紙の剛性や曲げ戻りは含まないため、実材料での試作も確認してください。

展開線意味
CUT_OUTER / CUT_OPENING外周と窓・ライト穴。切断します。
CUT_OUTER（複数）各展開片の外周。自動・手動の完全な分割線は、隣り合う2片の外周になります。
RELIEF_CUT途中で止まる手動切れ目。外周へ組み込まれたV字はCUT_OUTERに一度だけ出力されます。
FOLD曲面を近似する折り線。SVG/PDFでは破線、DXFでは専用レイヤーです。

展開結果をCAD内のワイヤーと3D板にする

選ぶ
展開元の板材を1枚。

視点を変えたいのに形状を選んでしまう自由回転は Shift+中ドラッグ。平行移動は中または右ドラッグ。左ボタンは選択・作図専用です。

制限現在の回避方法
