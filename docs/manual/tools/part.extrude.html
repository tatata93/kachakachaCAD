押し出し

具体例: ライトを中央面と同じ角度の端面まで伸ばす

準備

閉じたライト輪郭と、中央の平らなフェイスを用意する

操作手順

  1. 押し出しを選ぶ
  2. 押す面・輪郭欄へライトを追加する
  3. 範囲を選んだ面までにする
  4. 終端面を選ぶボタンを押して中央フェイスを押す
  5. 方向と終端の向き、オフセットを指定して下見し、確定する

設定: 終端の平面を延長して使うを有効にする。オフセット0.5mmで終端を押し出し方向へ0.5mm進める

結果を確認

ライトから終端平面まで伸びた部品ができる。元面平行と終端面平行を下見で比較する。

取消・やり直し

ダイアログの取消、またはペインの取消を使います。即時操作には未確定段階がありません。 確定済みの文書変更はCtrl+Z、やり直しはCtrl+Yです。保存・書出し済みのファイルはUndoの対象ではありません。

進めない場合

閉じた輪郭を1つ以上、または立体の平らな面を選んでください。

対象欄と3Dの強調を照合し、必要な線・面・部品を各役割へ指定します。処理中は計算表示を確認し、取消が可能な処理は取消を使います。

距離

準備: 閉じた矩形

  1. 輪郭欄へ追加
  2. 距離5mm
  3. 方向
  4. 下見
  5. Enter

確認: 5mm伸びた部品

中央面まで

準備: ライト輪郭と中央の平らなフェイス

  1. 輪郭欄へライト
  2. 選んだ面まで
  3. 終端を3Dで選択
  4. 平面を延長して使う
  5. 方向を中央へ
  6. Enter

確認: 終端の平面まで伸びる

終端をずらす

準備: 終端面を選択済み

  1. 終端オフセット0.5mm
  2. 下見
  3. Enter

確認: 終端を押し出し方向へ0.5mm延ばす

元面と同じ向き

準備: 閉じた平面輪郭

  1. 終端の向き:元面と同じ
  2. 距離5mm
  3. 下見
  4. Enter

確認: 始端に平行な終端

選んだ面と平行

準備: 輪郭と傾いた平面フェイス

  1. 終端の向き:選んだ面と平行
  2. 参照面を指定
  3. 下見
  4. Enter

確認: 選んだ角度に平行な終端

角度入力

準備: 閉じた輪郭

  1. 終端の向き:角度入力
  2. 角度を入力
  3. 下見
  4. Enter

確認: 指定角度の終端

ワイヤーのみ

準備: 閉じた輪郭

  1. 距離5mm
  2. 出力ワイヤーのみ
  3. 下見
  4. Enter

確認: 始端・終端・側面線を指定に応じて生成
