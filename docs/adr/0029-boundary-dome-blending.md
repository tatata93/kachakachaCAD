# ADR 0029: 選択した輪の断面の丸みを広げる張り方

状態: 採用 (2026-10-11、オーナー指示)

## 問題

115の屋根で外周と中央断面から面を作ると、Coonsの直線的な混合では断面から離れるにつれ丸みが弱まり、平らな翼や局所的なこぶに見える。境界に一致するだけでは内部形状の検証にならない。

## 決定

四辺面・境界面の張り方に「滑らかなドーム（近似）」を追加する。選択した閉区画だけを生成し、反対側の区画は「作る」を外せば生成しない。標準・平坦優先・丸み優先は保持し、既存保存データの値0〜2の意味を変えない。新しい張り方は値3で保存する。

境界から端点間の弦を引いた残差を、対向する境界の曲がりの強さに応じた二次・三次の重みで混合する。曲がりが強い側の断面を内部へ広く伝える。四辺の制御点列を固定した非有理B-spline面を正本とし、表示メッシュを編集対象にしない。平面と同形状の対向断面は不要に膨らませない。

境界のみから内部形状は一意には決まらず、この方法も設計上の近似である。全入力への偏差を従来の許容で検査する。内部の折返し・面の潰れも検査して拒否理由を示す。内部ガイドや支持面に対するG1/G2はこの張り方の対象外と明示し、黙って捨てたり従来法へ戻したりしない。これらは従来の張り方で扱う。

## 検証

境界適合、内部断面の丸み、平面・円筒・非対称形状、輪の開始位置と逆順、複合辺、退化した端接線、保存再生成と方式切替を検査する。115の右側だけを生成して実アプリの下見と確定画像を確認する。Windows自動試験と手動受入は区別する。
