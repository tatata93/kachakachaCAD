場面を配置

具体例: 用紙へ3D場面を置く

準備

保存した場面とA4用紙を用意する

操作手順

  1. 用紙編集で場面を配置を選ぶ
  2. 場面一覧から選ぶ
  3. 用紙上に配置して大きさを調整する

設定: 場面をラスタ画像へ置き換えない

結果を確認

3D状態を持つ場面が用紙に表示される。

取消・やり直し

未確定入力をEscで取り消します。道具を終えるときは選択(V)または別の道具へ切り替えます。 確定済みの文書変更はCtrl+Z、やり直しはCtrl+Yです。保存・書出し済みのファイルはUndoの対象ではありません。

進めない場合

文書がありません。

対象欄と3Dの強調を照合し、必要な線・面・部品を各役割へ指定します。処理中は計算表示を確認し、取消が可能な処理は取消を使います。

instructions.place_scene。図の設定と縮尺は例です。方式ごとの制限、プレビューと確定済み結果の区別を確認してください。
