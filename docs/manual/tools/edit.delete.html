削除

具体例: 線と、それを使う面を確認して消す

準備

20×10mm矩形から面を作る

操作手順

  1. 元の矩形を選ぶ
  2. Deleteを押す
  3. 削除一覧と赤い3D対象を確認し、削除か取消を選ぶ

設定: 原点の基準面は削除できない

結果を確認

確認した依存先も含めて削除する。Ctrl+Zで一括復元できる。

取消・やり直し

ダイアログの取消、またはペインの取消を使います。即時操作には未確定段階がありません。 確定済みの文書変更はCtrl+Z、やり直しはCtrl+Yです。保存・書出し済みのファイルはUndoの対象ではありません。

進めない場合

消すものを1つ以上選んでください。

対象欄と3Dの強調を照合し、必要な線・面・部品を各役割へ指定します。処理中は計算表示を確認し、取消が可能な処理は取消を使います。

Windows版の操作画面

edit.delete。図の設定と縮尺は例です。方式ごとの制限、プレビューと確定済み結果の区別を確認してください。
