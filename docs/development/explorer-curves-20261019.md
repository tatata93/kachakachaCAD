# 左ペインと不要な曲線分割の改善（2026-10-19）

状態: 完了。基点745717a02、WP-08の画面・操作アダプターを担当する。

## 範囲と受入

左ペインの選択・表示変更を計時し、重複更新や不要な木・形状の再構築を除く。
チェック操作後も選択行、スクロール、折り畳みを保持し、クリックした場所から飛ばないようにする。
既存グループと同じ階層のグループと、子グループを明示して作れる入口を設ける。
作業面・ワイヤ・面などカテゴリのチェックで対象を一括表示／非表示にし、Undoは1回とする。
グループの表示操作はグループ自身の可視性に作用し、中身や子グループの個別状態を維持する。

投影・近似・展開・押し出しの分割を、保存エンティティ、曲線区間、表示メッシュに分けて調べる。
意味のある角・境界や誤差契約を維持し、不要な分割・サンプリングを減らす。
幾何コアの公開API・保存形式を独断で変えず、既存の厳密曲線と結合機能を優先して利用する。
等価な長いBSplineへの統合を検討中に、既存の検査用SampleCurveが全体の四分点で
周期的な曲がりを見失う不具合を発見した。公開APIを変えず節点区間ごとに検査し、
3次曲線の変曲点も四分点で調べる内部修正と数値回帰を同じ変更に含める。

読み取り専用調査2名、実装・ビルド・試験は主担当だけで行う。
再現と重点試験、混在表示状態・選択位置保持・同列／子作成・曲線種類と接続の回帰を追加し、
最終候補はWindows全体ゲートと配布版試験、通常起動を通す。元モデル・旧配布・他作業は保全する。


## 実装と確認記録

- Explorerの表示切替は、文書コマンドと可視シーンの更新だけを行う。木の全再生成と
  選択コールバックの再発火を避ける。通常の選択変更も棚の二重更新を除いた。
- チェックの通知は行ポインターではなく安定したキーと永続ModelIndexで解決する。
  必要な再構築では選択行・現在行・折り畳み・スクロールを復元する。
- カテゴリは一括表示/非表示を1トランザクションにまとめ、グループのチェックと
  「選択を隠す」はグループ自身だけを変更する。隠れた子や各要素の状態を保持する。
- 同列の新規グループと子グループの入口を一覧上部に置いた。
- 候補一覧のホバーで該当線・面を強調し、区間番号を表示する。メニューへのLeaveで
  候補が消える経路を保護し、終端面等のreference pickにも確定を渡す。
- 新規生成するワイヤーでは、同一直線/同円弧をまとめ、等価なBezier列を一様BSplineに
  統合する。Bezier制御点の差の上界は1e-9mm。非一様列や角を無理にフィットしない。
  元のWire/Segment UUIDは書き換えない。
- 平面パネルの外周と既存開口は、サンプル輪郭と一致する元曲線があれば厳密な剛体変換で
  生成する。円穴やBezierを標本数だけの短い直線に置き換えない。
- 3次曲線の検査用標本化は各BSpline節点と四分点を調べ、周期や変曲点の取りこぼしを修正。
- 曲面の窓穴は可視支持面を優先し、その後に非表示支持面も探す。支持面を隠しただけで
  関係のない面に張り替えない。
