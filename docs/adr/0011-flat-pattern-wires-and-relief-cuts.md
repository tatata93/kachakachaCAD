# ADR 0011: 展開結果のワイヤー化と切れ目

## 状態

採用。

## 背景

二方向に緩く曲がる車体部材を紙や薄いプラ板で作るとき、外周だけの展開図では局所的な伸び縮みを吸収できない。折り目が増える部材では、外周から切れ目を入れて小さな面を順に合わせるペーパークラフト型の製作が必要になる。また、展開結果をSVGやPDFだけにすると、CAD内で切れ目や輪郭を修正できず、厚み付き部材としてSTL/STEPへ渡せない。

## 検討した案

1. 元の3D板を自動で多数の板へ分割する。
2. 展開出力へだけ切れ目を描き、CADモデルには残さない。
3. 元板は維持し、展開結果へ折り線と切れ目を生成して、必要ならCAD内のワイヤーと平らな3D板へ変換する。

案1は部品数を勝手に増やし、中核方針に反する。案2は出力後の修正と3D出力につながらない。このため案3を採用する。

## 決定

- 手動切れ目は、板材の元面へ投影した開いたワイヤーとの関係として保存する。
- 自動切れ目は二方向曲面の展開時だけ明示的に有効化し、間隔と外周からの深さを指定する。
- 折り線は曲面の法線変化がしきい値を超える位置へ生成する。
- SVG、DXF、PDFは外周、開口、折り線、切れ目を別の線種またはレイヤーで出力する。
- 展開結果は任意作業平面上へ、編集可能な外周・開口・折り線・切れ目ワイヤーとして生成できる。
- 同時に元の板厚、厚み方向、材質を引き継ぐ平らな3D板を生成する。切れ目は指定幅の細いスロットとして3D形状へ反映する。
- 自動生成した計算格子や三角形は、プロジェクトの編集対象として保存しない。

## 結果

元の車体形状を保持したまま、同じ板材から印刷・切断用データ、修正可能な展開ワイヤー、STL/STEPへ出せる平らな部材を作れる。自動結果が工作上不適切な場合は、生成後の通常ワイヤーを編集して調整できる。
