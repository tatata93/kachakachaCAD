# 密な曲面の共通部分の矛盾

左右の `.kshape` は通常のUIで作成・保存し、別プロセスで再読込した曲面押し出し2部品の
native転送データである。文書全体、表示名、画像や編集履歴は含めない。
既存の `CaptureOutputShape` / `RestoreOutputShape` の長さ・CRC付き形式を使用する。

OCCT 8.0.1で、各部品は単独の閉鎖性・正体積・自己交差の出力検査を通る。
点 `(0,-5,32.4)` mm は両方で厳密に内側と分類されるが、素のCommonは入力順の両方で
警告もエラーもなく空を返す。境界の別の点を使う製品側の矛盾検出とは独立に照合する。
回帰はこれを「重なっていない」と誤案内しないことと、入力バイト列の保全を検証する。
正しい共通形状の生成や接合・切取りの修正完了を示す試験ではない。

- left: 688,603 bytes、SHA256 `6d24a09c7eaf8e5d56ec21df8d2beffbfadab96be7dc722694de7c25968ed4b1`
- right: 1,026,157 bytes、SHA256 `df9aba661644b9caa21e9870330e8ee8e638442c1bdddb22ce406509d16f21c5`

体積は左118.7318478146、右118.7563474229 mm³。これは完成した模型や製作用の部材ではない。
