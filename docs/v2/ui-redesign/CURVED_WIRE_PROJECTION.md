# 曲面へのワイヤー投影

状態: 完了（2026-10-13、検証コミットd2ea53cc9）。WP-08の独立した投影ツール。

- 作図→編集→面へ投影／巻き付け投影から、対象未選択でも開始する。
- 右ペインに図面から投影、曲面に巻き付け、3Dワイヤーを面に載せるの3方式。
- 入力ワイヤーと投影先を別々に追加・解除。形状ガイドとソリッドの選択フェイスに対応。
  投影先を選んでいない面へは生成しない。元の形状・画像・表示状態を変更しない。
- 方向投影では入力ごとに方向を設定でき、正面図と側面図を同じ操作で扱える。
  初期方向は作業面の法線を最初の投影先へ向ける。手動指定の方向は自動反転しない。
  選択した面で切り取り、接続許容差内の端点だけ接続する。離れた端点に橋を作らない。
- 最近点投影は面上のネイティブ曲線を生成し、最大距離を指定できる。
- 等長巻き付けは平面・円柱・円錐の可展面を対象とする。基準点と向きで位置を決める。
  複曲面に等長と偽って貼らない。適用できない面では理由と他方式への案内を表示する。
- 曲線をネイティブ投影し、保存用に必要なら許容偏差内の滑らかな3次曲線へ変換する。
  表示メッシュから折れ線を作らない。最大偏差を表示する。
- 対象と設定変更で3Dプレビューを更新。計算中は共通計算バー、取消は文書不変。
  Enterは表示済み結果を1操作で確定、Escは入力だけ取消して方式・数値・ツールを維持する。
- 生成ワイヤーは入力UUIDを持つ独立した幾何スナップショット。面番号を永続参照にしない。
  派生ワイヤーとして保存し、直接編集する場合は現在状態を固定する。入力変更への自動再投影は行わない。
  Undo/Redo、保存再読込を試験する。

## 受入試験

平面、円柱、円錐、複曲面、穴付き面、複数面、異なる方向の入力、方向反転、面範囲外、
零方向、入力の向き・順序違い、離れた輪郭、接続、巻き付けの長さと面上偏差を検査する。
GUIでは未選択開始、フェイスクリック、左ペイン選択取込、設定変更、取消後の再使用、
プレビュー不変、原画像保持、一括確定とUndo、保存再読込を検査する。

## 実装と事前検証

新しい独立UIクラスV2ProjectionToolとネイティブAPI ProjectNativeWiresを追加。
UIは方式に必要な設定だけを表示し、ワイヤー別の方向と複数フェイスを個別に指定する。
方向投影・最近点はトリムと穴で切り取り、等長巻き付けは指定可展面内に収まる輪郭に使う。
正面→R→側面の閉じた窓、斜め方向、円・Bezier、7次有理面を含む幾何22ケースが成功。
面の部分的な重なりと前後関係が切り替わる交差も試験し、元曲線を正確に分割して手前の区間を残す。
巻き付けの円柱16 mmの輪郭、円錐4 mmの線は長さ偏差0.001 mm以内を検査。
ネイティブ入力のBRep不変、独立128点の面上偏差を検査し、表示メッシュからの逆生成は行わない。
投影は深い幾何コピー上で計算し、OCCTによる面のフラグや許容差の変更を元形状へ伝えない。
C0継ぎ目を持つ有理面も方向／最近点の両方でBRep不変を回帰検査。
添付モデル由来の複雑な右側面でも1 mmの輪郭を方向3,024 ms／最近点3,083 msで生成、
1本の閉じたワイヤーとなり、元BRepは完全一致。面上の標本偏差はそれぞれ約3.4e-9／8.5e-9 mm。
これらの数値はその条件の計測と標本結果で、全形状の処理時間・全域の誤差保証ではない。
Windows通常描画の投影8ケースが成功。既存の投影窓→近似部材の開口→型紙の工程も成功。
結果の実画面をHTMLマニュアルと既存の取扱説明書へ追加した。
