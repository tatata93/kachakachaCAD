# ADR 0013: 組立方式と形状追従切れ込みを独立させる

## 背景

二方向曲面を帯へ完全分割すれば形状精度は上げられるが、部品数と接着線が増える。車体前面の丸い角、箱形車体のフィレット、円錐に近い収束部は、外周からダーツ状の切れ込みを入れて余る材料を閉じることで、一体の紙や薄板として近似できる。

## 決定

- 「一枚から折って接着／部品へ分割して接着」と「必要箇所のV字切れ込みを許可」を独立した設定にする。分割片にも切れ込みを使用できる。
- V字は展開外周を維持する各部品の外周輪郭そのものへ組み込む。
- 切れ込み形状は、直線2辺の「鋭いV字」と、曲面上の経路を展開して切断辺自体を曲げる「形状追従の曲線切れ込み」から選ぶ。谷底だけへRを付ける方式ではない。
- 立体再現度1から10を、全部品方式の分割数、折り目、切れ込み密度、組立近似3Dの細かさへ共通に使う。必要な場合だけ間隔を個別指定する。
- 切れ込み深さ、V字の開き角、曲線追従度、反応する最小曲がり角を利用者が指定する。
- 開口または手動切れ目と重なる候補は反対側へ移し、両側とも干渉する場合は生成しない。
- 曲線切れ込みは曲面上の腕を複数点で展開し、SVG、DXF、PDF、CAD内の展開3D板で同じ輪郭を使う。
- 外周へ組み込んだV字は `RELIEF_CUT` へ重複出力しない。切断機が同じ辺を二度通らないためである。
- 元の3D板は変更しない。組立3D確認では折り目・切れ目に加え、選んだ再現度の平面片を組んだ近似形状を重ねる。
- 組立近似の三角ファセットは誤差を可視化する派生表示に限定し、主編集対象や保存形状を三角形メッシュへ置換しない。
- 手動分割線は部品境界として優先するが、各部品内で必要な曲線切れ込みは引き続き生成できる。

## 結果

一枚折り、完全分割、分割と切れ込みの併用を同じ生成器で扱える。再現度を上げれば元形状へ近づき、下げれば部品数と切断量を減らせる。どの方式も実材の伸縮や曲げ戻りを含む厳密解ではないため、最大推定ずれと組立近似3Dを確認してから製作へ使う。
