STEPで保存

具体例: 曲面と部品をSTEPへ出す

準備

面とソリッドを用意する

操作手順

  1. 必要な要素を選ぶ
  2. STEPで保存を選ぶ
  3. 保存先を指定する
  4. 検査結果を確認する

設定: ネイティブ形状から出力

結果を確認

B-RepのSTEPができる。検査失敗の対象は理由を確認する。

取消・やり直し

ダイアログの取消、またはペインの取消を使います。即時操作には未確定段階がありません。 確定済みの文書変更はCtrl+Z、やり直しはCtrl+Yです。保存・書出し済みのファイルはUndoの対象ではありません。

進めない場合

選んだ立体・面・線を3DプレビューしてSTEPへ出力します。

対象欄と3Dの強調を照合し、必要な線・面・部品を各役割へ指定します。処理中は計算表示を確認し、取消が可能な処理は取消を使います。

export.step。図の設定と縮尺は例です。方式ごとの制限、プレビューと確定済み結果の区別を確認してください。
