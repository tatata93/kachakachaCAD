# 最低限の完成形までの工程

## 完成の定義

このCADの最低限の完成形は、次の2系統を一つのプロジェクト内で最後まで実行できる状態とする。

### プラ板・紙工作

1. 任意の作業平面へ断面図や平面図を正確に描く。
2. 断面ワイヤーから車体の面を作る。
3. ライト穴などを別の平面図から投影する。
4. 面を板材として定義し、製作可能な大きさへ分割する。
5. 外周、穴、切断線、曲げ線を含む1:1型紙を出力する。

### 3Dプリント部品・治具

1. ワイヤーと面から閉じた3D部品または治具を作る。
2. 板材との隙間や肉厚を数値で指定する。
3. 3Dプリント可能性を検査する。
4. 選択した部品だけをSTLへ、CAD形状をSTEPへ出力する。

PDFの装飾、一般的なソリッドCAD並みの全機能、自動で大量分割する機能は、この最低限の完成条件に含めない。

## 現在つながっている工程

- 任意配置・任意角度・3点指定・オフセットによる作業平面。
- 作業平面への正対と、3D空間内での直接2D作図。
- 直線、ポリライン、矩形、円、3点円弧、ベジェ曲線、通過点B-spline。
- 選択した直線・ポリライン・ベジェ・B-spline・円・円弧の点やハンドルを3D画面で直接編集し、1操作単位でUndoできる。
- 作図中の長さ、角度、幅、高さ、半径の実寸入力。
- グリッド、端点、水平、垂直、正方形への一時スナップ。
- 複数ワイヤーの3D直接選択、移動、回転、コピー、ミラー、分割、結合。
- 直線、ポリライン、円、円弧の平行オフセット複製と3Dプレビュー。
- 交点へのトリム・延長、C面取り、R丸め。
- 閉輪郭から平面、2断面からルールド面、複数断面からロフト面。
- 平面図から面へのライト穴投影と、元図・面への追従。
- 面の板材化、板厚、材質、厚み方向、ライト穴開口。
- 板材の展開可能性判定、手動2分割、1:1 SVG / DXF / PDF。
- 保存、再読込、Undo / Redo、表示切替、配布フォルダからの起動。

## 残りの必須工程

### 1. 正確な作図を完成させる

- 補助線と、通常ワイヤーから除外する属性は実装済み。作図時または作成後に切り替えられ、面・投影・開口・切断出力には使われない。
- 作成後も維持される拘束。直線の長さ、作業平面内角度、水平、垂直、円・円弧の半径、異なる開ワイヤー間の端点一致、追従側ベジェ・円弧のG1接線接続、追従側ベジェのG2曲率接続は実装済み。直線の端点一致と長さ・角度、曲線連鎖の端点一致・G1・G2は反復して同時に解く。成立しない両端条件は形状を巻き戻し、追従側の線名を診断できる。残りは任意寸法とすべての曲線を同時に扱う一般数値ソルバー。
- 参照寸法と3D測定。2点間、点・ワイヤー間、ワイヤー間、点・平面間、平行平面間の距離、ワイヤー全長、曲線半径、接線角、線・平面角、平面角を測定でき、必要な値は図面へ残して形状編集に追従させられる。
- 楕円、閉じたB-spline / NURBS曲線、接線指定などの円弧作成方式。
- ベジェやスプラインの正確なオフセット。

合格条件:

- 車体中心線、床面、窓位置を補助線と寸法で定義できる。
- 寸法値を変更すると断面輪郭が破綻せず追従する。

### 2. 複雑な前面曲面を実用品質にする

- G0端点一致、追従側ベジェ・円弧のG1接線接続、追従側ベジェのG2曲率接続は実装済み。
- B-spline / NURBSを保持したロフト面。
- 縦横ワイヤー群から作るネットワーク面。
- 面の再計算順序を管理する依存関係。
- 投影、交差、面境界の許容誤差と失敗表示。

合格条件:

- 4断面以上と縦方向ガイドから、段差やねじれのない鉄道車両前面を作れる。
- 元断面を修正すると、面とライト穴が自動更新される。

### 3. OCCTによるCAD形状層を入れる

- ワイヤー、面、板をOpen CASCADEのEdge / Wire / Faceへ変換する境界層。
- 許容誤差、単位、形状検査を一元化する。
- 既存の軽量コアを編集データとして保ち、OCCT形状は再生成可能にする。

合格条件:

- 曲線を三角形や細かい折れ線へ変換せず、CAD曲線として面と出力へ渡せる。

### 4. 部品と治具を作れる3D形状を実装する

- Component / Body階層、ローカル座標、複製配置。
- 閉じた面群からBodyを作る。
- 面の厚み付け、指定断面のスイープ、ロフトによる3D部品。
- 治具用の肉厚、逃げ量、板材との隙間を数値指定する操作。
- 部品のグループ化、分離、再結合。

合格条件:

- 車体前面に合う雄型または雌型の成形治具を、指定クリアランス付きで作れる。
- 同じ部品を左右反転または複数位置へ配置できる。

### 5. 3Dプリント出力を完成させる

- 閉形状、法線、非多様体、最小肉厚の検査。
- STL出力時だけ行う精度指定付きメッシュ化。
- 選択部品の個別・一括STL出力。
- ワイヤー、面、BodyのSTEP出力。

合格条件:

- 作成した治具を選択し、スライサーで修復なしに開けるSTLを出せる。
- 同じ部品をCAD形状のSTEPとして他CADへ渡せる。

### 6. 板材工作情報を完成させる

- ワイヤーの切断線、曲げ線、接合線、分割推奨・禁止・必須属性。
- 任意ワイヤーによる手動分割。
- 材質別の曲げ代、中立軸係数、板厚中央以外の展開。
- 曲げ方向の3D表示と、製作困難箇所の候補提示。

合格条件:

- 0.3 mm、0.5 mmなどのプラ板条件を変えると型紙寸法へ反映される。
- CADが勝手に多数の細片を作らず、ユーザーが選んだ分割線で部品化できる。

### 7. 長時間作業に耐える状態へする

- 自動保存と異常終了からの復元。
- プロジェクト形式のバージョン管理と移行。
- 部品・作業平面のロック、誤選択防止。
- 大量ワイヤー・断面・投影を使った性能試験。
- 操作単位が分かるUndo履歴表示。

合格条件:

- 実車1両分の部品を置いても、選択・視点・編集が実用速度で動く。
- 強制終了後に直前の自動保存から復元できる。

## 実装順序

1. 作図拘束、補助線、寸法、スプライン。
2. NURBS曲面、接続条件、ネットワーク面。
3. OCCT形状変換層。
4. Component / Bodyと治具作成。
5. STL / STEPと3Dプリント検査。
6. 板材属性、曲げ代、任意分割。
7. 自動保存、ロック、大規模性能試験。

## 最終受入モデル

最低限の完成判定には、専用の鉄道車両前面モデルを一つ用意する。

- 4枚以上の断面作業平面。
- 曲率の異なる上部・下部を持つ前面。
- 左右のライト穴と窓境界。
- 0.5 mmプラ板の複数パネル。
- 前面パネル用の3Dプリント成形治具。

断面寸法の変更から、面、穴、板材、型紙、治具、STL / STEPまで再生成できた時点を最低限の完成とする。

## 後回しにするもの

- PDFの見栄えや印刷設定の細かな拡張。
- 自動ネスティング。
- 全自動の板分割。
- 一般機械CADと同等のブーリアン機能一式。
- 図枠、表題欄、詳細図を含む本格製図機能。
- アセンブリ拘束や干渉解析の高度化。
