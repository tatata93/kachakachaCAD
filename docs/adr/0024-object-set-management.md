# ADR 0024: 部材グループによるオブジェクト管理

## 状態

採用(2026-09-04)。実装済み。

## 背景

モデルツリーは種類別(作業平面/ワイヤー/面/板材…)の平置き一覧で、オブジェクトが
増えると管理できない。実際の設計は「前面・右側面・左側面・屋根・妻面」のような部材単位で
進み、各部材の中に理想完成形・製作用の近似ワイヤ・面・板が属する(オーナー要件)。
コアには ObjectSet(セット)が既にあり、部材近似モデルが自動セットとして使っていたが、
ユーザーが自分でセットを作って所属を管理するUIが無かった。

## 決定

既存の ObjectSet を「部材グループ」としてユーザーに開放する。

1. **モデルツリーのグループ化**: 最上位 = 部材グループ(太字)+「未分類」。
   その下に種類別セクション(空の種類は出さない)、末尾に端点一致・滑らか接続・
   参照寸法(グループに属さない全体情報)。所属は「1オブジェクト = 最大1グループ」。
2. **所属は自分で管理**: ツリーの右クリックメニューで
   「部材グループへ割り当て(複数選択可)」「新しい部材グループ…」「部材グループから外す」。
   グループ行の右クリックで「表示状態(表示/参照のみ/非表示)」「.kcd書き出しに含める」
   「部材グループを削除(中身は未分類へ)」。
3. **一括表示/非表示**: グループ行のチェックボックス = ObjectSetState の
   Visible/Hidden 切り替え(既存の描画側 ObjectStateInSets がそのまま効く)。
4. **kcd出力からの除外**: ObjectSet に `exportEnabled`(既定 true)を追加。
   - .kcd には `object_set_export <名前> 0` として**スクリプト末尾**に保存
     (自動セットが part_model 再生成で作られた後に読めるようにするため)。
   - **通常の保存には影響しない**(データを失わないため)。効くのは出力タブの
     「出力対象のみで .kcd 書き出し」だけ: プロジェクトの複製から除外グループの
     メンバーを依存順(部材モデル→立体→板→面→ワイヤ→点→平面)に削除して書き出す。
     出力対象側が除外部材を参照している場合は理由を列挙して中断する
     (依存も含めて所属をユーザーが管理する、という方針に合わせた明示的エラー)。
5. ツリーのフィルタは多階層対応の再帰判定に変更。
6. **エクスプローラ風の入れ子とドラッグ&ドロップ**(2026-09-04 追記、オーナー指示):
   - ObjectSet に `parentName` を追加(空=最上位)。グループの中にグループを作れる
     (例: 前面 > 理想形 / 近似)。循環は拒否。`object_set_parent 子 親` として
     スクリプト末尾に保存。
   - グループ削除時、子グループは1つ上へ、メンバーは未分類へ。
   - 実効表示状態は祖先を合成(非表示>参照のみ>表示)。`ObjectStateInSets` が担う。
   - ツリーはフォルダアイコン付きで入れ子表示。**ドラッグ&ドロップ**で
     オブジェクトをグループへ、グループをグループの中へ移動(未分類・空欄へ
     ドロップで未所属/最上位へ)。Qt標準のアイテム移動は使わず、
     `ModelTreeWidget`(moc不使用)の dropEvent からプロジェクト側の所属を
     変更してツリーを作り直す(`HandleModelTreeDrop`)。
   - 右クリックに「子グループを作成…」。割り当てメニューは「親 / 子」のパス表示。

## 実装

- コア: `ObjectSet::exportEnabled` / `Project::SetObjectSetExport` /
  ProjectScript の `object_set_export` コマンド(読み書き)。
- UI: `RefreshModelViews`(グループ構築)、`ShowModelTreeContextMenu`、
  `ApplyModelTreeFilter`(再帰化)、`ExportProjectExcludingSets`(MainWindowOutput.cpp)。
- テスト: project_script_tests に往復テスト、セルフテストに
  割り当て→グループ表示→一括非表示→復帰の検査を追加。

## 検証方法

linux-core → Windows 実機ビルド → 17テスト → 起動 → ツリーのスクリーンショット確認。
