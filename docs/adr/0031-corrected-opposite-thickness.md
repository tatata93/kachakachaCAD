# ADR 0031: 元の面を保持する厚み補正

2026-10-13。オーナー承認済み。実装・検証中。

## 問題

一定厚みの内側オフセットは、局所曲率半径を超えると自己交差する。
添付屋根でも発生しており、失敗の拒否だけでは部品作成を進められない。
半径5 mmの面を外面として1 mm付けた内面が4 mmになる通常の意味は維持する。

## 決定

- 厚みツールに「一定厚み」と「反対面を補正」をボタンで設ける。
  既存文書の既定は一定厚み。補正を黙って適用しない。
- 補正を選んでも、元の形状ガイドと上流ワイヤー・画像・履歴は変更しない。
  一方向付けでは元の面を立体の片側として保持し、新しい反対面のみ補正する。
  中央付けは元面を中央の参照形状として保持し、両側に新しい面を作る。
- 補正を選んでも、指定値を満たす形が作れる場合は既存の一定厚みを使う。
  不能な曲面では法線変位を滑らかにしたネイティブB-spline面を作り、境界を閉じる。
  穴や任意トリムを矩形で埋めず、対応できない入力は理由を表示して拒否する。
- 指定値を実厚みだと偽らない。補正の使用有無、検査標本での法線方向の厚み範囲、
  指定した法線オフセットからの最大/RMS位置偏差を下見・確定時に表示する。
  標本検査は全域の数学的誤差上界とはしない。
- 閉鎖性・正のネイティブ体積・自己交差の既存検査は補正結果にも適用する。
  表示メッシュを正本にしない。検査に失敗した試作を確定できるようにしない。
- 保存時に補正モードをThickenSurfaceDefinitionへ記録する。旧ファイルの省略値はfalse。
  再読込で同じモードを再構築する。取消・条件変更は古い下見を採用しない。

## 受入

半径5→4の厳密例、平面、反転・剛体変換、局所曲率を超える曲面、添付屋根の
内側/中央、過大な厚み、穴付き入力の明示拒否を検査する。
実ツールのボタン選択、設定変更、下見、確定、元面保持、Undo/Redo、保存再生成を試験する。
添付KCDを上書きしない。Windowsの全体ゲートと配布版試験後に実装済みと記録する。
