# 共通ツールUI（2026-10-01 オーナー合意）

状態: 実装中。従来の製作工程タブより、この合意を優先する。

- 上部はモード・分類・コンパクトな道具一覧。右は未選択時に同じ分類、名前、順序の大きな道具一覧。
- ツール→対象を基本とし、対象→ツールも保持する。右は選んだツールの設定だけ。
- 設定の順序は入力、条件、作るもの、生成先、確認。不要な欄は出さない。
- 入力の役割を明記する。空欄を全対象と解釈しない。「すべて」は明示指定。
- 取消・確定は下端。方法の選択と実行を分ける。同じボタンの二度押し確定をなくす。
- 設定変更で下見更新。重い操作は明示更新。失敗理由・近似誤差を確認欄に表示。
- 作成後は道具と条件を保持して次の対象へ。Escで一覧へ戻る。
- Win95テーマはボタンの隆起・押込み、入力欄の沈み、無効状態を明確にする。
- ホーム・新規は前右上の等角視点。キューブと回転操作の描画・クリック領域を競合させない。
