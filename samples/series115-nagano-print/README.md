# クハ115-1000 長野色・1/80 印刷用モデル

先頭車1両。リニューアル後・黒Hゴム・集中冷房の代表形を、編集可能な通常のワイヤー、押し出し、ロフト、切抜き、結合で作成した。窓は実際に開口しており、前面隅の曲面に沿うガラス/Hゴム、側面サッシ、中桟を別部品とした。輸入メッシュや凍結BRepが編集の正本ではない。

**実車の全局所寸法を実測した精密模型ではない。** 大寸法は公開一次資料に合わせたが、窓・扉の配置、前頭曲率、屋根上・床下機器、台車外観、帯幅は推定を含む。特定の車番・編成・時期を完全再現したものとは扱わない。実物の3Dプリント、接着、走行試験は未実施。台車・車輪は展示用の一体構造で、走行・集電・市販シャーシへの互換性はない。

## 開くファイル

- `kuha115-1000-nagano-1-80.kcd2`: 通常版。完成状態の129部品。
- `kuha115-1000-nagano-1-80-split.kcd2`: 小型プリンタ版。134部品。車体・屋根・床板・室内トレーの4部位をX=123.75mmで前後に分割。床板用の添え板を追加。最長約123.75mm。
- `three-view.png`: 自作の寸法基準三面図。`side.png`、`front.png`、`top.png`を各0.1mm/pixelでCADに埋込み、グループ12に非表示で置いた。
- `model-preview.png`: CAD出力形状から作った塗装・分解説明図。CADの画面ではない。
- `cad-screen.png`: 検証済みWindows配布版でこのモデルを開いた実画面。
- `design.json` / `design-split.json`: 寸法・材質・色・グループ・部品ID・干渉確認対象。

CADではグループ12の画像を必要なときだけ表示する。描かれた図は参考形状で、主要寸法以外の実車寸法を保証しない。色名は部品の製作属性に保存した。現行CADの部品表示は灰色であり、説明図のように長野色が自動描画されるわけではない。

車体外板0.85mm、屋根断面半径差0.9mm、床板1.2mm。スケール通りの薄板ではなく印刷のため内側へ増厚した。床板外周は車体内側から0.25mm逃がした。ガラス0.5mmは開口より大きい裏貼りで、側面は車体内側から0.1mm、客扉ガラス等は0.1～0.25mmの接着用隙間を持つ。細小物には0.35～0.45mmの箇所があり、FDMでは省略・拡大するか別材料へ置換する。

前頭は平面中央と水平面上のR隅、屋根ドーム、曲面に沿う前面窓で構成した近似形。実車の複合曲率や傾斜を全点測量したものではない。AU75、通風器、床下機器、TR62A側枠、室内は簡略外形であり、機器銘板、配管、リベット、車番・標記は未再現。

サポート・露光時間・印刷角度・材料収縮はプリンタ固有なので自動決定していない。まず窓枠、床板前端、屋根端の小片で収縮と隙間を確認する。透明部品や0.4mm前後の小物は通常レジンと分けて出力する。

配布用フォルダーの `full-car` は通常版、`small-printer` は分割版。中の `STL/01` 等が部位別。`parts.csv` と `print-parts.json` に部品名・寸法・色・UUIDとファイルの対応を記録する。STLは**各部品のXY中央を原点、最下面をZ=0**へ平行移動済み。縮尺や向きは変えていない。STEPは**組立時の座標**を保持する。STLを全部同時に読込んで完成位置へ自動整列する用途にはSTEPを使う。

## 組み立て順

1. 通常版か分割版のどちらかを選ぶ。部品表を見て129/134個全部を印刷する必要があるか決める。透明板・真鍮線などへ置換した部品は印刷しない。
2. 分割版は床板前後を平面上で合わせ、下面の12×8×1mm添え板で接着する。その床板を基準に車体前後を合わせる。車体と屋根の分割には自動ロック爪はなく、平面治具・仮止めテープで位置を保持して接着する。
3. 屋根を仮組みし、車体内側の取付桟で位置を合わせる。前頭と屋根の接合部は磨き・接着調整の余地を残す。必要な表面仕上げを塗装前に行う。
4. フォギーグレーを下塗りし、青帯、緑の細帯を塗る。説明図の帯境界はレール面基準Z=24.7/26/38.5mm。RGB値と帯幅は推定なので、採用する実車写真と塗料の試し塗りで合わせる。
5. サッシとHゴムを貼り、乾燥後、裏貼りガラスを内側から透明用接着剤で固定する。ワイパー・手すり・灯具は最後に取り付ける。
6. 床下機器の接着座と台車の心皿を床板下面へ合わせ、室内トレーを床板上へ置く。台車のねじ穴は締付け用。車輪は固定されている。
7. 床板を車体へ差し込み、屋根を載せる。最終固定は接着/ねじ等、保守できる方法を選ぶ。車体と床板を固定する専用爪・ボスは設けていない。

## 検証

CADは `camera-navigator-verified-20261023` の検証済みWindows配布版を使用した。製品修正38dd139ebの全体ゲート（CTest195件、開発版/配布版UI各566件、旧CAD自己試験）が成功した後のモデル制作で、製品実装は変更していない。

最終モデルの別検証は `validation-summary.json`、`validation-main.json`、`validation-split.json` を参照。ネイティブ再生成、部品ごとの閉ソリッド・正の体積・全体寸法、STEP往復、STLの閉鎖/向き/退化/体積を調べた。体積一致はメッシュの離散化を含むのでSTL許容差0.2%、STEPはmax(1e-5mm³,体積×1e-7)。これは製品の幾何許容差の緩和ではない。

干渉確認は指定した組合せが対象で、実際の接着強度や全組合せの無干渉・走行性を保証するものではない。モデルごとのCAD初回再生成時間は計時したが、反復比較による性能保証値ではない。
