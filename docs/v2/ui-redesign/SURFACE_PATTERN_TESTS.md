元ファイルは読み取り専用。画像の選択IDは保存されていないため、画像と座標から選択を推定する。環境変数KACHACAD_SURFACE_TEST_FILEとKACHACAD_SURFACE_TEST_OUTPUTで任意のローカル入力と出力先を渡し、自己テストHP-LF-115を実行する。元ファイルを上書きしない。

- 下部右・左：各7Wire、1面、未使用4区間を明示。
- 中央断面を含む上部：7Wire、2面。
- 丸窓：逆方向の区間を含む1Wire、1面。
- 上部の別の選択：8Wire、3面。

各ケースで実アプリのプレビュー・確定画像と別名kcd2を出力。下部右・上部中央は張り方3種類の切替も検査。元Wire数、Undo/Redo、保存再読込時の再生成を検査する。

## 滑らかなドーム（近似、2026-10-11）

kernel_dome_testsは境界全4辺を101点ずつ比較し、内部断面の丸みを25/50/75/90%位置で数値検証する。非一様ノット・次数上げ、平面・同じ対向断面、U/V反転・UV交換、正負円弧・四辺面/境界面、内部ガイド・支持面G1の明示拒否、任意3D配置、鞍形、潰れを検査。裾の直線への断面全体の拡縮と、丸い裾を含む輪の高さ伝播も検証する。ドームの内部は31×31位置で接線の外積を検査し、潰れ・標準面に対する法線反転を拒否する。全ての自己交差を証明する検査ではない。

HP-LF-115-DOMEは中央断面付き7Wireから2区画を検出し、左の「作る」を外す。右だけの標準/ドームの実面下見、Enter、全元要素保持、Undo/Redo、保存再生成を検査。生成点が選択右側の外周の範囲に収まることも調べる。同じXY位置12点を鉛直線と正本面の交点で比較し、中央から離れた場所と外周寄りの丸みも検査する。異なるUVパラメータを同じ位置とみなさない。元の画像の選択IDは推定である。

## 限界

全形状の保証ではない。代替ネットワークは24区間まで。G0の境界適合は隣接面のG1/G2や内部の曲率品質を保証しない。境界と中央線だけからユーザー意図の面が一意に決まるとは限らず、張り方を実形状下見で比較する。閉立体ケージの全フェイス復元は対象外。

全体ゲートはWindows offscreen自動試験。115-DOMEは通常Windows画面の自動試験も実施。手動操作・Linux/cloudは未実施。最終ゲートの結果はTASK_LEDGERに記録する。
