# 画像を面に貼る（2026-10-04 オーナー依頼）

## 操作
作図の画像ツール → PNG/JPEG/BMPを読む → 任意の作業面・面・ソリッドのフェイスを選ぶ。
現在の作業面もボタンで採用可能。事前選択とツール先行を両方扱う。
主3Dビューの画像上で基準点を指定し、続けて同じ3Dビューで配置先の基準点を指定する。
基準点を選ぶだけでは画像は移動しない。画像側・CAD側の測定点も全て主3Dビューで指定する。
画像上の2点→CAD上の2点で画像フィットを行う。回転ありは位置・向き・縮尺を同時に合わせ、回転なしは元の長い軸に合わせる。縦横比を保つ。数値の幅・回転・透明度（0%が不透明、100%が透明）も編集可能。
左右反転は指定した基準点を固定して行い、再度切り替えると戻る。
貼付後は画像を選択→画像ツール、または画像ツール→3Dビューで画像を選択して、位置・反転・透明度を再編集できる。
Enterで確定、Escで取消。下見だけで文書を変更しない。選択した画像の再編集を同じツールで行う。

### ドラッグによる位置合わせ
画像ツール内で画像を左ドラッグすると、つかんだ位置に画像が追従する。
離した位置で仮置きし、Enterで確定、Escで編集開始時へ戻す。Undoは確定した移動を一度で戻す。
ドラッグ中は開始位置の画像平面上を連続移動し、グリッドへ吸着させない。
曲面ではその移動先を貼付面へ投影する（UVの伸縮・継ぎ目の制約は同じ）。
厳密なスナップ位置合わせには従来の画像基準点→配置基準点のクリックを使用する。

## 貼り方
- 平面: 画像を平面に配置。
- 投影: 指定位置の接平面の向きから面へ投影。画像外は透明、面の境界と穴で切る。
- 面に沿う: 面のUVに沿って貼る。自由曲面のUVは均一な実長ではなく伸縮が生じるため説明を表示。
  円筒等の周期面はUVの継ぎ目を持つ。表示は面の三角形による近似で、幾何や型紙を変更しない。
曲面UVの長さ合わせは局所UV尺度による近似。曲面上の測地距離ではない。投影方式のフィットは貼付平面上の2点を使い、面外の指定には理由を表示する。

## 保存と整合
新しいImage要素/CreateImage定義。PNGデータ、画像寸法、貼付座標系、縮尺・回転・基準点、
投影/面沿い、面に貼る場合の確定時BRepを保存する。パス参照ではなく画像を内包。
貼付先は確定時の位置・形状を固定して保持し、元部品の編集には自動追従しないことをUIで明示する。
画像は図形へ変換しない。STL/STEPは色付き画像を表せないため選択出力時に理由を示す。
Undo/Redo・削除・表示切替・グループ・KCD往復を扱う。空画像、ゼロ距離、面に当たらない点は拒否し理由を出す。
