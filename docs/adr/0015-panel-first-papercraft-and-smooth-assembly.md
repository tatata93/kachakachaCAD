# ADR 0015: 連続部材優先の展開と滑らかな途中組立

## 背景

曲げ紙方式の初版は、一枚の紙として展開図を作っていても、途中組立では計算用三角形ごとの辺長拘束が別々の折れ方向へ逃げた。再現度10では細分化した面がしわ状に反転し、「この曲げ状態を3Dモデル化」は計算三角形を一枚ずつ板へ変換して1万個以上のオブジェクトを作った。

工作上必要なのは、解析メッシュではなく、少数の長い部材、曲線の窓・ライト開口、部材を分離しない短い切れ目である。

## 調査

- Liu、Lai、Huのstripificationは、自由曲面を少数のC0接続された可展ストリップで近似し、全体誤差上限を制御する。最終部材を三角形ではなく長い帯として扱う根拠にした。[Stripification of Free-Form Surfaces With Global Error Bounds for Developable Approximation](https://orca.cardiff.ac.uk/id/eprint/20104)
- Dev2PQは可展面の母線と曲率方向を利用して平面四角形ストリップを作る。単純なUV等間隔線だけでなく、主曲率方向を部材方向候補にする根拠にした。[Dev2PQ](https://arxiv.org/abs/2103.00239)
- Developable Wrappingは可展パッチ数と元形状への近似を同時に扱う。誤差達成後に部材数を評価する設計の参考にした。[Developable Wrapping](https://igl.ethz.ch/projects/developable-wrapping/)
- Boundary First Flatteningは境界を先に決める低歪みの共形平面化である。曲線外周や開口を保つ補助解析には有用だが、辺長保存を保証しないため、工作寸法を決める唯一の展開器にはしない。[Boundary First Flattening](https://arxiv.org/abs/1704.06873)
- ARAP surface modelingは局所回転と全体整合を交互に解き、局所剛性を保つ。途中組立を点座標の直線補間から局所回転場の補間へ変更する根拠にした。[As-Rigid-As-Possible Surface Modeling](https://igl.ethz.ch/projects/ARAP/)
- Alexaらのshape interpolationは、局所変換を回転と伸縮へ分け、回転を補間して全体形状を再構成する。0%から100%の間に縮んだ点群を辺長だけで押し戻す方式を廃止する根拠にした。[As-Rigid-as-Possible Shape Interpolation](https://doi.org/10.1145/344779.344859)
- Boのpaper bendingは、平面と曲げた紙の間を伸縮なしの連続な可展変形として扱う。将来、帯ごとの厳密な可展アニメーションへ進める際の基準とする。[Geodesic-Controlled Developable Surfaces for Modeling Paper Bending](https://doi.org/10.1111/j.1467-8659.2007.01059.x)

## 決定

- `PapercraftCutKind` で `SeparatingSeam` と `NonSeparatingReliefCut` を別データにする。窓・ライトはどちらでもなく `openings` のまま保持する。
- UIへ「部材優先 / バランス / 精度優先」「最大許容3D偏差」「最小部材幅」を追加する。初期値は部材優先、0.10 mm、3.0 mmとする。
- 最適化順は、許容誤差、部材数、完全分割線、relief cutの順とする。現段階では曲げ紙方式を一枚に保ち、許容値を厳しくした場合は分割より先に局所切れ目候補を増やす。
- 途中組立は、固定密度の滑らかな回転場で解く。曲面の局所直交座標から回転を作り、単位Quaternionを球面補間し、回転した材料辺ベクトルをグラフLaplacianの最小二乗問題として前処理付き共役勾配法で全体整合する。
- 再現度による細かい三角形は、この連続変形場を双線形に標本化するだけとする。解析密度を上げても新しい折れ方向を作らない。
- 中程度以下の再現度では、滑らかな場から離れない範囲の短い辺長補正を行う。高密度では補正が局所座屈を起こすため、連続場を優先し、実測寸法誤差を表示する。
- 「この曲げ状態を3Dモデル化」は、計算三角形を板へ変換しない。9本の連続断面から一つのLoft板を作り、窓とライトを同じ変形場で追従させて実開口として投影する。relief cutは別の3Dガイド線として残す。
- SVG/DXFでは `RELIEF_CUT` と `SEPARATING_SEAM` を別レイヤーにする。
- 三角形群によるSTL/STEPは比較用の多面体方式に限定し、曲げ紙方式は連続板を優先する。

## 検証基準

- 再現度10、途中30%で隣接計算面の最大角が45度未満で、反転しない。
- 途中状態と完成状態の最大材料辺長誤差を実測し、0.11 mm以下を作業基準とする。
- relief cutを追加しても `pieceCount` は増えない。
- 自動relief cutは全て `NonSeparatingReliefCut`、手動分割線は `SeparatingSeam` として出力される。
- 曲げ途中をCADへ追加したとき、板オブジェクトは一つで、窓・ライト開口数が元板と一致する。
- 連続板のSTL/STEPが有効な閉じたB-Repとして出力できる。

## 既知制約

- 現在の部材候補は一枚の連続外板が中心で、主曲率線・測地線から複数の長い帯を自動探索する完全なstripificationは未実装である。
- 最大許容誤差は設計目標として使い、結果の実測値が超えた場合は警告する。relief候補ごとに再展開して改善量/切断長を比較する探索は次段階である。
- 連続Loft板の3Dモデルでは窓・ライトを実開口にするが、ゼロ幅スリットは厚み付き板から材料を除去せず、3Dガイド線として表示する。加工幅を持つスロット化は展開板出力に残る。
- これは紙の弾性、塑性、座屈、曲げ戻りを解く物理シミュレーションではない。工作可否は実測誤差と試作で判断する。
