# ワイヤーとスケッチ仕様

## 目的

ワイヤーは、このCADで面・板・部品を作るための中心データである。

ユーザーは以下のどちらでもワイヤーを作れる。

- 3D空間で直接、始点と終点などを数値指定する。
- 作業平面上で2D作図し、その結果を3Dワイヤーとして配置する。

## 直線ワイヤー

3D直線ワイヤーは、始点と終点で決まる。

```text
始点: X=0, Y=0, Z=0
終点: X=2, Y=7, Z=4
```

内部的には以下のようなデータとして持つ。

```text
Wire
- kind: Line
- control points:
  - (0, 0, 0)
  - (2, 7, 4)
```

## 曲線ワイヤー

曲線は、始点と終点だけでは形が決まらない。必ず追加条件を持つ。

初期実装では Cubic Bezier を扱う。

```text
Wire
- kind: CubicBezier
- control points:
  - start
  - control1
  - control2
  - end
```

将来的に追加する候補:

- 円弧
- 3点円弧
- 通過点スプライン
- NURBS / B-spline
- 接線条件付き曲線
- G0/G1/G2 接続条件

## 作業平面上のスケッチ

作業平面上では、2D座標で作図する。

```text
u: 平面内の横方向
v: 平面内の縦方向
```

例えば、X=10の作業平面に以下の線を描く。

```text
始点: u=2, v=3
終点: u=5, v=7
```

作業平面の座標系に従って、3D上では以下のワイヤーになる。

```text
始点: X=10, Y=2, Z=3
終点: X=10, Y=5, Z=7
```

## 初期実装範囲

- 3D直線ワイヤー
- 3Dポリライン
- 3D Cubic Bezier
- 作業平面上の2D直線を3Dワイヤーへ変換
- 作業平面上の2D Cubic Bezierを3Dワイヤーへ変換

## 実装上の注意

- ワイヤーは三角形メッシュではない。
- 画面表示で分割線分が必要になっても、元データは曲線として保持する。
- OCCTへ渡すときは、できるだけ曲線・エッジ・ワイヤーとして変換する。
- STL用メッシュ化は出力時だけにする。
