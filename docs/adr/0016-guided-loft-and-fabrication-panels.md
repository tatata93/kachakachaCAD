# ADR 0016: ガイド付きロフトと製作用大部材を分離する

## 状態

採用。

## 背景

鉄道車両前面では、直交する作業平面上の外形曲線と、任意位置の断面曲線を同時に満たす必要がある。単純な断面ロフトだけでは外形ガイドを厳密に保てない。また、元サーフェスの解析三角形を直接展開部品にすると、人が切って曲げる外板ではなく多数の小片になる。

## 決定

1. モデリングへ `GuidedLoft` を追加する。外形ガイド2本と断面1本以上を受け取り、断面端点からガイドの再パラメータを作る。
2. 断面補間面へ、両ガイドとの差を線形ブレンドした補正を加える。これにより断面とガイドをともに通る。これは曲線網を補間するGordon/Boolean-sumの考え方を、このCADの2ガイド用途へ限定したものとする。
3. 展開へ既存方式と独立した「製作用大部材」方式を追加する。最初は元板全体を一部材候補とし、主曲げ方向へ長い帯を保ったまま、実測偏差が大きい候補だけ分割する。
4. 窓・ライト穴を横切る自動分割を避ける。ユーザーが板の分割線へ指定した投影ワイヤーは大部材境界として先に適用する。
5. 各大部材は一枚の曲げ板、独立した型紙、独立した連続ロフトモデルとして保持する。解析三角形は組立誤差の測定と表示だけに使う。
6. 許容偏差へ届かない場合は成功扱いにせず、実測最大偏差をUIへ警告表示する。

## 技術調査

- Open CASCADEの `GeomFill_Gordon` はプロファイル列とガイド列のBoolean sumによる曲線網補間を提供する。現在のコアはQt/OCCT非依存を保つため、まず2ガイド専用補間をC++コアで実装した。<https://dev.opencascade.org/doc/refman/html/class_geom_fill___gordon.html>
- `GeomFill_Generator` は複数断面を通るB-spline面を生成するが、ガイド列を同時に拘束する機能ではない。<https://dev.opencascade.org/doc/refman/html/class_geom_fill___generator.html>
- Developable strip近似は、指定した大域誤差内で自由曲面を可展帯へ近似する方針を示す。本実装はまず鉄道模型向けの少数長帯と実測偏差を優先し、厳密な大域誤差境界は後続課題とする。<https://users.cs.cf.ac.uk/Yukun.Lai/papers/pg07.pdf>
- Piecewise developable approximationは、紙や板金向けに一般NURBS面を可展面群へ近似する製造上の動機を示す。<https://gershon.cs.technion.ac.il/papers/SrfPiecewiseDevelop.pdf>

## 結果

- 外形ガイドが直交平面上にあっても、1本以上の断面から面と板を作れる。
- 新展開方式は元CAD面、解析メッシュ、製作用部材、近似完成モデル、型紙を別データとして扱う。
- 円筒・円錐・一般developable stripの厳密な候補比較、複数CAD面をまたぐ自動統合、偏差ヒートマップは後続実装とする。
