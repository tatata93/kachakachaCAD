# ADR 0030: 元の面に沿う製作近似と日常設定

2026-10-11、オーナー指示による変更。状態: 実装中。

## 決定

近似の主設定は枚数（0は誤差から自動）、許容誤差、分割方向、間隔の自動調整とする。
方式、候補比較、手動境界、最小幅、枚数上限、材料・範囲などは折り畳んだ詳細に置く。
方式を知らなくても通常の帯近似を開始できる。条件の変更は下見へ反映する。

GPT版製作近似の新規作成入口は削除する。既存method=2ファイルの再読込・生成互換は
残す。GPT版面作製は別機能であり、この削除の対象ではない。

近似と生成は元の面と同じ範囲だけを使う。元の曲面を評価できる環境では粗い表示用
格子から外形を再構成せず、カーネルの元の面を直接評価する。近似の誤差を粗い格子
との誤差で過小表示しない。トリムや開口を黙って矩形へ置換することは禁止する。

生成した帯の面は下見のレールと同じ点対応を使う。ルールド面作製時の自動的な
断面・頂点対応変更で短辺や外周を横切らない。誤差は測定標本値であり全域保証とは呼ばない。

## 受入試験

- HP-AP-OUTLINE: 実データの面を対象に方向・枚数・自動間隔を変え、下見・確定・
  面とワイヤーの生成・保存再読込を確認。元の面とのずれを数値で報告し画像を保存する。
- HP-AP-QUICK: 枚数・誤差・方向・自動間隔が通常表示、方式は折り畳み、設定変更と
  取消からの復帰が可能。GPT近似の新規入口が上部バー・メニュー・検索に存在しない。
- コア: 平面、円筒、円錐、ドーム、局所急曲率、反転・交換したUV、手動境界、角、
  最小幅と上限の競合、退化を検査。等間隔と自動間隔を比較する。
- カーネル: 対応点を維持するルールド面と生成ワイヤーの境界一致、交差しない短辺、
  曲げ0/途中/100%、再読込を検査する。

見た目だけの推定画像は試験証拠に使わない。元のユーザーファイルは変更しない。

曲線に沿う評価点も全レールで共通の不等間隔とする。急な曲がりでは細分化し、通常96区間から最大2048区間まで評価する。レール側の標本誤差には許容誤差の1%を割り当て、幅方向の推定偏差に測定した標本誤差を加算して表示する。上限まで細分化しても誤差内にできなければ拒否する。帯の枚数とは別の表示・生成曲線の標本であり、部材の枚数は増やさない。
