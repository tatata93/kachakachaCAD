# 立方体(20mm角)を作る ── 2通り

同じ立方体を、**作り方の違う2つの道** で作ります。
違いは「辺(ワイヤ)がどこから来るか」です。

| | 方法A かごから | 方法B 押し出し |
| --- | --- | --- |
| 辺の12本 | **自分で引く** | **押し出しが作る**(チェックを入れたとき) |
| 打つ数 | 12本 × 6個 = 72個 | 幅・高さ・距離の3個 |
| 向いている場面 | 辺の位置が先に決まっている(図面から起こす) | 断面が決まっている(普通はこちら) |
| 立体の作り方 | `part.from_wire_cage` | `part.extrude` |

**普通は方法Bです。** 方法Aは、辺の座標が先に分かっているときの道です。

---

## 方法B ── 正面に正方形を書いて押し出す(おすすめ)

### 1. 作図面を決める

上の帯の **「作図面」** コンボで **`front_XZ`**(正面)を選びます。
画面に薄い四角で出ている面のうち、**青緑になったもの** が作業中の面です。

> 上面 `top_XY` でも構いません。押し出しは **その面に垂直** に出ます。

### 2. 正方形を引く

1. 道具を **「矩形」**
2. 3D 画面で1回押す → カーソルの脇に **幅 / 高さ** の欄が出ます
3. 幅 `20`、高さ `20` と打って `Enter`

### 3. 押し出す距離を決める

右の棚を **「部品」** にして、**押し出しの距離** に `20` と打ちます。
(「数」の棚の「押し出しの距離」と同じ値です。どちらで打っても構いません。)

### 4. 押し出す

1. モードを **「部品」** に
2. 3D 画面か左の一覧で、いま引いた正方形を選びます
3. 右の棚の **「押し出し」**(上の帯にも同じものがあります)
4. 窓が出たら:

| 欄 | 選ぶもの | なぜ |
| --- | --- | --- |
| 押す向き | **作業平面に垂直** | 正面に引いた四角が、奥へまっすぐ出ます |
| 逆向きにする | 外す | 手前に出したいときだけ入れます |
| どこまで | **距離** | |
| 距離 | `20` | 20mm角なので |
| **部品(立体)を作る** | **✓** | これが立方体 |
| **押し出し先の輪郭を作る** | **✓** | **反対側の正方形**(4辺)が残ります |
| **側面の境界を作る** | **✓** | **縦の4本** が残ります |
| 部品どうしの演算 | **新しい部品** | 既にある部品に足し引きしないので |

5. **OK**

**この3つのチェックが「ワイヤ付きソリッド」の正体です。**
既定では下2つは **外れています**。外したまま押すと、立体はできますが
辺は文書に残らず、最初に引いた正方形の4辺だけが残ります。

帯にこう出ます:

```
押し出し: 厚み 20 mm の部品を 1 個、ワイヤーを 5 本作りました(体積 8000 mm3)。
```

> ワイヤー **5本** は「反対側の輪郭1本(4辺が1本にまとまっている)+ 縦4本」です。
> 最初に引いた正方形と合わせて、辺は 4 + 4 + 4 = **12辺** そろいます。
> 体積 `8000 mm3` = 20 × 20 × 20。ここが合っていなければ、距離か辺の長さが違います。

立方体が灰色に塗られて画面に出ます。塗ったところを押せば選べます。

## 方法A ── 12本の辺を引いて、かごから作る

### 1. 辺を12本、数値で引く

作図モードで、右の棚を **「作図」** にします。
下のほうに **「数値で線を作る」** があります。

1. **種類** を **「3D 直線」** にします

   > これが肝心です。「平面上の直線」だと、いまの作図面の上にしか引けません。
   > **「3D 直線」なら、作図面に関係なく x, y, z をそのまま打てます。**
   > 立方体の12辺は3つの向きを向いているので、これでないと面を4枚作る羽目になります。

2. **点1** と **点2** に下の表の値を打って、**「線を作る」** を押します
3. これを **12回** 繰り返します

| # | 点1 (x, y, z) | 点2 (x, y, z) | |
| --- | --- | --- | --- |
| 1 | 0, 0, 0 | 20, 0, 0 | 下面 |
| 2 | 20, 0, 0 | 20, 20, 0 | 下面 |
| 3 | 20, 20, 0 | 0, 20, 0 | 下面 |
| 4 | 0, 20, 0 | 0, 0, 0 | 下面 |
| 5 | 0, 0, 20 | 20, 0, 20 | 上面 |
| 6 | 20, 0, 20 | 20, 20, 20 | 上面 |
| 7 | 20, 20, 20 | 0, 20, 20 | 上面 |
| 8 | 0, 20, 20 | 0, 0, 20 | 上面 |
| 9 | 0, 0, 0 | 0, 0, 20 | 縦 |
| 10 | 20, 0, 0 | 20, 0, 20 | 縦 |
| 11 | 20, 20, 0 | 20, 20, 20 | 縦 |
| 12 | 0, 20, 0 | 0, 20, 20 | 縦 |

> **端の座標をぴったり合わせてください。** 0.001mm ずれていると、
> かごが閉じず `GEO-S003 端がつながっていない線があります。` で断られます。
> 表を上から順に打てば、必ず合います。

### 2. 12本を全部選ぶ

左の一覧の **絞り込み欄** に `数値の線` と打つと、引いた12本だけが残ります。
いちばん上を押し、いちばん下を `Shift` を押しながら押すと、12本がまとめて選べます。

> 左で選んだものは 3D 画面でも選ばれます。**12本が全部光っていること** を見てください。

### 3. かごから部品を作る

1. モードを **「部品」** に
2. 右の棚の **「ワイヤー群から部品」**

帯にこう出ます:

```
ワイヤー群から部品: 1個の部品を作りました。
```

立方体が出ます。**辺は自分で引いた12本がそのまま残っています。**

---

## どちらでも同じか

**出来る立体は同じです。** 違うのは、あとから直すときの効きかたです。

- **方法B**: 元の正方形を「数値で編集」で 25mm に直すと、**立方体も作り直されます**。
  押し出しは「この輪郭を、この距離だけ出す」という作り方を覚えているからです。
- **方法A**: 辺を1本直しても、立体は作り直されません。
  かごは「この12本から作った」ことを覚えていますが、
  1本だけ動かすと **かごが閉じなくなる** ので、12本を全部直すことになります。

**だから普通は方法Bです。** 方法Aは、辺の位置が図面で先に決まっていて、
それをそのまま入れたいときの道です。

## 断られたら

| 出た理由 | 意味 | 直しかた |
| --- | --- | --- |
| `閉じた輪郭を1つ以上選んでください。` | 押し出しの相手が閉じていない | 矩形で引き直す。線4本なら「結合」でつなぐ |
| `EXT-006 距離が0なので、部品は作れません。` | 距離が 0 | 「部品」の棚の押し出しの距離を打つ |
| `GEO-S003 端がつながっていない線があります。` | かごが閉じていない | 座標を打ち直す。1本でもずれると閉じない |
| `GEO-S005 作った立体が閉じていません。` | 面が張れない組み合わせ | 辺が足りないか、重なっている |
| `ワイヤー群から部品: 閉じたかごになる線を3本以上選んでください。` | 選択が2本以下 | 12本すべて選ぶ |

**押せない(灰色の)ボタンは、カーソルを置くと何を選べばよいか出ます。**
