選択にズーム

具体例: 小さなライトに拡大する

準備

大きな板と半径2mmの円を用意する

操作手順

  1. 円だけを選ぶ
  2. 選択にズームを押す

設定: 選択した要素を中心に表示

結果を確認

円が見やすい大きさになり、モデル座標は変化しない。

取消・やり直し

ダイアログの取消、またはペインの取消を使います。即時操作には未確定段階がありません。 確定済みの文書変更はCtrl+Z、やり直しはCtrl+Yです。保存・書出し済みのファイルはUndoの対象ではありません。

進めない場合

対象を選んでください。

対象欄と3Dの強調を照合し、必要な線・面・部品を各役割へ指定します。処理中は計算表示を確認し、取消が可能な処理は取消を使います。

Windows版の操作画面

view.fit_selection。図の設定と縮尺は例です。方式ごとの制限、プレビューと確定済み結果の区別を確認してください。
