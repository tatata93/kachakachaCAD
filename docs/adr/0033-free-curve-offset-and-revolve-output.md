# ADR 0033: 曲線オフセットの誤差管理と回転面の生成物

状態: 採用（2026-11-19、オーナーの機能追加指示）。

## 決定

一般のベジェ・Bスプラインの等距離曲線は同じ次数で厳密には表せない。従来の未対応拒否を、誤差を明示して検査する曲線近似へ拡張する。折れ線を正本にせず、既存の3次Bスプライン型で各滑らかな入力曲線を保持する。直線・円・円弧の従来の解析的オフセットと符号規則は保持する。

指定平面内の法線方向の等距離曲線を求め、文書のmodelLinearMm以内で近似する。下見で偏差上限と標本RMSを表示し、満たせない場合は確定しない。元の曲線、面、ID、表示を変更しない。近似用の計算分割を選択対象の細かなワイヤーへ変換しない。平面外の線を黙って平面化しない。

接続した開いた鎖と閉じた輪は接続を保つ。滑らかな接続は同じ端点にし、角は曲線の交点または外側の接線延長によるマイターでつなぐ。実際の角の接続線と曲線の細分化は区別する。元から離れた入力を勝手に接続せず、縮退、向きの反転、自己交差、誤差超過は理由を示して全体を拒否する。既存の公開signatureと保存形式は変更しない。

回転面では生成物を「面のみ／ワイヤのみ／面＋ワイヤ」から選ぶ。既定は面のみとし、従来の操作を保持する。ワイヤーには形状線の端が描く円・円弧と回転後の形状線を使う。一周では反対側（180度）の形状線を使い、元と同じ位置の線を重複生成しない。軸上の端に半径ゼロの円を作らない。曲線は線種を保持する。

ワイヤのみでは文書へ面や隠れた面を追加しない。面＋ワイヤは同じ確定にまとめ、Undo/Redoを各1回で行う。元の入力は保持し、生成したワイヤーは独立して編集できるものとする。下見、選択、取消、保存再読込を生成物の各方式で試験する。

## 所有と検証

WP-04のオフセット計算とコア回帰を先に行い、重点検証後にWP-08の既存UI接続と実操作回帰へ所有を移す。新しい公開幾何型や保存enumは追加しない。ベジェ、Bスプライン、直線混成、開閉、逆順、傾いた平面、内外、複数輪、共有ER1、誤差と無効入力を検査する。全体ゲートと配布版検証を通して公開する。
