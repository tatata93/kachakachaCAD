- 下部右・左：各7Wire、1面、未使用4区間を明示。
- 中央断面を含む上部：7Wire、2面。
- 丸窓：逆方向の区間を含む1Wire、1面。
- 上部の別の選択：8Wire、3面。

各ケースで実アプリのプレビュー・確定画像と別名kcd2を出力。下部右・上部中央は張り方3種類の切替も検査。元Wire数、Undo/Redo、保存再読込時の再生成を検査する。

## 限界

全形状の保証ではない。代替ネットワークは24区間まで。G0の境界適合は隣接面のG1/G2や内部の曲率品質を保証しない。境界と中央線だけからユーザー意図の面が一意に決まるとは限らず、張り方を実形状下見で比較する。閉立体ケージの全フェイス復元は対象外。

Windows offscreen自動試験の範囲。手動操作・Linux/cloudは未実施。最終ゲートの結果はTASK_LEDGERに記録する。
