選択を隠す

具体例: 屋根だけを隠して車体を見る

準備

面または立体を2つ用意する

操作手順

  1. 隠したい屋根を選ぶ
  2. 選択を隠すを押す

設定: 選択対象だけ

結果を確認

形状は削除されず、屋根だけが非表示になる。

取消・やり直し

ダイアログの取消、またはペインの取消を使います。即時操作には未確定段階がありません。 確定済みの文書変更はCtrl+Z、やり直しはCtrl+Yです。保存・書出し済みのファイルはUndoの対象ではありません。

進めない場合

線・部品・面のどれかを選んでください。

対象欄と3Dの強調を照合し、必要な線・面・部品を各役割へ指定します。処理中は計算表示を確認し、取消が可能な処理は取消を使います。

Windows版の操作画面

view.hide_selected。図の設定と縮尺は例です。方式ごとの制限、プレビューと確定済み結果の区別を確認してください。
