# ADR 0023: ビューナビゲータの再設計

## 状態

採用(2026-09-03)。実装済み。docs/view-navigator-survey.md(調査と他CAD比較)に基づき、
オーナーのスケッチ指示(ホームボタン追加/モデルに追従する回転矢印/画面固定の回転矢印)で確定。

## 決定

常設23ターゲットのボタン群を、「キューブ+追従リング+固定矢印+ホーム」の1系統に統合する。

1. **回転リング(視点に追従)**: モデルのX/Y/Z軸まわりの回転は、キューブと同じ投影で
   描く3本の色付きリング(X赤/Y緑/Z青、両端に逆向きの矢じり)。クリックした矢じり側へ
   15°(Shiftで5°)回る。リングは視点に追従して傾くので「どの軸で回るか」が見た目で分かる。
   旧「絶対」パネル(6ボタン)の置き換え。
2. **画面基準の回転矢印(位置固定)**: 下=左右回し、右=上下回し、上=ロール2ボタン。
   位置も向きも変わらない。旧「相対」パネル(6ボタン)+オービット`<` `>`の置き換え。
   ※オーナーの用語では、追従リングが「相対回転」、固定矢印が「絶対回転」。
   実装の関数名(WorldAxis=リング、RelativeAxis=固定矢印)と呼び方が逆なので注意。
3. **ホームボタン**: 家アイコンをナビゲータ左上に常設(等角ビューへ復帰)。旧「3D」ダイヤ廃止。
4. **キューブの26領域化**: 面6+辺12+角8。辺は投影した辺の中点がヒット領域で、
   ホバーで辺そのものが光る。角のダイヤは10px→14px。
5. **正対を行き止まりにしない**: 面に正対中のみ、隣の面へ90°回る三角矢印を四方に表示。
6. **アップ方向の保存**: 面クリックの正対は、面に垂直な4方向のうち現在のアップに
   最も近いものを選ぶ(上面図にしても「どちらが前か」が直前ビューと連続する)。
7. **遷移アニメーション**: 面・辺・角・隣接面・ホームのビュー変更は約180msの
   クォータニオン補間(smoothstep)。手動操作(ドラッグ・回転ボタン)は即時で、
   アニメーション中でも常に勝つ(StopViewAnimation)。
8. **不感帯の解消**: クリック判定とドラッグ開始閾値を3pxに統一
   (旧: クリック≤1.5px・ドラッグ>2.0pxで、1.5〜2pxが無反応だった)。
9. **非アクティブ時は半透明(55%)**: カーソルがナビゲータ近傍にあるときだけ全表示。
10. 面ラベル「正」→「前」。占有幅 260px→176px。

## 実装

`CadViewport.cpp` のみ(ViewCubeGeometry/HitViewCube/描画/マウス処理、
クォータニオン補間ヘルパー、`SetDirectionView`/`AnimateViewTo`/`StopViewAnimation`)。
`SetIsometricView`/`SetCornerView` は即時のまま残す(セルフテストが使用)。

Autodesk の ViewCube 特許(US7782319ほか)に配慮し、見た目・構成は独自
(リング+固定矢印の2系統、平行投影の平面描画)とし、機能面の慣行
(26領域・正対時の隣接矢印・アップ保存・アニメーション)だけを揃えた。

## 検証方法

linux-core → Windows 実機ビルド → 17テスト → 起動 → スクリーンショットで
リング・固定矢印・ホーム・辺マーカーの表示を確認。
