# 押し出しの入力と候補表示（2026-10-15）

WP-08内の操作改善。幾何API・保存形式は変更しない。

- ツール開始時から面／輪郭の選択、方向、距離、範囲を表示する。入力前に設定した値を対象選択後も維持する。
- 押す面／輪郭と加工先の立体を区別して表示する。未選択でも選択ボタンを押せる。
- 「選んだ線の向き」には3Dビューの直線を拾う専用ボタンを付ける。方向線を輪郭へ混ぜず、元面を保持する。再選択・取消・他ツールへの移行でも入力を混同しない。
- 押し出し中はクリック候補の面をHover色で塗る。同一部品の他の面や非表示の形状を強調しない。Tab候補送りとクリック対象を一致させ、CPU/GPU両描画へ反映する。
- 無効な方向、入力不足、失敗時は確定を許可しない。事前選択、面押し引き、輪郭領域、Undoを退行させない。

受入: 選択前の小数距離・方向設定、方向線→面／面→方向線、方向線の選び直し、空振り、取消、面ホバーの移動と解除、実形状の押し出しをGUI試験する。
