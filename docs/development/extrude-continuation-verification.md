# 押し出し後の入力継続と矩形選択の残留

押し出し確定後、通常輪郭・終端指定・ネイティブ面・複数平面の経路で道具の入力待ち状態を解除していた。さらに、クリック時のプレビュー計算がマウス解放を受け取れない場合、矩形選択の構えが残り、ボタンを押していない移動でも範囲が伸びた。

文書の確定と再構築の後で押し出し入力待ちへ戻し、次の輪郭をそのまま選べるようにした。確定・取消では残った矩形を解除し、マウス移動時にも左ボタンが離れていれば残留状態を解除する。左ボタンを押している通常の範囲選択は維持する。元データ・幾何計算は変更しない。

回帰試験は「HP-EX-REPEAT commit and lost mouse release」。ツール起動1回で2個の押し出しを確定、確定中の矩形状態の除去、マウス解放イベント欠落、押下中の矩形、Escによるツール維持、明示的な選択ツールへの切替を検証する。既存のネイティブフェイス・終端指定試験にも確定後の入力継続の検査を追加した。

重点UI91件では新規の再現試験を含む90件が成功。旧仕様の「確定後に棚が閉じる」を要求した1件を、オーナー指示に合わせて「棚を維持して次の入力を待つ」検査へ更新した。更新した1件と新規再現試験の2件を再実行して成功。幾何・出力・Undoに関する既存の検査は削除していない。

証拠は `out/role-ui-check-20261015-192800`（旧期待値による失敗を保持）、`out/role-ui-check-20261015-193326`（修正後2件成功）。短い構造チェックで不足していた試験用のQEventヘッダーも補い、再検査に成功した。
