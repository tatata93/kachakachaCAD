面を作る

具体例: 2つの円をつないだロフト面を作る

準備

Z=0とZ=10に半径5mmの円を描く

操作手順

  1. 面作成のロフト面を選ぶ
  2. 断面欄へ下・上の順で円を追加する
  3. 下見を確認して確定する

設定: 閉断面2本。境界面では入力の役割が異なる

結果を確認

2つの円をつなぐ側面ができる。ソリッドが必要ならロフト立体を使う。

取消・やり直し

ダイアログの取消、またはペインの取消を使います。即時操作には未確定段階がありません。 確定済みの文書変更はCtrl+Z、やり直しはCtrl+Yです。保存・書出し済みのファイルはUndoの対象ではありません。

進めない場合

線を1つ以上、または形状ガイドの面を選んでください。

対象欄と3Dの強調を照合し、必要な線・面・部品を各役割へ指定します。処理中は計算表示を確認し、取消が可能な処理は取消を使います。

平面

準備: 同一平面内の閉じた矩形

  1. 平面を選ぶ
  2. 境界を追加
  3. 下見
  4. Enter

確認: 矩形の内部に平面

2本を直線でつなぐ

準備: 離れた2本の曲線

  1. 両曲線を追加
  2. 向きを確認
  3. Enter

確認: 対応点間を直線で結ぶ面

ロフト面

準備: 高さ0/10mmの2円

  1. 断面欄に下・上の順
  2. 下見
  3. Enter

確認: 断面間をつなぐ側面

境界面

準備: 接続した4辺

  1. 境界欄へ追加
  2. 通る線があれば別欄へ
  3. 下見
  4. Enter

確認: 境界を保持する面

四辺面

準備: 順につながる4つの辺

  1. 境界を周回順に追加
  2. 下見
  3. Enter

確認: 4辺間の面

曲線網

準備: 交差する縦2本・横2本以上

  1. 縦と横を別欄へ追加
  2. 全交差確認
  3. 下見
  4. Enter

確認: 曲線網に沿う面

オフセット面

準備: 作成済みの面

  1. オフセット面を選ぶ
  2. 元面
  3. 距離1mm
  4. 下見
  5. Enter

確認: 元面から離れた面

回転面

準備: 弧と回転軸

  1. 回転面を選ぶ
  2. 断面・軸
  3. 角度180度
  4. 下見
  5. Enter

確認: 軸回りの面

厳密曲線網

準備: 全て交差する縦横の曲線

  1. 厳密曲線網
  2. 縦横を別欄へ
  3. 検査
  4. Enter

確認: 成立条件を満たす曲線網を通る面

ガイド付きロフト（互換）

準備: 2断面と両断面に交差するガイド

  1. 断面・ガイドを別欄へ
  2. 検査
  3. Enter

確認: ガイドに沿うロフト面
