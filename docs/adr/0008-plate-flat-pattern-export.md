# ADR 0008: 板材の展開図は元面から導出し誤差を明示する

## 状態

採用

## 決定

- 板材の3D形状は従来どおり面と板厚で保持し、展開計算用の三角形は保存・表示・編集しない。
- 切断長の基準は現段階では板厚中央とする。これは中立軸係数 `K=0.5` に相当する。
- 平面板は元面の閉じた境界を作業平面へ写し、分割範囲がある場合はその範囲で輪郭を切り取る。
- 曲面板は板厚中央を規則格子で標本化し、隣接する三角形の辺長を保ちながら平面へ順次開く。
- 分割板材は元面の `U/V` 範囲だけを展開する。
- 曲面上の開口は、保存済みの元平面図・投影先面・投影方向から面パラメータを再計算し、展開後の同じ位置へ写す。
- SVGとDXFはmm単位の1:1とし、外周を `CUT_OUTER`、開口を `CUT_OPENING` へ分ける。
- 展開格子の辺長不一致と境界標本化の差を最大推定ずれとして表示する。
- 二方向曲面、または最大推定ずれが0.10 mmを超える板材は、近似図の保存前にユーザー確認を必須にする。

## 理由

ユーザーが編集する面を三角形へ置き換えると、断面、投影、板厚、分割の関係が失われる。一方、切断図を作る瞬間だけ面を細分化すれば、元の設計関係を保ったままルールド面やロフト面を平面へ近似できる。

二方向曲面は伸縮なしでは平面にならない。見た目だけ整った図を正確な展開図として出すと工作時の寸法不良につながるため、分類と数値の両方を画面へ出し、危険な出力は明示確認する。

## 制限

- 材料、曲げ半径、加熱成形方法に応じた中立軸係数は未指定で、現在は板厚中央に固定する。
- 二方向曲面の近似図は成形型や分割位置を検討するための参考であり、無歪みの展開図ではない。
- 任意曲線による板材分割、のりしろ、曲げ線、部品の自動配置、PDF出力は今後の対象とする。
