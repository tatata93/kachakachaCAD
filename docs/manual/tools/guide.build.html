表から面を作る

具体例: 役割表から面を生成する

準備

2断面以上を順番に役割表へ入れる

操作手順

  1. 役割と向き、順序を確認する
  2. 表から面を作るを実行する
  3. 失敗した場合は診断を修正して再実行する

設定: 実行時に検査して面を追加する

結果を確認

表の条件から面ができる。生成後の取り消しはUndoを使う。

取消・やり直し

ダイアログの取消、またはペインの取消を使います。即時操作には未確定段階がありません。 確定済みの文書変更はCtrl+Z、やり直しはCtrl+Yです。保存・書出し済みのファイルはUndoの対象ではありません。

進めない場合

役割表に行を1つ以上入れてください。

対象欄と3Dの強調を照合し、必要な線・面・部品を各役割へ指定します。処理中は計算表示を確認し、取消が可能な処理は取消を使います。
