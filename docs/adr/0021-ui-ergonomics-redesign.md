# ADR 0021: エルゴノミクスに基づくUI再設計(現状批判と新方針)

## 状態

採用(2026-09-03)。段階A実装済み。ADR 0020(段階的移行の枠組み)を引き継ぎ、
実機スクリーンショットに基づく批判的分析で内容を確定した。

## 1. 現状UIの批判的分析(2026-09-03 実機画面より)

起動直後の画面(タブ統合後)を対象に分析した。

1. **ナビゲーションが三重**。上部ツールバー(3本)、右パネルのワークフローボタン
   (1平面/2作図/3面・板/4出力)、7枚のタブ。同じ目的地への入口が3系統あり、
   どれが正かユーザーには判別できない。学習コストがそのまま3倍になる。
2. **作図ツールの完全な二重化**。上部ツールバーの 直線/ポリライン/矩形/円/円弧/ベジェ/
   スプライン と、スケッチタブの巨大な2列ボタングリッド(9個、パネル高の約4割)が
   同一のQActionを指す。機能ゼロ増で画面と注意を消費する最悪の冗長。
3. **設定と操作の混在**。スナップ間隔・点グリッド(副点分割・基準X/Y・原点移動)という
   「たまにしか触らない設定」が、毎回使う作図動線の一等地に常設。
   Progressive disclosure(必要になるまで隠す)の逆を行っている。
4. **モードの可視性不足**。いま何面に描いているのか(作図面)が右パネル奥のコンボで
   しか分からない。SolidWorksのスケッチ確認コーナー、Fusionのツールバー切替に相当する
   「モードの常時表示」が無い。
5. **Fitts's law違反**。使用頻度最高の操作(ツール切替・トリム・面取り)が
   カーソル位置(ビューポート)から最も遠い右端の縦パネルにある。
   ポインタ移動距離ゼロの右クリックメニューが無い。
6. **上部ツールバーの未分節**。ファイル/履歴/表示モード/選択操作/作図/変形が
   一続きで、グレーアウトの理由(平面未選択なのか、モード違いなのか)が読めない。
7. **常設の操作ガイド**が左下の一等地を専有し、熟練後は畳めない。
8. 出力タブの旧ペーパークラフト長大フォーム(前段で既定折りたたみ済み、撤去は今後)。

## 2. 市販ソフト・エルゴノミクスの分析

- **Fitts's law**: 到達時間は距離に比例・対象サイズに反比例。→ 高頻度操作は
  カーソル近傍(右クリック)か大きな固定ターゲット(画面端のツールバー)へ。
- **Hick's law**: 選択肢数が増えるほど選択は遅い。→ モードに関係するコマンドだけ見せる。
- **Progressive disclosure**: 高度な設定は実行時にだけ出す。Fusion 360のコマンドダイアログ、
  SolidWorksのPropertyManagerは「コマンド実行中のみ」現れて消える。
- **モードの可視化と脱出**: SolidWorksは確認コーナー、Fusionはスケッチ専用ツールバーへの
  切替で「今スケッチ中」を常時明示し、終了操作が常に同じ場所にある。
- **JWCAD**: クロックメニュー(ポインタ位置でコマンド発動=移動距離ゼロ)と
  上部コントロールバー(数値はその場で入力)。作図系ソフトで右手がほぼ動かない好例。
- 共通の空間文法: **上=コマンド(モード連動) / 左=ブラウザ / 中央=キャンバス /
  右or浮動=実行中コマンドのパラメータのみ / 下=ステータス・入力**。

## 3. 新デザインの決定

目標の空間文法を上記「共通の空間文法」に一致させる。

1. **コマンドは上へ、パラメータは右へ、設定は表示タブへ。**
   右パネルからコマンド起動ボタンを撤去していき、右パネルは
   「実行中コマンドのパラメータ+選択オブジェクトのプロパティ+ワークフロー固有ビュー(部材など)」へ純化する。
2. **作図面はツールバーの常設要素**(モードの可視化)。スナップトグルも同居。
3. **右クリックメニュー(選択ツール中)**: 選択内容に応じたコマンド
   (2線→交点に点/面取り対象化、2点→線で結ぶ、板材→部材近似へ)+作図/編集ツールの
   クイック切替+表示操作。作図ツール中の右クリックは従来の「近傍スナップから引き始める」を維持。
4. **ガイド・補助UIは折りたたみ可能**(初心者には開いた状態で提供)。
5. 将来(段階C): コマンド実行中のみ出るパラメータパネル、平行・直交・中点の推測スナップ、
   コマンド検索(Ctrl+K)、確認コーナー(ビューポート右上の完了/取消)。

## 4. 段階A(2026-09-03 実装)

- スケッチタブの**ツールボタングリッドを撤去**(上部ツールバーへ一本化)。
  ツールバーに 作図点 を追加し、全作図ツールが上段で完結。
- **作図面コンボ+正対+スナップを上部「平面作図」ツールバー先頭へ移設**。
- **スナップ間隔・点グリッド設定を表示タブ**(背景・点グリッドの隣)へ移動。
  スケッチタブは 作図状態・補助線・実寸確定・完了/取消 だけの薄いパネルになる。
- **ビューポート右クリックメニュー**(選択ツール中のみ、右ドラッグ回転とは非干渉)。
- **操作ガイドを折りたたみ可能**に(既定は展開)。
