局所表示を解除

具体例: 局所表示から元の表示へ戻る

準備

ライトだけを局所表示する

操作手順

  1. 局所表示を解除を押す

設定: 元から非表示の要素は非表示のまま

結果を確認

局所表示の前に見えていた要素を再表示する。

取消・やり直し

ダイアログの取消、またはペインの取消を使います。即時操作には未確定段階がありません。 確定済みの文書変更はCtrl+Z、やり直しはCtrl+Yです。保存・書出し済みのファイルはUndoの対象ではありません。

進めない場合

元の表示に戻します。文書の非表示設定は変更しません。

対象欄と3Dの強調を照合し、必要な線・面・部品を各役割へ指定します。処理中は計算表示を確認し、取消が可能な処理は取消を使います。

Windows版の操作画面

view.restore_isolation。図の設定と縮尺は例です。方式ごとの制限、プレビューと確定済み結果の区別を確認してください。
