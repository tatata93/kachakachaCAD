# 近似モデルからの独立生成（2026-09-30）

オーナー依頼: 近似の確定時にもワイヤのみ／ワイヤ＋近似面を生成し、後から選択部材の任意の
曲げ状態を同一文書または別のkcd2へ生成できるようにする。新命令ではなく既存の生成を拡張する。

- 確定時の独立生成は「生成しない／ワイヤのみ／ワイヤ＋近似面」で選ぶ。既存操作は生成しないを維持。
- 現在状態の生成は、各部材の曲げ率を含む現在の評価形状を使う。近似モデルを変更しない。
- 対象部材の番号が空なら全体、指定があればその部材だけ。読めない番号・範囲外を黙って無視しない。
- ワイヤは長辺だけでなく短辺も含めて閉じる。ワイヤ＋近似面では同じ輪郭から面を作り保存・再読込可能にする。
- 生成先は同じ文書／別のkcd2。別ファイルは生成物と必要な定義だけを保存し、元文書や保存先を切り替えない。
- 元文書への生成は一回のUndoで戻せる。保存取消・生成失敗で中途半端な生成物を残さない。
- 面は厚みのない近似面（形状ガイド）。厚み付き部品の既存指定とは分ける。近似であることを明記。

受入: 短辺と閉じた輪郭、部材指定、0/任意/100%の形状、面の再読込、別ファイルの独立性、
保存取消、番号不正、近似確定時の自動生成。従来帯近似とGPT版を確認する。
