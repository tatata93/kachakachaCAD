# 投影入力の識別と実モデルの窓投影

状態: 進行中（2026-10-14）。WP-08の投影ツール改善。

オーナー指定のモデルで窓をソリッドのフェイスへ投影し、原本を変更せず別ファイルへ保存する。
不足する輪郭は補助ワイヤーとして追加できる。投影曲線から閉領域を作る場合も支持面の曲率を維持する。

- 投影元は紫・「元」、投影先は緑・「先」、未確定結果は既存のPreview色と破線。
  右ペインの凡例、3Dラベル、左ペインの行に同じ役割を示す。色だけに依存しない。
- 元ワイヤー／投影先ボタンは排他的な押下表示と件数を持ち、現在の選択段階を明示する。
  3Dまたは左ペインから現在の役割へ対象を追加できる。設定値と複数入力を維持する。
- ソリッドは指定フェイスだけを着色する。左ペインには部品名と選択フェイス番号を示す。
  左ペインでソリッド全体を選んだ場合は、3Dで投影先フェイスを選ぶよう案内する。
- 入力追加・解除、Esc、別ツールへの切替、文書切替で一時表示を更新・解除する。
  表示名、色、可視性、カテゴリの展開状態を文書へ書き込まない。
- 高速描画とCPU描画で同じフェイス識別を行い、編集用のネイティブ形状を変更しない。
- 方向投影では「ワイヤーのみ／面＋ワイヤー」を選べる。面の出力は閉じた平面輪郭を
  指定方向へ伸ばした領域と、明示した投影先フェイスとの共通部分をネイティブで求める。
  投影先の曲率と穴を保ち、選択面ごとの境界を出す。面の出力で手前判定を偽らず、
  明示したすべての面を対象とする旨を表示する。開いた輪郭・平行方向・非平面輪郭は理由を示して拒否する。

## 受入

ツール先行、両ペインからの入力、役割切替、複数元・先、指定フェイスだけの色、非表示保持、
カテゴリ折畳み保持、解除・Esc・ツール切替の後始末、原形状不変を自動検査する。
添付モデルで実際の窓輪郭を投影し、閉鎖性・面上偏差・保存再読込を検査し、実画面を残す。
Windows全体ゲートと配布版の起動検査を通すまで完了とはしない。
