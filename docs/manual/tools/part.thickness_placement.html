厚みの付け方

具体例: 厚みの配置を中央へ切り替える

準備

厚みを付ける面を用意する

操作手順

  1. 厚みの付け方を押す
  2. 状態表示を確認し、中央になるまで切り替える

設定: 外側→中央→内側の循環

結果を確認

次の厚み操作で使う配置条件が変わる。厚み数値は厚みツールで指定する。

取消・やり直し

ダイアログの取消、またはペインの取消を使います。即時操作には未確定段階がありません。 確定済みの文書変更はCtrl+Z、やり直しはCtrl+Yです。保存・書出し済みのファイルはUndoの対象ではありません。

進めない場合

面に厚みを付けるときの付け方を、外側・中央・内側の順に切り替えます。

対象欄と3Dの強調を照合し、必要な線・面・部品を各役割へ指定します。処理中は計算表示を確認し、取消が可能な処理は取消を使います。

Windows版の操作画面

part.thickness_placement。図の設定と縮尺は例です。方式ごとの制限、プレビューと確定済み結果の区別を確認してください。
